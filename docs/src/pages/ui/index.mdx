# UI

`@hellajs/ui` ships a copy-paste registry: `bunx @hellajs/ui add <name>` copies one editable file per component into your project. Every component ships in two style flavors (`css`, the default, styled with [`@hellajs/css`](/reference/css) under the `hella` cascade layer; `tailwind`, backed by `theme.css` and `cn.ts`) and two formats (`jsx` and `html`), with `hella.ui.json` remembering your defaults. The components running on these pages were installed by that same `add` command: the site vendors them into `src/components/ui/` (css flavor, html format, pure runtime, no compiler), byte-identical to what `add --format html` writes. Registry styles inject under the `hella` cascade layer, declared after the site's own layers so component rules win over the site's preflight; each page carries the full install and per-style usage from the package docs.

- [Input](/ui/input): a controlled input echoing its value, plus the invalid state.
- [Card](/ui/card): the seven-part composition - header, title, description, action, content, footer.
- [Dialog](/ui/dialog): a portal-mounted modal with wired titles, enter/exit animations, and dismissal wiring.
- [Tabs](/ui/tabs): pill and line tablists with roving tabindex and aria wiring across panels.
- [Badge](/ui/badge): six status-chip variants with anchor-aware hover styles.
- [Alert](/ui/alert): default and destructive callouts with an auto-reserved icon column.
- [Kbd](/ui/kbd): keyboard-key chips and grouped key sequences on the semantic `kbd` element.
- [Separator](/ui/separator): horizontal and vertical dividers with orientation attributes.
- [Skeleton](/ui/skeleton): pulsing placeholders composed into profile and text-line shapes.
- [Spinner](/ui/spinner): the loader-circle glyph with status semantics at three sizes.
- [Empty](/ui/empty): empty-state compositions with an icon-tile media part.
- [Label](/ui/label): form captions wired to inputs through the `for` attribute.
- [Textarea](/ui/textarea): an auto-sizing multi-line input with a live character count.
- [Native Select](/ui/native-select): real select elements with caller-authored options and a compact size.
- [Aspect Ratio](/ui/aspect-ratio): fixed-ratio media frames at 16/9, 1/1, and 4/3.
- [Avatar](/ui/avatar): portraits whose fallback returns when the image errors, plus groups and a count.
- [Progress](/ui/progress): a determinate bar you can advance and an indeterminate sweep.
- [Table](/ui/table): the seven semantic parts over a horizontally scrolling container.
- [Button Group](/ui/button-group): joined button rows and columns with text plates and separators.
- [Input Group](/ui/input-group): fake-input composites where the group owns the focus and invalid rings.
- [Field](/ui/field): ten-part form kit with disabled and invalid propagation and a responsive orientation.
- [Pagination](/ui/pagination): paged navigation links whose active state skips the router through `onclick`.
- [Item](/ui/item): list rows with media, actions, and reactive selection state.
- [Marker](/ui/marker): labeled divider strips with rule and border variants.
- [Direction](/ui/direction): a layout-neutral `dir` wrapper that right-to-left behaviors read.
- [Bubble](/ui/bubble): chat bubbles in seven variants with floating reaction chips.
- [Message](/ui/message): chat rows whose avatar, content, and meta parts coordinate through data attributes.
- [Message Scroller](/ui/message-scroller): an auto-sticking chat viewport with a jump-to-end button.
- [Attachment](/ui/attachment): upload chips whose spinner and error glyphs follow one `state` prop.
- [Collapsible](/ui/collapsible): a disclosure trigger and region whose open state lives in a signal.
- [Accordion](/ui/accordion): single and multiple stacked items with grid-animated content regions.
- [Checkbox](/ui/checkbox): a checked-state button carrying the check icon and an indeterminate state.
- [Radio Group](/ui/radio-group): one labeled row per entry with arrow-key focus movement.
- [Switch](/ui/switch): an on/off button whose thumb slides through pure CSS.
- [Toggle](/ui/toggle): a pressed-state button with the full variant and size maps.
- [Toggle Group](/ui/toggle-group): pressed-state buttons in single or multiple mode with roving arrows.
- [Slider](/ui/slider): a pointer and keyboard value control with one thumb per value.
- [Resizable](/ui/resizable): flex panels with drag handles that move the boundary between neighbors.
- [Tooltip](/ui/tooltip): a hover-delayed label, portaled and anchored, with collision flipping.
- [Hover Card](/ui/hover-card): a rich preview panel that stays open while the pointer remains inside it.
- [Popover](/ui/popover): a click-toggled anchored panel with Escape, outside-press, and stacked-layer dismissal.
- [Dropdown Menu](/ui/dropdown-menu): a button-triggered item menu with checkbox and radio items and submenus.
- [Context Menu](/ui/context-menu): the same item menu opened by a right-click at the pointer coordinates.
- [Menubar](/ui/menubar): a horizontal bar holding one open menu at a time with full arrow wiring.
- [Navigation Menu](/ui/navigation-menu): triggers opening content panels into a shared viewport under a sliding indicator.
- [Breadcrumb](/ui/breadcrumb): a navigation trail with separators, collapsed segments, and dropdown overflow.
- [Select](/ui/select): an anchored, width-matched listbox with arrow roving, typeahead, and Enter commit.
- [Combobox](/ui/combobox): a filterable listbox narrowed by a query signal, single or multiple.
- [Command](/ui/command): a command palette with ranked filtering over labels, values, and keywords.
- [Alert Dialog](/ui/alert-dialog): a modal confirmation with wired title and description and an Action/Cancel pair.
- [Sheet](/ui/sheet): a panel sliding in from any of the four screen edges with enter and exit animations.
- [Drawer](/ui/drawer): a drag-dismissable edge panel that follows the pointer and dismisses past a threshold.
- [Sonner](/ui/sonner): a toast queue with type icons, rich colors, promise loading, hover-pause, and swipe dismissal.
- [Scroll Area](/ui/scroll-area): native scrolling under custom thumbs, with a composable horizontal bar for both axes.

- [Form](/ui/form): a signals-native form controller with validators, touched and dirty tracking, and explicit-state field parts.
- [Sidebar](/ui/sidebar): the composite shell - provider-owned open and mobile state, three collapsible variants, an inline mobile sheet, and the full menu part family.
