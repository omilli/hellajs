# UI

`@hellajs/ui` ships a copy-paste registry: `npx @hellajs/ui add <name>` copies one editable file per component into your project. Every component ships in two style flavors (`css`, the default, styled with [`@hellajs/css`](/reference/css); `tailwind`, backed by `theme.css` and `cn.ts`) and two formats (`jsx` and `html`), with `hella.ui.json` remembering your defaults. The components running on these pages are the registry's own built output: the site imports the compiled css-flavor, jsx-format files that `add` copies into your project, so every demo runs exactly what you install. Registry styles register unlayered like every site sheet; their class-scoped rules outrank the element-level preflight by specificity. Install, theming, and CLI questions live in the sidebar's Config section: [Installation](/ui/installation), [Theming](/ui/theming), and [CLI](/ui/cli).
