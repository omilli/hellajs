# State

Short, copy-pasteable patterns for common state management tasks using [`store`](/reference/store/store). Each pattern is self-contained with imports.

### Store with Validation

Use middleware to trim strings and clamp numbers before storing values.

```typescript
import { store } from '@hellajs/store';

const form = store({
  name: '',
  email: '',
  age: 0,
}, {
  middleware: {
    name: (v) => v.trim(),
    email: (v) => v.toLowerCase().trim(),
    age: (v) => Math.min(150, Math.max(0, v)),
  },
});

form.name('John');  // stored as 'John'
```

### Partial Deep Updates

Update nested properties without replacing the entire object using `update()` with a partial.

```typescript
import { store } from '@hellajs/store';

const app = store({
  user: { name: 'Alice', role: 'viewer' },
  theme: 'light',
});

app.update({
  user: { name: 'Bob' },
  theme: 'dark',
});

app.user.name(); // 'Bob'
app.user.role(); // 'viewer' (unchanged)
app.theme();     // 'dark'
```

### Mutable Draft Updates

Pass a function to `update()` for ergonomic array operations and coordinated mutations.

```typescript
import { store } from '@hellajs/store';

const todos = store({
  items: [
    { id: 1, text: 'Write tests', done: false },
    { id: 2, text: 'Ship it', done: false },
  ],
  count: 2,
});

todos.update(draft => {
  draft.items.push({ id: 3, text: 'Refactor', done: false });
  draft.items = draft.items.filter(item => item.id !== 1);
  draft.count = draft.items.length;
});

todos.items(); // [{ id: 2, ... }, { id: 3, ... }]
todos.count(); // 2
```

### Readonly Properties

Lock specific keys to read-only access using the `readonly` option.

```typescript
import { store } from '@hellajs/store';

const config = store({
  apiUrl: 'https://api.example.com',
  theme: 'light',
  debug: false,
}, {
  readonly: ['apiUrl'],
});

config.theme('dark');       // Updates normally
config.apiUrl('localhost');  // No effect — readonly
config.apiUrl();            // 'https://api.example.com'
```

### Store Composition

Nest existing stores inside a parent store for hierarchical state with shared references.

```typescript
import { store } from '@hellajs/store';

const userStore = store({
  name: 'Alice',
  role: 'admin',
});

const uiStore = store({
  sidebar: true,
  theme: 'dark',
});

const appStore = store({
  user: userStore,
  ui: uiStore,
});

appStore.user.name('Bob');
userStore.name(); // 'Bob' — same signal reference

appStore.ui.theme(); // 'dark'
```

### Store Snapshot

Get a plain object snapshot of the entire store. Snapshots are reactive — use them in [`computed`](/reference/core/computed) for derived state.

```typescript
import { computed } from '@hellajs/core';
import { store } from '@hellajs/store';

const cart = store({
  items: [{ id: 1, price: 10 }, { id: 2, price: 20 }],
  discount: 0.1,
});

const total = computed(() => {
  const { items, discount } = cart.snapshot();
  const subtotal = items.reduce((sum, item) => sum + item.price, 0);
  return subtotal * (1 - discount);
});

total(); // 27
cart.discount(0.2);
total(); // 24
```
