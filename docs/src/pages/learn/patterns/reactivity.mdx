# Reactivity

Short patterns for common tasks using [`@hellajs/core`](/reference/core).

### Derived State

Chain [`computed`](/reference/core/computed) values to derive state from multiple signals.

```typescript
import { signal, computed } from '@hellajs/core';

const firstName = signal('Jane');
const lastName = signal('Doe');
const fullName = computed(() => `${firstName()} ${lastName()}`);

firstName('John');
console.log(fullName()); // "John Doe"
```

### Batched Updates

Group multiple signal updates so dependent effects run once with [`batch`](/reference/core/batch).

```typescript
import { signal, computed, effect, batch } from '@hellajs/core';

const base = signal(1);
const multiplier = signal(2);
const sum = computed(() => base() + multiplier());

effect(() => console.log(`Sum: ${sum()}`)); // Initial run logs "Sum: 3"

batch(() => {
  base(10);
  multiplier(20);
});
// Batch causes one additional run: "Sum: 30"
```

### Effect Cleanup

[`effect`](/reference/core/effect) returns a function that stops tracking. Use it for cleaning up intervals, listeners, and subscriptions.

```typescript
import { signal, effect } from '@hellajs/core';

const active = signal(true);

const cleanup = effect(() => {
  if (!active()) return;
  const id = setInterval(() => console.log('polling...'), 1000);
  // Store cleanup to run when effect re-executes or is disposed
  return () => clearInterval(id);
});

// Stop the effect entirely
cleanup();
```

### Conditional Dependencies

A [`computed`](/reference/core/computed) only tracks signals read during its last execution.

```typescript
import { signal, computed } from '@hellajs/core';

const view = signal('first');
const first = signal(1);
const second = signal(2);

const value = computed(() => view() === 'first' ? first() : second());

console.log(value()); // 1: tracks view and first
second(99); // value doesn't update: second is not a dependency
view('second');
console.log(value()); // 99: now tracks view and second instead of first
```

### Untracked Reads

Read a signal without creating a dependency using [`untracked`](/reference/core/untracked).

```typescript
import { signal, effect, untracked } from '@hellajs/core';

const data = signal('hello');
const logPrefix = signal('[app]');

effect(() => {
  // Read logPrefix without tracking it
  const prefix = untracked(() => logPrefix());
  console.log(`${prefix} ${data()}`);
});

logPrefix('[debug]'); // Effect does NOT re-run
data('world');       // Effect re-runs, uses current logPrefix
```

### Scope for Multiple Effects

[`scope`](/reference/core/scope) wraps multiple effects with a single cleanup call.

```typescript
import { signal, effect, scope } from '@hellajs/core';

const userId = signal(1);

const cleanup = scope(() => {
  effect(() => console.log(`User: ${userId()}`));
  effect(() => console.log(`Loading data for ${userId()}...`));
});

userId(2); // Both effects re-run

cleanup(); // All effects stopped
```

### Incremental Computation

[`computed`](/reference/core/computed) receives the previous value as an argument for incremental calculations.

```typescript
import { signal, computed } from '@hellajs/core';

const items = signal<number[]>([]);

const total = computed((prev = { sum: 0, count: 0 }) => {
  const current = items();
  const newItems = current.slice(prev.count);
  const newSum = newItems.reduce((s, v) => s + v, 0);
  return { sum: prev.sum + newSum, count: current.length };
});

items([10, 20]);
console.log(total()); // { sum: 30, count: 2 }

items([10, 20, 15]);
console.log(total()); // { sum: 45, count: 3 }
```

### Error Handling in Effects

Use `try/catch` inside [`effect`](/reference/core/effect) to handle errors without breaking dependency tracking.

```typescript
import { signal, effect } from '@hellajs/core';

const data = signal(10);
const shouldThrow = signal(false);
let result = 0;

effect(() => {
  const throwFlag = shouldThrow();
  const value = data();
  try {
    if (throwFlag) throw new Error('fail');
    result = value;
  } catch {
    result = -1;
  }
});

shouldThrow(true);  // result: -1
shouldThrow(false); // result: 10
data(25);           // result: 25 (tracking preserved)
```

### Error Propagation

Errors thrown in one effect abort the flush queue so remaining effects are skipped.

```typescript
import { signal, effect } from '@hellajs/core';

const threshold = signal(1);
const value = signal(2);

effect(() => {
  if (threshold() > 5) throw new Error('fail');
  console.log('threshold:', threshold());
});

effect(() => {
  console.log('value:', value());
});

value(10); // Logs: "value: 10" (effect runs normally)
threshold(10); // Throws: first effect aborts the flush, second effect never runs

// Subsequent updates start a fresh flush
threshold(1); // Both effects recover and run normally
```

### Computed Auto-GC

A [`computed`](/reference/core/computed) with no subscribers releases its dependencies. Re-subscribing rebuilds the graph.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const source = signal(1);
const doubled = computed(() => source() * 10);

const cleanup1 = effect(() => doubled());
console.log(doubled()); // 10

cleanup1(); // Computed has no subscribers: dependencies released

source(2); // doubled is not notified: no propagation

const cleanup2 = effect(() => doubled());
console.log(doubled()); // 20 (graph rebuilt, recomputed)

cleanup2();
```
