# Rendering

Short patterns for common DOM rendering tasks using [`@hellajs/dom`](/reference/dom).

### Reactive Class Names

Use `bind:class` with a ternary for state-driven styling.

```jsx
import { signal } from '@hellajs/core';
import { mount } from '@hellajs/dom';

const isActive = signal(false);
const activeClass = () => isActive() ? 'btn-active' : 'btn-inactive';

const template = <div bind:class={activeClass}>Toggle</div>;

mount(template, '#app');
```

### Conditional Class Arrays

Use arrays for composable class lists — falsy values are filtered out.

```jsx
import { signal } from '@hellajs/core';
import { mount } from '@hellajs/dom';

const status = signal('active');
const taskClasses = () => [
  'task-item',
  status() === 'active' && 'task-active',
  status() === 'done' && 'task-done',
  status() === 'error' && 'task-error'
].filter(Boolean).join(' ');

const template = <div bind:class={taskClasses}>Task</div>;

mount(template, '#app');
```

### Two-Way Input Binding

Combine `bind:value` with `on:input` for controlled inputs.

```jsx
import { signal } from '@hellajs/core';
import { mount } from '@hellajs/dom';

const name = signal('');
const onNameInput = (e) => name(e.target.value);

const template = <div>
  <input bind:value={name} on:input={onNameInput} placeholder="Enter name" />
  <p>Hello, {name}</p>
</div>;

mount(template, '#app');
```

### Conditional Rendering

Wrap conditionals in function references for reactivity.

```jsx
import { signal } from '@hellajs/core';
import { mount } from '@hellajs/dom';

const showPanel = signal(false);
const togglePanel = () => showPanel(!showPanel());
const panelContent = () => showPanel() && <div class="panel">Panel content</div>;

const template = <div>
  <button on:click={togglePanel}>Toggle Panel</button>
  {panelContent}
</div>;

mount(template, '#app');
```

### Keyed List Rendering

Use [`ForEach`](/reference/dom/foreach) for reactive lists with efficient reconciliation.

```jsx
import { signal } from '@hellajs/core';
import { mount, ForEach } from '@hellajs/dom';

const items = signal([
  { id: 1, text: 'First' },
  { id: 2, text: 'Second' }
]);
const renderItem = (item) => <li key={item.id}>{item.text}</li>;

const template = <ul>
  <ForEach each={items} use={renderItem} />
</ul>;

mount(template, '#app');
```

### Dynamic Component

A signal can hold a component, rendered with `{signal}`.

```jsx
import { signal } from '@hellajs/core';
import { mount } from '@hellajs/dom';

const HomePage = <h1>Home</h1>;
const AboutPage = <h1>About</h1>;

const currentPage = signal(HomePage);

const template = <div>
  <nav>
    <button on:click={() => currentPage(HomePage)}>Home</button>
    <button on:click={() => currentPage(AboutPage)}>About</button>
  </nav>
  {currentPage}
</div>;

mount(template, '#app');
```
