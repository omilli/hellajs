# Learn HellaJS

HellaJS is a reactive JavaScript framework built on fine-grained reactivity. Only the specific values that change trigger updates — no virtual DOM diffing, no component re-renders.

## Package Overview

HellaJS ships as focused, independent packages. Install only what you need.

- **[@hellajs/core](/reference/core)** — Reactive primitives: signals, computed values, effects. The foundation of HellaJS.
- **[@hellajs/dom](/reference/dom)** — Surgical DOM rendering, event delegation, components, lists, portals, lazy loading.
- **[@hellajs/css](/reference/css)** — Type-safe CSS-in-JS with reactive CSS variables and automatic memory management.
- **[@hellajs/store](/reference/store)** — Deeply reactive state management from plain objects with granular property reactivity.
- **[@hellajs/router](/reference/router)** — Client-side routing with nested routes, hooks, and parameter inheritance.
- **[@hellajs/resource](/reference/resource)** — Async data fetching with caching, deduplication, polling, and mutations.

HellaJS runs in the browser. Server-side rendering is not currently supported.
