# Styling

HellaJS supports two styling approaches: traditional CSS classes with reactive bindings, and CSS-in-JS with automatic scoping. Both integrate with [signals](/reference/core/signal) for dynamic styling.

## Traditional CSS Classes

Apply CSS classes using the `class` attribute. Static classes work with external stylesheets, while [`bind:class`](/reference/dom/bind) enables reactive class names that respond to state changes.

### Reactive Classes

Arrow functions in `bind:class` recalculate when signals change.

```jsx
const Counter = () => {
  const count = signal(0);

  return (
    <div class="counter-container">
      <h1 bind:class={() => `counter-display ${count() % 2 === 0 ? 'even' : 'odd'}`}>
        {count}
      </h1>
      <button
        bind:class={() => `btn ${count() > 5 ? 'btn-success' : 'btn-primary'}`}
        on:click={() => count(count() + 1)}
      >
        {count() > 5 ? 'Great job!' : 'Increment'}
      </button>
    </div>
  );
};
```

### Class Arrays

Arrays provide a cleaner syntax for conditional classes. Falsy values are filtered out.

```jsx
const TodoItem = ({ todo }) => {
  return (
    <div bind:class={() => [
      'todo-item',
      todo().done && 'completed',
      todo().priority === 'high' && 'priority-high',
      todo().editing && 'editing'
    ]}>
      {todo().text}
    </div>
  );
};
```

## CSS-in-JS

The [`css`](/reference/css/css) function creates scoped styles from JavaScript objects with automatic class name generation and DOM injection.

### Static Styles

```jsx
import { signal } from '@hellajs/core';
import { css } from '@hellajs/css';

const Counter = () => {
  const count = signal(0);

  const buttonStyle = css({
    padding: '0.75rem 1.5rem',
    border: 'none',
    borderRadius: '0.5rem',
    background: '#3b82f6',
    color: 'white',
    fontWeight: '600',
    cursor: 'pointer',
    transition: 'all 0.2s ease',

    '&:hover': {
      background: '#2563eb',
      transform: 'translateY(-1px)'
    }
  });

  return (
    <div>
      <h1>Count: {count}</h1>
      <button class={buttonStyle} on:click={() => count(count() + 1)}>
        Increment
      </button>
    </div>
  );
};
```

### Reactive CSS Variables

[`cssVars`](/reference/css/cssvars) creates CSS custom properties from signals. When signals change, the variables update automatically.

```jsx
import { signal } from '@hellajs/core';
import { cssVars, css } from '@hellajs/css';

const ThemeButton = () => {
  const theme = signal('light');

  const themeVars = cssVars({
    button: {
      background: () => theme() === 'dark' ? '#374151' : '#3b82f6',
      color: '#ffffff'
    }
  });

  const buttonStyle = css({
    padding: '0.75rem 1.5rem',
    border: 'none',
    borderRadius: '0.5rem',
    background: themeVars.button.background,
    color: themeVars.button.color,
    fontWeight: '600',
    cursor: 'pointer',
    transition: 'all 0.2s ease',

    '&:hover': {
      transform: 'translateY(-1px)',
      opacity: '0.8'
    }
  });

  return (
    <button
      class={buttonStyle}
      on:click={() => theme(theme() === 'light' ? 'dark' : 'light')}
    >
      Toggle Theme ({theme()})
    </button>
  );
};
```

### Style Scoping

[`css`](/reference/css/css) supports three scoping modes: automatic (unique class names per object), manual (scoped to a CSS selector), and global (no scoping). See the [css reference](/reference/css/css) for scoping options and configuration.

<details>
<summary>Internal Mechanics</summary>

HellaJS processes CSS objects into rules through deterministic key generation with built-in caching and memory management.

- **Memoization**: Identical CSS objects share the same class name through hash-based caching
- **Reference Counting**: Each `css()` call increments a counter; styles are removed from the DOM when the count reaches zero
- **Synchronous Updates**: DOM stylesheets update immediately when styles are created or removed
- **Automatic Scoping**: Sequential counter generates unique class names (`c1`, `c2`, ...) ensuring isolation

</details>
