# Attribute Prefixes

HellaJS uses a prefix system to categorize element attributes. Each prefix maps to a specific behavior,  events, reactive bindings, lifecycle hooks, or error configuration.

## Events

### `on:` - Delegated Events

Delegated event handlers attached globally to `document.body` in the capture phase. Recommended for most cases: (1,000 buttons = 1 click listener).

```jsx
import { mount } from '@hellajs/dom';

const App = () => (
  <button on:click={() => console.log('Clicked')}>Click Me</button>
);

mount(App, '#app');
```

See [`on:`](/reference/dom/on) for full details.

### `e:` - Direct Events

Non-delegated event handlers attached directly to elements in the bubble phase. Use when you need `stopPropagation()` to work predictably or when working with third-party libraries that expect direct listeners.

```jsx
import { mount } from '@hellajs/dom';

const App = () => (
  <button e:click={(e) => {
    e.stopPropagation();
    console.log('Direct click');
  }}>Click Me</button>
);

mount(App, '#app');
```

See [`e:`](/reference/dom/e) for full details.

## Reactive Attributes

### `bind:` - Reactive Attribute Bindings

Reactive attribute bindings that update the DOM when signals change.

```jsx
import { mount } from '@hellajs/dom';
import { signal } from '@hellajs/core';

const isActive = signal(false);

const App = () => (
  <div bind:class={() => isActive() ? 'active' : 'inactive'}>
    <button on:click={() => isActive(!isActive())}>Toggle</button>
  </div>
);

mount(App, '#app');
```

See [`bind:`](/reference/dom/bind) for full details.

## Lifecycle Hooks

### `hook:` - Element Lifecycle Hooks

Element-level lifecycle hooks that fire at specific points in an element's existence.

```jsx
import { mount } from '@hellajs/dom';

const App = () => (
  <div
    hook:afterMount={() => console.log('Element is in DOM')}
    hook:beforeDestroy={() => console.log('About to be removed')}
  >
    Content
  </div>
);

mount(App, '#app');
```

**Available hooks:**
- `hook:beforeMount`: Synchronously before element is inserted into DOM (no element argument)
- `hook:afterMount`: After element is in DOM (deferred via `setTimeout`)
- `hook:beforeUpdate`: Before reactive updates (errors not caught)
- `hook:afterUpdate`: After reactive updates (errors not caught)
- `hook:beforeDestroy`: Before removal
- `hook:afterDestroy`: After removal and effect cleanup (no element argument)

See [`hook:`](/reference/dom/hook) for timing details and usage patterns.

## Error Configuration

### `error:` - Element Error Handling

Element-level error configuration for fine-grained error boundaries.

```jsx
import { mount } from '@hellajs/dom';

const App = () => (
  <div error:fallback={(e) => <span>Error: {e.message}</span>} error:category="sidebar">
    <FlakyComponent />
  </div>
);

mount(App, '#app');
```

**Available attributes:**
- `error:fallback`: Function receiving the error, returns fallback UI
- `error:category`: String for error categorization
- `error:boundary`: Boolean marking element as error boundary (stops error propagation without requiring a fallback)

See [`error:`](/reference/dom/error) for full details.
