# Custom Elements

Define reusable Web Components with reactive props, slots, and lifecycle management using [`element`](/reference/dom/element).

```jsx
import { element } from '@hellajs/dom';
import { signal } from '@hellajs/core';

element('my-counter', (props) => {
  const count = signal(Number(props.initial()) || 0);

  return (
    <div>
      <span id="count">{count}</span>
      <button on:click={() => count(count() + 1)}>+</button>
    </div>
  );
});
```

## Reactive Props

Props are reactive getter functions that track attribute changes. Missing attributes return `null`, so use nullish coalescing (`??`) for defaults:

```jsx
element('my-greeter', (props) => (
  <div>
    {() => `Hello, ${props.name() ?? 'World'}!`}
  </div>
));
```

`setAttribute` and `removeAttribute` trigger synchronous reactive updates. Effects that read props re-evaluate immediately.

## Slots

Support default and named slots for content projection. Whitespace-only text nodes are excluded from the default slot (`props.children`):

```jsx
element('my-card', (props) => (
  <article>
    <header>{props.slots?.title}</header>
    <main>{props.children}</main>
    <footer>{props.slots?.footer}</footer>
  </article>
));
```

Usage in HTML:
```html
<my-card>
  <h1 slot="title">Card Title</h1>
  <p>Default slot content</p>
  <small slot="footer">2025</small>
</my-card>
```

## Lifecycle

When a custom element is disconnected from the DOM, all effects are disposed and internal state resets. Reconnection triggers a fresh render from scratch.

**Important:** Custom elements use light DOM rendering, not shadow DOM. Page styles apply normally to the element's content.

See [`element`](/reference/dom/element) for full API details.
