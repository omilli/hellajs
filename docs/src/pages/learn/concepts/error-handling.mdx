# Error Handling

HellaJS provides a global error handler with element-level configuration for fine-grained control.

### Global Error Handler

Set up a global handler using [`onError`](/reference/dom/onerror). The handler receives the error and a context object, and must return a fallback element:

```jsx
import { onError, html } from '@hellajs/dom';

onError((error, context) => {
  console.error(`[${context.phase}]`, error.message);
  return html`<div class="error">Something went wrong</div>`;
});
```

### Element Error Configuration

Configure error behavior on individual elements with the `error:` prefix. Your [`onError`](/reference/dom/onerror) handler must delegate to `context.config?.fallback?.(error)` for element-level fallbacks to work:

```jsx
import { onError, mount, html } from '@hellajs/dom';

// Delegate to element fallback when available, otherwise use global fallback
onError((error, context) =>
  context.config?.fallback?.(error) ?? html`<div class="error">Something went wrong</div>`
);

const App = () => html`
  <div error:fallback=${(e) => html`
    <div class="error-boundary">
      <p>Failed: ${e.message}</p>
      <button on:click=${() => location.reload()}>Reload</button>
    </div>
  `}>
    <FlakyComponent />
  </div>
`;

mount(App, '#app');
```

**Available attributes:**
- `error:fallback`: Function receiving the error, returns fallback UI
- `error:category`: String for error categorization
- `error:boundary`: Boolean marking element as error boundary (stops error propagation without requiring a fallback)

See [`onError`](/reference/dom/onerror) and [`error:`](/reference/dom/error) for full details.
