# Blog App

A blog with nested routing and resource-based data loading. Uses [`@hellajs/router`](/reference/router) for nested route configuration, [`@hellajs/resource`](/reference/resource) for per-route data fetching, and [`@hellajs/dom`](/reference/dom) for rendering and lazy loading.

## Setup

```bash
npm create vite@latest blog-app -- --template vanilla
cd blog-app
npm install @hellajs/core @hellajs/dom @hellajs/router @hellajs/resource
npm install -D vite-plugin-hellajs
```

Configure `vite.config.js`:

```js
import { defineConfig } from 'vite';
import viteHellaJS from 'vite-plugin-hellajs';

export default defineConfig({
  plugins: [viteHellaJS()],
});
```

## The Application

Replace `main.js` with the following. The code uses mock data and simulated fetch delays so it runs without a backend.

```jsx
import { signal } from "@hellajs/core";
import { mount, ForEach, Lazy } from "@hellajs/dom";
import { router, route, navigate } from "@hellajs/router";
import { resource } from "@hellajs/resource";

// --- Mock Data ---

const POSTS = [
  { id: "1", title: "Reactive Primitives", category: "core", body: "Signals are the foundation..." },
  { id: "2", title: "Computed Values", category: "core", body: "Derived state updates automatically..." },
  { id: "3", title: "Surgical DOM Updates", category: "dom", body: "No virtual DOM diffing required..." },
  { id: "4", title: "Keyed List Reconciliation", category: "dom", body: "The LIS algorithm minimizes moves..." },
  { id: "5", title: "Nested Routing", category: "router", body: "Routes mirror your app structure..." },
];

const delay = (ms) => new Promise((r) => setTimeout(r, ms));

const fetchPosts = () => delay(300).then(() => [...POSTS]);

const fetchPostsByCategory = (cat) =>
  delay(200).then(() => POSTS.filter((p) => p.category === cat));

const fetchPost = (id) =>
  delay(150).then(() => POSTS.find((p) => p.id === id) || null);

// --- Resources ---

const postsResource = resource(() => fetchPosts(), {
  cacheTime: 30000,
});

const categoryResource = resource(
  (cat) => fetchPostsByCategory(cat),
  { key: () => route().params.category, refetchOnKeyChange: true }
);

const postResource = resource(
  (id) => fetchPost(id),
  { key: () => route().params.postId, refetchOnKeyChange: true }
);

// --- Components ---

const BlogLayout = () => {
  const currentPath = () => route().path;

  return (
    <div class="min-h-screen bg-gray-50">
      <header class="bg-white border-b">
        <div class="max-w-4xl mx-auto px-4 py-3 flex items-center justify-between">
          <a on:click={() => navigate("/blog")} class="text-xl font-bold cursor-pointer">
            HellaBlog
          </a>
          <nav class="flex gap-4">
            <a on:click={() => navigate("/blog")} class="cursor-pointer text-blue-600">
              All Posts
            </a>
            <a on:click={() => navigate("/blog/core")} class="cursor-pointer text-blue-600">
              Core
            </a>
            <a on:click={() => navigate("/blog/dom")} class="cursor-pointer text-blue-600">
              DOM
            </a>
            <a on:click={() => navigate("/blog/router")} class="cursor-pointer text-blue-600">
              Router
            </a>
          </nav>
        </div>
      </header>

      <main class="max-w-4xl mx-auto px-4 py-6">
        {currentView}
      </main>

      <footer class="max-w-4xl mx-auto px-4 py-4 text-center text-sm text-gray-400">
        Built with HellaJS
      </footer>
    </div>
  );
};

const PostList = () => {
  postsResource.fetch({ force: true });

  return (
    <div>
      <h1 class="text-2xl font-bold mb-4">All Posts</h1>
      {() => postsResource.isLoading()
        ? <p class="text-gray-500">Loading posts...</p>
        : <ul class="space-y-3">
            <ForEach each={() => postsResource.data() || []} use={(post) => (
              <li class="bg-white p-4 rounded border" key={post.id}>
                <div class="flex justify-between items-center">
                  <a
                    on:click={() => navigate("/blog/:category/:postId", {
                      params: { category: post.category, postId: post.id }
                    })}
                    class="font-medium text-blue-600 cursor-pointer"
                  >
                    {post.title}
                  </a>
                  <a
                    on:click={() => navigate("/blog/:category", {
                      params: { category: post.category }
                    })}
                    class="text-xs bg-gray-100 px-2 py-1 rounded cursor-pointer"
                  >
                    {post.category}
                  </a>
                </div>
              </li>
            )} />
          </ul>
      }
    </div>
  );
};

const CategoryView = () => {
  const category = () => route().params.category;

  return (
    <div>
      <div class="flex items-center gap-2 mb-4">
        <a on:click={() => navigate("/blog")} class="text-blue-600 cursor-pointer text-sm">
          All Posts
        </a>
        <span class="text-gray-400">/</span>
        <h1 class="text-2xl font-bold capitalize">{category}</h1>
      </div>
      {() => categoryResource.isLoading()
        ? <p class="text-gray-500">Loading {category()} posts...</p>
        : <ul class="space-y-3">
            <ForEach each={() => categoryResource.data() || []} use={(post) => (
              <li class="bg-white p-4 rounded border" key={post.id}>
                <a
                  on:click={() => navigate("/blog/:category/:postId", {
                    params: { category: post.category, postId: post.id }
                  })}
                  class="font-medium text-blue-600 cursor-pointer"
                >
                  {post.title}
                </a>
              </li>
            )} />
          </ul>
      }
    </div>
  );
};

// Lazy-loaded full post view — simulates a chunked bundle
const PostDetail = (props) => {
  const post = () => postResource.data();

  return (
    <div>
      <div class="flex items-center gap-2 mb-4">
        <a on:click={() => navigate("/blog")} class="text-blue-600 cursor-pointer text-sm">
          All Posts
        </a>
        <span class="text-gray-400">/</span>
        <a
          on:click={() => navigate("/blog/:category", {
            params: { category: props.category }
          })}
          class="text-blue-600 cursor-pointer text-sm capitalize"
        >
          {props.category}
        </a>
        <span class="text-gray-400">/</span>
        <span class="text-sm text-gray-500">{post()?.title}</span>
      </div>

      {() => postResource.isLoading()
        ? <p class="text-gray-500">Loading post...</p>
        : post()
          ? <article class="bg-white p-6 rounded border">
              <h1 class="text-3xl font-bold mb-2">{post().title}</h1>
              <p class="text-sm text-gray-400 mb-4 capitalize">{post().category}</p>
              <p class="text-gray-700 leading-relaxed">{post().body}</p>
            </article>
          : <p class="text-red-500">Post not found.</p>
      }
    </div>
  );
};

// Simulates a dynamic import — in production this would be
// () => import("./PostDetail.js").then(m => m.default)
const loadPostDetail = () =>
  delay(100).then(() => PostDetail);

// --- Router ---

const currentView = signal(null);

router({
  routes: {
    "/blog": {
      handler: () => currentView(<PostList />),
      children: {
        "/:category": {
          handler: () => currentView(<CategoryView />),
          children: {
            "/:postId": (params) =>
              currentView(
                <Lazy
                  loader={loadPostDetail}
                  loading={<p class="text-gray-500">Loading component...</p>}
                  props={{ category: params.category }}
                />
              ),
          },
        },
      },
    },
  },
  notFound: () => navigate("/blog"),
});

// --- Mount ---

const App = () => <BlogLayout />;

mount(App, "#app");
```

Start the dev server with `npm run dev`.

## Key Patterns

- **Nested route configuration** — The `/blog` parent sets up the layout. Children `/:category` and `/:category/:postId` inherit parameters automatically via the [`router`](/reference/router/router) nesting structure. Each level fills `currentView` so the [`BlogLayout`](/learn/concepts/templates#components) wrapper persists across navigation.

- **Resource-based data loading per route** — Each route level has its own [`resource`](/reference/resource/resource) with a reactive `key` derived from [`route`](/reference/router/route) parameters. Setting `refetchOnKeyChange: true` triggers automatic refetching when the URL changes, keeping data in sync with the current route.

- **Lazy loading with [`Lazy`](/reference/dom/lazy)** — The post detail view is loaded asynchronously through the `Lazy` component. The `loader` returns a Promise resolving to the component function, `loading` shows a placeholder while resolving, and `props` are forwarded to the resolved component. In production, replace the mock `loadPostDetail` with a real dynamic `import()`.
