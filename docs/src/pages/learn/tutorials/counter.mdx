# Build a Counter App

Let's build an interactive counter app to learn the fundamentals of HellaJS step-by-step.

Jump to the [Complete Code](#complete-code) for the finished application.

## What You'll Learn

- **[Signals](/reference/core/signal)**:  How to create and use reactive state
- **Derived values**:  How to derive state automatically
- **[Effects](/reference/core/effect)**:  How to run side effects when state changes
- **Event handling**:  Reactive state updates from user interactions
- **Conditional rendering**:  Showing different UI based on state

We'll start simple and add complexity step by step, so you see how each concept builds on the previous ones.

## Project Setup

### Installation

Use your favorite package manager to scaffold a new Vite project.

```bash
npm create vite@latest counter-app -- --template vanilla
```

Navigate into your new project directory and install the HellaJS packages and the Vite plugin.

```bash
cd counter-app
npm install @hellajs/core @hellajs/dom @hellajs/css
npm install -D vite-plugin-hellajs
```

### Configuration

Update your `vite.config.js` to use the HellaJS plugin.

```js
// vite.config.js
import { defineConfig } from 'vite';
import viteHellaJS from 'vite-plugin-hellajs';

export default defineConfig({
  plugins: [viteHellaJS()],
});
```

If you're using TypeScript, add type definitions for HellaJS. Update your `tsconfig.json`.

```json
{
  "compilerOptions": {
    //...
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
    //...
  }
}
```

## Reactive Component

[Components](/learn/concepts/templates#components) are functions that return an element and [signals](/reference/core/signal) automatically update when their values change.

Replace the content of `main.jsx` with the component shell.

```jsx
// main.jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

//... styles from previous section

const Counter = () => {
  const count = signal(0);

  return (
    <div class={container}>
      <h1>Counter: {count}</h1>
      <button on:click={() => count(count() + 1)} class={btnIncrement}>
        Click me!
      </button>
    </div>
  );
};

mount(Counter, '#app');
```

**Code Explanation**

- **`signal(0)`**:  Creates a reactive state with an initial value of 0
- **`{count}`**:  Creates a reactive binding that updates automatically
- **`on:click={() => count(count() + 1)}`**:  Updates the signal value on click
- **[`mount`](/reference/dom/mount)`(Counter, '#app')`**:  Renders the component into the DOM


## Styles

Define named styles using [`css`](/reference/css/css). Each call returns a class name string.

```jsx
//... add after dom import
import { css } from "@hellajs/css";

const container = css({
  padding: '1rem',
  textAlign: 'center',
  'h1': {
    fontSize: '1.5rem',
    marginBottom: '1rem',
  },
  'p': {
    marginBottom: '1rem',
  },
  'button': {
    padding: '0.5rem 0.75rem',
    color: 'white',
    borderRadius: '0.25rem',
    border: 'none',
    cursor: 'pointer',
  },
});

const controls = css({
  display: 'flex',
  gap: '0.5rem',
  justifyContent: 'center',
});

const btnDecrement = css({ backgroundColor: '#ef4444' });
const btnIncrement = css({ backgroundColor: '#3b82f6' });
const btnReset = css({ backgroundColor: '#6b7280' });

const Counter = () => {
  //... rest of the code unchanged
}
```

**Code Explanation**

- **`css({ ... })`**:  Defines styles and returns a class name string
- **`button`**:  Nested CSS selectors style all buttons inside the container
- **Descendant selectors**:  Buttons inherit base styles (padding, color, border-radius) from the container's `button` key, individual classes only set the background color

## Derived State

What if you want to show information that depends on the count? [`computed`](/reference/core/computed) creates a cached derived value that updates when its dependencies change.

Update the import to include `computed`:

```jsx
//... import computed at the top
import { signal, computed } from "@hellajs/core";
```

Add a computed value and update the return:

```jsx
const Counter = () => {
  const count = signal(0);

  // add this computed value
  const doubled = computed(() => count() * 2);

  return (
    <div class={container}>
      ...
    </div>
  );
};
```

**Code Explanation**

- **[`computed`](/reference/core/computed)`(() => count() * 2)`**:  Creates a cached derived value that updates when `count` changes

Regular functions work fine for derived state, but [`computed`](/reference/core/computed) caches the result and skips recomputation when the value has not changed.

**Cached:** `const doubled = computed(() => count() * 2)` (skips recomputation when `count` is unchanged)

**Uncached:** `const doubled = () => count() * 2` (re-executes on every call)

## Counter Controls

Let's make our counter more interactive by adding increment, decrement, and reset buttons with smart disabling.

Replace the single button with three control buttons:

```jsx
const Counter = () => {
  //... derived values unchanged

  return (
    <div class={container}>
      <h1>Counter: {count}</h1>

      <p>Doubled: {doubled}</p>

      <div class={controls}>
        <button
          on:click={() => count(count() - 1)}
          class={btnDecrement}
          bind:disabled={() => count() === 0}
        >
          -
        </button>

        <button
          on:click={() => count(count() + 1)}
          class={btnIncrement}
        >
          +
        </button>

        <button
          on:click={() => count(0)}
          class={btnReset}
          bind:disabled={() => count() === 0}
        >
          Reset
        </button>
      </div>
    </div>
  );
}
```

Start the development server to see your app in action.

```bash
npm run dev
```

Your app will be running at `http://localhost:5173`. Try clicking the buttons and watch the counter update!

**Code Explanation**

- **Event handlers**:  Simple functions that update state
- **`bind:disabled={() => count() === 0}`**:  Reactively disables buttons when count is zero

## Signal Side Effects

What about actions that happen when state changes? Like updating the browser tab title?

[Effects](/reference/core/effect) run side effects automatically when their dependencies change.

Update the import to include `effect`:

```jsx
//... import effect at the top
import { signal, effect } from "@hellajs/core";
```

Add an effect inside the component:

```jsx
const Counter = () => {
  const count = signal(0);

  // add this effect
  effect(() => {
    document.title = `Counter: ${count()}`;
  });

  //... derived values and return unchanged
}
```

**Code Explanation**

- **`effect(() => { document.title = ... })`**:  Side effect that runs when `count` changes
- **Automatic dependency tracking**:  The effect detects `count()` inside and re-runs whenever it changes

## Complete Code

```jsx
import { signal, computed, effect } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { css } from "@hellajs/css";

const container = css({
  padding: '1rem',
  textAlign: 'center',
  'h1': {
    fontSize: '1.5rem',
    marginBottom: '1rem',
  },
  'p': {
    marginBottom: '1rem',
  },
  'button': {
    padding: '0.5rem 0.75rem',
    color: 'white',
    borderRadius: '0.25rem',
    border: 'none',
    cursor: 'pointer',
  },
});

const controls = css({
  display: 'flex',
  gap: '0.5rem',
  justifyContent: 'center',
});

const btnDecrement = css({ backgroundColor: '#ef4444' });
const btnIncrement = css({ backgroundColor: '#3b82f6' });
const btnReset = css({ backgroundColor: '#6b7280' });

const Counter = () => {
  const count = signal(0);

  effect(() => {
    document.title = `Counter: ${count()}`;
  });

  const doubled = computed(() => count() * 2);

  return (
    <div class={container}>
      <h1>Counter: {count}</h1>
      <p>Doubled: {doubled}</p>

      <div class={controls}>
        <button
          on:click={() => count(count() - 1)}
          class={btnDecrement}
          bind:disabled={() => count() === 0}
        >
          -
        </button>

        <button
          on:click={() => count(count() + 1)}
          class={btnIncrement}
        >
          +
        </button>

        <button
          on:click={() => count(0)}
          class={btnReset}
          bind:disabled={() => count() === 0}
        >
          Reset
        </button>
      </div>
    </div>
  );
};

mount(Counter, '#app');
```
