# Build Tool Plugins

Official plugins that transform HellaJS JSX syntax and `html` tagged templates into HellaNode objects at build time. Without a plugin, JSX and `html` templates won't be compiled.

All plugins are zero-config: install and add to your build tool. No options to configure.

## TypeScript Configuration

All plugins support TypeScript out of the box. Add HellaJS types to your project.

```json
// tsconfig.json
{
  "compilerOptions": {
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
  }
}
```
