# Build Tool Plugins

Official plugins that compile HellaJS JSX at build time. The `hellajs-compiler` engine does the compiling: it emits the HellaNode AST that `@hellajs/ssr` stringifies for server builds, and imperative `@hellajs/dom/runtime` construction for client builds. The Vite and Rollup wrappers drive it per build environment.

Install, add to your build tool, done: the wrappers resolve the emission target automatically. Pass an explicit `target` option to override.

<Plugins/>

## TypeScript Configuration

All plugins support TypeScript out of the box. Add HellaJS types to your project.

```json
// tsconfig.json
{
  "compilerOptions": {
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
  }
}
```
