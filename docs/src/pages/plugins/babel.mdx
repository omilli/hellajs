# Babel Plugin

The Babel plugin transforms HellaJS JSX syntax into JavaScript objects and function calls that can be rendered by the HellaJS runtime.

## Installation

```bash
npm install --save-dev babel-plugin-hellajs
```

## Configuration

Add the plugin to your `babel.config.js`.

```js
module.exports = {
  plugins: [
    'babel-plugin-hellajs'
  ]
};
```

## TypeScript

For TypeScript projects, combine with the TypeScript preset.

```js
module.exports = {
  presets: ['@babel/preset-typescript'],
  plugins: ['babel-plugin-hellajs']
};
```

Ensure your `tsconfig.json` includes:

```json
{
  "compilerOptions": {
    "jsx": "preserve",
    "types": ["@hellajs/dom"] // Important
  }
}
```


## Webpack
```js
module.exports = {
  module: {
    rules: [
      {
        test: /\.(js|jsx|ts|tsx)$/,
        use: {
          loader: 'babel-loader',
          options: {
            plugins: ['babel-plugin-hellajs']
          }
        }
      }
    ]
  }
};
```

## Jest
```js
module.exports = {
  transform: {
    '^.+\\.(js|jsx|ts|tsx)$': ['babel-jest', {
      plugins: ['babel-plugin-hellajs']
    }]
  }
};
```


## Static hoisting

Fully-static subtrees — lowercase tags, literal-only attributes, no `on:` / `e:` / `hook:` / `error:` prefixes, no expressions, no components — are hoisted to module-level constants tagged `static: true`:

```js
// input
const Row = () => <td class="col"><span class="icon" /></td>;

// output (shape)
const _hellaStatic = {
  tag: "td",
  props: { class: "col" },
  children: [{ tag: "span", props: { class: "icon" }, static: true }],
  static: true
};
const Row = () => _hellaStatic;
```

The runtime keeps a prototype DOM subtree per static node, so every mount of the constant is a single native `cloneNode(true)` instead of re-walking construction — and repeated renders of the same site (list rows, re-mounted panels) share one object instead of allocating per call. Static children of a dynamic parent hoist individually.

Because these constants are shared, mutating a returned node is unsafe — the same caveat the runtime `html`` ` template cache has always carried.
