# Babel Plugin

The Babel plugin transforms HellaJS JSX syntax into JavaScript objects and function calls that can be rendered by the HellaJS runtime.

## Installation

```bash
npm install --save-dev babel-plugin-hellajs
```

## Configuration

Add the plugin to your `babel.config.js`.

```js
module.exports = {
  plugins: [
    'babel-plugin-hellajs'
  ]
};
```

## Build Target

The plugin emits HellaNode AST objects by default (`target: "ast"`), the input format of `@hellajs/ssr`. Client pipelines that run the compiled output in the browser pass `{ target: "dom" }` to emit imperative construction calls against `@hellajs/dom/runtime` instead:

```js
module.exports = {
  plugins: [['babel-plugin-hellajs', { target: 'dom' }]]
};
```

The vite, rollup, and astro wrappers own this option themselves, so direct babel plugin use is the only path that needs it.

## TypeScript

For TypeScript projects, combine with the TypeScript preset.

```js
module.exports = {
  presets: ['@babel/preset-typescript'],
  plugins: ['babel-plugin-hellajs']
};
```

Ensure your `tsconfig.json` includes:

```json
{
  "compilerOptions": {
    "jsx": "preserve",
    "types": ["@hellajs/dom"] // Important
  }
}
```


## Webpack
```js
module.exports = {
  module: {
    rules: [
      {
        test: /\.(js|jsx|ts|tsx)$/,
        use: {
          loader: 'babel-loader',
          options: {
            plugins: ['babel-plugin-hellajs']
          }
        }
      }
    ]
  }
};
```

## Jest
```js
module.exports = {
  transform: {
    '^.+\\.(js|jsx|ts|tsx)$': ['babel-jest', {
      plugins: ['babel-plugin-hellajs']
    }]
  }
};
```


## Static hoisting

Fully-static subtrees (lowercase tags, literal-only attributes, no `on:` / `e:` / `hook:` / `error:` prefixes, no expressions, no components) are hoisted to module-level constants tagged `static: true`:

```js
// input
const Row = () => <td class="col"><span class="icon" /></td>;

// output (shape)
const _hellaStatic = {
  tag: "td",
  props: { class: "col" },
  children: [{ tag: "span", props: { class: "icon" }, static: true }],
  static: true
};
const Row = () => _hellaStatic;
```

The hoisted constant is shared by reference: repeated renders of the same site (list rows, re-mounted panels) reuse one object instead of allocating per call. Static children of a dynamic parent hoist individually.

Because these constants are shared, mutating a returned node is unsafe: every mount of the same site reuses the one object.

Static hoisting applies to the `ast` target; the `dom` target folds static subtrees into cached `template()` prototypes instead.
