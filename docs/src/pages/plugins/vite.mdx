# Vite Plugin

The Vite plugin provides JSX transformation for HellaJS with lightning-fast hot module replacement (HMR) and optimized development experience.

## Installation

```bash
npm install --save-dev vite-plugin-hellajs
```
## Configuration

Add the plugin to your `vite.config.js`.

```js
import { defineConfig } from 'vite';
import viteHellaJS from 'vite-plugin-hellajs';

export default defineConfig({
  plugins: [viteHellaJS()]
});
```

## Build Target

JSX compiles per build environment: client builds emit imperative DOM construction through `@hellajs/dom/runtime`, and server or SSR builds emit the HellaNode AST that `@hellajs/ssr` stringifies. Pass an explicit `target` option (`"dom"` or `"ast"`) to override the per-environment resolution.

## TypeScript

The plugin includes full TypeScript support. Configure your `tsconfig.json`.

```json
{
  "compilerOptions": {
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
  }
}
```
