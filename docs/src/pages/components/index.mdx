# Components

`@hellajs/ui` ships a copy-paste registry: `bunx @hellajs/ui add <name>` copies one editable file per component into your project. Every component ships in two style flavors (`css`, the default, styled with [`@hellajs/css`](/reference/css) under the `hella` cascade layer; `tailwind`, backed by `theme.css` and `cn.ts`) and two formats (`jsx` and `html`), with `hella.ui.json` remembering your defaults. The components running on these pages were installed by that same `add` command: the site vendors them into `src/components/ui/` (css flavor, html format, pure runtime, no compiler), byte-identical to what `add --format html` writes. Registry styles inject under the `hella` cascade layer, declared after the site's own layers so component rules win over the site's preflight; each page carries the full install and per-style usage from the package docs.

- [Tabs](/components/tabs): pill and line tablists with roving tabindex and aria wiring across panels.
- [Badge](/components/badge): six status-chip variants with anchor-aware hover styles.
- [Alert](/components/alert): default and destructive callouts with an auto-reserved icon column.
- [Kbd](/components/kbd): keyboard-key chips and grouped key sequences on the semantic `kbd` element.
- [Separator](/components/separator): horizontal and vertical dividers with orientation attributes.
- [Skeleton](/components/skeleton): pulsing placeholders composed into profile and text-line shapes.
- [Spinner](/components/spinner): the loader-circle glyph with status semantics at three sizes.
- [Empty](/components/empty): empty-state compositions with an icon-tile media part.
- [Label](/components/label): form captions wired to inputs through the `for` attribute.
- [Textarea](/components/textarea): an auto-sizing multi-line input with a live character count.
- [Native Select](/components/native-select): real select elements with caller-authored options and a compact size.
- [Aspect Ratio](/components/aspect-ratio): fixed-ratio media frames at 16/9, 1/1, and 4/3.
- [Avatar](/components/avatar): portraits whose fallback returns when the image errors, plus groups and a count.
- [Progress](/components/progress): a determinate bar you can advance and an indeterminate sweep.
- [Table](/components/table): the seven semantic parts over a horizontally scrolling container.
- [Button Group](/components/button-group): joined button rows and columns with text plates and separators.
- [Input Group](/components/input-group): fake-input composites where the group owns the focus and invalid rings.
- [Field](/components/field): ten-part form kit with disabled and invalid propagation and a responsive orientation.
- [Pagination](/components/pagination): paged navigation links whose active state skips the router through `onclick`.
- [Item](/components/item): list rows with media, actions, and reactive selection state.
- [Marker](/components/marker): labeled divider strips with rule and border variants.
- [Direction](/components/direction): a layout-neutral `dir` wrapper that right-to-left behaviors read.
- [Bubble](/components/bubble): chat bubbles in seven variants with floating reaction chips.
- [Message](/components/message): chat rows whose avatar, content, and meta parts coordinate through data attributes.
- [Message Scroller](/components/message-scroller): an auto-sticking chat viewport with a jump-to-end button.
- [Attachment](/components/attachment): upload chips whose spinner and error glyphs follow one `state` prop.
- [Collapsible](/components/collapsible): a disclosure trigger and region whose open state lives in a signal.
- [Accordion](/components/accordion): single and multiple stacked items with grid-animated content regions.
- [Checkbox](/components/checkbox): a checked-state button carrying the check icon and an indeterminate state.
- [Radio Group](/components/radio-group): one labeled row per entry with arrow-key focus movement.
- [Switch](/components/switch): an on/off button whose thumb slides through pure CSS.
- [Toggle](/components/toggle): a pressed-state button with the full variant and size maps.
- [Toggle Group](/components/toggle-group): pressed-state buttons in single or multiple mode with roving arrows.
- [Slider](/components/slider): a pointer and keyboard value control with one thumb per value.
- [Resizable](/components/resizable): flex panels with drag handles that move the boundary between neighbors.
- [Tooltip](/components/tooltip): a hover-delayed label, portaled and anchored, with collision flipping.
- [Hover Card](/components/hover-card): a rich preview panel that stays open while the pointer remains inside it.
- [Popover](/components/popover): a click-toggled anchored panel with Escape, outside-press, and stacked-layer dismissal.
- [Dropdown Menu](/components/dropdown-menu): a button-triggered item menu with checkbox and radio items and submenus.
- [Context Menu](/components/context-menu): the same item menu opened by a right-click at the pointer coordinates.
- [Menubar](/components/menubar): a horizontal bar holding one open menu at a time with full arrow wiring.
- [Navigation Menu](/components/navigation-menu): triggers opening content panels into a shared viewport under a sliding indicator.
- [Breadcrumb](/components/breadcrumb): a navigation trail with separators, collapsed segments, and dropdown overflow.
- [Select](/components/select): an anchored, width-matched listbox with arrow roving, typeahead, and Enter commit.
- [Combobox](/components/combobox): a filterable listbox narrowed by a query signal, single or multiple.
- [Command](/components/command): a command palette with ranked filtering over labels, values, and keywords.
- [Alert Dialog](/components/alert-dialog): a modal confirmation with wired title and description and an Action/Cancel pair.
- [Sheet](/components/sheet): a panel sliding in from any of the four screen edges with enter and exit animations.
- [Drawer](/components/drawer): a drag-dismissable edge panel that follows the pointer and dismisses past a threshold.
- [Sonner](/components/sonner): a toast queue with type icons, rich colors, promise loading, hover-pause, and swipe dismissal.

- [Sidebar](/components/sidebar): the composite shell - provider-owned open and mobile state, three collapsible variants, an inline mobile sheet, and the full menu part family.
