# Why

Chasing a phantom uncovered line wastes a test-writing cycle: no behavioral test can execute a closing brace "harder". The istanbul/bun coverage instrumentation treats the block-scoped case's closing line as a statement location that never registers execution. The unbraced-case + hoisted-let form sidesteps the artifact entirely and matches the existing switch style in `hydrateDynamic` (all other cases unbraced). Root rule interaction: AGENTS.md requires re-deriving uncovered lines from the CURRENT bundle before acting — reading the line's content (`sed -n '<n>p' dist/bundle.js`) is the discriminator between a real branch and this artifact.

# Evidence

- Red: `bun coverage dom` after the braced-case edit → `Uncovered Line #s: … 844 …`; `sed -n '844p' dist/bundle.js` → the case's closing `}` with `break;` above it fully covered.
- Green: restructured to `let swappedStage` above the switch + unbraced case (`packages/dom/lib/internal/hydrate.ts`, `hydrateDynamic`) → zero uncovered lines, 357/0, no test added.
