# Why

Three interlocking facts from the core optimization pass:

1. **endTracking loop** — `tracking.ts` removed only the FIRST stale dep after `rpd` (no loop). Effects/computeds dropping 2+ deps in one re-run kept silent subscriptions: writes to dropped deps triggered spurious runs/recomputes until the graph self-healed one link per run. Upstream `purgeDeps` loops; hellajs had lost the loop. Any future rewrite of tracking must keep `while (remove) remove = removeLink(remove, subscriber)`.

2. **SIGNAL_DEPS fast path (user-approved trade-off)** — `propagateChange` marks clean subscribers `PENDING | (SIGNAL_DEPS ? DIRTY : 0)`. Signals-only effects therefore enter `executeEffect` with DIRTY set and short-circuit past `validateStale` entirely. The bit is set at effect creation (`GUARDED | SIGNAL_DEPS`), cleared permanently in `createLink`'s NEW-link path when the source carries `COMPUTED` (reuse paths skip the clear — an existing computed link already cleared it), and preserved by `executeEffect`'s constant flag store `(flags & (EFFECT_DEP | SIGNAL_DEPS)) | GUARDED | TRACKING`. Ceiling was measured with a probe forcing unconditional runs: -9.5%/-18%/-12% on the three write benches; shipped result hit those ceilings (-12%/-23%/-15%). Alternatives rejected: version-counter staleness (full rewrite, no measured need), notify chain-reversal (upstream alien-signals approach, equal work moved to schedule time).

3. **Flag conventions after the pass** — free bits are gone: EFFECT_DEP=8 (gates skip-path child-effect walk; stale bit = no-op walk), COMPUTED=64 (type-bit dispatch in `updateValue` + removeLink auto-GC — never probe `cbf`), SIGNAL_DEPS=256. `WRITABLE|COMPUTED|DIRTY` is the computed auto-GC reset (dropping COMPUTED breaks dispatch). No `startTracking` exists anymore — execute paths rebuild rf from constants + reset `rpd` inline; any new rf store on an effect MUST preserve the sticky bits (EFFECT_DEP, SIGNAL_DEPS).

Also measured: `arguments.length` beats rest-param for signal arity checks under JSC (29 vs 31ns/100 reads); signal getter returning the destructured `sbc` local (sbc===sbv at return, proven invariant) halved read-path cost (-24%).

- Fix probe (pre-fix output "BUG: still subscribed to C"): effect reading A,B,C then only A still ran on C/B writes.
