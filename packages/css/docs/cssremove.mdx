# cssRemove

Removes specific CSS rules and decrements their reference count for memory management.

## API

```typescript
function cssRemove(obj: CSSObject, options?: CSSOptions): void
```
- `obj`: CSS object to remove (must match exactly the object used in `css()`)
- `options`: Optional configuration object (must match the options used in `css()`)
  - `scoped`: CSS selector scope used when creating the style
  - `name`: Custom class name used when creating the style
  - `global`: Whether the style was created with global scope
- **Returns**: `void`

## Basic Usage


```jsx
import { css, cssRemove } from '@hellajs/css';

const buttonStyle = css({
  background: 'blue',
  color: 'white',
  padding: '0.5rem 1rem'
});

// Use the style...
<button class={buttonStyle}>Click me</button>

// Later, remove it when no longer needed
cssRemove({
  background: 'blue',
  color: 'white',
  padding: '0.5rem 1rem'
});
```

## Key Concepts

### Reference Counting

The `cssRemove` function provides precise control over CSS rule lifecycle:

- **Reference Counting**: Each `css()` call increments the reference count for the style
- **Automatic Cleanup**: Removes CSS rules from DOM when reference count reaches zero
- **Memory Management**: Frees memory used by unused styles
- **Cache Cleanup**: Clears the inline cache for the removed style

### Usage Pattern

Styles are deduplicated via memoization — all `css()` calls with the same object return the same class name. Each call increments the reference count, so `cssRemove()` must be called the same number of times to fully remove the style.

```jsx
import { css, cssRemove } from '@hellajs/css';

const sharedStyle = {
  display: 'flex',
  alignItems: 'center',
  gap: '0.5rem'
};

// Each call increments the reference count — CSS is injected once
const classA = css(sharedStyle); // refCount = 1
const classB = css(sharedStyle); // refCount = 2, same class name
const classC = css(sharedStyle); // refCount = 3, same class name

// Remove one reference — style persists (refCount = 2)
cssRemove(sharedStyle);

// Remove remaining references to fully clear
cssRemove(sharedStyle);
cssRemove(sharedStyle); // refCount = 0, CSS removed from DOM
```

### With Options

```jsx
import { css, cssRemove } from '@hellajs/css';

const scopedStyle = css({
  '.header': { fontSize: '1.5rem' },
  '.content': { padding: '1rem' }
}, { scoped: '.my-component' });

// Later remove with matching options
cssRemove({
  '.header': { fontSize: '1.5rem' },
  '.content': { padding: '1rem' }
}, { scoped: '.my-component' });
```

### Component Cleanup

```jsx
import { css, cssRemove } from '@hellajs/css';

const MyComponent = () => {
  const styleObjects = [
    { background: 'white', padding: '1rem' },
    { color: 'blue', fontWeight: 'bold' },
    { border: '1px solid #ccc', borderRadius: '4px' }
  ];

  const classNames = styleObjects.map(obj => css(obj));

  const destroy = () => {
    styleObjects.forEach(obj => cssRemove(obj));
  };

  return (
    <div class={classNames.join(' ')}>
      <p>Styled component</p>
    </div>
  );
};
```

### Dynamic Style Management

```jsx
import { signal } from '@hellajs/core';
import { css, cssRemove } from '@hellajs/css';

let currentTheme = null;

const applyTheme = (colors) => {
  // Remove old theme if exists
  if (currentTheme) {
    cssRemove(currentTheme);
  }

  // Apply new theme
  currentTheme = {
    background: colors.background,
    color: colors.text,
    borderColor: colors.border
  };

  return css(currentTheme, { global: true });
};

// Switch themes
applyTheme({ background: '#fff', text: '#000', border: '#ccc' });
applyTheme({ background: '#000', text: '#fff', border: '#444' });
```

## Important Considerations

### Exact Matching Required

`cssRemove()` uses a deterministic hash key computed from the CSS object and options. The same object reference is not required — structurally identical objects will match:

```jsx
// ✓ Works - structurally identical objects match
css({ color: 'red', fontSize: '16px' });
cssRemove({ color: 'red', fontSize: '16px' }); // Works — same hash key

// ✓ Works - same reference (also works, and is clearer)
const style = { color: 'red', fontSize: '16px' };
css(style);
cssRemove(style);

// ✗ Won't work - different CSS content
css({ color: 'red' });
cssRemove({ color: 'blue' }); // Different hash key
```

### Use Cases

Perfect for:
- **Component unmounting** - Clean up styles when components are destroyed
- **Dynamic styling** - Remove old styles before applying new ones
- **Long-running applications** - Prevent CSS accumulation over time
- **Testing** - Ensure clean state between test runs

### Global Styles

```jsx
// Global styles require matching global flag
css(globalStyles, { global: true });
cssRemove(globalStyles, { global: true }); // Must include global: true
```
