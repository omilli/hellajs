# removeKeyframes

Removes a `@keyframes` rule registered by `keyframes()` and decrements its reference count. The rule leaves the stylesheet when the count reaches zero; above it it stays.

## Basic Usage

```typescript
import { keyframes, removeKeyframes } from '@hellajs/css';

const spin = keyframes({
  from: {
    transform: 'rotate(0deg)',
  },
  to: {
    transform: 'rotate(360deg)',
  },
});

// Later, when the animation is no longer needed; key order never matters
removeKeyframes({
  to: {
    transform: 'rotate(360deg)',
  },
  from: {
    transform: 'rotate(0deg)',
  },
});
```

## API

```typescript
function removeKeyframes(obj: KeyframesObject): void
```
- `obj`: Keyframes object to remove (structurally identical objects match, same reference not required)
- **Returns**: `void`

## Key Concepts

### Reference Counting

Each `keyframes()` call with a structurally equal object bumps one reference count and reuses one rule; each `removeKeyframes` decrements it. The rule persists until the last reference drops.

```typescript
import { keyframes, removeKeyframes } from '@hellajs/css';

const steps = {
  from: {
    opacity: '0',
  },
  to: {
    opacity: '1',
  },
};

keyframes(steps); // refCount = 1
keyframes(steps); // refCount = 2; same name, one rule

removeKeyframes(steps); // refCount = 1, rule still present
removeKeyframes(steps); // refCount = 0, rule removed
```

### Deterministic Re-Derivation

The name and rule text are re-derived from the object through the same canonical transform [`keyframes`](/reference/css/keyframes) uses (steps key-sorted before hashing), so structurally identical objects locate the registration in any key order. No reference needs to be held. On the server (no DOM) the decrement still runs; only the sheet write is DOM-gated.

## Important Considerations

### Unknown Input

`removeKeyframes` is a no-op for inputs not previously registered by a `keyframes` call: no throw, no stylesheet change.

For clearing every css-side registration at once, use [`resetCss`](/reference/css/resetcss).
