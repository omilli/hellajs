# resetCssVars

Clears all CSS variables, caches, and reactive effects, resetting the CSS variables system to initial state.

## API

```typescript
function resetCssVars(): void
```
- **Returns**: `void`

## Basic Usage


```jsx
import { cssVars, resetCssVars } from '@hellajs/css';

// Create some CSS variables
const theme = cssVars({
  colors: { primary: '#3b82f6', secondary: '#64748b' },
  spacing: { base: '1rem', large: '2rem' }
});

// Later, reset everything
resetCssVars();

// All CSS variables are removed from DOM and memory
// All reactive effects are disposed
```

## Key Concepts

### Complete System Reset

The `resetCssVars` function provides complete cleanup of the CSS variables system:

- **CSS Variables**: Clears all CSS custom properties from the `hella-vars` style element
- **Cache Cleanup**: Clears all cached variable objects and hash mappings
- **Reactive Effects**: Disposes all active reactive effects created by `cssVars`
- **Memory Management**: Frees all internal references and prevents memory leaks

### Testing Scenarios

```jsx
import { cssVars, resetCssVars } from '@hellajs/css';

// Clean slate before creating variables
resetCssVars();

const theme = cssVars({
  colors: { primary: '#ff0000' }
});

// theme.colors.primary === 'var(--colors-primary)'
// document.getElementById('hella-vars')?.sheet?.cssRules[0]?.cssText includes '--colors-primary: #ff0000'
```

### Reactive Effects Cleanup

```jsx
import { signal } from '@hellajs/core';
import { cssVars, resetCssVars } from '@hellajs/css';

const primaryColor = signal('#3b82f6');
const isDark = signal(false);

const theme = cssVars({
  colors: {
    primary: primaryColor,
    background: () => isDark() ? '#1a1a1a' : '#ffffff'
  }
});

resetCssVars();

primaryColor('#ff0000'); // No CSS update after reset
isDark(true);           // No CSS update after reset
```

### Integration with resetCss

```jsx
import { resetCss, resetCssVars } from '@hellajs/css';

// Complete CSS system reset
const resetAllCSS = () => {
  resetCss();      // Clear CSS rules and styles
  resetCssVars();  // Clear CSS variables and effects
};
```

### Safety

- **Non-destructive** - Only affects HellaJS CSS variables
- **Signal preservation** - Does not affect original signals, only CSS effects
- **Isolation** - Does not impact other CSS systems or frameworks
