# removeVars

Removes CSS custom properties registered by [`vars`](/reference/css/vars) and decrements the reference count. The declarations leave the stylesheet when the count reaches zero; above it they stay.

## Basic Usage

```jsx
import { removeVars, vars } from '@hellajs/css';

vars({
  colors: {
    primary: 'red',
    secondary: 'blue',
  },
});

// Later, when the tokens are no longer needed; structurally equal object
removeVars({
  colors: {
    primary: 'red',
    secondary: 'blue',
  },
});
```

## API

```typescript
function removeVars<T extends CSSVarInputObject>(vars: T, options?: VarsOptions): void
```
- `vars`: Object containing CSS variable definitions. For reactive vars, must be the same reference passed to `vars`; for static vars, a structurally equal object matches by hash
- `options`: Optional configuration. Reactive entries are matched by reference and use the options recorded at the first `vars` call; `options` is consulted only to locate the static entry by hash
- **Returns**: `void`

## Key Concepts

### Static Removal Matches by Structure

Static vars (no function leaves) register by a hash of the object and its options, so a structurally equal object removes them regardless of reference identity. The `options` must match the creating call (`scoped`, `prefix`, `host` all feed the hash):

```jsx
import { removeVars, vars } from '@hellajs/css';

vars({
  color: 'red',
}, {
  scoped: '.card',
  prefix: 'ui',
});

removeVars({
  color: 'red',
}, {
  scoped: '.card',
  prefix: 'ui',
}); // ✅ same hash; matches

removeVars({
  color: 'red',
}); // ❌ different hash; no-op
```

### Reactive Removal Matches by Reference

Reactive vars (any function leaf) register by object reference. Hold the original object and pass that same reference to remove; a structurally equal copy locates nothing.

```jsx
import { signal } from '@hellajs/core';
import { removeVars, vars } from '@hellajs/css';

const color = signal('red');
const tokens = {
  primary: color,
};

vars(tokens); // refCount = 1, one reactive effect

removeVars(tokens); // refCount = 0, effect disposed, declaration dropped

color('blue'); // No stylesheet update; no longer tracked
```

Disposal stops the stylesheet updates; the signals themselves keep their values and every other consumer.

### Scopes Keep Their Remainder

Multiple `vars()` calls writing the same scope merge their keys. `removeVars` removes only the keys of the registration it matches; other calls' contributions survive.

```jsx
import { removeVars, vars } from '@hellajs/css';

vars({
  theme: {
    primary: 'red',
  },
});
vars({
  spacing: {
    small: '0.5rem',
  },
});

removeVars({
  theme: {
    primary: 'red',
  },
});
// --spacing-small remains registered
```

## Important Considerations

### Unknown Input

`removeVars` is a no-op for inputs not previously registered by a `vars` call: no throw, no stylesheet change.

### Bulk Reset

[`resetVars`](/reference/css/resetvars) is the nuclear option: it clears all variables, caches, and reactive effects in one go. `removeVars` is the granular alternative for per-call cleanup.
