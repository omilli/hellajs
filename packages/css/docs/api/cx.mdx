# cx

Joins class-name fragments into one space-separated string, clsx-compatible, with no styling side effects.

## Basic Usage

```typescript
import { cx } from '@hellajs/css';

const isHighlighted = true;
const isDisabled = false;

cx('card', isHighlighted && 'card-highlight', {
  'card-disabled': isDisabled,
});
// "card card-highlight"
```

## API

```typescript
function cx(...args: CXArg[]): string
```
- `args`: Fragments to join: strings and numbers contribute themselves, falsy values drop, objects contribute the keys whose values are truthy, and arrays recurse
- **Returns**: The joined class string, `""` when nothing survives

## Key Concepts

### What Joins

- Strings join verbatim; numbers stringify (`cx('col', 4)` gives `"col 4"`)
- Falsy values drop: `false`, `null`, `undefined`, `0`, `""` never reach the output
- Objects keep the keys whose values are truthy; only key names join, value shapes are ignored
- Arrays recurse to any depth; falsy items and empty results contribute nothing

```typescript
import { cx } from '@hellajs/css';

cx('menu', ['item', ['selected', null]], {
  hidden: false,
  active: true,
}, 0);
// "menu item selected active"
```

### Composing Recipes and Styles

[`cva`](/reference/css/cva) recipes and [`style`](/reference/css/style) classes are plain strings; `cx` is the join point when several sources feed one `class` attribute.

```jsx
import { cx, cva } from '@hellajs/css';

const button = cva({
  base: {
    cursor: 'pointer',
  },
  variants: {
    size: {
      sm: {
        padding: '0.25rem',
      },
      lg: {
        padding: '0.75rem',
      },
    },
  },
});
const isFullWidth = true;

<div class={cx(
  button({
    size: 'lg',
  }),
  isFullWidth && 'w-full',
)}>
  Save
</div>
```

The `class` attribute also accepts an array of fragments, so inside a template the two overlap: both re-derive when the signals they read change. `cx` earns its call when you need the keyed object form, nested arrays, or the string outside a template, as a recipe `base`, a stored value, or a class for another framework.

## Important Considerations

### No Styling Side Effects

`cx` generates and registers nothing; it never touches the stylesheet. Every fragment it joins must already exist: a recipe class from `cva`, a hashed class from `style`, or an external class.

### A Hoisted Result Never Updates

`cx` returns a plain string, not a live binding. Resolving it into a variable and binding that variable freezes the class at its first value; keep the `cx()` call inside the `class` attribute so it re-derives on change. The [Styling concept](/learn/concepts/styling#joining-classes) shows both forms.
