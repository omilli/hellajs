# css

Creates global CSS rules from JavaScript objects. Every top-level key is a raw selector or at-rule; the call registers the rules and returns an empty string on both platforms. For styles scoped to a component, use [`style`](/reference/css/style).

## Basic Usage

```jsx
import { css } from '@hellajs/css';

css({
  body: {
    margin: 0,
    fontFamily: 'system-ui, sans-serif',
  },
  '*': {
    boxSizing: 'border-box',
  },
});
```

On the client the rules are injected into the CSSOM. On the server the registration is state-only; [`cssText`](/reference/css/csstext) collects the text for the response's `<style>` tag.

## API

```typescript
function css(obj: CSSObject, options?: CSSOptions): string
```
- `obj`: CSS object containing style properties and nested selectors
- `options`: Optional configuration
  - `host`: Node the `<style>` element is created in, e.g. a `ShadowRoot` for web components. Defaults to `document.head`
- **Returns**: Always `""`, on both platforms. The generated text is never the return value; it lives in `cssText()`

## Key Concepts

### Nested Selectors

Nested keys compose against the active selector: `&` refers to it at every occurrence, plain keys become descendants, and conditional at-rules inherit it.

```jsx
import { css } from '@hellajs/css';

css({
  '.card': {
    padding: '1rem',
    borderRadius: '0.5rem',
    '&:hover': {
      transform: 'translateY(-2px)',
    },
    'h2': {
      margin: '0 0 0.5rem 0',
      fontSize: '1.25rem',
    },
    '@media (max-width: 768px)': {
      padding: '0.75rem',
    },
  },
});
// Generated:
// .card { padding: 1rem; border-radius: 0.5rem; }
// .card:hover { transform: translateY(-2px); }
// .card h2 { margin: 0 0 0.5rem 0; font-size: 1.25rem; }
// @media (max-width: 768px) { .card { padding: 0.75rem; } }
```

### At-Rules

Every CSS `@` rule works as a key. Two kinds behave differently:

- **Conditional** (`@media`, `@container`, `@supports`, `@starting-style`): inherits the selector it is nested under. At the top level it must contain selectors, not direct declarations, or the call throws.
- **Definitional** (`@keyframes`, `@font-face`, `@layer`): always global. Direct declarations inside the body are their normal shape.

```jsx
import { css } from '@hellajs/css';

css({
  '@font-face': {
    fontFamily: '"Inter"',
    src: 'url("/fonts/inter.woff2") format("woff2")',
  },
  '@container (min-width: 400px)': {
    '.card': {
      fontSize: '1.25rem',
    },
  },
  '.sidebar': {
    '@media (min-width: 768px)': {
      width: '16rem',
    },
  },
});
// @media (min-width: 768px) { .sidebar { width: 16rem; } }
// (the at-rule inherits .sidebar)
```

`@import` and other block-less statements take a scalar value and hoist ahead of every braced rule regardless of key order, because statements must precede rules:

```jsx
import { css } from '@hellajs/css';

css({
  body: {
    margin: 0,
  },
  '@import': 'url("fonts.css")',
});
// @import url("fonts.css");
// body { margin: 0px; }
```

### Value Rules

Property names and values are fully typed with `csstype`, so typos fail at compile time. At runtime:

- Numbers append `px`, except on unitless properties (`zIndex`, `opacity`, `lineHeight`, `flexGrow`, ...) and `--` custom properties
- Array values join with commas (font stacks, transition lists)
- `content` auto-quotes unquoted strings
- `null` and `undefined` values drop
- camelCase keys convert to kebab-case

```jsx
import { css } from '@hellajs/css';

css({
  '.stack': {
    fontFamily: ['Helvetica', 'Arial', 'sans-serif'],
    transition: ['color 0.2s', 'background 0.3s'],
  },
  '.meter': {
    width: 5,
    zIndex: 10,
    opacity: 0.5,
    lineHeight: 1.5,
    '--gap': 4,
  },
  '.label': {
    '&::before': {
      content: 'arrow',
    },
  },
});
// .stack { font-family: Helvetica, Arial, sans-serif;
//          transition: color 0.2s, background 0.3s; }
// .meter  { width: 5px; z-index: 10; opacity: 0.5;
//           line-height: 1.5; --gap: 4; }
// .label::before { content: "arrow"; }
```

Quoted values may contain braces; a `}` inside a string never truncates a rule.

### Shared Registrations

The generated text is the registration identity: every `css()` call producing the same text lands on one registration and increments its reference count. Three calls need three [`removeCss`](/reference/css/removecss) calls before the rules leave the stylesheet. Structurally equal objects in any key order match the same registration.

### Shadow DOM Hosts

Pass `host` to create the `<style>` element inside a shadow root instead of `document.head`. Sheets are per host: the same styles injected into two hosts produce two independent `<style>` elements with separate reference counting, and [`removeCss`](/reference/css/removecss) with the same `host` removes from that host's sheet.

```typescript
import { css, vars } from '@hellajs/css';

class MyCard extends HTMLElement {
  connectedCallback() {
    const root = this.attachShadow({
      mode: 'open',
    });

    // Shadow roots don't match :root; scope the vars to the host element
    const theme = vars({
      accent: '#3b82f6',
    }, {
      host: root,
      scoped: ':host',
    });

    css({
      ':host': {
        display: 'block',
        padding: '1rem',
      },
      ':host > .content': {
        border: '1px solid #e5e7eb',
      },
    }, {
      host: root,
    });

    root.innerHTML = '<div class="content"><slot></slot></div>';
  }
}
customElements.define('my-card', MyCard);
```

Styles injected with a `host` never reach `document.head`, and `resetCss()` clears only the document sheet; hosted sheets are abandoned, not cleared.

## Important Considerations

### Declarations Need a Selector

A declaration with no selector in scope would be silently dropped by the browser, so `css()` rejects it loudly instead. The same object throws in [`removeCss`](/reference/css/removecss) and on the server; the check runs before any platform branching.

```jsx
// ❌ Throws: top-level declarations have no selector
css({
  color: 'red',
});
// Error: [css] top-level declarations have no selector;
//        nest them under a selector or at-rule

// ❌ Throws: a top-level conditional at-rule has no selector to inherit
css({
  '@media (min-width: 1px)': {
    color: 'red',
  },
});
// Error: [css] conditional at-rule "@media (min-width: 1px)" contains
//        declarations with no selector; nest selectors under the at-rule

// ✅ Nest under a selector
css({
  body: {
    '@media (min-width: 1px)': {
      color: 'red',
    },
  },
});
```

### Comma Groups Compose Per Part

Every part of a comma-separated nested key composes against the parent on its own: a part carrying `&` substitutes it at every occurrence, a part without one becomes a descendant. No part escapes the scope, and no `&` repetition is needed.

```jsx
import { css } from '@hellajs/css';

// ✅ Both parts scoped; no & repetition
// Generated: .toolbar .copy, .toolbar .toggle { color: var(--fg); }
css({
  '.toolbar': {
    '.copy, .toggle': {
      color: 'var(--fg)',
    },
  },
});

// ✅ & composes non-descendant parts (pseudo-states, compounds)
// Generated: .toolbar:hover, .toolbar:focus-within { … }
css({
  '.toolbar': {
    '&:hover, &:focus-within': {
      outline: '1px solid var(--fg)',
    },
  },
});
```

Commas inside parens, brackets, or quoted strings never split a part (`:is(a, b)` and `[data-tags='a,b']` stay whole). One caveat: a nested `&` under a comma-group parent substitutes the whole parent list verbatim, so `&:hover` under `'h1, h2'` pins the hover to the last part; keep state selectors inside per-element rules.

### Function Values Throw

`css()` evaluates values eagerly; a function passed as a property value throws at any nesting depth, on both platforms. Reactive values travel through [`vars`](/reference/css/vars) instead:

```typescript
import { signal } from '@hellajs/core';
import { css, vars } from '@hellajs/css';

const spacing = signal('1rem');

// ❌ Throws; css() never calls property functions
try {
  css({
    '.card': {
      padding: () => spacing(),
    },
  });
} catch {}

// ✅ Reactive values are vars leaves
const theme = vars({
  spacing: () => spacing(),
});
// theme.spacing === 'var(--spacing)'
```

### Platform-Rejected Rules Log a Warning

Injection goes through the CSSOM, so a rule the platform cannot parse is skipped rather than injected via a text fallback. When that happens the call logs a `console.warn` naming the dropped rule; the absence from the stylesheet is deliberate, not a silent failure. Rejections surface mostly in constrained test DOMs (some reject `@layer`); in a browser they point at genuinely invalid CSS.
