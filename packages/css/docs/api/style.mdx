# style

Creates a scoped style from a declarations-first object and returns a content-hashed class name, the same string on client and server.

## Basic Usage

```jsx
import { style } from '@hellajs/css';

const card = style('card', {
  padding: '1rem',
  borderRadius: '0.5rem',
  backgroundColor: '#f8f9fa',
  'h2': {
    margin: '0 0 0.5rem 0',
  },
  '&:hover': {
    backgroundColor: '#e9ecef',
  },
  '@media (max-width: 768px)': {
    padding: '0.5rem',
  },
});
// "card-izfpuyv"; client AND server derive the same class

const Card = ({ title }: { title: string }) => (
  <div class={card}>
    <h2>{title}</h2>
  </div>
);
```

The string argument is a label for readable class names. The equivalent options-bag form:

```jsx
import { style } from '@hellajs/css';

const card = style({
  padding: '1rem',
  borderRadius: '0.5rem',
}, {
  label: 'card',
});
```

## API

```typescript
// From a single style object
function style(obj: StyleObject, options?: StyleOptions): string;

// Positional label: the string wins over a bag `label`
function style(label: string, obj: StyleObject, options?: StyleOptions): string;

// Composition: an object base plus an override
function style(base: StyleObject, override: StyleObject, options?: StyleOptions): string;
```
- `obj`: Style object to scope under the generated class
- `label`: Readable segment embedded in the class name; wins over a bag `label`
- `base`: Style object to compose onto
- `override`: Style object contributing the new declarations
- `options`: Optional configuration
  - `label`: Segment embedded in the class name (`{label}-{hash}`), sanitized to `[a-zA-Z0-9-]`; a label empty after sanitization is treated as absent
  - `layer`: Cascade layer name the emitted rules wrap in (`@layer <name>`). Unlayered author CSS beats layered rules, so consumer overrides win by construction; composes outermost of `@media` when both apply
  - `host`: Node the `<style>` element is created in, e.g. a `ShadowRoot` for web components. Defaults to `document.head`
- **Returns**: The class name (`{label}-{hash}`, a bare letter-only hash without a label) for `class` attributes

## Key Concepts

### Content-Hashed Class Names

The class is a hash of the object's contents, never a name you invent: no collisions between components, no coordination between server and client. The same object always produces the same class, and key order never matters.

```jsx
import { style } from '@hellajs/css';

const primary = style({
  color: 'blue',
}, {
  label: 'text',
});
const again = style({
  color: 'blue',
}, {
  label: 'text',
});
// primary === again; identical content, identical class
```

The label rides in front of the hash for humans; it does not affect which rule the class points at (see [Same Object, Different Labels](#same-object-different-labels)).

### Nested Selectors

Nested keys compose against the generated class: `&` refers to it at every occurrence, plain keys become descendants, and conditional at-rules (`@media`, `@container`, `@supports`, `@starting-style`) inherit it. Definitional at-rules (`@keyframes`, `@font-face`, `@layer`) stay global.

```jsx
import { style } from '@hellajs/css';

const article = style('article', {
  lineHeight: 1.6,
  'p': {
    margin: '0 0 1rem 0',
  },
  '&:first-child': {
    marginTop: 0,
  },
  'h2, h3': {
    fontWeight: 600,
  },
});
// .article-… p { … }
// .article-…:first-child { … }
// .article-… h2, .article-… h3 { … }
```

Every part of a comma group composes on its own, so no part escapes the scope. Value rules match [`css`](/reference/css/css) exactly: numbers append `px` (unitless properties excepted), array values join with commas, `content` auto-quotes strings, and `null`/`undefined` values drop.

### Composition

A second object argument deep-merges into the first and returns one class. The typical shape is a base object authored once and reused, plus a small override: the override wins, nested selector blocks merge key by key, and arrays replace. Class strings join with [`cx`](/reference/css/cx) instead.

```jsx
import { cx, style } from '@hellajs/css';

// Shared base, authored once and reused by every variant
const fieldBase = {
  padding: '0.75rem',
  borderRadius: '0.5rem',
  border: '1px solid #d1d5db',
  '&:focus': {
    borderColor: '#3b82f6',
  },
};

// One merged class: the focus block merges key by key,
// the red borderColor wins over the base's blue
const errorField = style(fieldBase, {
  borderColor: '#dc2626',
  '&:focus': {
    borderColor: '#dc2626',
  },
});

// Two classes, two rules; cx joins the strings
const card = style('card', {
  padding: '1rem',
});
const alert = cx(
  card,
  style('alert', {
    border: '1px solid #dc2626',
  }),
);
// "card-… alert-…"
```

### Identical on Both Platforms

`style()` returns the class string everywhere. On the client the rules are injected into the CSSOM; on the server the registration is state-only and [`cssText`](/reference/css/csstext) collects the rule text for the response's `<style>` tag.

```typescript
import { cssText, style } from '@hellajs/css';

const card = style({
  background: 'white',
}, {
  label: 'card',
});

// Server: the class string, never the CSS text
const head = `<style id="hella-css">${cssText()}</style>`;
```

## Important Considerations

### Function Values Throw

Style objects are static: a function passed as a property value throws, at any nesting depth, on both platforms. Reactive values belong in [`vars`](/reference/css/vars); for classes that change with state, resolve the condition before the call.

```jsx
// ❌ Throws; functions are not CSS values
try {
  style({
    padding: () => '1rem',
  });
} catch {}

// ✅ Resolve conditions outside the object, pick classes at the attribute
const compactBtn = style({
  padding: '0.5rem',
});
// class={isCompact() ? compactBtn : regularBtn}
```

### Same Object, Different Labels

The hash covers the object only, never the label: the same object with different labels produces two classes whose rule bodies are identical. Each registers its own rule; use one label per distinct style.

```jsx
import { style } from '@hellajs/css';

const primary = style({
  color: 'blue',
}, {
  label: 'primary',
});
const info = style({
  color: 'blue',
}, {
  label: 'info',
});
// Two classes, two identical rules
```

### Removal

Every registration holds a reference count. [`removeStyle`](/reference/css/removestyle) with the same arguments decrements it and drops the rule at zero; [`resetCss`](/reference/css/resetcss) clears every css-side registration at once. Removing a DOM node that used the class does not decrement anything: call `removeStyle` for styles tied to a component's lifetime.
