# resetVars

Clears every CSS-variable registration, cache, and reactive effect, resetting the vars system to its initial state. Css-side registrations (`css()`, `style()`, `keyframes()`) are untouched.

## Basic Usage

```jsx
import { resetVars, vars } from '@hellajs/css';

const theme = vars({
  colors: {
    primary: '#3b82f6',
  },
  spacing: {
    base: '1rem',
  },
});

// Later: every vars registration goes at once
resetVars();

// All declarations are removed from the sheet; all effects are disposed
```

## API

```typescript
function resetVars(): void
```
- **Returns**: `void`

## Key Concepts

### What the Reset Covers

`resetVars()` disposes every reactive effect [`vars`](/reference/css/vars) created, clears the vars registries and the static cache, and empties the `hella-vars` style element. The reset is vars-side only: css-side registrations ([`css`](/reference/css/css), [`style`](/reference/css/style), [`keyframes`](/reference/css/keyframes)) are untouched; call [`resetCss`](/reference/css/resetcss) for those.

```jsx
import { vars, resetVars } from '@hellajs/css';

const theme = vars({
  primary: '#ff0000',
});

resetVars();

// theme.primary === 'var(--primary)' still; a var() reference is a plain
// string, but its --primary declaration is gone from the sheet
```

### Reactive Effects Stop Updating

Disposing the effects stops stylesheet updates; the signals themselves keep their values and every other consumer:

```jsx
import { signal } from '@hellajs/core';
import { resetVars, vars } from '@hellajs/css';

const primaryColor = signal('#3b82f6');
const isDark = signal(false);

const theme = vars({
  primary: primaryColor,
  background: () => isDark() ? '#1a1a1a' : '#ffffff',
});

resetVars();

primaryColor('#ff0000'); // No CSS update after reset
isDark(true);            // No CSS update after reset
```

## Important Considerations

### When to Reach for It

Use `resetVars()` when every vars registration should go at once: between test runs, or when tearing down an app instance that owned its theme. For removing one registration while the rest live on, use [`removeVars`](/reference/css/removevars) (reactive entries dispose their effect at zero references). For a complete reset of both sides, pair it with [`resetCss`](/reference/css/resetcss).

### Safety

Only HellaJS CSS variables are affected: the reset never touches external stylesheets, and the signals feeding reactive vars keep working for every other consumer; only the CSS effects are disposed.
