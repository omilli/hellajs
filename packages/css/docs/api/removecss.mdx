# removeCss

Removes specific CSS rules and decrements their reference count for memory management. Client-only; a no-op on the server (no DOM).

## API

```typescript
function removeCss(obj: CSSObject, options?: CSSOptions): void
```
- `obj`: CSS object to remove (structurally identical objects match)
- `options`: Optional configuration object (must match the options used in `css()`)
  - `host`: Parent node the style was injected into — a removal without the same `host` targets a different entry
- **Returns**: `void`

## Basic Usage

```jsx
import { css, removeCss } from '@hellajs/css';

const styles = { body: { margin: 0, fontFamily: 'system-ui' } };

// Inject the style
css(styles);

// Later, remove it when no longer needed
removeCss(styles);
```

## Key Concepts

### Reference Counting

The `removeCss` function provides precise control over CSS rule lifecycle:

- **Reference Counting**: Each `css()` call increments the reference count for the style
- **Automatic Cleanup**: Removes CSS rules from DOM when reference count reaches zero
- **Memory Management**: Frees memory used by unused styles
- **Cache Cleanup**: Drops the style's entry from the injected-rules map when the count reaches zero

### Usage Pattern

Styles are deduplicated via memoization: all `css()` calls with the same object use the same registration. Each call increments the reference count, so `removeCss()` must be called the same number of times to fully remove the style.

```jsx
import { css, removeCss } from '@hellajs/css';

const sharedStyle = {
  body: { display: 'flex', alignItems: 'center' }
};

// Each call increments the reference count: CSS is injected once
css(sharedStyle); // refCount = 1
css(sharedStyle); // refCount = 2
css(sharedStyle); // refCount = 3

// Remove one reference: style persists (refCount = 2)
removeCss(sharedStyle);

// Remove remaining references to fully clear
removeCss(sharedStyle);
removeCss(sharedStyle); // refCount = 0, CSS removed from DOM
```

### With Host

```jsx
import { css, removeCss } from '@hellajs/css';

const el = document.createElement('my-card');
document.body.appendChild(el);
const shadowRoot = el.attachShadow({ mode: 'open' });

css({ ':host': { fontSize: '1.5rem', padding: '1rem' } }, { host: shadowRoot });

// Later remove with matching host
removeCss({ ':host': { fontSize: '1.5rem', padding: '1rem' } }, { host: shadowRoot });
```

### Component Cleanup

```jsx
import { css, removeCss } from '@hellajs/css';

const MyComponent = () => {
  const styleObjects = [
    { body: { background: 'white', padding: '1rem' } },
    { h1: { color: 'blue', fontWeight: 'bold' } },
    { '.card': { border: '1px solid #ccc', borderRadius: '4px' } }
  ];

  styleObjects.forEach(obj => css(obj));

  const destroy = () => {
    styleObjects.forEach(obj => removeCss(obj));
  };

  return (
    <div class="card">
      <h1>Styled component</h1>
    </div>
  );
};
```

### Dynamic Style Management

```jsx
import { signal } from '@hellajs/core';
import { css, removeCss } from '@hellajs/css';

type ThemeStyles = { 'body': { background: string; color: string } };

let currentTheme: ThemeStyles | null = null;

const applyTheme = (colors: { background: string; text: string }) => {
  // Remove old theme if exists
  if (currentTheme) {
    removeCss(currentTheme);
  }

  // Apply new theme, store for removal on next switch
  currentTheme = {
    body: { background: colors.background, color: colors.text }
  };

  css(currentTheme);
};

// Switch themes
applyTheme({ background: '#fff', text: '#000' });
applyTheme({ background: '#000', text: '#fff' });
```

## Important Considerations

### Exact Matching Required

`removeCss()` re-derives the CSS text from `(obj, options)` using the same deterministic transform as [`css`](/reference/css/css) — no hash key or cached reference needed. Structurally identical objects produce the same text and match:

```jsx
// ✅ Works - structurally identical objects match
css({ body: { margin: '0' } });
removeCss({ body: { margin: '0' } }); // Same CSS text

// ✅ Works - same reference (also works, and is clearer)
const style = { body: { margin: '0' } };
css(style);
removeCss(style);

// ❌ Won't work - different CSS content
css({ body: { margin: '0' } });
removeCss({ body: { margin: '1rem' } }); // Different CSS text
```

### Function Values Throw

`removeCss()` re-derives the CSS text through the same transform as [`css`](/reference/css/css), so an object containing a function property value throws here too — the same error both entry points report. Build reactive values with [`vars`](/reference/css/vars) instead:

```jsx
// ❌ Throws — functions are not CSS values in css() or removeCss()
try {
  removeCss({ padding: () => '1rem' });
} catch {}
// Error: [css] function values are not supported in css objects —
//        use vars() for reactive values, key: padding
```

### Use Cases

Perfect for:
- **Component unmounting** - Clean up styles when components are destroyed
- **Dynamic styling** - Remove old styles before applying new ones
- **Long-running applications** - Prevent CSS accumulation over time
- **Testing** - Ensure clean state between test runs

For bulk cleanup of all styles at once, use [`resetCss`](/reference/css/resetcss) instead.

### Global Styles

```jsx
const globalStyles = { body: { margin: '0', fontFamily: 'system-ui, sans-serif' } };

// Global styles don't need any options
css(globalStyles);
removeCss(globalStyles);
```
