# removeCss

Removes rules registered by [`css`](/reference/css/css) and decrements their reference count. The rules leave the stylesheet when the count reaches zero; above it they stay injected.

## Basic Usage

```jsx
import { css, removeCss } from '@hellajs/css';

const styles = {
  body: {
    margin: 0,
    fontFamily: 'system-ui',
  },
};

css(styles);

// Later, when the rules are no longer needed
removeCss(styles);
```

## API

```typescript
function removeCss(obj: CSSObject, options?: CSSOptions): void
```
- `obj`: CSS object to remove (structurally identical objects match, same reference not required)
- `options`: Optional configuration, must match the options used in `css()`
  - `host`: Node the rules were injected into; a removal without the same `host` targets a different entry
- **Returns**: `void`

## Key Concepts

### Reference Counting

All `css()` calls deriving the same text land on one registration; each call increments the count, each `removeCss` decrements it, and the rules leave the stylesheet at zero.

```jsx
import { css, removeCss } from '@hellajs/css';

const sharedStyle = {
  body: {
    display: 'flex',
    alignItems: 'center',
  },
};

css(sharedStyle); // refCount = 1, injected once
css(sharedStyle); // refCount = 2

removeCss(sharedStyle); // refCount = 1, rules stay
removeCss(sharedStyle); // refCount = 0, rules removed
```

For styles tied to a component's lifetime, keep the objects together and remove them together when it goes away.

### Deterministic Matching

The CSS text is re-derived from `(obj, options)` through the same transform `css` uses, so structurally identical objects in any key order locate the registration; no reference needs to be held. On the server (no DOM) the decrement still runs; only the sheet write is DOM-gated.

### Removing from a Host

Styles injected with a `host` option (e.g. a shadow root) remove from that host only when the same `host` is passed:

```jsx
import { css, removeCss } from '@hellajs/css';

const el = document.createElement('my-card');
document.body.appendChild(el);
const shadowRoot = el.attachShadow({
  mode: 'open',
});

css({
  ':host': {
    padding: '1rem',
  },
}, {
  host: shadowRoot,
});

removeCss({
  ':host': {
    padding: '1rem',
  },
}, {
  host: shadowRoot,
});
```

## Important Considerations

### Mismatched Arguments Miss

A removal that derives different text finds no entry: it is a no-op, never a throw. Every option (`host` included) must match the creating call.

### Function Values Throw

`removeCss` re-derives the text through the same transform as `css`, so an object containing a function property value throws here too, with the same error both entry points report. Build reactive values with [`vars`](/reference/css/vars) instead.

For clearing every css-side registration at once, use [`resetCss`](/reference/css/resetcss).
