# removeCss

Removes specific CSS rules and decrements their reference count for memory management. Registration state is decremented on both platforms; the CSSOM rules drop at zero references (a no-op without a DOM).

## Basic Usage

```jsx
import { css, removeCss } from '@hellajs/css';

const styles = {
  body: {
    margin: 0,
    fontFamily: 'system-ui',
  },
};

// Inject the style
css(styles);

// Later, remove it when no longer needed
removeCss(styles);
```

## API

```typescript
function removeCss(obj: CSSObject, options?: CSSOptions): void
```
- `obj`: CSS object to remove (structurally identical objects match)
- `options`: Optional configuration object (must match the options used in `css()`)
  - `host`: Parent node the style was injected into; a removal without the same `host` targets a different entry
- **Returns**: `void`

## Key Concepts

### Reference Counting

Each `css()` call increments the reference count of the registration its text resolves to; each `removeCss()` call decrements it. The rules leave the stylesheet when the count reaches zero, and stay injected above it.

### Usage Pattern

Styles are deduplicated by their derived text: all `css()` calls with the same object land on the same registration. Each call increments the reference count, so `removeCss()` must be called the same number of times to fully remove the style.

```jsx
import { css, removeCss } from '@hellajs/css';

const sharedStyle = {
  body: {
    display: 'flex',
    alignItems: 'center',
  },
};

// Each call increments the reference count: CSS is injected once
css(sharedStyle); // refCount = 1
css(sharedStyle); // refCount = 2
css(sharedStyle); // refCount = 3

// Remove one reference: style persists (refCount = 2)
removeCss(sharedStyle);

// Remove remaining references to fully clear
removeCss(sharedStyle);
removeCss(sharedStyle); // refCount = 0, CSS removed from DOM
```

For styles tied to a component's lifetime, keep the objects together and remove them together when it goes away; for clearing everything at once, use [`resetCss`](/reference/css/resetcss) instead.

### With Host

```jsx
import { css, removeCss } from '@hellajs/css';

const el = document.createElement('my-card');
document.body.appendChild(el);
const shadowRoot = el.attachShadow({
  mode: 'open',
});

css(
  {
    ':host': {
      fontSize: '1.5rem',
      padding: '1rem',
    },
  },
  {
    host: shadowRoot,
  },
);

// Later remove with matching host
removeCss(
  {
    ':host': {
      fontSize: '1.5rem',
      padding: '1rem',
    },
  },
  {
    host: shadowRoot,
  },
);
```

### Component Cleanup

```jsx
import { css, removeCss } from '@hellajs/css';

const overlayStyles = {
  '.overlay': {
    position: 'fixed',
    inset: 0,
  },
};

const Overlay = () => {
  css(overlayStyles);

  const destroy = () => removeCss(overlayStyles);

  return (
    <div class="overlay" on:click={destroy}>
      Click to dismiss
    </div>
  );
};
```

### Dynamic Style Management

```typescript
import { css, removeCss } from '@hellajs/css';

type ThemeStyles = { 'body': { background: string; color: string } };

let currentTheme: ThemeStyles | null = null;

const applyTheme = (colors: { background: string; text: string }) => {
  // Remove old theme if exists
  if (currentTheme) {
    removeCss(currentTheme);
  }

  // Apply new theme, store for removal on next switch
  currentTheme = {
    body: {
      background: colors.background,
      color: colors.text,
    },
  };

  css(currentTheme);
};

// Switch themes
applyTheme({
  background: '#fff',
  text: '#000',
});
applyTheme({
  background: '#000',
  text: '#fff',
});
```

## Important Considerations

### Exact Matching Required

`removeCss()` re-derives the CSS text from `(obj, options)` using the same deterministic transform as [`css`](/reference/css/css); no hash key or cached reference needed. Structurally identical objects produce the same text and match:

```jsx
// ✅ Works - structurally identical objects match
css({
  body: {
    margin: '0',
  },
});
removeCss({
  body: {
    margin: '0',
  },
}); // Same CSS text

// ✅ Works - same reference (also works, and is clearer)
const style = {
  body: {
    margin: '0',
  },
};
css(style);
removeCss(style);

// ❌ Won't work - different CSS content
css({
  body: {
    margin: '0',
  },
});
removeCss({
  body: {
    margin: '1rem',
  },
}); // Different CSS text
```

### Function Values Throw

`removeCss()` re-derives the CSS text through the same transform as [`css`](/reference/css/css), so an object containing a function property value throws here too, the same error both entry points report. Build reactive values with [`vars`](/reference/css/vars) instead:

```jsx
// ❌ Throws; functions are not CSS values in css() or removeCss()
try {
  removeCss({
    '.card': {
      padding: () => '1rem',
    },
  });
} catch {}
// Error: [css] function values are not supported in css objects
//        (message continues: use vars() for reactive values, key: padding)
```
