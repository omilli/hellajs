# removeStyle

Removes a style registered by [`style`](/reference/css/style) and decrements its reference count. The rules leave the stylesheet when the count reaches zero; above it they stay injected.

## Basic Usage

```jsx
import { removeStyle, style } from '@hellajs/css';

const buttonStyle = {
  background: 'blue',
  color: 'white',
  padding: '0.5rem 1rem',
};

const className = style(buttonStyle, {
  label: 'btn',
});

// Later, when the owning component goes away
removeStyle(buttonStyle, {
  label: 'btn',
});
```

## API

```typescript
// Remove a single-object style
function removeStyle(obj: StyleObject, options?: StyleOptions): void;

// Remove a labeled style (matching the style() label overload)
function removeStyle(label: string, obj: StyleObject, options?: StyleOptions): void;

// Remove a merged style (matching the style() array overload)
function removeStyle(objs: readonly StyleObject[], options?: StyleOptions): void;
```
- `obj`: Style object to remove (structurally identical objects match, same reference not required)
- `label`: Label used when creating the style; `removeStyle('card', obj)` matches `style('card', obj)`
- `objs`: The array passed to the matching `style()` call, in the same order (structurally identical objects match, same reference not required)
- `options`: Optional configuration, must match the options used in `style()`
  - `label`: Label used when creating the style
  - `host`: Node the style was injected into; a removal without the same `host` targets a different entry
- **Returns**: `void`

## Key Concepts

### Reference Counting

Every `style()` call whose arguments derive the same rule text lands on one registration and increments its count; every matching `removeStyle` decrements it. The rule persists until the last reference drops.

```jsx
import { removeStyle, style } from '@hellajs/css';

const sharedStyle = {
  display: 'flex',
  alignItems: 'center',
};

const classA = style(sharedStyle); // refCount = 1
const classB = style(sharedStyle); // refCount = 2, same class

removeStyle(sharedStyle); // refCount = 1, rule stays
removeStyle(sharedStyle); // refCount = 0, rule removed
```

Removing a DOM node that used the class does not decrement anything: call `removeStyle` yourself for styles tied to a component's lifetime.

### Deterministic Matching

The class and rule text are re-derived from the arguments through the same transform `style` uses, so no cached reference is needed: structurally identical objects in any key order locate the registration. On the server (no DOM) the decrement still runs; only the sheet write is DOM-gated.

## Important Considerations

### Mismatched Arguments Miss

A removal that derives different text simply finds no entry: it is a no-op, never a throw. The `label` and every option (`host` included) must match the creating call.

```jsx
// ✅ Matches; structurally identical objects derive the same text
removeStyle({
  color: 'red',
}, {
  label: 'x',
});

// ❌ Different content; no-op, never registered
removeStyle({
  color: 'blue',
}, {
  label: 'x',
});
```

### Function Values Throw

`removeStyle` re-derives the rule text through the same transform as `style`, so an object containing a function property value throws here too. Build reactive values with [`vars`](/reference/css/vars) instead.

For clearing every css-side registration at once, use [`resetCss`](/reference/css/resetcss).
