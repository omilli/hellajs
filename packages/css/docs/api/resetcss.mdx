# resetCss

Clears every css-side registration and resets the rules system to its initial state: all `css()`, `style()`, and `keyframes()` registrations, on both platforms. `vars()` registrations are untouched.

## Basic Usage

```jsx
import { resetCss, style } from '@hellajs/css';

const button = style({
  background: 'blue',
  color: 'white',
}, {
  label: 'btn',
});
const card = style({
  padding: '1rem',
}, {
  label: 'card',
});

// Later: everything css-side goes at once
resetCss();
```

## API

```typescript
function resetCss(): void
```
- **Returns**: `void`

## Key Concepts

### What the Reset Covers

`resetCss()` clears the css side only: the registration map (including `keyframes()` registrations and their reference counts) and the `hella-css` style element. Two isolation rules hold:

- [`vars`](/reference/css/vars) registrations and the `hella-vars` sheet are untouched; call [`resetVars`](/reference/css/resetvars) for those
- Hosted sheets (a `host` option, e.g. a shadow root) are abandoned, not cleared: their `<style>` elements keep their rules, and re-registering into the same host creates fresh sheets

```jsx
import { css, resetCss, style } from '@hellajs/css';

const buttonClass = style({
  color: 'white',
}, {
  label: 'btn',
});
css({
  body: {
    margin: 0,
  },
});

resetCss();

// The hella-css element stays in the DOM, emptied; nothing css-side remains
```

The sheet reset itself is DOM-only (a no-op without a document); the registration state clears on both platforms.

## Important Considerations

### When to Reach for It

Use `resetCss()` when every css-side registration should go at once: between test runs, during hot-module replacement in development, or when tearing down an app instance that owned its styles. For removing one registration while the rest live on, use [`removeCss`](/reference/css/removecss) / [`removeStyle`](/reference/css/removestyle) / [`removeKeyframes`](/reference/css/removekeyframes); for a complete reset of both sides, pair it with [`resetVars`](/reference/css/resetvars).

### Safety

Only HellaJS-generated CSS is affected: the reset never touches external stylesheets or hand-authored `<style>` elements. The `hella-css` element itself stays in the DOM, emptied.
