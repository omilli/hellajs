# resetCss

Clears all css-side rules and resets the CSS system to its initial state: every `css()`, `style()`, and `keyframes()` registration, on both platforms. The sheet reset is DOM-only (a no-op without a document); `vars()` registrations are untouched.

## Basic Usage

```jsx
import { style, resetCss } from '@hellajs/css';

// Create some styles
const button = style({
  background: 'blue',
  color: 'white',
}, {
  label: 'btn',
});
const card = style({
  padding: '1rem',
  border: '1px solid #ccc',
}, {
  label: 'card',
});

// Later, reset everything
resetCss();

// All previous styles are removed from DOM and memory
```

## API

```typescript
function resetCss(): void
```
- **Returns**: `void`

## Key Concepts

### What the Reset Covers

`resetCss()` clears the css side only: the injected-rules registry (including `keyframes()` registrations and their reference counts) and the `hella-css` style element. Two isolation rules hold:

- [`vars`](/reference/css/vars) registrations and the `hella-vars` sheet are untouched; call [`resetVars`](/reference/css/resetvars) for those.
- Hosted sheets (a `host` option, e.g. a shadow root) are abandoned, not cleared: their `<style>` elements keep their rules, and re-registering into the same host creates fresh sheets.

```jsx
import { css, style, resetCss } from '@hellajs/css';

const buttonClass = style({
  color: 'white',
}, {
  label: 'btn',
});
css({
  body: {
    margin: 0,
  },
});

resetCss();

// The hella-css element stays in the DOM, emptied; nothing css-side remains registered
```

### Testing Scenarios

```jsx
import { css, resetCss } from '@hellajs/css';

// Reset before each test suite for a predictable starting state
resetCss();

const buttonStyle = css({
  body: {
    margin: 0,
  },
});
// buttonStyle === ''; styles injected cleanly
```

## Important Considerations

### Use Cases

Reach for `resetCss()` when every css-side registration should go at once: between test runs, during hot-module replacement in development, or when tearing down an app instance that owned its styles. For removing one registration while the rest live on, use [`removeCss`](/reference/css/removecss) / [`removeStyle`](/reference/css/removestyle) / [`removeKeyframes`](/reference/css/removekeyframes); for a complete reset of both sides, pair it with [`resetVars`](/reference/css/resetvars).

### Safety

Only HellaJS-generated CSS is affected: the reset never touches external stylesheets or hand-authored `<style>` elements. The `hella-css` element itself stays in the DOM, emptied.
