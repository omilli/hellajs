

Type-safe CSS-in-JS with runtime style generation, reactive CSS variables, and automatic memory management. Generates unique class names with reference counting for cleanup.

## Installation

```bash
npm install @hellajs/core @hellajs/css
```

## Example

```jsx
import { signal } from '@hellajs/core';
import { css } from '@hellajs/css';

// Create scoped styles
const cardStyle = css({
  padding: '1rem',
  borderRadius: '8px',
  backgroundColor: '#f8f9fa',

  // Nested selectors and pseudo-states
  'h2': { marginTop: 0 },
  '&:hover': {
    backgroundColor: '#e9ecef',
    transform: 'translateY(-2px)'
  },

  // Responsive design
  '@media (max-width: 768px)': {
    padding: '0.5rem'
  }
});

const Card = ({ title, children }) => (
  <div class={cardStyle}>
    <h2>{title}</h2>
    {children}
  </div>
);
```

## API

- **[css](/reference/css/css)** — Create scoped styles with nested selectors and pseudo-states
- **[cssVars](/reference/css/cssvars)** — Reactive CSS custom properties that update when signals change
- **[cssRemove](/reference/css/cssremove)** — Manually remove a generated stylesheet
- **[cssReset](/reference/css/cssreset)** — Remove all generated stylesheets
- **[cssVarsReset](/reference/css/cssvarsreset)** — Remove all generated CSS variable stylesheets
