## CSS

Type-safe CSS-in-JS with runtime style generation, reactive CSS variables, and automatic memory management. Scoped styles via the `name` option with reference-counted cleanup; global by default.

### Installation

```bash
npm install @hellajs/core @hellajs/css
```

### Example

```jsx
import { css } from '@hellajs/css';

// Define styles at module level — client: injects into CSSOM; server: returns CSS text
css({
  padding: '1rem',
  borderRadius: '8px',
  backgroundColor: '#f8f9fa',

  // Nested selectors and pseudo-states
  'h2': { marginTop: 0 },
  '&:hover': {
    backgroundColor: '#e9ecef',
    transform: 'translateY(-2px)'
  },

  // Responsive design
  '@media (max-width: 768px)': {
    padding: '0.5rem'
  }
}, { name: 'card' });

// Components hardcode the class name (the `name` provided to css)
const Card = ({ title, children }) => (
  <div class="card">
    <h2>{title}</h2>
    {children}
  </div>
);
```

### API

- **[css](/reference/css/css)**: Create scoped styles with nested selectors and pseudo-states
- **[cssVars](/reference/css/cssvars)**: Reactive CSS custom properties that update when signals change
- **[removeCss](/reference/css/removecss)**: Manually remove a generated stylesheet
- **[resetCss](/reference/css/resetcss)**: Remove all generated stylesheets
- **[removeCssVars](/reference/css/removecssvars)**: Remove specific CSS variable declarations with reference counting
- **[resetCssVars](/reference/css/resetcssvars)**: Remove all generated CSS variable stylesheets
