## CSS

Type-safe CSS-in-JS with a tiny runtime: [`style`](/reference/css/style) scopes declarations under a content-hashed class, [`css`](/reference/css/css) registers globals, [`cva`](/reference/css/cva) builds typed variant recipes, [`vars`](/reference/css/vars) drives reactive theming, and [`keyframes`](/reference/css/keyframes) hashes animation names. Every creator returns the same value on client and server, so server-rendered HTML and hydrated markup agree without coordination. [`cssText`](/reference/css/csstext) collects the registered rules for server rendering.

### Installation

```bash
npm install @hellajs/core @hellajs/css
```

### Example

A themed button in three moves: tokens live in [`vars`](/reference/css/vars), declarations in [`style`](/reference/css/style), and the returned class lands straight on the element.

```jsx
import { signal } from '@hellajs/core';
import { style, vars } from '@hellajs/css';

const darkMode = signal(false);

// A var() proxy; values re-resolve when their signals change
const tokens = vars({
  accent: () => darkMode() ? '#93c5fd' : '#3b82f6',
});

// A class name derived from the object's content: "button-{hash}"
const button = style('button', {
  padding: '0.5rem 1rem',
  borderRadius: '0.5rem',
  border: 'none',
  background: tokens.accent,
  color: 'white',
  cursor: 'pointer',
  '&:hover': {
    opacity: 0.9,
  },
});

const ThemeToggle = () => (
  <button class={button} on:click={() => darkMode(!darkMode())}>
    Toggle theme
  </button>
);
```

Clicking the button rewrites one custom property on `:root`; no rule is rebuilt and no component re-renders.

### API

- **[style](/reference/css/style)**: Scoped styles returning a content-hashed class name, identical on client and server
- **[css](/reference/css/css)**: Global styles with nested selectors and at-rules
- **[vars](/reference/css/vars)**: Reactive CSS custom properties that update when signals change
- **[cva](/reference/css/cva)**: Variant recipes with typed props, responsive breakpoints, and compounds
- **[cx](/reference/css/cx)**: Class-name joiner with no styling side effects
- **[keyframes](/reference/css/keyframes)**: Collision-free `@keyframes` definitions returning a hashed animation name
- **[reset](/reference/css/reset)**: Preflight reset sheet; register once with `css(reset)` to normalize browser defaults
- **[cssText](/reference/css/csstext)**: The server-side `<style>` source; `cssText.css()` / `cssText.vars()` split it into per-sheet tags
- **[removeStyle](/reference/css/removestyle)**: Remove a `style()` registration
- **[removeCss](/reference/css/removecss)**: Remove a `css()` registration
- **[removeVars](/reference/css/removevars)**: Remove a `vars()` registration
- **[removeKeyframes](/reference/css/removekeyframes)**: Remove a `keyframes()` registration
- **[resetCss](/reference/css/resetcss)**: Clear every css-side registration
- **[resetVars](/reference/css/resetvars)**: Clear every vars registration and reactive effect
