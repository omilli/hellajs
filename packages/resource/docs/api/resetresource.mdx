# resetResource

Factory-reset every piece of resource package state at once: cache entries, in-flight request tracking, online status subscribers, and the cleanup throttle.

## Basic Usage

```typescript
import { resetResource } from '@hellajs/resource';

// On logout, HMR, session reset, or error recovery:
resetResource();
```

Use `resetResource` for a complete teardown of package-global state. Unlike [`resourceCache.invalidateAll()`](/reference/resource/resourcecache#invalidateall), which only clears cache entries, it also releases in-flight request registrations, drops online status subscribers, and resets the cleanup throttle.

## API

```typescript
function resetResource(): void
```

## Key Concepts

### What Gets Reset

| State | Effect |
|---|---|
| Cache entries | Every entry across all fetcher scopes is cleared |
| In-flight requests | Dedup registrations are released; in-flight promises still settle, but new fetches for the same key start fresh requests instead of joining |
| Online status subscribers | [`onOnlineChange`](/reference/resource/resourcecache#ononlinechange) callbacks no longer fire |
| Cleanup throttle | Reset so the next cache write runs expiry cleanup immediately |

### vs `resourceCache.invalidateAll()`

`invalidateAll()` only clears the cache map. After it runs, online callbacks remain registered, the cleanup throttle is unchanged, and the dedup map still holds prior in-flight registrations. `resetResource()` is the only way to fully reset all resource package mutable state.
