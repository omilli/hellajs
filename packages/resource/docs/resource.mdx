# resource

Reactive async data fetching with caching, abort, and mutation.

## API

```typescript
// Overload for simple URL fetching
function resource<T, TTransformed = T>(url: string, options?: ResourceOptions<T, string, TTransformed>): Resource<TTransformed, T>;

// Overload for custom fetcher functions
function resource<T, K = undefined, TTransformed = T>(fetcher: (key: K) => Promise<T>, options?: ResourceOptions<T, K, TTransformed>): Resource<TTransformed, T>;

// The returned resource object
// - TTransformed: the type returned by data() (after transform, defaults to T)
// - T: the raw data type used by setData() and mutate()
interface Resource<TTransformed, T = TTransformed> {
  data: () => (TTransformed | undefined);
  error: () => (ResourceError | undefined);
  isLoading: () => boolean;
  isFetching: () => boolean;
  isIdle: () => boolean;
  status: () => ResourceStatus;
  fetch(options?: FetchOptions): void;
  abort(): void;
  invalidate(): void;
  setData: (updater: T | ((old: T | undefined) => T)) => void;
  cacheKey: () => unknown;
  mutate: <TVariables = unknown>(variables: TVariables) => Promise<T>;
  reset(): void;
  dispose(): void;
}

type ResourceStatus = "idle" | "loading" | "success" | "error";

type ResourceErrorCategory =
  | 'not_found'     // Resource not found (404)
  | 'server'        // Server errors (5xx)
  | 'client'        // Client errors (4xx)
  | 'abort'         // Request was cancelled
  | 'unknown';      // Unclassified errors (including network failures)

interface ResourceError {
  /** Human-readable error message */
  message: string;
  /** Categorized error type for structured handling */
  category: ResourceErrorCategory;
  /** HTTP status code if available */
  statusCode?: number;
  /** Original error object for debugging */
  originalError?: unknown;
}

interface ResourceOptions<T, K, TTransformed = T> {
  /** Function to generate cache key or static key value */
  key?: (() => K) | K;
  /** Whether the resource can make requests (default: true) */
  enabled?: boolean;
  /** Auto-refetch when key dependencies change (default: false) */
  refetchOnKeyChange?: boolean;
  /** Initial data before first request completes */
  initialData?: T;
  /** Cache TTL in milliseconds (0 = no caching) */
  cacheTime?: number;
  /** Duration in ms data is considered fresh before background revalidation (default: Infinity = never stale, 0 = always stale) */
  staleTime?: number;
  /** Whether to auto-refetch when data becomes stale (default: true) */
  revalidateOnStale?: boolean;
  /** Request timeout in milliseconds */
  timeout?: number;
  /** External abort signal for cancellation */
  abortSignal?: AbortSignal;
  /** Deduplicate concurrent requests with same key (default: true) */
  deduplicate?: boolean;
  /** Retry count on failure, boolean for simple on/off, or function for conditional retry */
  retry?: number | boolean | ((failureCount: number, error: ResourceError) => boolean);
  /** Delay between retries in ms, or function returning delay based on attempt number */
  retryDelay?: number | ((attempt: number, error: ResourceError) => number);
  /** Transform data before returning; cache stores original data */
  transform?: (data: T) => TTransformed;
  /** Callback when request succeeds */
  onSuccess?: (data: T) => void;
  /** Callback when request fails */
  onError?: (err: unknown) => void;
  /** Refetch interval in ms, false to disable, or function returning interval based on data */
  refetchInterval?: number | false | ((data: TTransformed | undefined) => number | false);
  /** Continue polling when tab is hidden (default: false) */
  refetchIntervalInBackground?: boolean;
  /** Refetch when window regains focus (default: false) */
  refetchOnWindowFocus?: boolean;
  /** Refetch when browser reconnects after going offline (default: false) */
  refetchOnReconnect?: boolean;
  /** Hook for optimistic updates before mutation */
  onMutate?: (variables: unknown) => Promise<unknown> | unknown;
  /** Hook after mutation completion (success or error) */
  onSettled?: (data?: T, error?: unknown, variables?: unknown, context?: unknown) => Promise<void> | void;
}
```

### `data`

Reactive signal containing the fetched data or undefined if not yet loaded.

```typescript
import { resource } from '@hellajs/resource';
import { effect } from '@hellajs/core';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

effect(() => {
  const data = userResource.data();
  if (data) {
    console.log('User name:', data.name);
  }
});

userResource.fetch();
```

### `error`

Reactive signal containing error information if the request failed.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

effect(() => {
  const error = userResource.error();
  if (error) {
    console.log('Error category:', error.category);
    console.log('Error message:', error.message);
    if (error.statusCode) {
      console.log('HTTP status:', error.statusCode);
    }
  }
});

userResource.fetch();
```

### `isLoading`

Reactive signal indicating if an **initial** request is in progress. Only true when there's no data at all (not even `initialData`).

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

effect(() => {
  if (userResource.isLoading()) {
    console.log('Loading user data for the first time...');
  }
});

userResource.fetch();
```

### `isFetching`

Reactive signal indicating if **any** network request is in progress, including background refetches.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

effect(() => {
  if (userResource.isFetching()) {
    console.log('Fetching data...');
  }
});

userResource.fetch();
// Later, during background refetch:
userResource.invalidate();
// isFetching() is true, but isLoading() may be false if data already exists
```

### `isIdle`

Reactive signal indicating if no fetch has occurred yet.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

console.log(userResource.isIdle()); // true - no fetch yet

userResource.fetch();
console.log(userResource.isIdle()); // false - fetch started

userResource.reset();
console.log(userResource.isIdle()); // true - back to initial state
```

### `status`

Computed signal showing the current resource status.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(() =>
  fetch('/api/user').then(r => r.json())
);

effect(() => {
  const status = userResource.status();
  switch (status) {
    case 'idle':
      console.log('Resource not fetched yet');
      break;
    case 'loading':
      console.log('Fetching data...');
      break;
    case 'success':
      console.log('Data loaded successfully');
      break;
    case 'error':
      console.log('Failed to load data');
      break;
  }
});

userResource.fetch();
```

### `fetch`

Fetches data using a cache-first strategy by default. Pass `{ force: true }` to bypass cache and force a fresh network request.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { cacheTime: 300000 } // 5 minutes
);

// Cache-first - uses cached data if valid
userResource.fetch();

// Force fresh - bypasses cache
userResource.fetch({ force: true });
```

### `abort`

Cancels the ongoing request and resets resource to initial state.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/slow-endpoint').then(r => r.json()),
  { initialData: null }
);

userResource.fetch();

// Cancel the request after 1 second
setTimeout(() => {
  userResource.abort();
  console.log('Request cancelled');
  console.log('Data:', userResource.data()); // Back to initialData
}, 1000);
```

### `invalidate`

Clears the cache entry and triggers a fresh request.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { cacheTime: 300000 }
);

// After updating user data elsewhere
async function updateUser(data) {
  await fetch('/api/user', {
    method: 'PUT',
    body: JSON.stringify(data)
  });

  // Invalidate cache and refetch fresh data
  userResource.invalidate();
}
```

### `setData`

Updates cached data with a new value or updater function.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { cacheTime: 300000 }
);

// Update with new value
userResource.setData({ id: 1, name: 'Updated Name' });

// Update with function
userResource.setData(old => ({
  ...old,
  lastSeen: Date.now()
}));
```

When `cacheTime` is `0` (the default), `setData` updates the reactive signal but does not write to cache. The updater function still receives the current signal value, not a cached value.

### `cacheKey`

Returns the current cache key used for this resource.

```typescript
import { resource } from '@hellajs/resource';
import { signal } from '@hellajs/core';

const userId = signal(1);
const userResource = resource(
  (id) => fetch(`/api/users/${id}`).then(r => r.json()),
  { key: () => `user:${userId()}` }
);

console.log(userResource.cacheKey()); // 'user:1'

userId(2);
console.log(userResource.cacheKey()); // 'user:2'
```

### `mutate`

Executes a mutation with given variables, supporting optimistic updates.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  async (userData) => {
    const response = await fetch('/api/user', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(userData)
    });
    return response.json();
  },
  {
    onMutate: async (variables) => {
      // Optimistic update
      console.log('Starting mutation with:', variables);
      return { previousData: userResource.data() };
    },
    onSettled: async (data, error, variables, context) => {
      if (error) {
        console.log('Mutation failed, rollback if needed');
        // Could restore context.previousData here
      } else {
        console.log('Mutation succeeded:', data);
      }
    }
  }
);

// Execute mutation
try {
  const result = await userResource.mutate({
    name: 'John Doe',
    email: 'john@example.com'
  });
  console.log('Created user:', result);
} catch (error) {
  console.error('Mutation failed:', error);
}
```

### `reset`

Resets resource state to initial values, clearing data and errors.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { initialData: null }
);

userResource.fetch();
// ... resource has data or error

// Reset to clean state
userResource.reset();
console.log(userResource.data()); // null (initialData)
console.log(userResource.error()); // undefined
console.log(userResource.status()); // 'idle'
```

### `dispose`

Cleans up all resource effects, polling timers, and subscriptions. Call this when the resource is no longer needed to prevent memory leaks.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  {
    refetchOnKeyChange: true,
    refetchInterval: 5000 // Polling every 5 seconds
  }
);

// When component unmounts or resource is no longer needed:
userResource.dispose();
// All timers and effects are cleaned up
```

## Key Concepts

### Stale-While-Revalidate (SWR)

Control data freshness with `staleTime`. When data becomes "stale" but is still cached, `.fetch()` returns it immediately while fetching fresh data in the background.

```typescript
import { resource } from '@hellajs/resource';

// Fresh: 0-30s, Stale: 30s-5min, Expired: 5min+
const user = resource(
  () => fetch('/api/user').then(r => r.json()),
  { staleTime: 30000, cacheTime: 300000 }
);

user.fetch();
```

| Time | State | `fetch()` behavior |
|------|-------|--------------------|
| 0-30s | Fresh | Returns cached data instantly |
| 30s-5min | Stale | Returns cached data + background fetch |
| 5min+ | Expired | Fresh network request |

Use `isFetching()` to show refresh indicators while keeping stale data visible:

```typescript
const todos = resource(
  () => fetch('/api/todos').then(r => r.json()),
  { staleTime: 10000, cacheTime: 60000 }
);

todos.fetch();

// After 10+ seconds (data is stale):
todos.fetch();
// isLoading() → false (still has data)
// isFetching() → true (background refetch)
// data() → previous data (visible during refetch)
```

`staleTime` options:

```typescript
// Always stale: always triggers background fetch on fetch()
staleTime: 0

// Never stale: never refetches automatically
staleTime: Infinity

// Disable automatic revalidation when stale
staleTime: 30000,
revalidateOnStale: false
```

### Automatic Retry

Configure retry behavior for failed requests with support for conditional logic and custom delays.

```typescript
// Simple retry count
const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { retry: 3 }
);

// Boolean shorthand
{ retry: true }   // Retry once
{ retry: false }  // No retries (default)
```

Conditional retry based on error type:

```typescript
const resilient = resource(
  () => fetch('/api/data').then(r => r.json()),
  {
    retry: (count, error) => {
      // Don't retry 404s or client errors
      if (error.category === 'not_found' || error.category === 'client') return false;
      // Retry server errors up to 3 times
      return count < 3;
    }
  }
);
```

Retry delay configuration: fixed, exponential backoff, or jittered.

```typescript
// Fixed delay
{ retry: 3, retryDelay: 1000 }

// Exponential backoff
{
  retry: 3,
  retryDelay: (attempt) => Math.min(1000 * Math.pow(2, attempt - 1), 30000)
  // attempt 1: 1s, attempt 2: 2s, attempt 3: 4s, capped at 30s
}

// Error-aware delay
{
  retry: (count, error) => count < 3,
  retryDelay: (attempt, error) => {
    if (error.category === 'server') return attempt * 2000;
    return 1000;
  }
}
```

Retries respect abort signals: cancel at any point.

```typescript
const r = resource(() => fetch('/api/slow').then(r => r.json()),
  { retry: 10, retryDelay: 5000 }
);

r.fetch({ force: true });

// Cancel during retry delay
setTimeout(() => r.abort(), 2000);
```

### Polling / Interval Refetch

Periodically refresh data for real-time updates.

```typescript
// Fixed interval: every 5 seconds
const stockPrice = resource(
  () => fetch('/api/stock/price').then(r => r.json()),
  { refetchInterval: 5000, refetchOnKeyChange: true }
);
```

Dynamic interval based on data:

```typescript
// Poll faster when unhealthy
const health = resource(
  () => fetch('/api/health').then(r => r.json()),
  {
    refetchInterval: (data) => data?.status === 'unhealthy' ? 1000 : 30000,
    refetchOnKeyChange: true
  }
);
```

Continue polling when tab is hidden:

```typescript
{ refetchInterval: 10000, refetchIntervalInBackground: true }
```

Always call `dispose()` to stop polling and clean up timers.

### Window Focus Refetch

Automatically refetch when the user returns to the tab. Only triggers when the tab becomes **visible**.

```typescript
const session = resource(
  () => fetch('/api/session').then(r => r.json()),
  { refetchOnWindowFocus: true, refetchOnKeyChange: true }
);
```

With `refetchOnKeyChange: true`, the initial fetch and focus listener start automatically. Without it, call `fetch()` manually first; the focus listener still works for subsequent refetches.

### Reconnect Refetch

Automatically refetch when the browser reconnects after going offline.

```typescript
const data = resource(
  () => fetch('/api/data').then(r => r.json()),
  { refetchOnReconnect: true, refetchOnKeyChange: true }
);
```

### Data Transformation

Transform data before it's returned, while keeping the original data in cache.

```typescript
interface UserResponse {
  id: number;
  name: string;
  email: string;
  permissions: string[];
  metadata: Record<string, unknown>;
}

interface UserSummary {
  name: string;
  email: string;
}

const userResource = resource<UserResponse, undefined, UserSummary>(
  () => fetch('/api/user').then(r => r.json()),
  { transform: (data): UserSummary => ({ name: data.name, email: data.email }) }
);

userResource.fetch({ force: true });
// userResource.data() returns { name, email }, not full UserResponse
```

Multiple resources with different `transform` functions can share the same cache entry:

```typescript
// Both share cache entry "user-1"
const userName = resource(() => fetch('/api/user').then(r => r.json()),
  { key: () => 'user-1', cacheTime: 60000, transform: (d) => d.name });

const userEmail = resource(() => fetch('/api/user').then(r => r.json()),
  { key: () => 'user-1', cacheTime: 60000, transform: (d) => d.email });

userName.fetch();
userEmail.fetch(); // Joins the same request via deduplication
```

### Request Deduplication

Identical concurrent requests share a single network call by default.

```typescript
// Default: deduplicate enabled
{ deduplicate: true }

// Disable for sensitive operations
{ deduplicate: false }
```

Deduplication rules:

- Same cache key + concurrent requests = shared network request
- Different cache keys = separate requests
- `fetch({ force: true })` bypasses deduplication
- Sequential requests with caching = cache-based deduplication

### Timeout and Abort Control

Request timeout and external abort signals for coordinated cancellation.

```typescript
// Timeout after 5 seconds
const slowResource = resource(
  () => new Promise(resolve => setTimeout(() => resolve({ data: 'Slow' }), 10000)),
  {
    timeout: 5000,
    initialData: { data: 'Initial' },
    onError: (error) => {
      if (error.category === 'abort') console.log('Request timed out');
    }
  }
);
```

External abort controller for coordinated cancellation:

```typescript
const controller = new AbortController();

const r = resource(
  () => fetch('/api/long-operation').then(r => r.json()),
  { abortSignal: controller.signal }
);

r.fetch({ force: true });

// Cancel externally: affects all resources using this controller
controller.abort();
```

## Important Considerations

### AbortError Does Not Set Error State

When a request is aborted (via `.abort()`, `timeout`, or an external `abortSignal`), the error state is **not** set. The resource returns to `idle` status with the original `initialData`, not `error` status.

```typescript
// ❌ Don't rely on error() being set after abort
const r = resource(fetchData, { timeout: 5000 });
r.fetch();
// ...timeout fires...
if (r.error()) { /* ⚠️ won't enter here */ }

// ✅ Check status instead
if (r.isIdle() && !r.isFetching()) {
  console.log('Request was aborted or never started');
}
```

### Manual vs Key-Change Fetching

By default, resources don't auto-fetch on creation - you must explicitly call `.fetch()` or `.fetch({ force: true })`. Set `refetchOnKeyChange: true` for automatic fetching when key dependencies change.

```typescript
// ❌ No data fetched yet (manual mode)
const userResource = resource(() => fetch('/api/user'));
console.log(userResource.data()); // undefined
// ✅ Explicitly fetch data
userResource.fetch();

// ✅ Key-change refetch mode
const reactiveResource = resource(() => fetch('/api/user'), { refetchOnKeyChange: true });
// Data fetches automatically when effect runs
```

### enabled Is Static, Not Reactive

The `enabled` option is evaluated once at creation time and stored as a boolean. It does not reactively update when signals change.

```typescript
const userId = signal(null);

// enabled is evaluated NOW: if userId() is null, it's false forever
const r = resource(
  (id) => fetch(`/api/users/${id}`).then(r => r.json()),
  {
    key: () => userId(),
    enabled: !!userId()
  }
);

// Changing userId later does NOT re-evaluate enabled
userId(123); // enabled is still false from creation time
```

### Memory Management

Each unique key creates a separate cache entry - consider key design for large datasets.

```typescript
// ❌ Too many cache entries
{ key: () => Math.random() }
// ✅ Stable, meaningful keys
{ key: () => `user-${userId()}` }
```
