# Resource

Short patterns for common async data tasks using [`@hellajs/resource`](/reference/resource).

### Basic Data Fetching

Create a resource, trigger the fetch, and access reactive state.

```typescript
import { resource } from '@hellajs/resource';
import { effect } from '@hellajs/core';

const users = resource(
  () => fetch('/api/users').then(r => r.json())
);

effect(() => {
  if (users.isLoading()) console.log('Loading...');
  if (users.data()) console.log('Users:', users.data());
});

users.fetch({ force: true });
```

### Reactive Key Fetching

Refetch automatically when a key dependency changes.

```typescript
import { signal } from '@hellajs/core';
import { resource } from '@hellajs/resource';

const userId = signal(1);

const posts = resource(
  id => fetch(`/api/users/${id}/posts`).then(r => r.json()),
  { key: () => userId(), refetchOnKeyChange: true }
);

// Changing userId automatically triggers a refetch
userId(2);
```

### Cached Fetching

Control data freshness with `staleTime` and `cacheTime`.

```typescript
import { resource } from '@hellajs/resource';

const config = resource(
  () => fetch('/api/config').then(r => r.json()),
  {
    staleTime: 30000,  // Fresh for 30s
    cacheTime: 300000,  // Cached for 5min
  }
);

config.fetch(); // First call: network request
config.fetch(); // Within 30s: instant cache hit
```

### Cache Prefetching

Warm the cache before the user navigates; share a named fetcher so the resource hits the prefetched entry.

```typescript
import { signal } from '@hellajs/core';
import { resource, resourceCache } from '@hellajs/resource';

const userId = signal(1);
const fetchUser = async (id: number) => (await fetch(`/api/users/${id}`)).json();

// Same fetcher reference -> the resource reuses the prefetched entry
const userResource = resource(fetchUser, { key: () => userId(), cacheTime: 60000 });

// Call on link hover, or ahead of navigation
const prefetchUser = () =>
  resourceCache.prefetch({ fetcher: fetchUser, key: userId(), cacheTime: 60000 });
```

### Polling

Refresh data at regular intervals for real-time updates; `refetchInterval` works on its own, no `refetchOnKeyChange` needed.

```typescript
import { resource } from '@hellajs/resource';

const notifications = resource(
  () => fetch('/api/notifications').then(r => r.json()),
  { refetchInterval: 5000 }
);

notifications.fetch(); // Initial load; polling keeps it fresh every 5s
// Call dispose() to stop polling
```

### Optimistic Update

Update UI immediately, then sync with the server using `onMutate`/`onSettled`.

```typescript
import { resource } from '@hellajs/resource';

type Todo = { id: number; text: string; done: boolean };

const todos = resource<Todo[]>(
  () => fetch('/api/todos').then(r => r.json())
);

const addTodo = resource(
  async (text) => {
    const res = await fetch('/api/todos', {
      method: 'POST',
      body: JSON.stringify({ text, done: false })
    });
    return res.json();
  },
  {
    onMutate: (text) => {
      const temp: Todo = { id: Date.now(), text: String(text), done: false };
      todos.setData(old => [...(old || []), temp]);
      return { temp };
    },
    onSettled: (data, err, vars, ctx) => {
      const temp = (ctx as { temp: Todo } | undefined)?.temp;
      if (err && temp) {
        // Roll back on failure
        todos.setData(old => (old || []).filter(t => t.id !== temp.id));
      }
      todos.invalidate();
    }
  }
);

addTodo.mutate('Build something awesome').catch(() => { /* handled in onSettled */ });
```

### Invalidate After Mutations

Declare cache entries to clear on mutation success with `invalidates`; string prefixes and regex patterns combine in one list.

```typescript
import { resource, resourceCache } from '@hellajs/resource';

// Seed the entries the mutation will invalidate
resourceCache.set('user:1', { id: 1 }, 60000);
resourceCache.set('posts:1', [{ id: 10 }], 60000);

const saveUser = resource(
  (data) => fetch('/api/user', { method: 'PUT', body: JSON.stringify(data) }).then(r => r.json()),
  { invalidates: ['user:', /^posts:\d+$/] }
);

await saveUser.mutate({ name: 'John Doe' });
// On success: user:1 and posts:1 are gone; the next fetch for each goes to the network
```

### Error Recovery

Retry failed requests with a configurable count and delay.

```typescript
import { resource } from '@hellajs/resource';

const data = resource(
  () => fetch('/api/data').then(r => r.json()),
  {
    retry: 3,
    retryDelay: 1000,
  }
);

data.fetch({ force: true });
```

### Data Transformation

Transform raw API responses while caching the original data.

```typescript
import { resource } from '@hellajs/resource';

const stats = resource<{ total: number; completed: number }, undefined, number>(
  () => fetch('/api/todos').then(r => r.json()),
  { transform: (data) => data.completed / data.total * 100 }
);

stats.fetch({ force: true });
// stats.data() returns a percentage number, cache stores the full object
```

### Conditional Fetching

Disable fetching with a static `boolean` for branches that should never fetch, or use a reactive getter for toggling.

```typescript
import { signal } from '@hellajs/core';
import { resource } from '@hellajs/resource';

// Static; permanently disabled, no network request will ever be made
const dormant = resource(
  () => fetch('/api/data').then(r => r.json()),
  { enabled: false }
);

// Reactive; auto-fetches only when the gate signal is true
const gate = signal(false);
const conditional = resource(
  () => fetch('/api/data').then(r => r.json()),
  { enabled: () => gate(), refetchOnKeyChange: true }
);

gate(true); // enabled transitions to true -> fetch triggers automatically
conditional.fetch(); // manual fetch bypasses the enabled check
```

### Offline-Aware Fetching

Defer fetches while the browser is offline instead of letting them fail; the deferred fetch replays on reconnect.

```typescript
import { resource } from '@hellajs/resource';

const feed = resource(
  () => fetch('/api/feed').then(r => r.json()),
  { pauseWhenOffline: true, refetchOnKeyChange: true }
);

feed.fetch();
// While offline: isPaused() is true, no request attempted, no error state
// On reconnect: the deferred fetch runs and isPaused() flips back to false
```

### Structural Sharing

Reuse subtree references across refetches so dependent computeds skip re-evaluation.

```typescript
import { resource } from '@hellajs/resource';

const userResource = resource(
  () => fetch('/api/user').then(r => r.json()),
  { structuralSharing: true }
);

userResource.fetch({ force: true });
// ...wait for the fetch to resolve...
const firstProfile = userResource.data()?.profile;

userResource.fetch({ force: true });
// ...after the second fetch resolves, an unchanged profile subtree
// keeps its reference; dependent computeds skip re-evaluation
console.log(userResource.data()?.profile === firstProfile); // true
```
