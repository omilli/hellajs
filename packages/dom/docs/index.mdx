## DOM

Render UI with plain functions and JSX. Updates touch only the parts of the DOM that changed, cleanup is automatic, and everything ships tree-shaken to what you use.

### Installation

```bash
npm install @hellajs/core @hellajs/dom
```

### Example

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const Counter = () => {
  const count = signal(0);
  const countClass = () => count() % 2 === 0 ? "even" : "odd";

  const increment = () => count(count() + 1);
  const decrement = () => count(count() - 1);

  return (
    <div>
      <h1 class={countClass}>Count: {count}</h1>
      <button on:click={increment}>
        Increment
      </button>
      <button on:click={decrement}>
        Decrement
      </button>
    </div>
  );
};

// Mount the component to the DOM
mount(Counter, "#app");
```

### API

#### Prefixes

- **[on:](/reference/dom/on)**: Delegated event listeners
- **[e:](/reference/dom/e)**: Direct event listeners
- **[hook:](/reference/dom/hook)**: Element lifecycle hooks
- **[error:](/reference/dom/error)**: Element-level error handling

#### Functions

- **[mount](/reference/dom/mount)**: Render a component into a DOM element
- **[hydrate](/reference/dom/hydrate)**: Attach reactivity to server-rendered HTML in place
- **[element](/reference/dom/element)**: Author reactive Web Components
- **[raw](/reference/dom/raw)**: Embed pre-rendered HTML unescaped
- **[ForEach](/reference/dom/foreach)**: Render lists that track a signal, keyed for reuse
- **[Portal](/reference/dom/portal)**: Render children in a different DOM location
- **[Lazy](/reference/dom/lazy)**: Load components on demand with loading and error states
- **[Transition](/reference/dom/transition)**: Animate content in and out with CSS classes
- **[Suspense](/reference/dom/suspense)**: Streaming and async boundary with fallback UI
- **[onError](/reference/dom/onerror)**: Catch app-wide errors with one global handler
- **[$ref](/reference/dom/$ref)**: Bind reactivity to one existing element
- **[$collection](/reference/dom/$collection)**: Bind reactivity to every element matching a selector
- **[component](/reference/dom/component)**: Scope manual component trees for cleanup (low-level)
- **[registry](/reference/dom/registry)**: Register effects and hooks on elements directly (low-level)
- **[runtime](/reference/dom/runtime)**: Imperative DOM construction functions for compiler output
- **[trapFocus](/reference/dom/trapfocus)**: Keep Tab navigation inside a container
- **[onEscape](/reference/dom/onescape)**: Call a handler on Escape at a target
- **[onOutside](/reference/dom/onoutside)**: Call a handler on clicks outside elements
- **[rovingTabIndex](/reference/dom/rovingtabindex)**: Arrow-key focus navigation over a group
- **[anchorPosition](/reference/dom/anchorposition)**: Pin a floating element to an anchor, tracking scroll and resize
- **[computeAnchorPosition](/reference/dom/computeanchorposition)**: Compute floating placement as pure math
- **[hoverIntent](/reference/dom/hoverintent)**: Open and close overlays on hover or focus delays
- **[menuTypeahead](/reference/dom/menutypeahead)**: Select menu items by typing
- **[onDrag](/reference/dom/ondrag)**: Track pointer drags with total distance from the start
- **[onSwipe](/reference/dom/onswipe)**: Commit or cancel swipes by distance or speed
- **[onPinch](/reference/dom/onpinch)**: Track two-finger pinch zoom and pan
- **[onLongPress](/reference/dom/onlongpress)**: Fire a handler after a press is held
- **[onDoubleTap](/reference/dom/ondoubletap)**: Detect double taps, optionally reporting single taps
- **[layerDismissal](/reference/dom/layerdismissal)**: Dismiss stacked overlays one layer at a time
