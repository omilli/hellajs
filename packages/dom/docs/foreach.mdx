# forEach / ForEach

Efficiently renders dynamic lists with intelligent DOM diffing and key-based optimization.

## API

### forEach (Functional)

```typescript
function forEach<T>(
  each: T[] | Signal<T[]> | (() => T[]),
  use: (item: T, index: number) => HellaNodeValue
): (parent: HellaElement) => void
```
- `each`: An array, a [signal](/reference/core/signal) containing an array, or a function that returns an array.
- `use`: A function that is called for each item in the array and should return a renderable node.
- **Returns**: A function that is used internally to append the list to a parent element.

### ForEach (Component)

```typescript
function ForEach<T>(props: {
  each: T[] | Signal<T[]> | (() => T[]);
  use: (item: T, index: number) => HellaNodeValue;
  fallback?: HellaNodeValue;
}): (parent: HellaElement) => void
```
- `each`: An array, a [signal](/reference/core/signal) containing an array, or a function that returns an array.
- `use`: A function that is called for each item in the array and should return a renderable node.
- `fallback`: Optional content to display when the array is empty.
- **Returns**: A function that is used internally to append the list to a parent element.

## Basic Usage

### Functional Syntax

Use `forEach` to render lists that change over time.

```jsx
import { signal } from '@hellajs/core';
import { forEach } from '@hellajs/dom';

const items = signal(['Apple', 'Banana', 'Cherry']);

<ul>
  {forEach(items, (fruit) =>
    <li>{fruit}</li>
  )}
</ul>
```

### Component Syntax

Use `ForEach` component for more declarative syntax with fallback support.

```jsx
import { signal } from '@hellajs/core';
import { ForEach } from '@hellajs/dom';

const items = signal(['Apple', 'Banana', 'Cherry']);

<ul>
  <ForEach 
    each={items} 
    use={(fruit) => <li>{fruit}</li>}
    fallback={<li>No items available</li>}
  />
</ul>
```

## Key Concepts

### Key-Based Optimization

Use the `key` attribute for optimal reconciliation.

```jsx
import { signal } from '@hellajs/core';
import { forEach } from '@hellajs/dom';

const items = signal([
  { unique: 1, tag: 'Foo' },
  { unique: 2, tag: 'Bar' }
]);

const Items = () => <ul>
  {forEach(items, (item) =>
    <li key={item.unique}>{item.tag}</li>
  )}
</ul>
```

Items with an `id` property are automatically keyed - no explicit `key` needed.

```jsx
import { signal } from '@hellajs/core';
import { forEach } from '@hellajs/dom';

const users = signal([
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' }
]);

// ✅ id property is used as key automatically
const Users = () =>
  <ul>
    {forEach(users, (user) => 
      <li>{user.name}</li>
    )}
  </ul>
```

Key resolution order:
1. Explicit `key` prop on the rendered element
2. `id` property on the source item
3. Array index (fallback)

## Fallback Support

The `ForEach` component supports optional fallback content displayed when the array is empty.

```jsx
import { signal } from '@hellajs/core';
import { ForEach } from '@hellajs/dom';

const todos = signal([]);

<div>
  <ForEach 
    each={todos}
    use={(todo) => <div class="todo">{todo.text}</div>}
    fallback={<p class="empty">No todos yet. Add one to get started!</p>}
  />
</div>
```

Fallback content is automatically shown when the array becomes empty and hidden when items are added.

```jsx
// Initially empty - shows fallback
const items = signal([]);

// Add items - fallback hidden, items shown
items(['Item 1', 'Item 2']);

// Clear items - fallback shown again
items([]);
```

## Important Considerations

### Array Immutability

Always create new array instances for [signal](/reference/core/signal) updates - mutations don't trigger reactivity.

```jsx
// ✅ Create new array
todos([...todos(), newItem]);
// ❌ Mutation doesn't trigger updates
todos().push(newItem);
```

### Key Stability

Use stable, unique keys (like database IDs) rather than array indices for optimal performance.

```jsx
// ✅ Stable keys
{forEach(items, (item) => <li key={item.id}>{item.name}</li>)}
// ❌ Index keys cause re-renders
{forEach(items, (item, index) => <li key={index}>{item.name}</li>)}
```

### Automatic Cleanup

List items are automatically cleaned when removed from the DOM. No manual cleanup needed for reactive effects or event handlers on list elements.
