# $ref

Reactive reference to existing DOM elements with automatic watching for dynamically added elements.

## API

```typescript
function $ref<T extends Element = Element>(selector: string): ReactiveRef<T>
```
- `selector`: A CSS selector string to find elements.
- **Returns**: A reactive reference with declarative methods and array-like access.

## Basic Usage

Use `$ref` to select and manipulate existing DOM elements reactively.

```js
import { signal } from '@hellajs/core';
import { $ref } from '@hellajs/dom';

const count = signal(0);

// Select all buttons with class 'btn'
const buttons = $ref('.btn');

// Set reactive text content
buttons.text(() => `Count: ${count()}`);

// Add event handlers
buttons.on('click', () => count(count() + 1));
```

## Key Concepts

### Callable Reference

The returned reference is callable - invoke it to get raw DOM nodes.

```js
const ref = $ref('.item');

ref()    // First matched element
ref(0)   // Same as above
ref(1)   // Second matched element
ref(99)  // undefined (out of bounds)
```

### Method Chaining

All methods return the reference for fluent chaining.

```js
$ref('.counter')
  .text(() => `Count: ${count()}`)
  .attr({ class: () => count() > 10 ? 'high' : 'low' })
  .on('click', () => count(count() + 1))
  .hooks({ mount: () => console.log('ready') });
```

### Reactive Text

Set text content with static values or reactive functions.

```js
const status = signal('idle');

// Static text
$ref('.label').text('Hello');

// Reactive text (updates when signal changes)
$ref('.status').text(() => status());
$ref('.status').text(status); // Signal directly also works
```

Form elements (INPUT, TEXTAREA, SELECT) automatically use `.value` instead of `.textContent`.

```js
$ref('#username').text('default value'); // Sets input.value
```

### Reactive Attributes

Set attributes with static values, reactive functions, or arrays.

```js
const isLoading = signal(false);

$ref('.btn').attr({
  disabled: () => isLoading(),
  class: ['btn', 'primary'],           // Array joined with spaces
  'data-count': () => count()
});
```

Attribute behavior:
- `false`, `null`, `undefined` → removes attribute
- `true` → sets empty string attribute
- Arrays → filtered for falsy values, joined with spaces

### Event Handlers

Attach event handlers using global delegation.

```js
$ref('.btn').on('click', function(event) {
  console.log('Clicked:', this);  // 'this' is the element
  console.log('Event:', event);
});

// Multiple event types
$ref('.input')
  .on('focus', () => console.log('focused'))
  .on('blur', () => console.log('blurred'));
```

### Lifecycle Hooks

Add stackable lifecycle hooks to elements.

```js
$ref('.card').hooks({
  mount: () => console.log('Card mounted'),
  destroy: () => console.log('Card removed')
});

// Hooks are stackable - multiple hooks of same type all execute
$ref('.card').hooks({ mount: () => console.log('Also runs') });
```

If the element is already mounted, `mount` hooks execute immediately.

### Imperative Access

Access individual element wrappers for custom logic.

```js
// forEach for per-element operations
$ref('.items').forEach((element, index) => {
  element.text(`Item ${index + 1}`);
  element.attr({ 'data-index': index });
});

// Bracket notation for wrapper access
const wrapper = $ref('.single')[0];
console.log(wrapper.node); // The raw DOM element

// Length property
console.log($ref('.items').length); // Number of matched elements
```

## Important Considerations

### Automatic Watching

`$ref` watches for new elements matching the selector via MutationObserver. Operations are queued and automatically applied to elements added later.

```js
const ref = $ref('.dynamic-item');
ref.text('Hello');  // Applied to existing elements

// Later, when new elements are added to DOM:
document.body.innerHTML += '<div class="dynamic-item"></div>';
// The new element automatically gets text "Hello"
```

### Cleanup

Call `dispose()` to stop watching for new elements and clear queued operations.

```js
const ref = $ref('.temporary');
ref.text('Content');

// When done
ref.dispose();
```

### Multiple Elements

All operations apply to every matched element.

```js
// Sets text on ALL elements with class 'message'
$ref('.message').text('Updated');
```

### Bracket Access Limitation

Bracket access (`ref[0]`) provides a snapshot at creation time. New elements added via MutationObserver are accessible through `forEach` or the callable syntax, but not bracket notation.

```js
const ref = $ref('.item');
ref[0]  // First wrapper at creation time
ref()   // First element (always current)
```
