# bind:

Create reactive bindings between signals and DOM attributes.

## Overview

When the signal value changes, the attribute updates automatically.

```jsx
const isActive = signal(false);
const theme = signal('dark');

<div bind:class={() => isActive() ? 'active' : ''}>
  Content
</div>

<input bind:value={textInput} />
<div bind:style={() => `color: ${theme()}`} />
```

## Reactive Functions

For reactivity, `bind:` must be a **function** that returns the desired value.

```jsx
// ✅ Reactive binding
bind:class={() => count() > 5 ? 'large' : 'small'}

// ❌ Static value (no reactivity)
bind:class={count() > 5 ? 'large' : 'small'}
```

## Attribute Types

### String Attributes

```jsx
const itemId = signal(123);
const className = signal('active');

<div bind:class={className} />
<div bind:id={() => `item-${itemId()}`} />
<a bind:href={() => isActive() ? '#active' : '#inactive'}>Link</a>
```

### Boolean Attributes

```jsx
const isDisabled = signal(false);
const isChecked = signal(true);

<button bind:disabled={isDisabled}>
  Submit
</button>

<input type="checkbox" bind:checked={isChecked} />
```

When the function returns `true`, the attribute is added. When `false`/`null`/`undefined`, it's removed.

### Array Attributes

Attributes accept array values, which are joined with spaces:

```jsx
const classes = signal(['active', 'highlight']);

<div bind:class={classes} />
// Renders: <div class="active highlight"></div>
```

Falsy values are filtered out:

```jsx
<div bind:class={() => [
  isActive() && 'active',
  isDisabled() && 'disabled',
]} />
```
