# $ref

Bind reactivity to one existing DOM element: reactive text and attributes, event handlers, and lifecycle hooks, all chained off a single reference.

## Basic Usage

Use `$ref` to select and manipulate a single existing DOM element.

```js
import { signal } from "@hellajs/core";
import { $ref } from "@hellajs/dom";

const count = signal(0);

// Select the first button with class "btn"
const button = $ref(".btn");

// Bind reactive text content
button.text(() => `Count: ${count}`);

// Add event handler
button.on("click", () => count(count() + 1));
```

The reference is reactive: when `count` changes, the button text updates on its own.

## API

```typescript
// Find the first element matching a CSS selector
function $ref<T extends Element = Element>(selector: string): DomRef<T>

// Wrap an element you already hold
function $ref<T extends Element = Element>(element: T): DomRef<T>
```
- `selector`: A CSS selector string to find the first matching element.
- `element`: An element to wrap directly. Operations apply immediately.
- **Returns**: A reactive reference with `.text()`, `.attr()`, `.on()`, `.e()`, and `.hooks()` methods.

For multiple elements with auto-watching, see [`$collection`](/reference/dom/$collection).

## Key Concepts

### Callable Reference

The returned reference is callable - invoke it to get the raw DOM node.

```js
const ref = $ref("#app");

ref()      // The matched element or null
ref.node   // Same as above (property access)
```

### Method Chaining

All methods return the reference for fluent chaining.

```js
$ref(".counter")
  .text(() => `Count: ${count}`)
  .attr({ class: () => count() > 10 ? "high" : "low" })
  .on("click", () => count(count() + 1))
  .hooks({ afterMount: () => console.log("ready") });
```

### Reactive Bindings

Use `.text()` for text content and `.attr()` for attributes.

**Text/value binding** - pass a string or reactive function:

```js
const status = signal("idle");

// Static text
$ref(".label").text("Hello");

// Reactive text (updates when signal changes)
$ref(".status").text(() => status());
$ref(".status").text(status); // Signal directly also works
```

Form elements (INPUT, TEXTAREA, SELECT) automatically use `.value` instead of `.textContent`.

```js
$ref("#username").text("default value"); // Sets input.value
```

**Attribute binding** - pass an object:

```js
const isLoading = signal(false);

$ref(".btn").attr({
  disabled: () => isLoading(),
  class: ["btn", "primary"],           // Array joined with spaces
  "data-count": () => count()
});
```

Attribute behavior:
- `false`, `null`, `undefined` → removes attribute
- `true` → sets empty string attribute
- Arrays → filtered for falsy values, joined with spaces

### Event Handlers

Attach delegated event handlers with `.on()`: one shared capture-phase body listener per event type dispatches to every matching element.

```js
$ref(".btn").on("click", function(event) {
  console.log("Clicked:", this);  // "this" is the element
  console.log("Event:", event);
});

// Multiple event types via chaining
$ref(".input")
  .on("focus", () => console.log("focused"))
  .on("blur", () => console.log("blurred"));
```

### Direct Event Handlers

Attach non-delegated handlers with `.e()`. Unlike `.on()`, `.e()` calls `addEventListener` on the element itself. The plain form takes a handler; the spec form forwards native listener options (`once`, `passive`, `capture`) verbatim.

```js
// Plain handler; the wrapper types the event per DOMEventMap
$ref(".btn").e("focus", (event) => console.log("focused directly"));

// Spec form with native listener options
$ref(".slider").e("pointerdown", {
  handler: (event) => event.preventDefault(), // cancelable gesture
  options: { passive: false },
});
```

Prefer delegated `.on()` for most events. Reach for `.e()` when you need native listener options or a cancelable gesture: browsers treat body-level touch/wheel listeners as passive by default, so `preventDefault()` silently no-ops in `on:` handlers. A second `.e()` for the same event type replaces the first.

### Lifecycle Hooks

Add lifecycle hooks with `.hooks()`.

```js
$ref(".card").hooks({
  afterMount: () => console.log("Card mounted"),
  afterDestroy: () => console.log("Card removed")
});
```

Available hooks: `beforeMount`, `afterMount`, `beforeUpdate`, `afterUpdate`, `beforeDestroy`, `afterDestroy`

If the element is already mounted, `afterMount` hooks execute immediately.

### Wrapping an Element Directly

Pass an element instead of a selector when you already hold a reference. Operations apply immediately, no watching is started.

```js
import { signal } from "@hellajs/core";
import { $ref } from "@hellajs/dom";

const count = signal(0);

const button = document.createElement("button");
document.body.appendChild(button);

$ref(button)
  .text(() => `Count: ${count}`)
  .on("click", () => count(count() + 1));
```

## Important Considerations

### Detached Elements

When the passed element is detached (not in the document yet), `text`, `attr`, `on`, and `e` still apply immediately. `afterMount` waits until the element is inserted into a mounted container, and never fires for elements inserted outside one.

### Single Element Only

`$ref` returns the **first** matching element. For multiple elements with auto-watching for dynamically added nodes, use [`$collection`](/reference/dom/$collection).

```js
// Only selects the FIRST .item
const ref = $ref(".item");

// For all .item elements, use $collection
import { $collection } from "@hellajs/dom";
const refs = $collection(".item");
```

### Missing Elements Are Safe

If the selector matches nothing yet, `$ref` watches for a matching element: operations are queued and applied when it appears, and every method is a safe no-op until then. `$ref` stops watching once it finds its element.

```js
const ref = $ref(".not-in-yet");

ref()   // null
ref()   // still null; nothing throws

// Queued; applies automatically when a matching element is added to the DOM
ref.text("Hello");
ref.on("click", () => console.log("clicked"));
```

An element passed directly is always resolved, so it never starts watching. This differs from [`$collection`](/reference/dom/$collection), which continuously watches for all matching elements.
