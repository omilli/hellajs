# $ref

Reactive reference to a single DOM element with chainable methods for bindings, events, and hooks.

## API

```typescript
function $ref<T extends Element = Element>(selector: string): DomRef<T>
```
- `selector`: A CSS selector string to find the first matching element.
- **Returns**: A reactive reference with `.bind()`, `.on()`, and `.hooks()` methods.

For multiple elements with auto-watching, see [$collection](/reference/dom/collection).

## Basic Usage

Use `$ref` to select and manipulate a single existing DOM element.

```js
import { signal } from '@hellajs/core';
import { $ref } from '@hellajs/dom';

const count = signal(0);

// Select the first button with class 'btn'
const button = $ref('.btn');

// Bind reactive text content
button.bind(() => `Count: ${count()}`);

// Add event handler
button.on('click', () => count(count() + 1));
```

## Key Concepts

### Callable Reference

The returned reference is callable - invoke it to get the raw DOM node.

```js
const ref = $ref('#app');

ref()      // The matched element or null
ref.node   // Same as above (property access)
```

### Method Chaining

All methods return the reference for fluent chaining.

```js
$ref('.counter')
  .bind(() => `Count: ${count()}`)
  .bind({ class: () => count() > 10 ? 'high' : 'low' })
  .on('click', () => count(count() + 1))
  .hooks({ afterMount: () => console.log('ready') });
```

### Reactive Bindings

Use `.bind()` for text content or attributes.

**Text/Value binding** - pass a string or reactive function:

```js
const status = signal('idle');

// Static text
$ref('.label').bind('Hello');

// Reactive text (updates when signal changes)
$ref('.status').bind(() => status());
$ref('.status').bind(status); // Signal directly also works
```

Form elements (INPUT, TEXTAREA, SELECT) automatically use `.value` instead of `.textContent`.

```js
$ref('#username').bind('default value'); // Sets input.value
```

**Attribute binding** - pass an object:

```js
const isLoading = signal(false);

$ref('.btn').bind({
  disabled: () => isLoading(),
  class: ['btn', 'primary'],           // Array joined with spaces
  'data-count': () => count()
});
```

Attribute behavior:
- `false`, `null`, `undefined` → removes attribute
- `true` → sets empty string attribute
- Arrays → filtered for falsy values, joined with spaces

### Event Handlers

Attach event handlers with `.on()`.

```js
$ref('.btn').on('click', function(event) {
  console.log('Clicked:', this);  // 'this' is the element
  console.log('Event:', event);
});

// Multiple event types via chaining
$ref('.input')
  .on('focus', () => console.log('focused'))
  .on('blur', () => console.log('blurred'));
```

### Lifecycle Hooks

Add lifecycle hooks with `.hooks()`.

```js
$ref('.card').hooks({
  afterMount: () => console.log('Card mounted'),
  afterDestroy: () => console.log('Card removed')
});
```

Available hooks: `beforeMount`, `afterMount`, `beforeUpdate`, `afterUpdate`, `beforeDestroy`, `afterDestroy`

If the element is already mounted, `afterMount` hooks execute immediately.

## Important Considerations

### Single Element Only

`$ref` returns the **first** matching element. For multiple elements with auto-watching for dynamically added nodes, use [`$collection`](/reference/dom/collection).

```js
// Only selects the FIRST .item
const ref = $ref('.item');

// For all .item elements, use $collection
import { $collection } from '@hellajs/dom';
const refs = $collection('.item');
```

### Safe No-Op on Missing Elements

If the selector doesn't match any element, all methods are safe no-ops.

```js
const ref = $ref('.nonexistent');
ref()  // null
ref.node  // null

// These do nothing (no errors thrown)
ref.bind('text');
ref.on('click', () => {});
ref.hooks({ afterMount: () => {} });
```

### Auto-Watching Missing Elements

When an element doesn't exist, `$ref` automatically watches for it. Operations are queued and applied when the element appears.

```js
const ref = $ref('.not-in-yet');

// Element doesn't exist - operations are queued
ref.bind('Hello');
ref.on('click', () => console.log('clicked'));

// Later, when element is added to DOM:
document.body.appendChild(div);
// Queued operations automatically apply!
```

This differs from `$collection` which continuously watches for all matching elements. `$ref` stops watching once it finds its element.
