# raw

Embed pre-rendered HTML in a component exactly as-is: no escaping, no reactivity inside.

## Basic Usage

Wrap an HTML string with `raw()` to place it in a tree unescaped. The typical use is slot passthrough, where a foreign renderer has already produced HTML that must land in the page untouched.

```js
import { raw } from "@hellajs/dom";
import { ssr } from "@hellajs/ssr";

ssr({ tag: "main", children: [raw("<h1>Hi</h1><p>from a foreign renderer</p>")] });
// => '<main><!--[--><h1>Hi</h1><p>from a foreign renderer</p><!--]--></main>'
```

The wrapped region is opaque: `ssr` emits the HTML verbatim, and on the client [`hydrate`](/reference/dom/hydrate) adopts the existing DOM in place without binding anything inside. No reactive scope crosses the boundary.

## API

```typescript
function raw(html: string): HellaRaw
```

- `html`: The raw HTML string.
- **Returns**: A `HellaRaw` sentinel consumed by `ssr` and `hydrate`.

## Important Considerations

### Bypasses HTML Escaping (XSS)

`raw()` bypasses HTML escaping. **Never pass unsanitized user input**; it is an XSS vector. Sanitize untrusted HTML before wrapping it, exactly as you would for `dangerouslySetInnerHTML` / `set:html`.
