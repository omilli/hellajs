# mount

Renders HellaNodes to the DOM with reactive updates and lifecycle management.

## API

```typescript
// With a sync node or component function
function mount(
  hellaNode: HellaNode | (() => HellaNode),
  target?: string | Element
): MountHandle

// With an async component function
function mount(
  hellaNode: () => Promise<HellaNode | (() => HellaNode)>,
  target?: string | Element
): MountHandle
```
- `hellaNode`: A JSX element ([HellaNode](/learn/concepts/templates)) object or a function that returns one.
- `target`: A CSS selector string or DOM Element for the container. Defaults to `"#app"`.
- **Returns**: A [`MountHandle`](#mounthandle) with `flush()` and `unmount()` methods.

### MountHandle

```typescript
interface MountHandle {
  container: Element;
  flush(): void;
  unmount(): void;
}
```

- `container`: The DOM element the tree was mounted into.
- `flush()`: Optional escape hatch that drains the mount/cleanup queues synchronously. `afterMount` already fires during `mount()`, so this is only needed to force synchronous processing (e.g. `afterDestroy` in tests, or dynamically-added nodes).
- `unmount()`: Clean up and remove the mounted tree.

## Basic Usage

Pass a component function to `mount`. HellaJS will call this function to get the node tree and render it.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

// A simple component function
const Counter = () => {
  const count = signal(0);
  
  return (
    <div>
      <span>Count: {count}</span>
      <button on:click={() => count(count() + 1)}>
        Increment
      </button>
    </div>
  );
};

// Mount the component into the element with id="app"
mount(Counter, "#app");

// Defaults to #app if no selector is provided
mount(Counter);
```

## Key Concepts

### Reactive Context

`mount` establishes the reactive root where signals automatically update the DOM when values change.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const count = signal(0);
mount(<div>Count: {count}</div>, "#app");
```

### Component Functions

Components are plain functions that return HellaNodes, no classes or special syntax required.

```jsx
import { mount } from "@hellajs/dom";

const Greeting = ({name}) => <h1>Hello, {name}!</h1>;
mount(<Greeting name="World" />);
```

## Important Considerations

### Single Mount Point

Each `mount()` call creates an independent reactive tree - avoid multiple mounts on the same element.

```jsx
import { mount } from "@hellajs/dom";

// ❌ Multiple mounts on same element
mount(App1, "#app");
mount(App2, "#app");
```

### Async Component Errors

When an async component function rejects, the error routes through [`onError`](/reference/dom/onerror). If no handler is registered, the error is logged to `console.error`.

```jsx
import { mount, onError } from "@hellajs/dom";

onError((err) => {
  console.error("Mount failed:", err.message);
  return null;
});

mount(async () => {
  const data = await fetch("/api/data").then(r => r.json());
  return <div>{data.title}</div>;
});
```

### Lifecycle Hooks

Elements support lifecycle hooks via the [`hook:`](/reference/dom/hook) prefix. See [`hook:`](/reference/dom/hook) for all available hooks and usage patterns.

### Memory Management

HellaJS automatically manages reactive effects and event handlers. Reactive effects and DOM events are automatically cleaned up when elements are removed from the DOM. No manual cleanup is required for standard reactive bindings.

For component-level effects, use any of these approaches - they all provide automatic cleanup:

- **JSX syntax** - Babel plugin handles it
- **html`` templates** - Template system wraps components automatically
- **`component()` helper** - Manual wrapping for raw AST

```jsx
import { effect, signal } from "@hellajs/core";
import { mount, html } from "@hellajs/dom";

const Timer = () => {
  const seconds = signal(0);

  // This effect auto-cleans when Timer is removed from DOM
  effect(() => {
    const id = setInterval(() => seconds(seconds() + 1), 1000);
    return () => clearInterval(id);
  });

  return <span>{seconds}s</span>;
};

// Using JSX, component scope is automatic
mount(<Timer />);

// html`` also provides automatic component scope
mount(html`<${Timer} />`);
```
