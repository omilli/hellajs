# mount

Render a component into a DOM element: the tree becomes interactive on mount, reactive updates flow on their own, and unmounting cleans everything up.

## Basic Usage

Pass a component to `mount` and target a container element. The container's existing content is replaced.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const Counter = () => {
  const count = signal(0);

  return (
    <div>
      <span>Count: {count}</span>
      <button on:click={() => count(count() + 1)}>
        Increment
      </button>
    </div>
  );
};

// Mount into the element with id="app"
mount(Counter, "#app");

// "#app" is the default target
mount(Counter);
```

The target also accepts an `Element` or `ShadowRoot` directly, and the return value is a handle for cleanup:

```jsx
import { mount } from "@hellajs/dom";

const Status = () => <p>Ready</p>;

const app = mount(<Status />);

// Removes the tree and disposes every effect, handler, and hook in it
app.unmount();
```

## API

```typescript
// With a flagged build fn (the compiled component result)
function mount(
  node: TemplateBuildFn | (() => TemplateBuildFn),
  target?: string | Element | ShadowRoot
): MountHandle

// With an async component function
function mount(
  node: () => Promise<TemplateBuildFn | (() => TemplateBuildFn)>,
  target?: string | Element | ShadowRoot
): MountHandle
```

- `node`: A [flagged build fn](/reference/dom/runtime) (the compiled component result), a function returning one, or an async function resolving to one.
- `target`: A CSS selector string, DOM Element, or ShadowRoot for the container. Defaults to `"#app"`.
- **Returns**: A [`MountHandle`](#mounthandle) with `flush()` and `unmount()` methods.

### MountHandle

```typescript
interface MountHandle {
  container: Element | ShadowRoot;
  flush(): void;
  unmount(): void;
}
```

- `container`: The DOM element or shadow root the tree was mounted into.
- `flush()`: Escape hatch that drains mount and cleanup queues synchronously. `afterMount` already fires during `mount()`; reach for it only when you must observe cleanup immediately (common in tests).
- `unmount()`: Clean up and remove the mounted tree. A multi-root mount removes and disposes every root.

## Key Concepts

### One Mount, One Tree

Each `mount()` call creates an independent reactive tree. Mounting twice into the same element replaces the first tree: the second call unmounts the first tree's DOM.

```jsx
import { mount } from "@hellajs/dom";

const Header = () => <h1>Title</h1>;
const Footer = () => <footer>Bye</footer>;

mount(<Header />, "#app");
// Replaces the header's DOM; only the footer remains
mount(<Footer />, "#app");
```

### Fragment Roots

A template with multiple root elements mounts every root into the container, and `unmount()` removes them all.

```jsx
import { mount } from "@hellajs/dom";

const app = mount(
  <>
    <span>a</span>
    <span>b</span>
  </>
);

// Both roots removed, their effects disposed
app.unmount();
```

### Effects Clean Up Automatically

Effects created inside a mounted component are scoped to it. When the component's DOM is removed, its effects are disposed with it.

```jsx
import { effect, signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const Timer = () => {
  const seconds = signal(0);

  effect(() => {
    const id = setInterval(() => seconds(seconds() + 1), 1000);
    return () => clearInterval(id);
  });

  return <span>{seconds}s</span>;
};

// The interval clears itself when Timer's DOM is removed
mount(<Timer />);
```

## Important Considerations

### Hand-Built Input Is Rejected

`mount` accepts compiled build functions only; a hand-built tree object throws at mount time. JSX sources go through the [babel plugin](/plugins/babel) automatically. To construct DOM without the compiler, build imperatively via the [runtime](/reference/dom/runtime) module.

### Async Component Errors

When an async component function rejects, the error routes through [`onError`](/reference/dom/onerror). With no handler registered, the error is logged to `console.error`.

```jsx
import { mount, onError } from "@hellajs/dom";

onError((err) => {
  console.error("Mount failed:", err.message);
  return null;
});

mount(async () => {
  const data = await fetch("/api/data").then((r) => r.json());
  return <div>{data.title}</div>;
});
```

### Lifecycle Hooks

Elements support lifecycle hooks via the [`hook:`](/reference/dom/hook) prefix, from `beforeMount` through `afterDestroy`. See [`hook:`](/reference/dom/hook) for all available hooks and usage patterns.
