# element

Define a reactive custom element: attributes arrive as reactive getters, children and named slots are captured for projection, and updates re-render in place. Light DOM by default, shadow DOM opt-in.

## Basic Usage

Call `element` with a hyphenated tag name and a render function. Attributes on the element become reactive getters in `props`.

```jsx
import { signal } from "@hellajs/core";
import { element } from "@hellajs/dom";

type CounterProps = { initial?: () => string | null };

element("my-counter", (props: CounterProps) => {
  const count = signal(Number(props.initial?.()) || 0);

  return (
    <div>
      <span>{count}</span>
      <button on:click={() => count(count() + 1)}>+</button>
    </div>
  );
});
```

```html
<my-counter initial="5"></my-counter>
```

Change the attribute later and the element updates:

```js
document.querySelector("my-counter").setAttribute("initial", "10");
```

## API

```typescript
function element<T extends object = ComponentProps & Partial<ComponentSlots>>(
  tagName: string,
  render: ComponentRenderFn<T>,
  options?: ElementOptions
): void

type ComponentRenderFn<T> = (props: T) => HellaNode | (() => HellaNode);

interface ComponentProps {
  [key: string]: () => string | null;
}

interface ComponentSlots {
  children?: Node[];
  slots?: Record<string, Node[]>;
}

interface ElementOptions {
  shadow?: boolean | ShadowRootInit;
}
```

- `tagName`: The custom element tag name; must contain a hyphen (Web Components standard).
- `render`: Render function receiving `props`; returns the element's tree. Attribute values arrive as reactive getters (`ComponentProps`); children and named slots arrive as `ComponentSlots`.
- `options.shadow`: Render into a shadow root instead of light DOM.

## Key Concepts

### Reactive Attributes

Every attribute is a getter function returning the current string value (or `null` when absent). Call it inside an effect or reactive expression and the element re-renders when the attribute changes.

```jsx
type GreetingProps = { name?: () => string | null };

element("greeting-card", (props: GreetingProps) => (
  <h1>Hello, {props.name?.() ?? "World"}!</h1>
));
```

```html
<greeting-card name="Alice"></greeting-card>
<script>
  // Renders "Hello, Bob!" after this line
  document.querySelector("greeting-card").setAttribute("name", "Bob");
</script>
```

Attributes are strings: parse numbers and booleans where you need them.

```jsx
type SliderProps = {
  min?: () => string | null;
  max?: () => string | null;
  value?: () => string | null;
};

element("my-slider", (props: SliderProps) => {
  const min = () => Number(props.min?.() ?? 0);
  const max = () => Number(props.max?.() ?? 100);
  const value = signal(Number(props.value?.() ?? 50));

  return <input type="range" min={min()} max={max()} value={value} />;
});
```

### Slots and Children

Children of the element are captured before the first render. Unnamed children land in `props.children`; children carrying a `slot` attribute group into `props.slots` by slot name. Render them anywhere in the tree.

```jsx
element("card-layout", (props) => (
  <article>
    <header>{props.slots?.header}</header>
    <main>{props.children}</main>
    <footer>{props.slots?.footer}</footer>
  </article>
));
```

```html
<card-layout>
  <h1 slot="header">Card Title</h1>
  <p>Main content goes here</p>
  <small slot="footer">Footer text</small>
</card-layout>
```

### Shadow DOM

Pass `{ shadow: true }` to render into an open shadow root instead of light DOM; page CSS no longer leaks into the element's content.

```jsx
element("my-widget", (props: { children?: Node[] }) => (
  <div class="box">{props.children}</div>
), { shadow: true });
```

An options object is passed to `attachShadow` verbatim, so `mode: "closed"` works too. Projection still uses the captured `props.children` and `props.slots` nodes; native `<slot>` element projection is not available under `shadow: true` (see [Custom Elements](/learn/concepts/custom-elements)).

### Full Components

Everything composes: signals, [`ForEach`](/reference/dom/foreach), events, slots.

```jsx
import { signal } from "@hellajs/core";
import { element, ForEach } from "@hellajs/dom";

element("todo-list", () => {
  const items = signal<{ id: number; text: string }[]>([]);
  const input = signal("");

  const addItem = () => {
    if (input()) {
      items([...items(), { id: Date.now(), text: input() }]);
      input("");
    }
  };

  return (
    <div class="todo-list">
      <div class="input-group">
        <input
          type="text"
          value={input}
          on:keydown={(e) => e.key === "Enter" && addItem()}
        />
        <button on:click={addItem}>Add</button>
      </div>

      <ul>
        <ForEach
          each={items}
          use={(item: { id: number; text: string }) => <li key={item.id}>{item.text}</li>}
        />
      </ul>
    </div>
  );
});
```

## Important Considerations

### Connect, Disconnect, Reconnect

Effects and bindings are cleaned up when the element is removed from the DOM, and re-initialized when it is connected again. Children are captured after the parser finishes, before the first render, so `props.children` is always available inside the render function.

```jsx
import { effect, signal } from "@hellajs/core";

element("auto-refresh", () => {
  const data = signal("");

  // Clears its interval when the element is removed
  effect(() => {
    const id = setInterval(() => data(String(new Date())), 5000);
    return () => clearInterval(id);
  });

  return <div>{data}</div>;
});
```

### Light DOM by Default

Content renders in the element's light DOM, so page CSS applies normally. Opt into encapsulation with `{ shadow: true }` (see [Shadow DOM](#shadow-dom)).

### Tag Names Need a Hyphen

```js
// ✅ Valid names
element("my-component", render);
element("x-button", render);

// ❌ Invalid: no hyphen
element("mycomponent", render);
element("button", render);
```
