# $collection

Bind reactivity to every element matching a selector: reactive text and attributes, event handlers, and lifecycle hooks applied to all matches, including elements added to the page later.

## Basic Usage

```js
import { signal } from "@hellajs/core";
import { $collection } from "@hellajs/dom";

const count = signal(0);

// Select all buttons with class "btn"
const buttons = $collection(".btn");

// Bind reactive text to all matched elements
buttons.bind(() => `Count: ${count}`);

// Add event handlers to all elements
buttons.on("click", () => count(count() + 1));
```

Elements added to the DOM later that match the selector pick up the same bindings automatically.

## API

```typescript
function $collection<T extends Element = Element>(selector: string): DomCollection<T>
```
- `selector`: A CSS selector string to find all matching elements.
- **Returns**: A reactive reference with declarative methods and array-like access.

For a single element without collection watching, see [`$ref`](/reference/dom/$ref).

## Key Concepts

### Callable Reference

The returned reference is callable: invoke it with an index to get the raw DOM node at that position (undefined when out of bounds).

```js
const ref = $collection(".item");

ref()    // First matched element
ref(0)   // Same as above
ref(1)   // Second matched element
ref(99)  // undefined
```

### Length and Iteration

`length` counts the matches; `forEach` visits the current element wrappers for per-element logic.

```js
const items = $collection(".items");

console.log(items.length); // Number of matched elements

items.forEach((element, index) => {
  element.bind(`Item ${index + 1}`);
  element.bind({ "data-index": index.toString() });
});
```

### Method Chaining

All methods return the reference for fluent chaining.

```js
$collection(".counter")
  .bind(() => `Count: ${count}`)
  .bind({ class: () => count() > 10 ? "high" : "low" })
  .on("click", () => count(count() + 1))
  .hooks({ afterMount: () => console.log("ready") });
```

### Reactive Bindings

`.bind()` for text content or attributes, applied to **all** matched elements.

**Text/value binding** - pass a string or reactive function:

```js
const status = signal("idle");

// Static text on all elements
$collection(".label").bind("Hello");

// Reactive text (updates when signal changes)
$collection(".status").bind(() => status());
```

Form elements (INPUT, TEXTAREA, SELECT) automatically use `.value` instead of `.textContent`.

**Attribute binding** - pass an object:

```js
const isLoading = signal(false);

$collection(".btn").bind({
  disabled: () => isLoading(),
  class: ["btn", "primary"],
  "data-count": () => count()
});
```

Attribute behavior:
- `false`, `null`, `undefined` → removes attribute
- `true` → sets empty string attribute
- Arrays → filtered for falsy values, joined with spaces

### Event Handlers

Attach handlers to all matched elements, with `this` bound to the clicked element.

```js
$collection(".btn").on("click", function(event) {
  console.log("Clicked:", this);
  console.log("Event:", event);
});
```

### Lifecycle Hooks

Add hooks to all matched elements: `beforeMount`, `afterMount`, `beforeUpdate`, `afterUpdate`, `beforeDestroy`, `afterDestroy`. On already-mounted elements, `afterMount` runs immediately.

```js
$collection(".card").hooks({
  afterMount: () => console.log("Card mounted"),
  afterDestroy: () => console.log("Card removed")
});
```

## Important Considerations

### Watching Is the Difference From $ref

`$collection` keeps watching the DOM for new matching elements and applies every queued binding, handler, and hook to them on arrival. [`$ref`](/reference/dom/$ref) stops after finding its one element.

```js
const ref = $collection(".dynamic-item");
ref.bind("Hello");  // Applied to existing elements

// Later, anywhere in the app:
document.body.innerHTML += '<div class="dynamic-item"></div>';
// The new element now reads "Hello"
```

### Stop Watching With dispose()

Call `dispose()` to stop watching and drop queued operations. Bindings already applied to matched elements stay for each element's remaining lifetime and clean up when the element leaves the DOM.

```js
const ref = $collection(".temporary");
ref.bind("Content");

// Stop watching; later matches get nothing
ref.dispose();
```

### Bracket Access Is a Creation-Time Snapshot

`ref[0]` gives the wrapper that existed at creation; elements the watcher picked up later are reachable through `forEach` and the callable syntax.

```js
const ref = $collection(".item");

ref[0]  // First wrapper at creation time
ref()   // First element (always current)
```
