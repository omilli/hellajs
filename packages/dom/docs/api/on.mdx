# on:

Delegated event handlers: one shared listener per event type, automatic cleanup, and innermost-first dispatch.

## Usage

```jsx
import { mount } from "@hellajs/dom";

const App = () => {
  const handleClick = () => console.log("clicked");

  return (
    <button on:click={handleClick}>Click Me</button>
  );
};

mount(App, "#app");
```

Handlers receive the event and can be stacked on one element:

```jsx
const handleClick = () => console.log("clicked");
const handleChange = (event: Event) => console.log(event.target);
const handleFocus = () => console.log("focused");

<button on:click={handleClick}>Click Me</button>
<input on:input={handleChange} on:focus={handleFocus} />
```

## Key Concepts

### Delegation, Not per Element

`on:` registers one listener per event type on `document.body`, no matter how many elements use it. Handlers are cleaned up automatically when their element is removed from the DOM.

### Innermost Handler First

Handlers fire from the event's target outward: the innermost element's handler runs first, then each ancestor's in turn.

```jsx
const parentHandler = () => console.log("parent");
const childHandler = () => console.log("child");

<div on:click={parentHandler}>
  <button on:click={childHandler}>Click</button>
</div>

// Clicking the button logs "child", then "parent"
```

### Propagation

Every `on:` handler on the event path runs by default. Calling `event.stopPropagation()` (or `stopImmediatePropagation()`) halts the walk: handlers further out do not fire.

```jsx
const handler1 = () => console.log("one");
const handler2 = (e?: Event) => console.log("two");

// Both handlers fire
<div on:click={handler1}>
  <div on:click={handler2}>
    <button>Click Me</button>
  </div>
</div>

// handler2 fires, handler1 does not
<div on:click={handler1}>
  <div on:click={(e) => {
    e.stopPropagation();
    handler2(e);
  }}>
    <button>Click Me</button>
  </div>
</div>
```

## Important Considerations

### Touch and Wheel Are Passive by Default

Browsers treat body-level `touchstart`, `touchmove`, and `wheel` listeners as passive by default, and delegated `on:` handlers live on `document.body`. Calling `event.preventDefault()` inside a delegated handler for these events silently does nothing; the scroll cannot be canceled.

For cancelable gestures, attach a direct listener and opt out explicitly:

```jsx
<div
  e:touchmove={{ handler: (event) => event.preventDefault(), options: { passive: false } }}
>
  Drag to reorder
</div>
```

See [`e:`](/reference/dom/e) for the full direct-listener contract.
