# component

Wrap a manually-built component so its effects clean up when the component is removed from the DOM.

<Callout variant="info">This is a low-level API. JSX users never need it: the babel plugin wraps every component call automatically. Reach for it only when constructing component trees by hand.</Callout>

## Basic Usage

When you build trees by hand (raw AST objects, no JSX), wrap component calls with `component()`. Effects created inside the component are then scoped to it and disposed on removal.

```js
import { signal } from "@hellajs/core";
import { mount, component } from "@hellajs/dom";

const Counter = (props) => {
  const count = signal(props.initial ?? 0);

  return {
    tag: "button",
    on: { click: () => count(count() + 1) },
    children: [count],
  };
};

// Manual tree construction: wrap each component call
const app = {
  tag: "div",
  children: [
    component(Counter, { initial: 5 }),
    component(Counter, { initial: 10 }),
  ],
};

mount(app, document.body);
```

Without `component()`, effects created inside `Counter` would never be cleaned up when the node is removed.

## API

```typescript
function component<P extends Record<string, unknown>>(
  fn: (props: P) => ComponentReturn,
  props: P
): ComponentReturn
```

- `fn`: The component function to wrap.
- `props`: Props object passed to the component function.
- **Returns**: The component's build result with the disposal scope attached.

## Key Concepts

### JSX vs Raw AST

With JSX, the wrapping is automatic:

```jsx
const Counter = ({ initial }: { initial: number }) => <div>Count: {initial}</div>;

// The plugin compiles this to component(Counter, { initial: 5 })
<Counter initial={5} />;
```

With a hand-built tree, you wrap by hand:

```js
component(Counter, { initial: 5 })
```

### Each Level Needs Its Own Scope

Nested components each get their own `component()` call, at every level:

```js
const Parent = (props) => ({
  tag: "div",
  children: [
    component(Child, { name: "first" }),
    component(Child, { name: "second" }),
  ],
});

// Parent itself wrapped when used
mount(component(Parent, {}), document.body);
```

## Important Considerations

### Unwrapped Components Leak

A direct component call creates effects with no owner:

```js
// ❌ Effects created inside Counter are never cleaned up
const app = {
  tag: "div",
  children: [Counter({ initial: 5 })],
};

// ✅ Effects scoped and disposed with the node
const app = {
  tag: "div",
  children: [component(Counter, { initial: 5 })],
};
```

### Meta-Components Wrap Themselves

[`ForEach`](/reference/dom/foreach), [`Portal`](/reference/dom/portal), [`Lazy`](/reference/dom/lazy), [`Transition`](/reference/dom/transition), and [`Suspense`](/reference/dom/suspense) manage their own cleanup: call them directly, without `component()`.

```js
import { ForEach } from "@hellajs/dom";

const items = ["a", "b", "c"];
const renderItem = (item) => ({ tag: "li", children: [item] });

// No component() wrapper needed
const list = ForEach({ each: items, use: renderItem });
```
