# component

Wraps a component function with automatic effect cleanup scope.

<div role="alert" class="alert alert-info alert-soft">
  <span>ℹ️</span>
  <span>This is a low-level API used internally by the Babel plugin and `html` template system. You only need this when building components with raw HellaNode AST objects.</span>
</div>

## API

```typescript
function component(componentFn: ComponentFn, props: Record<string, unknown>): HellaNode
```

- `componentFn`: A function that returns a HellaNode.
- `props`: Props object passed to the component function.
- **Returns**: HellaNode with attached `componentScope` disposer for automatic cleanup.

## Basic Usage

When manually constructing component trees, wrap component calls with `component()`. You don't need `component()` if you're using JSX syntax or `html` templates; the Babel plugin and template system handle it automatically.

```js
import { signal } from "@hellajs/core";
import { mount, component } from "@hellajs/dom";

// A component function
const Counter = (props) => {
  const count = signal(props.initial ?? 0);
  
  return {
    tag: "button",
    on: { click: () => count(count() + 1) },
    children: [count]
  };
};

// Manual AST construction - must use component()
const app = {
  tag: "div",
  children: [
    component(Counter, { initial: 5 }),
    component(Counter, { initial: 10 })
  ]
};

mount(app, document.body);
```

Without `component()`, effects created inside `Counter` would not be cleaned up when the node is removed from the DOM.

## Key Concepts

### JSX vs html vs Raw AST

**With JSX (automatic):**

```jsx
const Counter = ({ initial }: { initial: number }) => <div>Count: {initial}</div>;

// Babel transforms this to component(Counter, { initial: 5 })
<Counter initial={5} />
```

**With html`` (automatic):**

```js
// Template system wraps in component() automatically
html`<${Counter} initial=${5} />`
```

**With raw AST (manual):**

```js
// You must wrap manually
component(Counter, { initial: 5 })
```

## Important Considerations

### Always Wrap Components

Without `component()`, effects leak and are never cleaned up:

```js
// ❌ Effects will leak
const app = {
  tag: "div",
  children: [Counter({ initial: 5 })]  // Direct call - no cleanup!
};

// ✅ Effects properly scoped
const app = {
  tag: "div",
  children: [component(Counter, { initial: 5 })]
};
```

### Passthrough Components

Some special components like `ForEach`, `Portal`, `Lazy`, and `Transition` bypass the `component()` wrapper because they manage their own cleanup:

```js
import { html, ForEach, Portal, Lazy } from "@hellajs/dom";

const items = ["a", "b", "c"];
const renderItem = (item: string) => html`<li>${item}</li>`;

// These components have `isDynamic: true` and are called directly without the `component()` wrapper
const list = ForEach({ each: items, use: renderItem });
const portal = Portal({ to: "#modal", children: [html`<div>Modal content</div>`] });
const lazy = Lazy({ loader: () => import("./Heavy.js") });
```

### Nested Components

Each component level needs its own scope:

```js
const Parent = (props) => ({
  tag: "div",
  children: [
    component(Child, { name: "first" }),
    component(Child, { name: "second" })
  ]
});

// Parent itself wrapped when used
mount(component(Parent, {}), document.body);
```

<details>
<summary>Internal Mechanics</summary>

`component()` creates a reactive scope around the component function:

```js
function component(componentFn, props) {
  let result;
  try {
    const dispose = scope(() => result = componentFn(props));
    result.componentScope = dispose;
  } catch (e) {
    dispatchError(e, { phase: "render" }); // Dispatches through error handling system
    return { tag: "$", children: [] };
  }
  return result;
}
```

- Calls the component function inside a `scope()`
- Attaches the disposer to the returned node as `componentScope`
- When the node is removed from DOM, cleanup system calls `componentScope()`

</details>
