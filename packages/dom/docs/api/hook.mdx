# hook:

Run code at points in an element's life: before or after it enters the DOM, around reactive updates, and at removal. Hooks attach directly to elements, no component wrapper needed.

## Usage

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <div
    hook:beforeMount={() => console.log("Creating element")}
    hook:afterMount={(element) => {
      // Safe to measure dimensions, initialize libraries, etc.
      const rect = element?.getBoundingClientRect();
      console.log("Element size:", rect?.width, rect?.height);
    }}
    hook:beforeUpdate={() => console.log("About to update")}
    hook:afterUpdate={() => console.log("Element updated")}
    hook:beforeDestroy={() => console.log("Cleaning up")}
    hook:afterDestroy={() => console.log("Element removed")}
  >
    Content
  </div>
);

mount(App, "#app");
```

## Key Concepts

### Available Hooks

| Hook | When it fires |
|------|---------------|
| `hook:beforeMount` | Synchronously before element is inserted into DOM |
| `hook:afterMount` | After element is in DOM (synchronously by the time `mount()`/`hydrate()` returns); dynamically added nodes on the next microtask |
| `hook:beforeUpdate` | Before reactive updates (not during initial render) |
| `hook:afterUpdate` | After reactive updates (not during initial render) |
| `hook:beforeDestroy` | Before element removal from DOM |
| `hook:afterDestroy` | After removal and effect cleanup |

### Access to Element

Most hooks receive the element as the first argument; `beforeMount` and `afterDestroy` do not. The parameter is typed `node?: Element`, so narrow before using element-specific APIs.

```jsx
<div
  hook:afterMount={(element) => {
    if (element instanceof HTMLElement) element.style.color = "red";
  }}
  hook:beforeDestroy={(element) => {
    console.log("cleaning up", element?.tagName);
  }}
>
  Content
</div>
```

### Initialize and Tear Down Third-Party Tools

The workhorse pattern: set up in `afterMount`, tear down in `beforeDestroy`, and keep per-element state in a `WeakMap` keyed by the element (typed, garbage-collectable, no property stashing on DOM nodes).

```jsx
interface Instance {
  destroy(): void;
}

const instances = new WeakMap<Element, Instance>();
const createInstance = (el: Element) => ({
  destroy: () => console.log("torn down", el.tagName),
});

<div
  hook:afterMount={(el) => {
    if (el) instances.set(el, createInstance(el));
  }}
  hook:beforeDestroy={(el) => {
    if (el) instances.get(el)?.destroy();
  }}
/>
```

The same shape drives chart libraries, subscriptions, observers, or any API with separate init and dispose steps: store the handle in the WeakMap, call its cleanup in `beforeDestroy`.

### Measure After Insertion

`afterMount` is the first moment dimensions are real:

```jsx
<div
  hook:afterMount={(el) => {
    const { width, height } = el?.getBoundingClientRect() ?? { width: 0, height: 0 };
    console.log("Dimensions:", width, height);
  }}
/>
```
