# hook:

Lifecycle hooks allow you to run code at specific points during an element's lifetime. Unlike component-based frameworks, hooks are tied directly to DOM elements.

## Usage

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <div
    hook:beforeMount={() => console.log("Creating element")}
    hook:afterMount={(element) => {
      // Safe to measure dimensions, initialize libraries, etc.
      const rect = element?.getBoundingClientRect();
      console.log("Element size:", rect?.width, rect?.height);
    }}
    hook:beforeUpdate={() => console.log("About to update")}
    hook:afterUpdate={() => console.log("Element updated")}
    hook:beforeDestroy={() => console.log("Cleaning up")}
    hook:afterDestroy={() => console.log("Element removed")}
  >
    Content
  </div>
);

mount(App, "#app");
```

## Key Concepts

### Available Hooks

| Hook | When it fires |
|------|---------------|
| `hook:beforeMount` | Synchronously before element is inserted into DOM |
| `hook:afterMount` | After element is in DOM — synchronously by the time `mount()`/`hydrate()` returns; dynamically added nodes on the next microtask |
| `hook:beforeUpdate` | Before reactive updates (not during initial render) |
| `hook:afterUpdate` | After reactive updates (not during initial render) |
| `hook:beforeDestroy` | Before element removal from DOM |
| `hook:afterDestroy` | After removal and effect cleanup |

### Access to Element

Most lifecycle hooks receive the element as the first argument. Exceptions: `beforeMount` and `afterDestroy` do not receive an element argument. The element arrives as `Element | undefined` — narrow before using HTMLElement-specific APIs.

```jsx
<div
  hook:afterMount={(element) => {
    // element is the DOM node (HTMLElement after an instanceof narrow)
    if (element instanceof HTMLElement) element.style.color = "red";
  }}
  hook:beforeDestroy={(element) => {
    // cleanup using the element reference
    console.log("cleaning up", element?.tagName);
  }}
>
  Content
</div>
```

### Common Patterns

Store per-element state in a `WeakMap` keyed by the element — typed, garbage-collectable, and no property stashing on DOM nodes.

```jsx
interface Instance {
  destroy(): void;
}

const instances = new WeakMap<Element, Instance>();
const subscribe = (onData: (data: string) => void) => ({
  unsubscribe: () => console.log("unsubscribed"),
});

<div
  hook:afterMount={(el) => {
    if (!el) return;
    instances.set(el, { destroy: () => console.log("destroyed", el.tagName) });
  }}
  hook:beforeDestroy={(el) => {
    if (el) instances.get(el)?.destroy();
  }}
/>
```

#### Initialize Third-Party Library

```jsx
interface Chart {
  destroy(): void;
}

const charts = new WeakMap<Element, Chart>();
const createChart = (el: Element) => ({
  destroy: () => console.log("chart destroyed", el.tagName),
});

<div
  hook:afterMount={(el) => {
    //… real libraries: const chart = new Chart(el, config)
    if (el) charts.set(el, createChart(el));
  }}
  hook:beforeDestroy={(el) => {
    if (el) charts.get(el)?.destroy();
  }}
/>
```

#### Measure DOM Dimensions

```jsx
<div
  hook:afterMount={(el) => {
    const { width, height } = el?.getBoundingClientRect() ?? { width: 0, height: 0 };
    console.log("Dimensions:", width, height);
  }}
/>
```

#### Setup and Cleanup Subscriptions

```jsx
const subscriptions = new WeakMap<Element, { unsubscribe(): void }>();
const dataSource = { subscribe: (onData: (data: string) => void) => ({ unsubscribe: () => console.log("done") }) };

<div
  hook:afterMount={(el) => {
    if (!el) return;
    subscriptions.set(
      el,
      dataSource.subscribe((data) => (el.textContent = data))
    );
  }}
  hook:beforeDestroy={(el) => {
    if (el) subscriptions.get(el)?.unsubscribe();
  }}
/>
```
