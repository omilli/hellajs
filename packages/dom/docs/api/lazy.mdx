# Lazy

Lazily loads and renders async components with optional fallback content.

## API

```typescript
function Lazy(props: LazyProps): JSX.Element

interface LazyOptions {
  signal?: AbortSignal;
}

interface LazyProps {
  loader: (options?: LazyOptions) => Promise<ComponentFn | HellaNode>;
  loading?: HellaChild;                              // Content to show while loading
  fallback?: HellaChild;                             // Fallback content on error
  props?: Record<string, unknown>;                  // Props to pass to loaded component
}
```

- `loader`: Async function that receives an options object with an optional `signal` for cancellation.
- `loading`: Content displayed between boundary markers while the loader Promise is pending.
- `fallback`: Content displayed if the loader Promise rejects.
- `props`: Forwarded to the loaded component function as its argument.
- **Returns**: A function with `isDynamic: true` that mounts into a parent element.

## Basic Usage

Use `Lazy` to load components asynchronously with automatic loading states and error handling.

```jsx
import { Lazy } from "@hellajs/dom";

const App = () => (
  <div>
    <Lazy
      loader={() => import("./HeavyComponent").then(mod => mod.default)}
      loading={<div>Loading...</div>}
    />
  </div>
);
```

## Key Concepts

### Async Component Loading

The `loader` function should return a Promise that resolves to either a component function or a HellaNode.

```jsx
// Function component
const fromModule = () => import("./MyComponent").then(mod => mod.default);

// Direct HellaNode
const fromNode = () => Promise.resolve({ tag: "div", children: ["Loaded"] });

// Factory function
const fromFactory = () => Promise.resolve((props: { message: string }) => (
  <div>{props.message}</div>
));
```

### Loading State

Provide optional loading content that displays while the component loads.

```jsx
<Lazy
  loader={() => import("./HeavyComponent")}
  loading={<div class="spinner">Loading...</div>}
  fallback={<div>Failed to load</div>}
/>
```

If no `loading` prop is provided, the space remains empty during load.

### Cancellation

When the parent element is removed during loading, the loader is automatically cancelled. The `loader` function receives an options object with an `AbortSignal`:

```jsx
<Lazy
  loader={({ signal } = {}) =>
    fetch("/api/component.js", { signal })
      .then(r => r.text())
      .then(html => ({ tag: "div", props: { class: "external" }, children: [html] }))
  }
  loading={<div>Loading...</div>}
  fallback={<div>Failed to load</div>}
/>
```

Existing `() => Promise` loaders continue to work — the options argument is ignored by functions that don't use it. The signal is useful for aborting network requests when the component is no longer needed.

### Fallback Content

Provide fallback content that displays when the loader fails.

```jsx
<Lazy
  loader={() => import("./UnreliableComponent")}
  fallback={
    <div class="error">
      Failed to load component
    </div>
  }
/>
```

### Props Passing

Pass props to the loaded component through the `props` attribute.

```jsx
<Lazy
  loader={() => import("./UserProfile")}
  props={{ userId: 123, theme: "dark" }}
  loading={<div>Loading profile...</div>}
/>
```

The loaded component receives these props:

```jsx
// UserProfile component
const UserProfile = ({ userId, theme }: { userId: number; theme: string }) => (
  <div class={`profile profile-${theme}`}>
    Loading profile for user: {userId}
  </div>
);
```

### html`` Template Syntax

Use Lazy with tagged template syntax.

```js
import { html, Lazy } from "@hellajs/dom";

html`
  <div>
    <${Lazy}
      loader=${() => import("./async-component")}
      fallback=${html`<div>Loading...</div>`}
      props=${{ message: "Hello" }}
    />
  </div>
`
```

## Important Considerations

### Loading Behavior

During loading, Lazy components either show the `loading` prop content or remain empty if no loading content is provided. On error, the `fallback` content is shown.

```jsx
// With loading prop: shows loading spinner during load
// On error: shows fallback content
// On success: shows loaded component
<Lazy
  loader={() => import("./SlowComponent")}
  loading={<div class="spinner">Loading...</div>}
  fallback={<div>Failed to load</div>}
/>
```

### Error Handling

Loader errors are caught locally. When `fallback` is provided, the fallback renders in place of the content. When no `fallback` is provided, the error is logged to `console.error` and nothing renders. Loader errors do **not** bubble to [`onError`](/reference/dom/onerror) — `Lazy` handles them entirely locally.

```jsx
const faultyLoader = async () => {
  throw new Error("Network error");
};

<Lazy
  loader={faultyLoader}
  fallback={<div>Something went wrong</div>}
/>
```

### Component Resolution

The loader can resolve to different component types:

```jsx
// Function component
const functionLoader = () => Promise.resolve((props: { text: string }) => <div>{props.text}</div>);

// Direct HellaNode object
const nodeLoader = () => Promise.resolve({ tag: "span", children: ["Direct node"] });

// Component class/function
const importLoader = () => import("./Component").then(mod => mod.default);
```

### Integration with ForEach

Lazy components integrate seamlessly with ForEach lists.

```jsx
import { signal } from "@hellajs/core";
import { ForEach } from "@hellajs/dom";
import type { ComponentFn, HellaNode } from "@hellajs/dom";

type LazyItem = { id: number; loader: () => Promise<ComponentFn | HellaNode> };

const lazyItems = signal<LazyItem[]>([
  { id: 1, loader: () => import("./Component1").then(mod => mod.default) },
  { id: 2, loader: () => import("./Component2").then(mod => mod.default) }
]);

<ForEach
  each={lazyItems}
  use={(item: LazyItem) => (
    <Lazy
      loader={item.loader}
      fallback={<div>Failed to load {item.id}</div>}
    />
  )}
/>
```

### Common Use Cases

**Code Splitting:**

```jsx
const AdminPanel = () => (
  <Lazy
    loader={() => import("./AdminDashboard")}
    fallback={<div>Loading admin tools...</div>}
  />
);
```

**Conditional Loading:**

```jsx
const FeatureFlag = ({ flag, children }: { flag: () => boolean; children?: unknown }) => (
  flag() ? (
    children
  ) : (
    <Lazy
      loader={() => import("./AlternativeFeature")}
      fallback={<div>Feature unavailable</div>}
    />
  )
);
```

**External Components:**

```jsx
const widgetConfig = { theme: "dark" };

const ThirdPartyWidget = () => (
  <Lazy
    loader={async () => {
      //… real loader: const widget = await loadExternalWidget()
      const widget = {
        render: (config: { theme: string }) => ({ tag: "div", children: [`Widget ${config.theme}`] }),
      };
      return (props: Record<string, unknown>) => {
        const { config } = props as { config: { theme: string } };
        return widget.render(config);
      };
    }}
    fallback={<div>Widget loading...</div>}
    props={{ config: widgetConfig }}
  />
);
```
