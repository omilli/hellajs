# Lazy

Load a component on demand: the loader starts when the element mounts, `loading` shows while it runs, `fallback` shows on failure.

## Basic Usage

```jsx
import { Lazy } from "@hellajs/dom";

const App = () => (
  <div>
    <Lazy
      loader={() => import("./HeavyComponent").then((mod) => mod.default)}
      loading={<div>Loading...</div>}
    />
  </div>
);
```

## API

```typescript
function Lazy(props: LazyProps): JSX.Element

interface LazyOptions {
  signal?: AbortSignal;
}

interface LazyProps {
  loader: (options?: LazyOptions) => Promise<ComponentFn | TemplateBuildFn>;
  loading?: HellaChild;
  fallback?: TemplateBuildFn;
  props?: Record<string, unknown>;
}
```

- `loader`: Async function returning the loaded component. Receives an options object with an optional `signal` for cancellation.
- `loading`: Content shown while the loader Promise is pending. Empty space when omitted.
- `fallback`: Content shown when the loader rejects.
- `props`: Forwarded to the loaded component as its argument.
- **Returns**: A dynamic render function that mounts into a parent element.

## Key Concepts

### What the Loader Returns

The loader resolves to a component function (the `default` export of a dynamic import is the common shape) or a flagged build fn. Props pass through `props`:

```jsx
import type { ComponentFn } from "@hellajs/dom";

const loadProfile = async (): Promise<ComponentFn> => {
  const mod = await import("./UserProfile");
  return mod.default;
};

<Lazy
  loader={loadProfile}
  props={{ userId: 123, theme: "dark" }}
  loading={<div>Loading profile...</div>}
/>
```

The loaded component receives the props:

```jsx
const UserProfile = ({ userId, theme }: { userId: number; theme: string }) => (
  <div class={`profile profile-${theme}`}>
    Loading profile for user: {userId}
  </div>
);
```

### Cancellation

When the parent element is removed during loading, the load is cancelled. The options object carries an `AbortSignal` for aborting network requests the loader started:

```jsx
<Lazy
  loader={({ signal } = {}) =>
    fetch("/api/component.js", { signal })
      .then((r) => r.text())
      .then((html) => () => <div class="external">{html}</div>)
  }
  loading={<div>Loading...</div>}
  fallback={<div>Failed to load</div>}
/>
```

Loaders that ignore the options argument keep working unchanged.

### Errors Are Handled Locally

A rejected loader renders `fallback`; without one, the error is logged to `console.error` and nothing renders. Loader errors do **not** bubble to [`onError`](/reference/dom/onerror).

```jsx
const faultyLoader = async () => {
  throw new Error("Network error");
};

<Lazy
  loader={faultyLoader}
  fallback={<div>Something went wrong</div>}
/>
```

## Important Considerations

### Server Rendering and Hydration

Under `ssr.async` and `ssr.stream` (see the [ssr docs](/reference/ssr/ssr)), the loader runs on the server and the loaded component renders into the HTML; the loader must be server-executable (a dynamic `import()` needs a server-resolvable module). A rejected loader renders `fallback`, or rejects the render when none is provided. The synchronous `ssr` call cannot await: it emits the `loading` content without calling the loader. On the client, [`hydrate`](/reference/dom/hydrate) re-runs the loader (the chunk must load for interactivity) and keeps the server-rendered content on screen until the fresh render replaces it, with no loading flash.

### In Lists

`Lazy` composes with [`ForEach`](/reference/dom/foreach) for per-item deferred loading:

```jsx
import { signal } from "@hellajs/core";
import { ForEach, Lazy } from "@hellajs/dom";
import type { ComponentFn } from "@hellajs/dom";

type LazyItem = { id: number; loader: () => Promise<ComponentFn> };

const lazyItems = signal<LazyItem[]>([
  { id: 1, loader: () => import("./Component1").then((mod) => mod.default) },
  { id: 2, loader: () => import("./Component2").then((mod) => mod.default) },
]);

<ForEach
  each={lazyItems}
  use={(item: LazyItem) => (
    <Lazy
      loader={item.loader}
      fallback={<div>Failed to load {item.id}</div>}
    />
  )}
/>
```
