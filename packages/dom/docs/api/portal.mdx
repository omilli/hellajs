# Portal

Render children into a remote DOM location: modals, toasts, and overlays escape their parent's stacking or overflow context while keeping their reactivity and cleanup.

## Basic Usage

Point `to` at a selector and the children render there instead of in place. The target element must already exist in the document.

```jsx
import { signal } from "@hellajs/core";
import { mount, Portal } from "@hellajs/dom";

const App = () => {
  const open = signal(false);

  return (
    <div>
      <button on:click={() => open(true)}>Open modal</button>
      {open() && (
        <Portal to="#modal-root">
          <div class="modal" on:click={() => open(false)}>
            Click the backdrop to close
          </div>
        </Portal>
      )}
    </div>
  );
};

mount(App, "#app");
```

```html
<!-- Somewhere in the page, outside #app -->
<div id="modal-root"></div>
```

Content stays reactive inside the target:

```jsx
import { signal } from "@hellajs/core";
import { Portal } from "@hellajs/dom";

const message = signal("Initial");

<Portal to="#notifications">
  <div class="toast">{message}</div>
</Portal>

// Later...
message("Updated!"); // The toast in #notifications updates
```

## API

```typescript
function Portal(props: PortalProps): JSX.Element

interface PortalProps {
  to: string;
  type?: PortalInsertType;
  children?: HellaChildren;
}

type PortalInsertType = "append" | "prepend" | "replace" | "before" | "after";
```

- `to`: CSS selector for the target element, resolved with `querySelector` when the portal mounts.
- `type`: How content is inserted relative to the target. Defaults to `"append"`. Any other value throws at construction.
- `children`: The content to portal; a single child or an array.
- **Returns**: A dynamic render function the renderer dispatches into its parent.

## Key Concepts

### Insertion Types

**`append`** (default) inserts as the target's last child; **`prepend`** as its first child; **`replace`** swaps the target's content; **`before`** and **`after`** insert as siblings of the target itself.

```jsx
// Inside #container, after any existing children
<Portal to="#container">
  <span>Appended</span>
</Portal>

// Replaces everything inside #container
<Portal to="#container" type="replace">
  <span>Replaces all target content</span>
</Portal>

// Sits next to the target element, not inside it
<Portal to="#banner" type="before">
  <span>Inserted before #banner</span>
</Portal>
```

### Lifecycle Travels With the Content

Portal children keep their lifecycle hooks and reactive bindings:

```jsx
<Portal to="#external">
  <div
    hook:afterMount={() => console.log("Mounted in portal target")}
    hook:afterDestroy={() => console.log("Cleaned up")}
  >
    Content with lifecycle
  </div>
</Portal>
```

## Important Considerations

### The Target Must Exist Before Mount

The `to` selector is resolved when the portal's region mounts, and a miss throws `[dom] Portal: target "#modal-root" not found in document` inside the containing render. Put the container in your page HTML, create it before mounting the app, or gate the portal on the target's presence.

```jsx
// ❌ #modals is not in the document yet: the containing render throws
<Portal to="#modals">
  <div class="modal">Dialog</div>
</Portal>
```

```jsx
// ✅ Create the host first, then portal into it
const host = document.createElement("div");
host.id = "modals";
document.body.append(host);
```

### Cleanup Follows the Source Region

Removing the portal's region in the original tree removes the remote nodes and unwinds their state; nested portals inside portaled content detach with it. Never hand-delete portal content from the target: remove or unmount the source region instead.

```jsx
const App = () => {
  const showModal = signal(true);

  return (
    <div>
      {showModal() && (
        <Portal to="#modal-root">
          <div>Cleans up when showModal turns false</div>
        </Portal>
      )}
    </div>
  );
};
```

### Common Recipes

```jsx
import { Portal } from "@hellajs/dom";
import type { HellaChildren } from "@hellajs/dom";

type DialogProps = { onClose: () => void; children?: HellaChildren };

const Dialog = ({ onClose, children }: DialogProps) => (
  <div class="dialog-backdrop" on:click={onClose}>
    <div class="dialog" on:click={(event) => event.stopPropagation()}>
      {children}
    </div>
  </div>
);

// Mount conditionally; the caller owns open state
// {dialogOpen() && <Portal to="#dialog-root"><Dialog onClose={close}>...</Dialog></Portal>}
```

```jsx
import { Portal } from "@hellajs/dom";

type TooltipProps = { x: number; y: number; label: string };

const Tooltip = ({ x, y, label }: TooltipProps) => (
  <Portal to="body">
    <div class="tooltip" style={`top: ${y}px; left: ${x}px`}>
      {label}
    </div>
  </Portal>
);
```

```jsx
import { Portal } from "@hellajs/dom";

type ToastProps = { message: string; kind: string };

const Toast = ({ message, kind }: ToastProps) => (
  <Portal to="#toast-root" type="prepend">
    <div class={`toast toast-${kind}`}>{message}</div>
  </Portal>
);
```
