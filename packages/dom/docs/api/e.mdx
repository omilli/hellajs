# e:

Event handlers attached directly to the element. Use for non-bubbling events (`focus`, `blur`), cancelable gestures, or third-party code expecting real listeners; everything else belongs on [`on:`](/reference/dom/on).

## Usage

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <form e:submit={(e) => e.preventDefault()}>
    <button type="submit">Submit</button>
  </form>
);

mount(App, "#app");
```

A direct listener participates in the browser's native listener chain, so `stopPropagation()` stops real listeners on the same elements, including ones other libraries registered:

```jsx
<div e:click={() => console.log("parent")}>
  <div e:click={(e) => {
    e.stopPropagation();
    console.log("child - stops here");
  }}>
    <button>Click Me</button>
  </div>
</div>

// Only "child - stops here" is logged
```

## Key Concepts

### Bubble Phase, Child First

Direct events fire in the bubble phase, the DOM default: the target's handler runs first, then ancestors' handlers as the event bubbles up.

```jsx
const parentHandler = () => console.log("parent");
const childHandler = () => console.log("child");

<div e:click={parentHandler}>
  <button e:click={childHandler}>Click</button>
</div>

// Clicking the button logs "child", then "parent"
```

### Listener Options

The `e:` value is either the handler function or a spec object pairing the handler with native listener options: `once`, `passive`, and `capture` are forwarded to `addEventListener` verbatim.

```jsx
const onceHandler = () => console.log("fired");

<button e:click={{ handler: onceHandler, options: { once: true } }}>Fire once</button>
```

```jsx
const trackMove = (event: MouseEvent) => console.log(event.clientX);

<div e:mousemove={{ handler: trackMove, options: { passive: true } }}>
  Move the pointer
</div>
```

Use the spec form when a gesture must be cancelable: `passive: false` opts out of the browser's passive-by-default touch and wheel treatment; delegated [`on:`](/reference/dom/on) handlers cannot do this.
