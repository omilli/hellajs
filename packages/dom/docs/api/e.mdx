# e:

Event handlers attached directly to the element via `addEventListener`. Use `e:` sparingly since it creates one listener per element, versus the single global listener used by [`on:`](/reference/dom/on).

## Usage

```jsx
import { mount } from "@hellajs/dom";

const parentHandler = () => console.log("parent");
const childHandler = () => console.log("child");

const App = () => (
  <form e:submit={(e) => e.preventDefault()}>
    <button type="submit">Submit</button>
  </form>
);

mount(App, "#app");
```

Use `e:` instead of `on:` when a handler must be a real DOM listener on the element: for non-bubbling events (`focus`, `blur`), for third-party libraries that expect direct listeners, or for edge cases where delegation causes issues. Delegated `on:` handlers also honor `stopPropagation()` — see [`on:`](/reference/dom/on) — but only `e:` participates in the browser's native listener chain.

```jsx
<div e:click={(e) => e.stopPropagation()}>
  {/* clicks won't bubble to parent */}
</div>
```

## Key Concepts

### Event Phase

Direct events fire in the **bubble phase** (after the event reaches the target). This is the default DOM behavior and differs from `on:` which uses capture phase.

```jsx
// Bubble phase (e:)
<div e:click={parentHandler}>
  <button e:click={childHandler}>Click</button>
</div>

// childHandler fires first, then parentHandler
```

### Propagation Control

With `e:` handlers, `stopPropagation()` works through the browser's native listener chain — it stops real listeners, including ones other libraries registered on the same elements:

```jsx
<div e:click={() => console.log("parent")}>
  <div e:click={(e) => {
    e.stopPropagation();
    console.log("child - stops here");
  }}>
    <button>Click Me</button>
  </div>
</div>

// Only "child - stops here" is logged
```

### Listener Options

The `e:` value is either the handler function or a spec object pairing the handler with native listener options — `once`, `passive`, and `capture` are forwarded to `addEventListener` verbatim. The spec matches the exported `DirectListenerSpec` type.

```ts
import { html } from "@hellajs/dom";

const onceHandler = () => console.log("fired");

html`<button e:click={{ handler: onceHandler, options: { once: true } }}>Fire once</button>`;
```

```jsx
const trackMove = (event: MouseEvent) => console.log(event.clientX);

<div e:mousemove={{ handler: trackMove, options: { passive: true } }}>
  Move the pointer
</div>
```

Use the spec form when a gesture must be cancelable: `passive: false` opts out of the browser's passive-by-default touch and wheel treatment — see [`on:`](/reference/dom/on) for why delegated handlers cannot do this.
