# bind:

Create reactive bindings between signals and DOM attributes. When the signal value changes, the attribute updates automatically.

## Usage

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const isActive = signal(false);
const theme = signal("dark");
const inputValue = signal("hello");

const App = () => (
  <div>
    <div bind:class={isActive() ? "active" : ""}>
      Content
    </div>
    <input bind:value={inputValue} />
    <div bind:style={`color: ${theme}`} />
  </div>
);

mount(App, "#app");
```

## Key Concepts

### Reactive Expressions

Pass a signal **reference** for a reactive binding — `bind:class={className}` works identically in JSX and `html\`\``. A **compound** expression (`bind:class={count() > 5 ? …}`) calls the signal and auto-wraps in compiled code; runtime `html\`\`` needs an explicit `() => …` wrapper.

```jsx
// Signal reference
bind:class={className}
// Compound expression — auto-wrapped in compiled code
bind:class={count() > 5 ? "large" : "small"}
```

To bind a value that should never update (a true one-time snapshot), hoist the read or wrap it in [`untracked`](/reference/core/untracked) — a signal reference like `bind:class={count}` is reactive, not static.

### Attribute Types

#### String Attributes

```jsx
const itemId = signal(123);
const className = signal("active");

<div bind:class={className} />
<div bind:id={`item-${itemId()}`} />
<a bind:href={isActive() ? "#active" : "#inactive"}>Link</a>
```

#### Boolean Attributes

```jsx
const isDisabled = signal(false);
const isChecked = signal(true);

<button bind:disabled={isDisabled}>
  Submit
</button>

<input type="checkbox" bind:checked={isChecked} />
```

When the function returns `true`, the attribute is added. When `false`/`null`/`undefined`, it's removed.

#### Array Attributes

Attributes accept array values, which are joined with spaces:

```jsx
const classes = signal(["active", "highlight"]);

<div bind:class={classes} />
// Renders: <div class="active highlight"></div>
```

Falsy values are filtered out:

```jsx
<div bind:class={[
  isActive() && "active",
  isDisabled() && "disabled",
]} />
```

## Important Considerations

### Reactive vs Static

A `bind:` expression that reads a signal is reactive (auto-wrapped). A value with no signal read — a literal, a hoisted constant, or an [`untracked`](/reference/core/untracked) read — binds once and never updates. Use the latter deliberately when you want a snapshot.

```jsx
// Reactive: updates when count changes
<div bind:class={count() > 0 ? "has-items" : "empty"} />

// Static snapshot: read once, never updates
const label = count() > 0 ? "has-items" : "empty";
<div bind:class={label} />
```
