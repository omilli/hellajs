# on:

Delegated event handlers attached globally to `document.body` in the capture phase.

## Overview

The `on:` prefix attaches event handlers using a global delegation system. A single listener per event type handles all delegated events across the entire document.

**Benefits:**
- One listener per event type regardless of element count
- Automatic cleanup when elements are removed
- Consistent capture-phase behavior
- Efficient for large numbers of elements

## Usage

```jsx
<button on:click={handleClick}>Click Me</button>
<input on:input={handleChange} on:focus={handleFocus} />
```

## How It Works

1. A global listener is created on `document.body` for each event type
2. Your handler is stored directly on the element as a property
3. When clicked, the global listener routes the event via `composedPath()`

## Event Phase

Delegated events fire in the **capture phase** (before the event reaches the target). This is different from direct event listeners which default to the bubble phase.

```jsx
// Capture phase (on:)
<div on:click={parentHandler}>
  <button on:click={childHandler}>Click</button>
</div>

// parentHandler fires first, then childHandler
```

## Propagation

The system does **NOT** stop propagation automatically. It traverses the entire event path to allow multiple handlers to execute.

```jsx
// Both handlers will fire
<div on:click={handler1}>
  <div on:click={handler2}>
    <button>Click Me</button>
  </div>
</div>
```

## Supported Events

Any standard DOM event is supported:

- Mouse: `click`, `dblclick`, `mousedown`, `mouseup`, `mousemove`, `mouseenter`, `mouseleave`
- Keyboard: `keydown`, `keyup`, `keypress`
- Form: `submit`, `input`, `change`, `focus`, `blur`
- Touch: `touchstart`, `touchend`, `touchmove`
- And more...

```jsx
<input
  on:focus={handleFocus}
  on:blur={handleBlur}
  on:input={handleChange}
  on:keydown={handleKeyDown}
/>
```

## Multiple Handlers

You can attach multiple handlers for the same event type:

```jsx
<button
  on:click={trackAnalytics}
  on:click={handleSubmit}
>
  Submit
</button>
```

Both handlers will execute in order when the button is clicked.

## Comparison with e:

Use `on:` for most cases. Use `e:` when:
- You need `event.stopPropagation()` to work predictably
- Working with third-party libraries expecting direct listeners
- Edge cases where delegation causes issues

| Feature | `on:` | `e:` |
|---------|-------|------|
| Listener type | Global (one per type) | Per element |
| Phase | Capture | Bubble |
| stopPropagation | Limited | Full support |
| Performance | Excellent for many elements | One listener per element |
