# Components

Components are plain functions that return elements. They compose through props and children, keep reactivity across boundaries, and clean up their effects when they leave the DOM.

## Defining and Using

A component is a function with an uppercase name in JSX.

```jsx
import type { HellaChildren } from "@hellajs/dom";

type CardProps = { title: string; children?: HellaChildren };

const Card = ({ title, children }: CardProps) => (
  <div class="card">
    <h2>{title}</h2>
    <div class="card-content">{children}</div>
  </div>
);

// JSX
<Card title="Hi">Content</Card>
```

## Composition

Components nest like ordinary functions. Extract multi-prop types to a named `type` and pass handlers as plain props the component wires itself.

```jsx
import { mount } from "@hellajs/dom";
import type { HellaChildren } from "@hellajs/dom";

type ButtonProps = { variant?: string; click: () => void; children?: HellaChildren };

const Button = ({ variant = "primary", click, children }: ButtonProps) => (
  <button class={`btn btn-${variant}`} on:click={click}>
    {children}
  </button>
);

type PageProps = { title: string };

const MyPage = ({ title }: PageProps) => (
  <Card title={title}>
    <p>Welcome to our application!</p>
    <Button click={() => console.log("Hello!")}>Get Started</Button>
  </Card>
);

mount(<MyPage title="Welcome" />, "#app");
```

Prefixed attrs at a call site also pass through verbatim: `<Button on:click={fn}>` arrives as `props["on:click"]`, and the component forwards it back onto its root element. See [attribute prefixes](/learn/concepts/attribute-prefixes).

To forward the whole set, type the component with `HTMLAttributes` and spread the rest props onto the root:

```jsx
import type { HTMLAttributes } from "@hellajs/dom";

type SpreadButtonProps = HTMLAttributes<"button"> & { variant?: string };

const SpreadButton = ({ variant = "primary", ...rest }: SpreadButtonProps) => (
  <button class={`btn btn-${variant}`} {...rest} />
);

// Every prefixed key arrives verbatim and forwards:
// <SpreadButton disabled on:click={fn} on:focusin={fn} />
```

Caller attributes override the component's own defaults: `{...rest}` spreads last, so a caller's `disabled` or `on:click` wins.

## Data Flow: Pass Signals as Props

Hand a signal to a child component and read it inside the child's template expressions; the binding stays reactive across the boundary.

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";
import type { Signal } from "@hellajs/core";

type Todo = { id: number; text: string; priority: string; done: boolean };
type TodoCardProps = { todo: Signal<Todo> };

const TodoCard = ({ todo }: TodoCardProps) => (
  <div class="todo-card">
    <h3>{todo().text}</h3>
    <p>Priority: {todo().priority}</p>
    <span class={`status ${todo().done ? "completed" : "pending"}`}>
      {todo().done ? "Completed" : "Pending"}
    </span>
  </div>
);

const TodoApp = () => {
  const selectedTodo = signal({
    id: 1,
    text: "Learn HellaJS",
    priority: "high",
    done: false,
  });

  return (
    <div class="todo-app">
      <TodoCard todo={selectedTodo} />
      <button on:click={() => selectedTodo({
        id: 2,
        text: "Build awesome app",
        priority: "medium",
        done: true,
      })}>
        Switch Todo
      </button>
    </div>
  );
};

mount(TodoApp, "#app");
```

### Component props and children are not auto-wrapped

Automatic reactive wiring applies to **element** children. Component props and component children pass through as-is: `<Comp>{expr}</Comp>` passes the eager-evaluated value. To keep a component child reactive, pass a signal reference (`<Comp>{mySignal}</Comp>`) or an explicit function (`<Comp>{() => expr}</Comp>`).

## Scope and Cleanup

Effects created inside a component are scoped to it and disposed when the component leaves the DOM.

```jsx
import { mount } from "@hellajs/dom";
import { signal, effect } from "@hellajs/core";

const Timer = () => {
  const count = signal(0);

  effect(() => console.log(`Count: ${count}`));

  return <h1>{count}</h1>;
};

mount(Timer, "#app");
// When Timer leaves the DOM, its effect is disposed automatically
```

JSX wraps every component with this scope automatically; the low-level [`component`](/reference/dom/component) function does the same for hand-built trees. Render errors dispatch through the error system and render an empty fragment; see [Error Handling](/learn/concepts/error-handling).
