# Headless Behaviors

Headless behaviors are pure DOM wiring functions: focus traps, escape and outside-click listeners, roving tabindex, anchor positioning, hover intent, menu typeahead, pointer drag, swipe gestures, pinch gestures, timed presses, double taps, and layered dismissal. They move focus, position overlays, and attach document-level events; they never own markup or state.

## Behavior Functions, Not Components

Each behavior is one function that takes real DOM nodes and returns a dispose handle. There is no component wrapper, no props object, no hidden instance: [`trapFocus`](/reference/dom/trapfocus) takes a container, [`onEscape`](/reference/dom/onescape) takes a target and a callback, [`onOutside`](/reference/dom/onoutside) takes a getter and a callback, [`rovingTabIndex`](/reference/dom/rovingtabindex) takes a container, [`anchorPosition`](/reference/dom/anchorposition) takes an anchor and a floating element, [`hoverIntent`](/reference/dom/hoverintent) takes a target and open/close handlers, [`menuTypeahead`](/reference/dom/menutypeahead) takes a container and an item getter, [`onDrag`](/reference/dom/ondrag) takes an element and move handling, [`onSwipe`](/reference/dom/onswipe) takes commit and cancel handling for a swipe, [`onPinch`](/reference/dom/onpinch) takes scale and translation handling for a two-pointer pinch, [`onLongPress`](/reference/dom/onlongpress) takes a timed-press handler with drift tolerance, [`onDoubleTap`](/reference/dom/ondoubletap) takes double- and single-tap handling, and [`layerDismissal`](/reference/dom/layerdismissal) takes a getter and a callback.

A headless component layer would rebuild component machinery HellaJS already has (component detection, lazy and async wrappers) and force props-passthrough plumbing onto what are three one-line wirings. Behavior functions compose with whatever renders the DOM: signals and templates, portals, custom elements, or no HellaJS at all.

## State Stays in Caller Signals

The behaviors hold no per-instance state. Which panel is open, which tab is active, whether the menu is dismissed: all of it lives in your signals, and the behaviors read it through the callbacks and getters you hand them. [`onOutside`](/reference/dom/onoutside) never learns what a portal is; it re-invokes your getter and trusts the nodes it returns. Two deliberate exceptions coordinate across wirings: [`hoverIntent`](/reference/dom/hoverintent) keeps a shared skip-delay clock and [`layerDismissal`](/reference/dom/layerdismissal) keeps a shared layer stack. The functions are dependency-free wiring over real nodes: they take plain nodes and callbacks, so they compose with any state model, HellaJS or not.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { onOutside } from "@hellajs/dom";

const open = signal(false);

const Menu = () => (
  <nav hook:afterMount={(node) => {
    if (!(node instanceof HTMLElement)) return;
    // open() is the single source of truth; onOutside only reports the gesture
    onOutside(() => [node], () => open(false));
  }}>
    <button>Menu</button>
  </nav>
);

mount(<Menu />, "#app");
```

## The Dispose-Handle Contract

Every behavior returns `() => void`. The handle removes the listeners and undoes the DOM mutations the behavior made ([`trapFocus`](/reference/dom/trapfocus) restores the pre-trap focus, [`rovingTabIndex`](/reference/dom/rovingtabindex) restores original `tabindex` attributes, [`anchorPosition`](/reference/dom/anchorposition) stops repositioning). Several wirings listen on `document` or `window`, so a dispose skipped on close leaks a live global listener: call the handle in the same path that closes or unmounts the UI.

## Composing With `hook:` and `$ref`

The `hook:` element prefixes are the natural mount and cleanup points: wire in `hook:afterMount`, dispose in `hook:beforeDestroy`. The hook hands you the very element it sits on, so no querying is needed at any layer.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { trapFocus, onEscape, onOutside } from "@hellajs/dom";

const open = signal(false);
const cleanup: (() => void)[] = [];

const Dialog = () => (
  <div class="overlay">
    <div
      class="panel"
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        cleanup.push(
          trapFocus(node),
          onEscape(node, () => open(false)),
          onOutside(() => [node], () => open(false))
        );
      }}
      hook:beforeDestroy={() => {
        cleanup.forEach((dispose) => dispose());
        cleanup.length = 0;
      }}
    >
      <button on:click={() => open(false)}>Close</button>
    </div>
  </div>
);

mount(<div>{() => (open() ? <Dialog /> : <p>Nothing open</p>)}</div>, "#app");
```

For markup you did not render (static HTML, server-generated pages), [`$ref`](/reference/dom/$ref) and [`$collection`](/reference/dom/$collection) fill the same role: resolve the nodes, wire the behaviors, keep the handles beside the ref. Inside your own templates, prefer `hook:`. The behaviors take plain `Node`s, so any way of producing a node works.

## Anchoring Floating Elements

[`anchorPosition`](/reference/dom/anchorposition) pins a floating element to an anchor and repositions it on scroll and resize; flip, shift-clamp, and width matching come from one `options` object. Every coordinate it applies is computed by [`computeAnchorPosition`](/reference/dom/computeanchorposition), a pure function over plain rects, so placement logic is testable without a DOM.

```jsx
import { mount } from "@hellajs/dom";
import { anchorPosition } from "@hellajs/dom";

let disposeAnchor: (() => void) | undefined;

const MenuButton = () => (
  <span>
    <button
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        const panel = node.nextElementSibling as HTMLElement;
        disposeAnchor = anchorPosition(node, panel, { placement: "bottom-start" });
      }}
      hook:beforeDestroy={() => disposeAnchor?.()}
    >
      Actions
    </button>
    <div class="menu-panel">Panel content</div>
  </span>
);

mount(<MenuButton />, "#app");
```

## Hover Intent and the Shared Skip-Delay Window

[`hoverIntent`](/reference/dom/hoverintent) is the tooltip and hover-card timing contract: an open delay on hover or focus, a close delay on leave, an immediate close on an outside press. It also keeps a module-level skip-delay clock: opening within 500ms of a previous open fires `onOpen` instantly, so moving between adjacent triggers never re-incurs the delay. The clock is shared by every wiring on the page.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { hoverIntent } from "@hellajs/dom";

const show = signal(false);
let disposeIntent: (() => void) | undefined;

const Trigger = () => (
  <button
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeIntent = hoverIntent(node, {
        onOpen: () => show(true),
        onClose: () => show(false)
      });
    }}
    hook:beforeDestroy={() => disposeIntent?.()}
  >
    ?
  </button>
);

mount(<Trigger />, "#app");
```

## Menu Typeahead

[`menuTypeahead`](/reference/dom/menutypeahead) buffers printable keystrokes into a case-insensitive query (reset 500ms after the last key) and selects the first match: a `startsWith` scan first, then a substring scan that wraps around from the item after the last selection. Arrow keys and modifier chords pass through untouched, so typeahead composes with roving-focus navigation.

```jsx
import { mount } from "@hellajs/dom";
import { menuTypeahead } from "@hellajs/dom";

let disposeTypeahead: (() => void) | undefined;

const collectItems = (menu: HTMLElement) =>
  Array.from(menu.querySelectorAll<HTMLElement>("[data-menu-item]")).map((node) => ({
    node,
    text: node.textContent ?? ""
  }));

const Menu = () => (
  <div
    role="menu"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeTypeahead = menuTypeahead(node, () => collectItems(node), (item) => item.node.focus());
    }}
    hook:beforeDestroy={() => disposeTypeahead?.()}
  >
    <button role="menuitem" data-menu-item>Cut</button>
    <button role="menuitem" data-menu-item>Copy</button>
    <button role="menuitem" data-menu-item>Paste</button>
  </div>
);

mount(<Menu />, "#app");
```

## Pointer Drag

[`onDrag`](/reference/dom/ondrag) reports cumulative deltas from the drag start and leaves all value math to the consumer: slider thumbs clamp, drawer swipes measure distance. It captures the pointer when the environment allows it and ends once on `pointerup`, `pointercancel`, or `lostpointercapture`. Draggable elements need `touch-action: none` to hold off native scrolling; the wiring never touches styles.

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { onDrag } from "@hellajs/dom";

const offset = signal(0);
let disposeDrag: (() => void) | undefined;

const Thumb = () => (
  <div
    class="thumb"
    style="touch-action: none"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeDrag = onDrag(node, { onMove: ({ dx }) => offset(dx) });
    }}
    hook:beforeDestroy={() => disposeDrag?.()}
  />
);

mount(<Thumb />, "#app");
```

## Layered Dismissal

[`layerDismissal`](/reference/dom/layerdismissal) is the outside-click and Escape contract for overlays that stack: a submenu over a menu over a popover. Each layer pushes onto a shared module-level stack, and a gesture reaches only the top layer, so one dismissal closes one surface. The `onDismiss` callback must dispose the layer in the same path; the dismissal never pops the stack itself.

```jsx
import { mount } from "@hellajs/dom";
import { layerDismissal } from "@hellajs/dom";

let disposeLayer: (() => void) | undefined;

const Submenu = () => (
  <div
    class="submenu"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeLayer = layerDismissal(() => [node], () => node.remove());
    }}
    hook:beforeDestroy={() => disposeLayer?.()}
  >
    <button>Rename</button>
  </div>
);

mount(<Submenu />, "#app");
```
