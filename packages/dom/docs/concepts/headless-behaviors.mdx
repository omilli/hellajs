# Headless Behaviors

Ready-made wiring for common UI mechanics: trapping focus in a dialog, closing a menu on outside clicks, anchoring a popover to its trigger, opening tooltips on a hover delay, searching a menu by typing, and tracking pointer gestures. Each is a plain function you call with DOM elements and callbacks.

## Close a Menu on Outside Clicks

Every behavior follows the same pattern as this one: call it with an element and a callback, get work done.

```jsx
import { signal } from "@hellajs/core";
import { mount, onOutside } from "@hellajs/dom";

const open = signal(false);

const Menu = () => (
  <nav hook:afterMount={(node) => {
    if (!(node instanceof HTMLElement)) return;
    // open() stays the single source of truth; onOutside only reports the click
    onOutside(() => [node], () => open(false));
  }}>
    <button on:click={() => open(!open())}>Menu</button>
  </nav>
);

mount(<Menu />, "#app");
```

The `hook:afterMount` hook fires when the `<nav>` enters the DOM and hands you the element; [`onOutside`](/reference/dom/onoutside) calls your handler whenever a pointerdown lands outside the nodes its getter returns. Your signal owns the state; the behavior only reports the gesture.

## What You Can Use

| Job | Behavior |
|---|---|
| Dismiss on Escape or outside click | [`onEscape`](/reference/dom/onescape), [`onOutside`](/reference/dom/onoutside), [`layerDismissal`](/reference/dom/layerdismissal) |
| Keyboard navigation | [`trapFocus`](/reference/dom/trapfocus), [`rovingTabIndex`](/reference/dom/rovingtabindex), [`menuTypeahead`](/reference/dom/menutypeahead) |
| Position a floating element | [`anchorPosition`](/reference/dom/anchorposition), [`computeAnchorPosition`](/reference/dom/computeanchorposition) |
| Open and close on a delay | [`hoverIntent`](/reference/dom/hoverintent) |
| Pointer gestures | [`onDrag`](/reference/dom/ondrag), [`onSwipe`](/reference/dom/onswipe), [`onPinch`](/reference/dom/onpinch), [`onLongPress`](/reference/dom/onlongpress), [`onDoubleTap`](/reference/dom/ondoubletap) |

Each has its own reference page with the full options.

## The Shared Contract

- **Elements and callbacks in, dispose handle out.** Every behavior returns `() => void`. Several of them listen on `document` or `window`, so call the handle when the UI closes or the element unmounts; a skipped dispose leaves a live global listener behind.
- **State stays in your signals.** Which panel is open, which tab is active: all of it lives in your code. The behaviors read current state through the getters and callbacks you hand them, and never hold per-instance state.
- **They compose with any renderer.** The functions take plain DOM nodes, so they work with templates and signals, portals, custom elements, or no HellaJS at all.

## Wire With hook: Mount and Cleanup

`hook:afterMount` is the natural place to wire a behavior and `hook:beforeDestroy` the place to dispose it. The dialog below combines three behaviors: trapped focus, Escape to close, and outside click to close.

```jsx
import { signal } from "@hellajs/core";
import { mount, trapFocus, onEscape, onOutside } from "@hellajs/dom";

const open = signal(false);
const cleanup: (() => void)[] = [];

const Dialog = () => (
  <div class="overlay">
    <div
      class="panel"
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        cleanup.push(
          trapFocus(node),
          onEscape(node, () => open(false)),
          onOutside(() => [node], () => open(false))
        );
      }}
      hook:beforeDestroy={() => {
        cleanup.forEach((dispose) => dispose());
        cleanup.length = 0;
      }}
    >
      <button on:click={() => open(false)}>Close</button>
    </div>
  </div>
);

mount(<div>{() => (open() ? <Dialog /> : <p>Nothing open</p>)}</div>, "#app");
```

[`trapFocus`](/reference/dom/trapfocus) keeps Tab and Shift+Tab inside the panel, wrapping from the last focusable child to the first. When the dialog closes, `beforeDestroy` fires and every handle runs.

## Wire Existing HTML

For markup you did not render (static HTML, server-generated pages), [`$ref`](/reference/dom/$ref) and [`$collection`](/reference/dom/$collection) fill the same role: resolve the nodes, wire the behaviors, keep the handles beside the ref. Inside your own templates, prefer `hook:`.

## Anchor a Floating Element

[`anchorPosition`](/reference/dom/anchorposition) pins a floating element to an anchor and keeps it placed while the page scrolls or resizes. One `options` object controls placement, offset, and matching the floating width to the anchor.

```jsx
import { mount, anchorPosition } from "@hellajs/dom";

let disposeAnchor: (() => void) | undefined;

const MenuButton = () => (
  <span>
    <button
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        const panel = node.nextElementSibling as HTMLElement;
        disposeAnchor = anchorPosition(node, panel, {
          placement: "bottom-start",
          matchAnchorWidth: true,
        });
      }}
      hook:beforeDestroy={() => disposeAnchor?.()}
    >
      Actions
    </button>
    <div class="menu-panel">Panel content</div>
  </span>
);

mount(<MenuButton />, "#app");
```

Need a one-shot position with no tracking? [`computeAnchorPosition`](/reference/dom/computeanchorposition) computes placement over plain rects, no listeners attached.

## Open on Hover With a Delay

[`hoverIntent`](/reference/dom/hoverintent) is the tooltip timing contract: open after a hover or focus delay, close after a leave delay, close instantly on an outside press. The delay is shared across the page: when any trigger opened within the last 500ms, the next open fires instantly, so moving between adjacent triggers never feels laggy.

```jsx
import { signal } from "@hellajs/core";
import { mount, hoverIntent } from "@hellajs/dom";

const showTip = signal(false);
let disposeIntent: (() => void) | undefined;

const TipButton = () => (
  <button
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeIntent = hoverIntent(node, {
        onOpen: () => showTip(true),
        onClose: () => showTip(false),
      });
    }}
    hook:beforeDestroy={() => disposeIntent?.()}
  >
    ?
  </button>
);

mount(<TipButton />, "#app");
```

Delays are configurable through the same options object.

## Search a Menu by Typing

[`menuTypeahead`](/reference/dom/menutypeahead) lets a menu user type to select: printable keystrokes buffer into a case-insensitive query and the first match is selected, preferring items that start with the query. The query resets 500ms after the last keystroke. Arrow keys and modifier chords pass through untouched, so typeahead composes with [`rovingTabIndex`](/reference/dom/rovingtabindex) navigation.

```jsx
import { mount, menuTypeahead } from "@hellajs/dom";

let disposeTypeahead: (() => void) | undefined;

const collectItems = (menu: HTMLElement) =>
  Array.from(menu.querySelectorAll<HTMLElement>("[data-menu-item]")).map((node) => ({
    node,
    text: node.textContent ?? "",
  }));

const Menu = () => (
  <div
    role="menu"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeTypeahead = menuTypeahead(node, () => collectItems(node), (item) => item.node.focus());
    }}
    hook:beforeDestroy={() => disposeTypeahead?.()}
  >
    <button role="menuitem" data-menu-item>Cut</button>
    <button role="menuitem" data-menu-item>Copy</button>
    <button role="menuitem" data-menu-item>Paste</button>
  </div>
);

mount(<Menu />, "#app");
```

## Track Pointer Gestures

[`onDrag`](/reference/dom/ondrag) reports cumulative `{ dx, dy }` deltas from the drag start and leaves all value math to you: slider thumbs clamp, drawer swipes measure distance. One drag ends on `pointerup`, `pointercancel`, or a lost capture.

```jsx
import { signal } from "@hellajs/core";
import { mount, onDrag } from "@hellajs/dom";

const dragOffset = signal(0);
let disposeDrag: (() => void) | undefined;

const Thumb = () => (
  <div
    class="thumb"
    style="touch-action: none"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeDrag = onDrag(node, { onMove: ({ dx }) => dragOffset(dx) });
    }}
    hook:beforeDestroy={() => disposeDrag?.()}
  />
);

mount(<Thumb />, "#app");
```

Give draggable elements `touch-action: none` in your CSS so native scrolling does not steal the pointer; the wiring never touches styles.

The gesture family covers the rest: [`onSwipe`](/reference/dom/onswipe) commits a swipe past a threshold or velocity, [`onPinch`](/reference/dom/onpinch) reports scale and translation for two-finger pinches, [`onLongPress`](/reference/dom/onlongpress) fires after a timed press with drift tolerance, and [`onDoubleTap`](/reference/dom/ondoubletap) fires on a second tap within a window.

## Dismiss Stacked Overlays One Layer at a Time

When overlays stack (a submenu over a menu over a popover), a dismissal should close one surface, not all of them. [`layerDismissal`](/reference/dom/layerdismissal) keeps a page-wide stack: Escape or an outside click dismisses only the top layer. Your `onDismiss` callback must dispose the wiring in the same path.

```jsx
import { mount, layerDismissal } from "@hellajs/dom";

let disposeLayer: (() => void) | undefined;

const Submenu = () => (
  <div
    class="submenu"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeLayer = layerDismissal(() => [node], () => node.remove());
    }}
    hook:beforeDestroy={() => disposeLayer?.()}
  >
    <button>Rename</button>
  </div>
);

mount(<Submenu />, "#app");
```

For single-surface cases, `onEscape` and `onOutside` are enough; reach for `layerDismissal` when surfaces stack.
