
# Lazy Loading

Load components on demand using [`Lazy`](/reference/dom/lazy), with optional loading states and error fallbacks. Useful for code splitting and reducing initial bundle size.

```jsx
import { mount, Lazy } from '@hellajs/dom';

const App = () => (
  <div>
    <Lazy
      loader={() => import('./HeavyComponent').then((mod) => mod.default)}
      loading={<div>Loading...</div>}
      fallback={<div>Failed to load</div>}
    />
  </div>
);

mount(App, '#app');
```

## Loading States

The `loader` function returns a Promise that resolves to a component function or HellaNode. Show optional content while loading:

```jsx
<Lazy
  loader={() => import('./Chart')}
  loading={<div class="spinner">Loading chart...</div>}
/>
```

If no `loading` prop is provided, the space remains empty during load.

## Error Handling

Loader errors are caught internally by the `Lazy` component and trigger the `fallback` directly, independent of the global [`onError`](/reference/dom/onerror) handler:

```jsx
<Lazy
  loader={() => import('./UnreliableComponent')}
  fallback={<div class="error">Component failed to load</div>}
/>
```

## Props Forwarding

Pass props to the loaded component:

```jsx
<Lazy
  loader={() => import('./UserProfile')}
  props={{ userId: 123, theme: 'dark' }}
/>
```

The loaded component receives these props as its argument.

## html Template Syntax

```js
import { html, Lazy } from '@hellajs/dom';

html`<div>
  <${Lazy}
    loader=${() => import('./async-component')}
    fallback=${html`<div>Failed</div>`}
    props=${{ message: 'Hello' }}
  />
</div>`
```

See [`Lazy`](/reference/dom/lazy) for full API details.
