# Control Flow

HellaJS uses function references for dynamic content. Wrap conditionals and dynamic expressions in functions to keep them reactive.

## Conditional Rendering

Function references make conditionals reactive, they re-evaluate when their signal dependencies change.

<div role="alert" class="alert alert-error text-base">
  <span>Unlike other frameworks, you <strong style="color: inherit; font-weight:800">MUST</strong> wrap conditionals in a reactive function.</span>
</div>

```jsx
import { mount } from '@hellajs/dom';
import { signal } from '@hellajs/core';

const Counter = () => {
  const count = signal(0);

  return (
    <div>
      <h1>Count: {count}</h1>
      <h2>Doubled: {() => count() * 2}</h2>
      <p>Count is: {() => count() % 2 === 0 ? 'even' : 'odd'}</p>
      {() => count() > 5 && <p>Great job! Count is greater than 5!</p>}
      <button on:click={() => count(count() + 1)}>
        Increment
      </button>
    </div>
  );
};

mount(Counter, '#app');
```

## Lists and Iteration

Use [`ForEach`](/reference/dom/foreach) for reactive lists that change over time. Use regular array methods for static lists rendered once.

```jsx
import { mount, ForEach } from '@hellajs/dom';
import { signal } from '@hellajs/core';

const TodoList = () => {
  const todos = signal([
    { id: 1, text: 'Learn HellaJS', done: false },
    { id: 2, text: 'Build an app', done: false }
  ]);

  return (
    <ul>
      <ForEach each={todos} use={(todo) => (
        <li key={todo.id} class={todo.done ? 'done' : ''}>
          <input
            type="checkbox"
            checked={todo.done}
            on:change={e => {
              const updated = todos().map(t =>
                t.id === todo.id ? { ...t, done: e.target.checked } : t
              );
              todos(updated);
            }}
          />
          {todo.text}
        </li>
      )} />
    </ul>
  );
};

mount(TodoList, '#app');
```

**Static lists** (no reactivity): `{todos().map(todo => <li>{todo.text}</li>)}`

See [`ForEach`](/reference/dom/foreach) for keyed reconciliation details.

## Portals

Render content to a different DOM location while maintaining reactivity.

```jsx
import { mount, Portal } from '@hellajs/dom';
import { signal } from '@hellajs/core';

const Modal = () => {
  const isOpen = signal(false);

  return (
    <div>
      <button on:click={() => isOpen(true)}>Open</button>
      {() => isOpen() && (
        <Portal to="#modal-root" type="append">
          <div class="modal">
            <button on:click={() => isOpen(false)}>Close</button>
            <p>Content rendered in modal-root</p>
          </div>
        </Portal>
      )}
    </div>
  );
};

mount(Modal, '#app');
```

**Portal types:** `append` (default), `prepend`, `replace`, `before`, `after`

See [`Portal`](/reference/dom/portal) for full details.

## Lazy Loading

Load components asynchronously with automatic code splitting. [`Lazy`](/reference/dom/lazy) shows optional loading state during load and optional fallback on error.

```jsx
import { Lazy } from '@hellajs/dom';

const Dashboard = () => {
  return (
    <div>
      <h1>Dashboard</h1>
      <Lazy
        loader={() => import('./HeavyChart')}
        loading={<div>Loading chart...</div>}
        fallback={<div>Failed to load chart</div>}
      />
    </div>
  );
};
```

- `loading`: Shown during async load (optional)
- `fallback`: Shown on loader error only (optional)

See [`Lazy`](/reference/dom/lazy) for full details.
