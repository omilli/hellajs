# Attribute Prefixes

Attributes that carry behavior instead of values: `on:` and `e:` for events, `hook:` for lifecycle, `error:` for error handling. Plain attributes stay reactive without any prefix.

## Delegated Events: on:

One shared listener per event type, automatic cleanup. Reach for it by default: 1,000 buttons still cost one click listener.

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <button on:click={() => console.log("Clicked")}>Click Me</button>
);

mount(App, "#app");
```

Handlers fire innermost-first, and `stopPropagation()` works as expected. One limit: delegated `touchstart`/`touchmove`/`wheel` handlers are passive, so `event.preventDefault()` silently fails; use `e:` with `{ passive: false }` for cancelable gestures. See [`on:`](/reference/dom/on).

## Direct Events: e:

A real listener on the element itself, in the bubble phase. Use it for non-bubbling events (`focus`, `blur`), cancelable gestures, or third-party code that expects direct listeners.

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <button e:click={(e) => {
    e.stopPropagation();
    console.log("Direct click");
  }}>Click Me</button>
);

mount(App, "#app");
```

The value may also be a `{ handler, options }` spec forwarding native listener options (`once`/`passive`/`capture`) to `addEventListener`. See [`e:`](/reference/dom/e).

## Reactive Attributes: No Prefix

Any attribute whose value is a function or signal is reactive: the DOM updates when the value's dependencies change.

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const isActive = signal(false);

const App = () => (
  <div class={isActive() ? "active" : "inactive"}>
    <button on:click={() => isActive(!isActive())}>Toggle</button>
  </div>
);

mount(App, "#app");
```

The `style` attribute also accepts an object of CSS declarations: camelCase keys serialize to kebab-case, falsy declarations are skipped, and numbers carry no automatic units (write `"12px"`, not `12`).

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const theme = signal("light");

mount(
  <div style={{ color: theme() === "dark" ? "#fff" : "#000", fontSize: "12px" }}>hi</div>,
  "#app"
);
```

A reactive style object re-serializes when its dependencies change; a static one serializes once.

## Lifecycle Hooks: hook:

Run code at points in an element's life: entering the DOM, around updates, at removal. Hooks attach to elements directly, and multiple hooks of the same type all run in registration order.

```jsx
import { mount } from "@hellajs/dom";

const App = () => (
  <div
    hook:afterMount={() => console.log("Element is in DOM")}
    hook:beforeDestroy={() => console.log("About to be removed")}
  >
    Content
  </div>
);

mount(App, "#app");
```

The full timing table (`beforeMount` through `afterDestroy`) lives in [`hook:`](/reference/dom/hook).

## Error Configuration: error:

Handle a subtree's errors where it sits: fallback UI, a category for filtering, or a boundary that stops propagation.

```jsx
import { mount } from "@hellajs/dom";

const FlakyComponent = () => <div>Flaky content</div>;

const App = () => (
  <div error:fallback={(e: Error) => <span>Error: {e.message}</span>} error:category="sidebar">
    <FlakyComponent />
  </div>
);

mount(App, "#app");
```

See [`error:`](/reference/dom/error) for the full contract.

## Prefixes Pass Through Components

A prefixed attribute on a component arrives in its props verbatim (`props["on:click"]`, `props["hook:afterMount"]`). Forward it by re-emitting the same attribute on an element in the component's template; the wiring activates on the element.

```jsx
type SubmitButtonProps = { "on:click"?: () => void };

const SubmitButton = (props: SubmitButtonProps) => (
  <button on:click={props["on:click"] ?? (() => {})}>Submit</button>
);
```
