# Templates

Templates bind reactive values directly to DOM elements, enabling surgical updates without virtual DOM diffing.

## Compiled Templates

JSX is the only template syntax. A build-time plugin (`babel-plugin-hellajs`, wired by the Vite, Rollup, and Astro integrations) compiles each component into plain [`HellaNode`](/reference/dom) objects: the same AST [`mount`](/reference/dom/mount) consumes, built once at module load instead of parsed at runtime. Nothing in the shipped bundle parses markup; the compiler does that work when your app builds.

Compilation is where reactivity gets wired. The rules below describe what the compiler emits; every rule holds identically on the server, where [`ssr`](/reference/ssr) walks the same AST to a string.

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const count = signal(0);

const App = () => (
  <div>
    <h1>{count}</h1>
    <button on:click={() => count(count() + 1)}>Increment</button>
  </div>
);

mount(App, "#app");
```

### Reactive Bindings

A signal **reference** is the simplest reactive binding. A **compound** expression (arithmetic, conditional, method call) calls the signal and the compiler auto-wraps it in a reactive thunk. Both update the DOM when their dependencies change.

```jsx
// Signal reference: updates when count changes
<h1>{count}</h1>

// Arithmetic: re-runs when count changes (auto-wrapped; no manual wrapper)
<h2>{count() * 2}</h2>

// Reactive conditional: re-evaluates when count changes
{count() > 5 && <p>Great job!</p>}
```

The auto-wrap applies to element children and element attributes only. Component children and props arrive as plain values; pass an explicit thunk when a component documents a getter prop. An explicit function is never wrapped again, so `{() => count() * 2}` behaves exactly like the auto-wrapped form.

### Static Values

To read a signal once with no reactivity, hoist the read out of the template or wrap it in [`untracked`](/reference/core/untracked).

```jsx
import { untracked } from "@hellajs/core";

// Hoist: read once into a plain value
const total = count();
<h1>{total}</h1>

// untracked: read once inside the template, no dependency tracked
<h1>{untracked(() => count())}</h1>
```

### Value Normalization

`false`, `null`, and `undefined` render as empty strings. `0` is preserved as `"0"`.

```jsx
{false}      // renders nothing
{null}       // renders nothing
{undefined}  // renders nothing
{0}          // renders "0"
```

### Array Attributes

Array values for attributes are joined with spaces, filtering falsy values. A call inside the array makes the whole attribute reactive in compiled code; no manual wrapper needed.

```jsx
const isActive = signal(true);

<div class={["base", isActive() && "active", "always"]}>
  {/* Compiled: isActive() auto-wraps, class="base active always"; → "base always" once false */}
</div>
```

## Static Hoisting

A fully-static subtree (lowercase tag, literal-only props, static text and children) hoists to a module-level constant allocated once per site. Every later use mounts that constant via a single clone instead of re-walking construction, so repeated static markup costs one allocation total.

Anything dynamic disqualifies the subtree: expressions, components, spreads, and [`attribute prefixes`](/learn/concepts/attribute-prefixes) (`on:`, `e:`, `hook:`, `error:`), which bind handlers and lifecycle hooks the clone must not share. Static children of a disqualified parent still hoist individually, so one dynamic boundary never flattens the whole tree.

## SVG and MathML

SVG and MathML mount in their correct namespaces automatically: an `<svg>` root creates in the SVG namespace, descendants inherit it, and a `<math>` root creates in the MathML namespace. No wrappers or namespace configuration are needed.

```jsx
import { mount } from "@hellajs/dom";

mount(
  <svg width="24" height="24">
    <clipPath id="clip"><rect width="10" height="10" /></clipPath>
  </svg>,
  "#app"
);
```

Dynamic content works the same way: [`ForEach`](/reference/dom/foreach), [`Lazy`](/reference/dom/lazy), and reactive children under an SVG parent all create their elements in the inherited namespace.

### CamelCase Tags

Multi-word SVG and MathML tags are authored camelCase (`clipPath`, `linearGradient`, `feGaussianBlur`), exactly as in hand-written SVG. The compiler preserves tag case, and cased attributes like `viewBox` and `patternUnits` pass through unchanged.

### foreignObject Resets to HTML

Inside `<foreignObject>` the namespace resets to HTML: its children are regular HTML elements. To re-enter SVG, open a new `<svg>` element inside.

```jsx
<svg>
  <foreignObject width="100" height="50">
    <div>HTML content here</div>
  </foreignObject>
</svg>
```

One edge: error fallback UI (from [`error:fallback`](/reference/dom/error)) always renders as HTML, even when the failing boundary sits inside an SVG subtree; keep fallback markup HTML-only.

## Bundle Composition

Every prefix and namespace the compiler detects maps to a small runtime feature module: [`hook:`](/reference/dom/hook) and [`error:`](/reference/dom/error) load their lifecycle and boundary wiring, [`e:`](/reference/dom/e) loads direct-event binding, component-position [`attribute prefixes`](/learn/concepts/attribute-prefixes) load prop routing, and `<svg>`/`<math>` load namespace resolution. The compiler emits a side-effect import for each feature it sees, next to the component imports it already writes:

```jsx
import "@hellajs/dom/features/hooks";
import "@hellajs/dom/features/errors";
import { component, mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const App = () => (
  <div error:fallback={<span>Boom</span>}>
    <span hook:afterMount={(el) => console.log(el)} />
  </div>
);

mount(App, "#app");
```

Apps never import feature modules directly. Features your code does not use never load, and their wiring tree-shakes out of the bundle entirely: a hook-free, error-free app ships the mount core only.

Nodes built by hand (no compiler pass) skip detection, so wiring a [`raw`](/reference/dom/raw) child, `hook:` buckets, or forwarded prefixes into a hand-built [`HellaNode`](/reference/dom) needs its feature imported once; see [`attribute prefixes`](/learn/concepts/attribute-prefixes) for the escape hatch.
