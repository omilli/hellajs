# Templates

Templates bind reactive values directly to DOM elements, enabling surgical updates without virtual DOM diffing.

## Template Approaches

Both produce the same internal HellaNode representation, so all reactive features work identically regardless of template syntax.

### JSX

A familiar syntax (with minor differences) for those coming from React or similar libraries.

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const count = signal(0);

const App = () => (
  <div>
    <h1>{count}</h1>
    <button on:click={() => count(count() + 1)}>Increment</button>
  </div>
);

mount(App, "#app");
```

### Template Literals

Template literals allow for pure runtime compilation and caching. An optional build-time compile step offers the same speed and size benefits as JSX.

```js
import { mount, html } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const count = signal(0);

const App = () => html`
  <div>
    <h1>${count}</h1>
    <button on:click=${() => count(count() + 1)}>Increment</button>
  </div>
`;

mount(App, "#app");
```

## Element Syntax

Pass a signal **reference** for a reactive value — `{count}` works identically in JSX and `html\`\`` (runtime or compiled). For a **compound** expression (`{count() * 2}`, `{items().map(…)}`) the call is required, and compiled code auto-wraps it; runtime `html\`\`` needs an explicit `() => …` wrapper. For a one-time static read, hoist the value out of the template or wrap the read in [`untracked`](/reference/core/untracked).

> **Runtime `html\`\``** (no compiler) requires explicit `() => …` wrappers for reactive **compound** expressions — simple signal references (`${count}`) work as-is. See [`html`](/reference/dom/html).

### Reactive Bindings

A signal **reference** is the simplest reactive binding. A **compound** expression (arithmetic, conditional, method call) calls the signal and auto-wraps in compiled code. Both update the DOM when their dependencies change.

```jsx
// Signal reference: updates when count changes
<h1>{count}</h1>

// Arithmetic: re-runs when count changes (auto-wrapped — no manual wrapper)
<h2>{count() * 2}</h2>

// Reactive conditional: re-evaluates when count changes
{count() > 5 && <p>Great job!</p>}
```

An explicit `() => …` wrapper is still accepted and behaves identically — required for compound expressions in runtime `html\`\``.

### Static Values

To read a signal once with no reactivity, hoist the read out of the template or wrap it in [`untracked`](/reference/core/untracked).

```jsx
import { untracked } from "@hellajs/core";

// Hoist: read once into a plain value
const total = count();
<h1>{total}</h1>

// untracked: read once inside the template, no dependency tracked
<h1>{untracked(() => count())}</h1>
```

### Value Normalization

`false`, `null`, and `undefined` render as empty strings. `0` is preserved as `"0"`.

```jsx
{false}      // renders nothing
{null}       // renders nothing
{undefined}  // renders nothing
{0}          // renders "0"
```

### Array Attributes

Array values for attributes are joined with spaces, filtering falsy values. A call inside the array makes the whole attribute reactive in compiled code — no manual wrapper needed (runtime `html\`\`` still requires `() => …`).

```jsx
const isActive = signal(true);

<div class={["base", isActive() && "active", "always"]}>
  {/* Compiled: isActive() auto-wraps — class="base active always"; → "base always" once false */}
</div>
```
