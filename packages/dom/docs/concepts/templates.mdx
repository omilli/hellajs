# Templates

Templates bind reactive values directly to DOM elements, enabling surgical updates without virtual DOM diffing.

## Template Approaches

Both produce the same internal HellaNode representation, so all reactive features work identically regardless of template syntax.

### JSX

A familiar syntax (with minor differences) for those coming from React or similar libraries.

```jsx
import { mount } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const count = signal(0);

const App = () => (
  <div>
    <h1>{count}</h1>
    <button on:click={() => count(count() + 1)}>Increment</button>
  </div>
);

mount(App, "#app");
```

### Template Literals

Template literals allow for pure runtime compilation and caching. An optional build-time compile step offers the same speed and size benefits as JSX.

```js
import { mount, html } from "@hellajs/dom";
import { signal } from "@hellajs/core";

const count = signal(0);

const App = () => html`
  <div>
    <h1>${count}</h1>
    <button on:click=${() => count(count() + 1)}>Increment</button>
  </div>
`;

mount(App, "#app");
```

## Element Syntax

Function references create reactive bindings between signals and DOM elements. Calling a signal directly produces a one-time static value.

### Reactive Bindings

Passing a signal reference or a function creates a live binding that updates the DOM when the signal changes.

```jsx
// Signal reference: updates when count changes
<h1>{count}</h1>

// Computed function: re-runs when dependencies change
<h2>{() => count() * 2}</h2>

// Reactive conditional: re-evaluates when count changes
{() => count() > 5 && <p>Great job!</p>}
```

### Static Values

Calling the signal with parentheses reads the value once with no reactivity.

```jsx
// One-time value (no reactivity)
<h1>{count()}</h1>

// Computed once
<h2>{count() * 2}</h2>

// One-time conditional render
{count() > 5 && <p>Great job!</p>}
```

### Value Normalization

`false`, `null`, and `undefined` render as empty strings. `0` is preserved as `"0"`.

```jsx
{false}      // renders nothing
{null}       // renders nothing
{undefined}  // renders nothing
{0}          // renders "0"
```

### Array Attributes

Array values for attributes are joined with spaces, filtering falsy values. Useful for dynamic class lists:

```jsx
const isActive = signal(true);

<div class={["base", isActive() && "active", "always"]}>
  // Renders: class="base active always"
</div>
```
