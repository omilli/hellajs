# Reactive Refs

Work with existing DOM elements reactively using [`$ref`](/reference/dom/ref) for single elements and [`$collection`](/reference/dom/collection) for multiple elements.

## `$ref` - Single Element

Select an element and chain methods for reactive bindings.

```js
import { signal } from '@hellajs/core';
import { $ref } from '@hellajs/dom';

const count = signal(0);

// Reactive text content
$ref('.counter').bind(count);

// Reactive attributes
$ref('.input').bind({ disabled: () => count() > 5 });

// Event handlers
$ref('.button').on('click', () => count(count() + 1));

// Method chaining
$ref('.node')
  .bind(() => `Count: ${count()}`)
  .bind({ 'data-active': () => count() > 5 })
  .on('click', () => console.log('clicked'));
```

`$ref` automatically watches for elements that don't exist yet. Operations queue and apply once when the first matching element appears, then watching stops. `$collection` watches continuously, applying queued operations to any new matching elements added later.

When binding a primitive value to form elements (INPUT, TEXTAREA, SELECT), `.value` is used instead of `.textContent`.

## `$collection` - Multiple Elements

Select multiple elements and apply operations to all of them:

```js
import { signal } from '@hellajs/core';
import { $collection } from '@hellajs/dom';

const status = signal('ready');
const items = $collection('.status-indicator');

// All current and future elements get the binding
items.bind(() => `Status: ${status()}`);
items.bind({ class: () => `indicator ${status()}` });
items.on('click', () => console.log('Clicked'));
items.forEach((wrapper, index) => {
  // Access individual DomWrapper elements
  console.log(`Element ${index}:`, wrapper.node);
});

// Stop watching and clear queued operations
items.dispose();
```

See [`$ref`](/reference/dom/ref) and [`$collection`](/reference/dom/collection) for full API details.
