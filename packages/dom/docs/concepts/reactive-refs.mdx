# Reactive Refs

Make existing DOM elements reactive without mounting a component: [`$ref`](/reference/dom/$ref) binds one element, [`$collection`](/reference/dom/$collection) binds every match and keeps watching for new ones. Both expose the same chainable methods: `.text()` for content, `.attr()` for attributes, `.on()`/`.e()` for delegated and direct events, and `.hooks()` for lifecycle.

## Single Element

Select an element and chain methods for reactive bindings.

```js
import { signal } from "@hellajs/core";
import { $ref } from "@hellajs/dom";

const count = signal(0);

// Reactive text content
$ref(".counter").text(count);

// Reactive attributes
$ref(".input").attr({ disabled: () => count() > 5 });

// Event handlers: delegated on(), direct e()
$ref(".button").on("click", () => count(count() + 1));
$ref(".button").e("focus", { handler: () => console.log("focused"), options: { once: true } });

// Method chaining
$ref(".node")
  .text(() => `Count: ${count}`)
  .attr({ "data-active": () => count() > 5 })
  .on("click", () => console.log("clicked"));
```

`$ref` automatically watches for elements that don't exist yet. Operations queue and apply once when the first matching element appears, then watching stops. `$collection` watches continuously, applying queued operations to any new matching elements added later.

`$ref` also accepts an element directly. Operations apply immediately with no watching.

```js
import { $ref } from "@hellajs/dom";

const node = document.querySelector(".counter");
if (node) {
  $ref(node).on("click", () => console.log("clicked"));
}
```

A primitive value on form elements (INPUT, TEXTAREA, SELECT) targets `.value` instead of `.textContent`.

Attribute values follow the same value rules as template props: `true` renders a bare attribute, `false` removes it, arrays join with spaces, and `style` objects serialize to kebab-case declarations.

```js
import { signal } from "@hellajs/core";
import { $ref } from "@hellajs/dom";

const theme = signal("light");

$ref(".hero").attr({ style: () => ({ color: theme() === "dark" ? "#fff" : "#000" }) });
```

## Multiple Elements

Select multiple elements and apply operations to all of them:

```js
import { signal } from "@hellajs/core";
import { $collection } from "@hellajs/dom";

const status = signal("ready");
const items = $collection(".status-indicator");

// All current and future elements get the binding
items.text(() => `Status: ${status()}`);
items.attr({ class: () => `indicator ${status()}` });
items.on("click", () => console.log("Clicked"));
items.forEach((wrapper, index) => {
  // Access individual DomWrapper elements
  console.log(`Element ${index}:`, wrapper.node);
});

// Stop watching and clear queued operations
items.dispose();
```

See [`$ref`](/reference/dom/$ref) and [`$collection`](/reference/dom/$collection) for full API details.
