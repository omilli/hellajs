## Headless

Headless wiring for common UI mechanics: trapping focus, Escape and outside dismissal, roving tabindex, anchor positioning, hover intent, menu typeahead, pointer gestures, and layered dismissal. Each behavior is a plain function that takes elements and callbacks and returns a dispose handle; state stays in your signals. The `modal` foundation composes the dialog-family wiring with automatic, node-scoped disposal instead of a dispose handle, and the parts factories (`popover`, `menu`, `menubar`, `tooltip`, `hoverCard`) grow a components tier: camelCase factories whose components render structure, never styles.

### Installation

```bash
npm install @hellajs/core @hellajs/dom @hellajs/headless
```

### Example

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { trapFocus, onEscape, onOutside } from "@hellajs/headless";

const open = signal(false);
const cleanup: (() => void)[] = [];

const Dialog = () => (
  <div class="overlay">
    <div
      class="panel"
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        cleanup.push(
          trapFocus(node),
          onEscape(node, () => open(false)),
          onOutside(() => [node], () => open(false))
        );
      }}
      hook:beforeDestroy={() => {
        cleanup.forEach((dispose) => dispose());
        cleanup.length = 0;
      }}
    >
      <button on:click={() => open(false)}>Close</button>
    </div>
  </div>
);

mount(<div>{() => (open() ? <Dialog /> : <p>Nothing open</p>)}</div>, "#app");
```

### API

- **[trapFocus](/reference/headless/trapfocus)**: Keep Tab navigation inside a container
- **[onEscape](/reference/headless/onescape)**: Call a handler on Escape at a target
- **[onOutside](/reference/headless/onoutside)**: Call a handler on clicks outside elements
- **[rovingTabIndex](/reference/headless/rovingtabindex)**: Arrow-key focus navigation over a group
- **[anchorPosition](/reference/headless/anchorposition)**: Pin a floating element to an anchor, tracking scroll and resize
- **[computeAnchorPosition](/reference/headless/computeanchorposition)**: Compute floating placement as pure math
- **[hoverIntent](/reference/headless/hoverintent)**: Open and close overlays on hover or focus delays
- **[menuTypeahead](/reference/headless/menutypeahead)**: Select menu items by typing
- **[onDrag](/reference/headless/ondrag)**: Track pointer drags with total distance from the start
- **[onSwipe](/reference/headless/onswipe)**: Commit or cancel swipes by distance or speed
- **[onPinch](/reference/headless/onpinch)**: Track two-finger pinch zoom and pan
- **[onLongPress](/reference/headless/onlongpress)**: Fire a handler after a press is held
- **[onDoubleTap](/reference/headless/ondoubletap)**: Detect double taps, optionally reporting single taps
- **[layerDismissal](/reference/headless/layerdismissal)**: Dismiss stacked overlays one layer at a time
- **[modal](/reference/headless/modal)**: Arm a modal panel: trap, dismissal, and exit notification with automatic disposal
- **[popover](/reference/headless/popover)**: Create the six popover parts in one factory call with controlled-or-internal state
- **[menu](/reference/headless/menu)**: Create the full menu part set in one factory call: trigger, content, selectable rows, and submenus
- **[menubar](/reference/headless/menubar)**: Create a menu bar whose menus announce to the bar: one open at a time, roving triggers, open-then-move
- **[tooltip](/reference/headless/tooltip)**: Create the tooltip parts in one factory call: provider slot, hover trigger, and the ported anchored label
- **[hoverCard](/reference/headless/hovercard)**: Create the hover-card parts in one factory call: hover trigger and the ported keep-open panel
