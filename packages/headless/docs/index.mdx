## Headless

Headless wiring for common UI mechanics ([install it first](/headless/installation); [styling is bring-your-own](/headless/theming)): trapping focus, Escape and outside dismissal, roving tabindex, anchor positioning, hover intent, menu typeahead, pointer gestures, and layered dismissal. Each util is a plain function that takes elements and callbacks and returns a dispose handle; state stays in your signals. `modal` composes the dialog-family wiring with automatic, node-scoped disposal instead of a dispose handle, and the component factories (`accordion`, `collapsible`, `avatar`, `popover`, `dialog`, `menu`, `menubar`, `tooltip`, `hoverCard`, `combobox`, `select`, `command`, `toggle`, `checkbox`, `toggleSwitch`, `toggleGroup`, `radioGroup`, `tabs`, `navigationMenu`, `slider`, `toast`, `calendar`, `inputOtp`, `createForm`, `scrollArea`, `messageScroller`) grow a components tier: camelCase factories whose components render structure, never styles.

### Installation

```bash
npm install @hellajs/core @hellajs/dom @hellajs/headless
```

### Example

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { trapFocus, onEscape, onOutside } from "@hellajs/headless/utils";

const open = signal(false);
const cleanup: (() => void)[] = [];

const Dialog = () => (
  <div class="overlay">
    <div
      class="panel"
      hook:afterMount={(node) => {
        if (!(node instanceof HTMLElement)) return;
        cleanup.push(
          trapFocus(node),
          onEscape(node, () => open(false)),
          onOutside(() => [node], () => open(false))
        );
      }}
      hook:beforeDestroy={() => {
        cleanup.forEach((dispose) => dispose());
        cleanup.length = 0;
      }}
    >
      <button on:click={() => open(false)}>Close</button>
    </div>
  </div>
);

mount(<div>{() => (open() ? <Dialog /> : <p>Nothing open</p>)}</div>, "#app");
```

### API

- **[anchorPosition](/headless/anchorposition)**: Pin a floating element to an anchor, tracking scroll and resize
- **[computeAnchorPosition](/headless/computeanchorposition)**: Compute floating placement as pure math
- **[hoverIntent](/headless/hoverintent)**: Open and close overlays on hover or focus delays
- **[layerDismissal](/headless/layerdismissal)**: Dismiss stacked overlays one layer at a time
- **[menuTypeahead](/headless/menutypeahead)**: Select menu items by typing
- **[modal](/headless/modal)**: Arm a modal panel: trap, dismissal, and exit notification with automatic disposal
- **[onDoubleTap](/headless/ondoubletap)**: Detect double taps, optionally reporting single taps
- **[onDrag](/headless/ondrag)**: Track pointer drags with total distance from the start
- **[onEscape](/headless/onescape)**: Call a handler on Escape at a target
- **[onLongPress](/headless/onlongpress)**: Fire a handler after a press is held
- **[onOutside](/headless/onoutside)**: Call a handler on clicks outside elements
- **[onPinch](/headless/onpinch)**: Track two-finger pinch zoom and pan
- **[onSwipe](/headless/onswipe)**: Commit or cancel swipes by distance or speed
- **[rovingTabIndex](/headless/rovingtabindex)**: Arrow-key focus navigation over a group
- **[trapFocus](/headless/trapfocus)**: Keep Tab navigation inside a container
- **[accordion](/headless/accordion)**: Create the accordion components in one factory call: the roving container, value-keyed rows, and the keyed regions
- **[avatar](/headless/avatar)**: Create the avatar components in one factory call: the container, the portrait image, and the initial fallback over one closure-owned loaded signal
- **[calendar](/headless/calendar)**: Create the calendar components in one factory call: the month view, the selection model, and the day grid with its keyboard
- **[checkbox](/headless/checkbox)**: Create the checkbox components in one factory call: the tri-state button and its indicator
- **[collapsible](/headless/collapsible)**: Create the collapsible components in one factory call: the toggle trigger and its content region
- **[combobox](/headless/combobox)**: Create the combobox components in one factory call: query input, filtered option panel, and multi-select chips
- **[command](/headless/command)**: Create the command palette components in one factory call: search input, ranked list, and the modal-wired palette dialog
- **[createForm](/headless/createform)**: Create a signals-native form controller in one factory call: per-field signals, validation timing, and the field components that read it through explicit props
- **[dialog](/headless/dialog)**: Create the four dialog components in one factory call: the trigger, the structural overlay, and the portaled modal panel with its close button
- **[hoverCard](/headless/hovercard)**: Create the hover-card components in one factory call: hover trigger and the ported keep-open panel
- **[inputOtp](/headless/inputotp)**: Create the one-time-code components in one factory call: the slot row, its display slots, and the separator over one transparent input
- **[menu](/headless/menu)**: Create the full menu component set in one factory call: trigger, content, selectable rows, and submenus
- **[menubar](/headless/menubar)**: Create a menu bar whose menus announce to the bar: one open at a time, roving triggers, open-then-move
- **[messageScroller](/headless/messagescroller)**: Create the message-scroller components in one factory call: the shared at-bottom state, stickiness on new content, and the jump-to-bottom button
- **[navigationMenu](/headless/navigationmenu)**: Create the navigation menu components in one factory call: the announced open-value store, the viewport-shared panels, and the moving indicator
- **[popover](/headless/popover)**: Create the six popover components in one factory call with controlled-or-internal state
- **[radioGroup](/headless/radiogroup)**: Create the radio-group components in one factory call: exclusive selection with move-and-select arrows
- **[scrollArea](/headless/scrollarea)**: Create the scroll-area components in one factory call: the native-scroll viewport and the self-measuring scrollbar whose thumb tracks and drags its axis
- **[select](/headless/select)**: Create the select components in one factory call: trigger, value label, and the ported roving listbox
- **[slider](/headless/slider)**: Create the slider components in one factory call: the drag-wired root, the measured track, the filled range, and the focusable thumbs
- **[tabs](/headless/tabs)**: Create the tabs components in one factory call: the roving tablist, its triggers, and the keyed panels
- **[toast](/headless/toast)**: Enqueue toast cards onto a shared stack from anywhere: timers, hover pause, swipe dismissal, and the portaled Toaster
- **[toggle](/headless/toggle)**: Create the pressed-state toggle button in one factory call with controlled-or-internal state
- **[toggleGroup](/headless/togglegroup)**: Create the toggle-group components in one factory call: roving items with single and multiple exclusion
- **[toggleSwitch](/headless/toggleswitch)**: Create the switch components in one factory call: the checked-state button and its moving thumb
- **[tooltip](/headless/tooltip)**: Create the tooltip components in one factory call: provider slot, hover trigger, and the ported anchored label
