# hoverIntent

Open a surface after a hover or focus delay and close it after a leave delay: the tooltip and hover-card timing contract.

## Basic Usage

```jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";
import { hoverIntent } from "@hellajs/headless/utils";

const show = signal(false);
let disposeIntent: (() => void) | undefined;

const Avatar = () => (
  <img
    src="/avatar.png"
    alt="Profile"
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      disposeIntent = hoverIntent(node, {
        openDelay: 200,
        closeDelay: 150,
        onOpen: () => show(true),
        onClose: () => show(false)
      });
    }}
    hook:beforeDestroy={() => disposeIntent?.()}
  />
);

mount(<Avatar />, "#app");
// Hovering or focusing the avatar sets show(true) after 200ms
```

## API

```typescript
function hoverIntent(
  target: Element,
  handlers: HoverIntentOptions
): () => void
```

```typescript
interface HoverIntentOptions {
  onOpen: () => void;
  onClose: () => void;
  openDelay?: number;
  closeDelay?: number;
}
```

- `target`: Element watched for hover and focus intent.
- `handlers`: `onOpen` fires when the open delay elapses; `onClose` fires after the close delay, on an outside pointerdown while open, or on keyboard blur.
- `openDelay`: Pointer-hover milliseconds before `onOpen` fires. Default `700`.
- `closeDelay`: Pointer-leave milliseconds before `onClose` fires. Default `300`.
- **Returns**: Dispose handle. Calling it removes all listeners and clears pending timers.

## Key Concepts

### Pointer and Keyboard Parity

`pointerenter` and `focus` share the open path; `pointerleave` and `blur` share the close path. A tooltip wired once responds to both mouse hover and keyboard traversal with the same delays.

### Outside Pointerdown Closes Immediately

A pointerdown outside the target skips the close delay: if the surface is open, `onClose` fires at once. A press inside the target never closes it.

### The Shared Skip-Delay Window

When any `hoverIntent` surface opened within the last 500ms, the next open fires instantly, with no delay. Moving the pointer between adjacent triggers never re-incurs the wait.

## Important Considerations

### Dispose With the Feature

One listener sits on `document`, so it outlives the target. Call the dispose handle in the same path that closes or unmounts the UI.

### Input Validation

`hoverIntent()` throws when `target` or `handlers` is `null` or `undefined`: `[headless] hoverIntent: target is required`, `[headless] hoverIntent: handlers is required`.
