# localStorageAdaptor

Backs a store's persistence with `window.localStorage` under a key, creating the `StoreAdaptor` that [`persistStore`](/reference/store/persiststore) writes through.

## Basic Usage

```typescript
import { localStorageAdaptor, persistStore, store } from '@hellajs/store';

const ui = store({ theme: 'light', fontSize: 12 });
const persist = persistStore(ui, localStorageAdaptor('ui-preferences'));

// Synchronous storage: persisted values are applied before this line runs.

ui.theme('dark'); // localStorage "ui-preferences": {"theme":"dark","fontSize":12}
```

## API

```typescript
import { localStorageAdaptor } from '@hellajs/store';

function localStorageAdaptor(key: string): StoreAdaptor
```

- `key`: the localStorage slot the persisted snapshot occupies
- **Returns**: a `StoreAdaptor` reading and writing that slot

## Key Concepts

### Lazy, Server-Safe Access

Storage is touched only when `persistStore` reads or writes, never at factory time, so calling `localStorageAdaptor` anywhere is safe and `persistStore` never touches it on the server. See [`persistStore`](/reference/store/persiststore) for the full hydration contract: synchronous reads apply before `persistStore` returns, and corrupt stored state self-heals.
