## ui

Copy/paste component registry: `npx @hellajs/ui add <name>` copies owned, editable component source into your project; the npm artifact IS the CLI, and there is no importable component surface.

### Installation

```bash
npx @hellajs/ui init
# bunx @hellajs/ui init
```

No install step is required; run the CLI through your package runner. `init` writes `hella.ui.json` (style and format defaults) and adds the shared `theme` entry; `add` copies components into `src/components/`.

### Example

```bash
npx @hellajs/ui add button
# bunx @hellajs/ui add button
```

```jsx
import Button from './components/button';

const App = () => (
  <Button variant="outline" on:click={() => console.log('clicked')}>
    Click me
  </Button>
);
```

The copied file is yours to edit; the style declarations ride inside it, so nothing is imported from the package at runtime.

### Registry

Sixty-one entries: fifty-nine components plus `theme` and `cn`, the shared entries every project themes and composes through. Every component follows one shape: `<name>.tsx` plus `<name>.ts` (html format) copied per `add`, css adds `@hellajs/css`, tailwind adds `clsx` and `tailwind-merge`, and registry dependencies copy recursively alongside.

| Entry | Styles | Copied files | Extra peers |
|---|---|---|---|
| `theme` | css, tailwind | `tokens.ts` (css) or `theme.css` + `cn.ts` (tailwind) | css: `@hellajs/css` |
| `cn` | tailwind only | `cn.ts` | `clsx`, `tailwind-merge` |

The component catalog, grouped by family:

| Family | Components |
|---|---|
| Core | `button`, `input`, `card`, `dialog`, `tabs` |
| Statics | `badge`, `alert`, `kbd`, `separator`, `skeleton`, `spinner`, `empty`, `label` |
| Forms and data | `textarea`, `native-select`, `table`, `aspect-ratio`, `avatar`, `progress`, `input-otp`, `form` |
| Composites | `button-group`, `input-group`, `field`, `pagination`, `item`, `marker`, `direction` |
| Chat | `bubble`, `message`, `message-scroller`, `attachment` |
| Disclosure | `collapsible`, `accordion` |
| Selection | `checkbox`, `radio-group`, `switch`, `toggle`, `toggle-group` |
| Sliders and panes | `slider`, `resizable` |
| Anchored surfaces | `tooltip`, `hover-card`, `popover` |
| Menus and navigation | `dropdown-menu`, `context-menu`, `menubar`, `navigation-menu`, `breadcrumb` |
| Select and command | `select`, `combobox`, `command` |
| Dialog variants | `alert-dialog`, `sheet`, `drawer` |
| Feedback and focus | `sonner`, `scroll-area` |
| Calendar | `calendar` |
| Layout shells | `sidebar` |

`add` resolves dependencies recursively: adding any component brings `theme` along, and tailwind adds also bring `cn`.

### API

The package's interface is the CLI:

- **`init`**: writes `hella.ui.json` with style and format defaults, then adds the theme entry for the configured style.
- **`add`**: copies registry entries into `componentsDir`, splicing the chosen style's declarations into the file; `--style`, `--format`, `--dir`, and `--overwrite` override the config per call.
- **`list`**: prints every entry name in the registry.
