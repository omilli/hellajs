## API

`Breadcrumb` renders the labeled `nav`; `BreadcrumbList` is the ordered list; each `BreadcrumbItem` is one `li` slot holding a `BreadcrumbLink`, the `BreadcrumbPage`, an ellipsis, or a dropdown. `BreadcrumbLink` takes an `href` passthrough (there is no router coupling), and `BreadcrumbPage` renders `role="link"` with `aria-disabled="true"` and `aria-current="page"`: it marks where the reader is, not a link to click. Separators are `role="presentation"` and hidden from the accessibility tree, so screen readers announce the trail through the list semantics alone.

### Breadcrumb

The labeled `nav` wrapper.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The list |

### BreadcrumbList

The trail: an `ol` laid out as the wrapping flex row with the `sm:` gap step.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The trail's items and separators |

### BreadcrumbItem

One trail slot: an `li` holding a link, the current page, an ellipsis, or a dropdown.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The slot's node |

### BreadcrumbLink

One trail link: an `a` with the color transition on hover.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `href` | `string` | `-` |
| `children` | `HellaChildren` | The segment label |

### BreadcrumbPage

The current segment: a `span` carrying `role="link"`, `aria-disabled="true"`, and `aria-current="page"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The current page's label |

### BreadcrumbSeparator

The between-items marker: an `li` carrying `role="presentation"` and `aria-hidden="true"`, inlining the chevron.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Replaces the inlined chevron when given |

### BreadcrumbEllipsis

The collapsed-segments marker: a `span` carrying `role="presentation"` and `aria-hidden="true"`, inlining the more-horizontal icon plus a screen-reader-only "More" label.

Every part also takes a `class` string, landing last in its style composition.

## Overflow with a Dropdown

When the trail hides middle segments, put a `DropdownMenu` inside a `BreadcrumbItem`: the ellipsis labels the trigger and the menu lists the hidden levels. The composed `DropdownMenu` owns its own open state, so the breadcrumb needs no extra wiring; the entry's registry dependency copies `dropdown-menu` (and its `button` dependency) alongside the trail.
