## Usage

`Breadcrumb` renders the labeled `nav`; `BreadcrumbList` is the ordered list; each `BreadcrumbItem` is one `li` slot holding a `BreadcrumbLink`, the `BreadcrumbPage`, an ellipsis, or a dropdown. `BreadcrumbSeparator` renders between items and inlines the chevron, accepting children to replace it:

### jsx

```jsx
import Breadcrumb from './components/breadcrumb';
import {
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
} from './components/breadcrumb';

const Trail = () => (
  <Breadcrumb>
    <BreadcrumbList>
      <BreadcrumbItem>
        <BreadcrumbLink href="/">Home</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbLink href="/ui">UI</BreadcrumbLink>
      </BreadcrumbItem>
      <BreadcrumbSeparator />
      <BreadcrumbItem>
        <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
      </BreadcrumbItem>
    </BreadcrumbList>
  </Breadcrumb>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${Breadcrumb}>
    <${BreadcrumbList}>
      <${BreadcrumbItem}><${BreadcrumbLink} href=${"/"}>Home</${BreadcrumbLink}></${BreadcrumbItem}>
      <${BreadcrumbSeparator}></${BreadcrumbSeparator}>
      <${BreadcrumbItem}><${BreadcrumbLink} href=${"/ui"}>UI</${BreadcrumbLink}></${BreadcrumbItem}>
      <${BreadcrumbSeparator}></${BreadcrumbSeparator}>
      <${BreadcrumbItem}><${BreadcrumbPage}>Breadcrumb</${BreadcrumbPage}></${BreadcrumbItem}>
    </${BreadcrumbList}>
  </${Breadcrumb}>
</main>`
```

## Manual Parts

Six named parts ship beside the default `Breadcrumb`: `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage`, `BreadcrumbSeparator`, and `BreadcrumbEllipsis`. `BreadcrumbLink` takes an `href` passthrough (there is no router coupling), and `BreadcrumbPage` renders `role="link"` with `aria-disabled="true"` and `aria-current="page"`: it marks where the reader is, not a link to click. Separators are `role="presentation"` and hidden from the accessibility tree, so screen readers announce the trail through the list semantics alone.

### BreadcrumbList

The trail: an `ol` laid out as the wrapping flex row with the `sm:` gap step.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The trail's items and separators |

### BreadcrumbItem

One trail slot: an `li` holding a link, the current page, an ellipsis, or a dropdown.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The slot's node |

### BreadcrumbLink

One trail link: an `a` with the color transition on hover.

| Prop | Type | Behavior |
|---|---|---|
| `href` | `string` | Passthrough anchor target; no router coupling |
| `children` | `HellaChildren` | The segment label |

### BreadcrumbPage

The current segment: a `span` carrying `role="link"`, `aria-disabled="true"`, and `aria-current="page"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The current page's label |

### BreadcrumbSeparator

The between-items marker: an `li` carrying `role="presentation"` and `aria-hidden="true"`, inlining the chevron.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Replaces the inlined chevron when given |

### BreadcrumbEllipsis

The collapsed-segments marker: a `span` carrying `role="presentation"` and `aria-hidden="true"`, inlining the more-horizontal icon plus a screen-reader-only "More" label.

## Overflow with a Dropdown

When the trail hides middle segments, put a `DropdownMenu` inside a `BreadcrumbItem`: the ellipsis labels the trigger and the menu lists the hidden levels.

```jsx
import { BreadcrumbEllipsis } from './components/breadcrumb';
import DropdownMenu from './components/dropdown-menu';
import { DropdownMenuItem } from './components/dropdown-menu';
import { BreadcrumbItem } from './components/breadcrumb';

const Overflow = () => (
  <BreadcrumbItem>
    <DropdownMenu
      content={
        <>
          <DropdownMenuItem>Components</DropdownMenuItem>
          <DropdownMenuItem>Labels</DropdownMenuItem>
        </>
      }
    >
      <BreadcrumbEllipsis />
    </DropdownMenu>
  </BreadcrumbItem>
);
```

The composed `DropdownMenu` owns its own open state, so the breadcrumb needs no extra wiring; the entry's registry dependency copies `dropdown-menu` (and its `button` dependency) alongside the trail.

Every part also takes a `class` string, landing last in its style composition.
