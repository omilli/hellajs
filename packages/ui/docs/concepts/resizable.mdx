## API

Compose the three exports: `ResizablePanelGroup` (the default), `ResizablePanel`, and `ResizableHandle`. Place one handle between each pair of panels you want to separate.

### ResizablePanelGroup

| Prop | Type | Default |
| ---- | ---- | ------- |
| `direction` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `onLayout` | `(sizes: number[]) => void` | `-` |
| `children` | panels and handles | Discovered in the DOM at mount |
| `class` | `string` | `-` |

`direction` is the flex axis, rendered as `aria-orientation`. `onLayout` reports the panel sizes in percent after each drag or keyboard resize; the initial layout does not fire it. Every `ResizablePanel` child joins the layout.

### ResizablePanel

| Prop | Type | Default |
| ---- | ---- | ------- |
| `defaultSize` | `number` | `-` |
| `minSize` | `number` | `0` |
| `maxSize` | `number` | `100` |
| `children` | any | Rendered inside the panel |
| `class` | `string` | `-` |

`defaultSize` is the initial share of the group in percent; required, it seeds the group's layout.

### ResizableHandle

| Prop | Type | Default |
| ---- | ---- | ------- |
| `withHandle` | `boolean` | `-` |
| `disabled` | `boolean` | `-` |
| `class` | `string` | `-` |

`withHandle` renders the grip icon chip centered on the divider; `disabled` blocks drags and keys, rendering `aria-disabled` and `data-disabled`.

## Sizing and Constraints

Dragging a handle moves the boundary between the panel before it and the panel after it: the pixel delta converts to a percentage of the group, the previous panel takes the share the next one gives up. Both sides clamp at their `minSize` and `maxSize`, so a drag that runs out of room stops at the boundary instead of pushing other panels. Panel geometry is measured when the drag starts, not observed continuously.

## Keyboard

Each handle is focusable (`role="separator"`, `tabindex="0"`) and moves its pair by 5 percent per press: `ArrowRight` and `ArrowDown` widen the earlier panel, `ArrowLeft` and `ArrowUp` narrow it, always within the pair's min and max.

## Divergences

Some panel-group layout features are absent; they stay out of scope rather than approximated:

- Resizes only move the handle's adjacent pair; a drag never cascades across the remaining panels in the group.
- No `onCollapse`, `onExpand`, or collapse API.
- No persisted layouts and no controlled size props: the group is uncontrolled and `onLayout` is the only observation point.

## Accessibility

| Aspect | Value |
|---|---|
| Role | `separator` on each handle |
| Focus | Handles carry `tabindex="0"` (`-1` while disabled) with the focus ring from the style layer |
| Orientation | `aria-orientation` on the group and every handle, set from `direction` at mount |
| Disabled | `aria-disabled` and `data-disabled` on the handle |
