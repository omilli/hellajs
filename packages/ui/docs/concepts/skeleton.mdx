## API

The element has no intrinsic size, so `h-*` and `w-*` classes come from you; stack a few strips to stand in for text. The root carries `data-slot="skeleton"`.

### Skeleton

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | Optional inner nodes |
Accepts all native `div` attributes (forwarded to the root element).
