## Usage

The composed `DropdownMenu` wraps its children in the trigger button (Button-wrapped, the outline variant) and takes the items through the `content` prop. Clicking toggles; ArrowDown opens; the trigger carries `data-state`, `aria-expanded`, and `aria-haspopup="menu"`, and focus returns to it when the menu closes.

### jsx

```jsx
import DropdownMenu from './components/dropdown-menu';
import { DropdownMenuItem } from './components/dropdown-menu';

const Actions = () => (
  <DropdownMenu
    content={
      <>
        <DropdownMenuItem onclick={() => console.log('opened')}>Open File</DropdownMenuItem>
        <DropdownMenuItem shortcut="⌘N">New Window</DropdownMenuItem>
      </>
    }
  >
    Actions
  </DropdownMenu>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${DropdownMenu} content=${html`<p>One item.</p>`}>
    Menu
  </${DropdownMenu}>
</main>`
```

| Prop | Type | Behavior |
|---|---|---|
| `open` | `() => boolean` | Controlled open accessor; when given, the root never writes its internal signal |
| `onOpenChange` | `(open: boolean) => void` | Reports every requested open and close flip |
| `children` | `HellaChildren` | The trigger label |
| `content` | `HellaChildren` | The menu items, portaled into `document.body` while open |
| `class` | `string` | Extra classes on the trigger button |

## Dismissal and Positioning

Dismissal runs through [`layerDismissal`](/reference/dom/layerdismissal): Escape and a pointerdown outside the panel ask the top layer to close, so stacked menus and popovers dismiss one layer at a time. Activating an item closes every open menu layer; the items fire that through a document-level activation event, which is also how Enter and Space close from the keyboard. Closing starts the exit - the panel stays mounted under `data-state="closed"` until its animation ends, with dismissal wiring down while it leaves.

The panel positions through [`anchorPosition`](/reference/dom/anchorposition): fixed coordinates against the trigger, flipping on viewport collision, repositioning on scroll and resize. The menu is non-modal: there is no focus trap, and focus moves to the first activatable item on open.

## Manual Parts

Thirteen named parts ship beside the default `DropdownMenu`: `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuGroup`, `DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`, `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`, `DropdownMenuSub`, `DropdownMenuSubTrigger`, and `DropdownMenuSubContent`. The parts take their state as explicit props: the checkbox item takes a `checked` accessor, the radio group is items-driven, and each sub owns its own open signal.

### DropdownMenuTrigger

The manual trigger button carrying `aria-haspopup="menu"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The trigger label |

### DropdownMenuContent

The `role="menu"` surface with the full keyboard model, positioned against its anchor.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle; `closed` tears the wirings down |
| `id` | `string` | Menu id |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | Anchor placement (default `"bottom"`) |
| `align` | `"start" \| "center" \| "end"` | Cross-axis alignment (default `"start"`) |
| `sideOffset` | `number` | Gap between the anchor and the content edge, in px (default 4) |
| `alignOffset` | `number` | Cross-axis shift applied after positioning, in px (default 0) |
| `anchor` | `() => Element \| undefined` | Resolves the element the content anchors to; positioning is skipped when undefined |
| `onDismiss` | `() => void` | Escape and an outside pointerdown dismiss the top layer into this callback, and item selection closes every open layer |
| `onExited` | `() => void` | Called when the exit animation ends under `data-state="closed"` |
| `onArrowLeft` | `() => void` | ArrowLeft closes the menu when provided (submenu exit; a top-level menu stays inert) |
| `children` | `HellaChildren` | The menu items |

### DropdownMenuGroup

A passthrough grouping `div`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The grouped items |

### DropdownMenuItem

A `role="menuitem"` row; activation closes every open layer.

| Prop | Type | Behavior |
|---|---|---|
| `onclick` | `() => void` | Click callback, fired before the close-all activation event |
| `destructive` | `boolean` | Renders the destructive `data-variant` treatment |
| `inset` | `boolean` | Renders `data-inset="true"` for the indented alignment |
| `disabled` | `boolean` | `data-disabled` plus `aria-disabled`; blocks `onclick` and the close |
| `shortcut` | `string` | Shortcut text rendered as a trailing `DropdownMenuShortcut` span |
| `children` | `HellaChildren` | The row's label |

### DropdownMenuCheckboxItem

A `role="menuitemcheckbox"` row with the check indicator.

| Prop | Type | Behavior |
|---|---|---|
| `checked` | `boolean \| (() => boolean)` | A boolean seeds the internal signal; an accessor makes the item controlled - activation then only reports through `onCheckedChange` |
| `onCheckedChange` | `(checked: boolean) => void` | Reports every requested flip, then closes every open layer |
| `disabled` | `boolean` | Blocks toggling; renders the disabled states |
| `children` | `HellaChildren` | The row's label |

### DropdownMenuRadioGroup

A group rendering one radio item per entry.

| Prop | Type | Behavior |
|---|---|---|
| `items` | `{ value, label?, disabled? }[]` | One `DropdownMenuRadioItem` per entry |
| `value` | `() => string` | Controlled selected value; when given, the group never writes its internal signal and `onValueChange` reports the requested selection |
| `onValueChange` | `(value: string) => void` | Reports every requested selection |
| `children` | `HellaChildren` | Static group content rendered alongside the items |

### DropdownMenuRadioItem

A `role="menuitemradio"` row with the circle indicator.

| Prop | Type | Behavior |
|---|---|---|
| `value` | `string` | This row's value in its group |
| `checked` | `boolean \| (() => boolean)` | A boolean reads statically; an accessor keeps the row reactive against its owning group |
| `onSelect` | `() => void` | Called on click when the row is enabled |
| `disabled` | `boolean` | Blocks selection |
| `children` | `HellaChildren` | The row's label |

### DropdownMenuLabel

A section label.

| Prop | Type | Behavior |
|---|---|---|
| `inset` | `boolean` | Renders the indented alignment |
| `children` | `HellaChildren` | The label text |

### DropdownMenuSeparator

A hairline between groups.

### DropdownMenuShortcut

The trailing key-hint span inside a row.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The hint text |

### DropdownMenuSub

A sub-trigger plus its portaled sub-content; open state owned here.

| Prop | Type | Behavior |
|---|---|---|
| `content` | `HellaChildren` | The sub-surface items |
| `children` | `HellaChildren` | The sub-trigger label |

### DropdownMenuSubTrigger

The manual sub-trigger row (chevron, `aria-haspopup`).

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `aria-expanded` and `data-state`; the composed `DropdownMenuSub` wires it |
| `onOpen` | `() => void` | Called on click and hover intent to open the submenu |
| `inset` | `boolean` | Renders the indented alignment |
| `children` | `HellaChildren` | The sub-trigger label |

### DropdownMenuSubContent

The `role="menu"` sub-surface, anchored against its sub-trigger (right, start aligned, collision flipped).

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | Anchor placement |
| `align` | `"start" \| "center" \| "end"` | Cross-axis alignment |
| `sideOffset` | `number` | Gap between the anchor and the content edge, in px |
| `anchor` | `() => Element \| undefined` | Resolves the element the content anchors to (the sub-trigger); positioning is skipped when undefined |
| `onDismiss` | `() => void` | Escape and an outside pointerdown dismiss the top layer into this callback, and item selection closes every open layer |
| `onExited` | `() => void` | Called when the exit animation ends under `data-state="closed"` |
| `onArrowLeft` | `() => void` | ArrowLeft closes the submenu |
| `onPointerEnter` | `() => void` | Pointer entering the content cancels the trigger's pending close |
| `children` | `HellaChildren` | The sub-surface items |

The sub-content registers its own [`layerDismissal`](/reference/dom/layerdismissal) layer, so Escape pops one level at a time and an outside press closes the sub before the parent.

Every part also takes a `class` string, landing last in its style composition.

Checkbox and radio state in a menu, one composition:

```jsx
import { signal } from '@hellajs/core';
import DropdownMenu from './components/dropdown-menu';
import {
  DropdownMenuCheckboxItem,
  DropdownMenuRadioGroup,
  DropdownMenuSeparator,
  DropdownMenuLabel,
} from './components/dropdown-menu';

const bold = signal(false);
const size = signal('medium');

const Format = () => (
  <DropdownMenu
    content={
      <>
        <DropdownMenuLabel>Formatting</DropdownMenuLabel>
        <DropdownMenuCheckboxItem
          checked={bold}
          onCheckedChange={(next) => bold(next)}
        >
          Bold
        </DropdownMenuCheckboxItem>
        <DropdownMenuSeparator />
        <DropdownMenuRadioGroup
          items={[
            { value: 'small', label: 'Small' },
            { value: 'medium', label: 'Medium' },
            { value: 'large', label: 'Large' },
          ]}
          value={size}
          onValueChange={(next) => size(next)}
        />
      </>
    }
  >
    Format
  </DropdownMenu>
);
```

The radio group mirrors the checkbox split: a `value` accessor keeps selection external, otherwise the group tracks its own signal until `onValueChange` reports.

Submenus compose through `DropdownMenuSub`: its children label the trigger row and its `content` builds the sub-surface. The sub opens on hover after roughly 100ms of rest, on click, or on ArrowRight; leaving the trigger schedules a close that entering the sub-content cancels.

```jsx
import DropdownMenu from './components/dropdown-menu';
import { DropdownMenuItem, DropdownMenuSub } from './components/dropdown-menu';

const More = () => (
  <DropdownMenu
    content={
      <>
        <DropdownMenuItem>Save</DropdownMenuItem>
        <DropdownMenuSub
          content={
            <>
              <DropdownMenuItem>Export as PDF</DropdownMenuItem>
              <DropdownMenuItem>Export as HTML</DropdownMenuItem>
            </>
          }
        >
          Export
        </DropdownMenuSub>
      </>
    }
  >
    File
  </DropdownMenu>
);
```

## Keyboard Interaction

| Key | Behavior |
|---|---|
| `ArrowDown` / `ArrowUp` | Opens the closed menu from the trigger; inside, roves items with wrap, skipping disabled entries |
| `Home` / `End` | Jumps to the first or last activatable item |
| `Enter` / `Space` | Activates the focused item (toggles checkbox and radio rows) |
| `ArrowRight` / `ArrowLeft` | Enters a focused sub-trigger or exits the sub; flips with the resolved writing direction |
| `Escape` | Dismisses the top layer only |
| `Tab` | Closes every open layer |
| printable keys | Typeahead: selects the first item starting with the buffered keys |
