## API

The composed `DropdownMenu` wraps its children in the trigger button (Button-wrapped, the outline variant) and takes the items through the `content` prop. Clicking toggles; ArrowDown opens; the trigger carries `data-state`, `aria-expanded`, and `aria-haspopup="menu"`, and focus returns to it when the menu closes.

Thirteen named parts ship beside the default `DropdownMenu`: `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuGroup`, `DropdownMenuItem`, `DropdownMenuCheckboxItem`, `DropdownMenuRadioGroup`, `DropdownMenuRadioItem`, `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuShortcut`, `DropdownMenuSub`, `DropdownMenuSubTrigger`, and `DropdownMenuSubContent`. The parts take their state as explicit props: the checkbox item takes a `checked` accessor, the radio group is items-driven, and each sub owns its own open signal.

### DropdownMenu

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `content` | `HellaChildren` | The menu items, portaled into `document.body` while open |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The trigger label |
Accepts all native `button` attributes (forwarded to the root element).

A controlled `open` stops the root from writing its internal signal; `onOpenChange` reports every requested open and close flip.

### DropdownMenuTrigger

The manual trigger button carrying `aria-haspopup="menu"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The trigger label |
Accepts all native `button` attributes (forwarded to the root element).

### DropdownMenuContent

The `role="menu"` surface with the full keyboard model, positioned against its anchor.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `0` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onDismiss` | `() => void` | `-` |
| `onExited` | `() => void` | `-` |
| `onArrowLeft` | `() => void` | `-` |
| `children` | `HellaChildren` | The menu items |
Accepts all native `div` attributes (forwarded to the root element).

`state` drives `data-state` and the enter/exit cycle; `closed` tears the wirings down. `sideOffset` is the gap between the anchor and the content edge in px, `alignOffset` the cross-axis shift applied after positioning. The anchor resolves to the element the content anchors to; positioning is skipped when undefined. `onDismiss` receives Escape and outside pointerdowns from the top layer, and item selection closes every open layer through it; `onExited` fires when the exit animation ends; `onArrowLeft` closes the menu when provided (submenu exit; a top-level menu stays inert).

### DropdownMenuGroup

A passthrough grouping `div`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The grouped items |
Accepts all native `div` attributes (forwarded to the root element).

### DropdownMenuItem

A `role="menuitem"` row; activation closes every open layer.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `destructive` | `boolean` | `-` |
| `inset` | `boolean` | `-` |
| `shortcut` | `string` | `-` |
| `children` | `HellaChildren` | The row's label |
Accepts all native `div` attributes (forwarded to the root element).

A user `on:click` chains with the owned close (it fires before the close-all activation event); `destructive` renders the destructive `data-variant` treatment; `inset` renders `data-inset="true"` for the indented alignment; `disabled` renders `data-disabled` plus `aria-disabled` and blocks the user's `on:click` and the close; `shortcut` renders as a trailing `DropdownMenuShortcut` span.

### DropdownMenuCheckboxItem

A `role="menuitemcheckbox"` row with the check indicator.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `checked` | `boolean \| (() => boolean)` | `-` |
| `onCheckedChange` | `(checked: boolean) => void` | `-` |
| `children` | `HellaChildren` | The row's label |
Accepts all native `div` attributes (forwarded to the root element).

A boolean `checked` seeds the internal signal; an accessor makes the item controlled - activation then only reports through `onCheckedChange`, which fires on every requested flip before every open layer closes.

| Prop | Type | Default |

| `children` | `HellaChildren` | Static group content rendered alongside the items |
Accepts all native `div` attributes (forwarded to the root element).

A controlled `value` stops the group from writing its internal signal; `onValueChange` reports the requested selection.

### DropdownMenuRadioItem

A `role="menuitemradio"` row with the circle indicator.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | `-` |

`checked` reads statically as a boolean; an accessor keeps the row reactive against its owning group. `onSelect` is called on click when the row is enabled.

### DropdownMenuSub

A sub-trigger plus its portaled sub-content; open state owned here. The sub opens on hover after roughly 100ms of rest, on click, or on ArrowRight; leaving the trigger schedules a close that entering the sub-content cancels.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `content` | `HellaChildren` | The sub-surface items |
| `children` | `HellaChildren` | The sub-trigger label |
Accepts all native `div` attributes (forwarded to the root element).

### DropdownMenuSubTrigger

The manual sub-trigger row (chevron, `aria-haspopup`).

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `onOpen` | `() => void` | `-` |
| `inset` | `boolean` | `-` |
| `children` | `HellaChildren` | The sub-trigger label |
Accepts all native `div` attributes (forwarded to the root element).

`state` drives `aria-expanded` and `data-state`; the composed `DropdownMenuSub` wires it. `onOpen` is called on click and hover intent.

### DropdownMenuSubContent

The `role="menu"` sub-surface, anchored against its sub-trigger (right, start aligned, collision flipped).

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `-` |
| `align` | `"start" \| "center" \| "end"` | `-` |
| `sideOffset` | `number` | `-` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onDismiss` | `() => void` | `-` |
| `onExited` | `() => void` | `-` |
| `onArrowLeft` | `() => void` | `-` |
| `onPointerEnter` | `() => void` | `-` |
| `children` | `HellaChildren` | The sub-surface items |
Accepts all native `div` attributes (forwarded to the root element).

`onDismiss` closes the sub's own layer; `onExited` fires when the exit animation ends; `onArrowLeft` closes the submenu; `onPointerEnter` cancels the trigger's pending close when the pointer enters the content.

Every part also takes a `class` string, landing last in its style composition.

The sub-content registers its own [`layerDismissal`](/reference/dom/layerdismissal) layer, so Escape pops one level at a time and an outside press closes the sub before the parent.

## Dismissal and Positioning

Dismissal runs through [`layerDismissal`](/reference/dom/layerdismissal): Escape and a pointerdown outside the panel ask the top layer to close, so stacked menus and popovers dismiss one layer at a time. Activating an item closes every open menu layer through a document-level activation event, which is also how Enter and Space close from the keyboard. Closing starts the exit - the panel stays mounted under `data-state="closed"` until its animation ends, with dismissal wiring down while it leaves.

The panel positions through [`anchorPosition`](/reference/dom/anchorposition): fixed coordinates against the trigger, flipping on viewport collision, repositioning on scroll and resize. The menu is non-modal: there is no focus trap, and focus moves to the first activatable item on open.

## Keyboard Interaction

| Key | Behavior |
|---|---|
| `ArrowDown` / `ArrowUp` | Opens the closed menu from the trigger; inside, roves items with wrap, skipping disabled entries |
| `Home` / `End` | Jumps to the first or last activatable item |
| `Enter` / `Space` | Activates the focused item (toggles checkbox and radio rows) |
| `ArrowRight` / `ArrowLeft` | Enters a focused sub-trigger or exits the sub; flips with the resolved writing direction |
| `Escape` | Dismisses the top layer only |
| `Tab` | Closes every open layer |
| printable keys | Typeahead: selects the first item starting with the buffered keys |
