## API

The wrapper carries `aspect-ratio: <ratio>` plus `width: 100%` inline (the ratio is a prop, so it cannot live in a stylesheet). The ratio accepts any number and defaults to a square, and `base` contributes `position: relative` so absolutely positioned children still anchor to the box. Children render as-is, so images should bring their own object-fit cover.

### AspectRatio

| Prop | Type | Default |
| ---- | ---- | ------- |
| `ratio` | `number` | `1` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The framed content |
Accepts all native `div` attributes (forwarded to the root element).
