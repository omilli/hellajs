## API

Pair `MessageContent` with the `bubble` entry's `Bubble` to get the message surface itself; the avatar well takes any small element (an image, an initial).

All six exports are named; each renders its `data-slot`, and the parts coordinate through data attributes rather than context. A footer lifts the avatar 2rem, a ghost-variant bubble (from the bubble entry) removes the header and footer side padding, and end alignment slides every direct content child to the inline end; all three conditions read `data-slot`/`data-align`/`data-variant` ancestors, so the wiring survives re-ordering parts.

### MessageGroup

The stack: a `div` carrying `data-slot="message-group"` that spaces its rows.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The message rows |

### Message

The row: a `div` carrying `data-align`, which the descendant conditions read.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `align` | `"start" \| "end"` | `"start"` |
| `children` | `HellaChildren` | The avatar well and content column |

`align="end"` flips the row with `flex-row-reverse`, pushes the content column to the inline end, and right-aligns the footer, so sent messages mirror received ones without extra classes on the parts.

### MessageAvatar

The avatar well: a `div` carrying `data-slot="message-avatar"`; a footer in the row lifts it 2rem.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Any small element (an image, an initial) |

### MessageContent

The content column: a `div` carrying `data-slot="message-content"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Header, bubble, and footer nodes |

### MessageHeader

The header meta row: a `div` carrying `data-slot="message-header"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The sender name node |

### MessageFooter

The footer meta row: a `div` carrying `data-slot="message-footer"`, right-aligned on end-aligned rows.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The timestamp node |

Every part also takes a `class` string, landing last in its style composition.
