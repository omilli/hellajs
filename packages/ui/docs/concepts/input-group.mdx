## API

The group owns the focus and invalid rings: its selectors light the whole composite up when the inner control receives focus or carries `aria-invalid`, while the control itself strips its own ring. `InputGroupInput` and `InputGroupTextarea` carry `data-slot="input-group-control"`, which is the hook those selectors read.

`InputGroupAddon`, `InputGroupButton`, `InputGroupText`, `InputGroupInput`, and `InputGroupTextarea` ship beside the default root for custom composition.

### InputGroup

| Prop | Type | Default |
| ---- | ---- | ------- |
| `disabled` | `boolean` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The addons and control |

Accepts all native `div` attributes (forwarded to the root element).

`disabled` renders `data-disabled="true"`; every addon reads that attribute and drops to half opacity.

### InputGroupAddon

The wrapper for content beside or above the control; clicking it focuses the group's input unless the click landed on a button. `align` orders and pads the addon around the control; block alignments stack the group into a column.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `align` | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `children` | `HellaChildren` | Addon content, typically text or buttons |

Accepts all native `div` attributes (forwarded to the root element).

### InputGroupButton

The group's button, a tighter take on the standalone button copy. It renders `type="button"` unless a native `type` rides the attributes.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |
| `children` | `HellaChildren` | Button content |

Accepts all native `button` attributes (forwarded to the root element); `type`, `on:click`, and friends ride the spread.

### InputGroupText

The text plate: a `span` for static labels and prefixes inside an addon.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Text content |

Accepts all native `span` attributes (forwarded to the root element).

### InputGroupInput

The composite's input: carries `data-slot="input-group-control"`, the hook the group's focus and error selectors read.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |

Accepts all native `input` attributes (forwarded to the root element): `type`, `placeholder`, `id`, `value`, `aria-label`, and friends ride the spread, and `value` binds as the element's value property so a plain string or a bare signal stays in sync after mount. The invalid state is driven by the native `aria-invalid` attribute, which turns the group's border destructive.

### InputGroupTextarea

The composite's textarea, wired like `InputGroupInput`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |

Accepts all native `textarea` attributes (forwarded to the root element): `placeholder`, `id`, `rows`, `value`, `aria-label`, and friends ride the spread, with the same `value` binding and native `aria-invalid` invalid state as the input.

Every part also takes a `class` string, landing last in its style composition.
