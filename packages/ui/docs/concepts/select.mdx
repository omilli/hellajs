## Usage

The composed `Select` takes its options as data and renders the trigger plus the portaled listbox; the copied file wires its positioning, dismissal, and typeahead from the `@hellajs/dom` behavior functions.

### jsx

```jsx
import Select from './components/select';

const fruits = [
  { value: 'apple', label: 'Apple' },
  { value: 'blueberry', label: 'Blueberry' },
  { value: 'canteloupe', label: 'Canteloupe', disabled: true },
];

const FruitPicker = () => (
  <Select items={fruits} placeholder="Pick a fruit" onValueChange={(value) => console.log(value)} />
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${Select}
    items=${fruits}
    placeholder="Pick a fruit"
  />
</main>`
```

| Prop | Type | Behavior |
|---|---|---|
| `items` | `{ value, label?, disabled? }[]` | Options rendered in order; each entry is one row, tabled under Items |
| `value` | `() => string` | Controlled selected value accessor; when given, the root never writes its internal signal |
| `onValueChange` | `(value: string) => void` | Reports the requested selection (including the empty string when cleared) |
| `placeholder` | `string` | Shown in the trigger with `data-placeholder` while nothing is selected |
| `size` | `"sm" \| "default"` | Trigger height; `"sm"` renders the compact `data-size="sm"` variant (default `"default"`) |
| `clearable` | `boolean` | Renders an inline clear affordance on the trigger while a value is selected |
| `class` | `string` | Extra classes on the trigger button |

The select renders only the button and listbox: no hidden native form control, so it submits nothing by itself. Pair it with `native-select` when a form needs a submittable field.

## Items

Each entry in the `items` array is one option row:

| Field | Type | Behavior |
|---|---|---|
| `value` | `string` | Selection identity: reported through `onValueChange`, matched against the controlled `value`, and rendered as the row's `data-value` |
| `label` | `HellaChildren` | The option's text node; the trigger echoes the selected entry's label through `SelectValue` |
| `disabled` | `boolean` | Skips the row in roving and typeahead, blocks commit, and renders `aria-disabled` plus `data-disabled` |

## Keyboard and Dismissal

The trigger opens on click and on ArrowDown/ArrowUp. Inside the listbox, arrows rove the options with wrap, Home and End jump to the edges, Enter and Space commit the highlighted option, and Tab closes. Typing buffers a typeahead query (reset after 500ms) and highlights the first match: prefix matches win, then a wrapping substring scan. The highlighted option carries `data-highlighted`; the selected option carries `aria-selected="true"`, `data-state="checked"`, and the check icon, and scrolls into view on open.

Dismissal runs through [`layerDismissal`](/reference/dom/layerdismissal): Escape and a pointerdown outside the listbox close it, and focus returns to the trigger. Closing starts the exit - the listbox stays mounted under `data-state="closed"` until its animation ends, with dismissal wiring down while it leaves.

The panel positions itself through [`anchorPosition`](/reference/dom/anchorposition) with `matchAnchorWidth`: the listbox always anchors below the trigger (flipped on viewport collision) and stretches to its width. Scroll buttons render at the listbox edges; they repeat-scroll while hovered and hide at their scroll bounds.

The clear affordance is pointer-only: it lives inside the trigger button, so it cannot take keyboard focus without nesting interactive content. Keyboard users clear by re-running the composed flow (the empty string is a valid `onValueChange` report) or by pairing with `native-select`.

## Manual Parts

Nine named parts ship beside the default `Select`: `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectGroup`, `SelectItem`, `SelectLabel`, `SelectSeparator`, `SelectScrollUpButton`, and `SelectScrollDownButton`. Manual composition passes state explicitly: portal the content yourself, hand it a `state` accessor and an `onDismiss` callback, and thread each item its selected state.

### SelectTrigger

The trigger button carrying `aria-haspopup="listbox"`, `aria-expanded`, and the open-state `data-state`.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and `aria-expanded`; the composed `Select` wires it |
| `id` | `string` | Button id |
| `ariaControls` | `string` | The listbox id, rendered as `aria-controls` |
| `ariaLabel` | `string` | Rendered as `aria-label` |
| `size` | `"sm" \| "default"` | Compact treatment through `data-size` (default `"default"`) |
| `onOpen` | `() => void` | Click and ArrowDown/ArrowUp call it to request an open toggle |
| `clearable` | `boolean` | Renders the inline clear affordance while `hasValue` resolves truthy |
| `onClear` | `() => void` | Called when the clear affordance activates |
| `hasValue` | `() => boolean` | Resolves whether a value is currently selected |
| `disabled` | `boolean` | Native `disabled` attribute; blocks `onOpen` |

### SelectValue

The chosen-label span inside the trigger, showing the placeholder with `data-placeholder` while empty.

| Prop | Type | Behavior |
|---|---|---|
| `placeholder` | `string` | Rendered while `value` resolves empty |
| `value` | `HellaChildren \| (() => HellaChildren \| undefined)` | The current label; an accessor keeps it reactive |

### SelectContent

The portaled `role="listbox"` surface with its keyboard model, typeahead, and edge scroll buttons.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle; `closed` tears the wirings down |
| `id` | `string` | Listbox id; the trigger's `aria-controls` points at it |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | Anchor placement (default `"bottom"`) |
| `align` | `"start" \| "center" \| "end"` | Cross-axis alignment (default `"start"`) |
| `sideOffset` | `number` | Gap between the anchor and the content edge, in px (default 6) |
| `anchor` | `() => Element \| undefined` | Resolves the element the content anchors to; positioning is skipped when undefined |
| `onDismiss` | `() => void` | Escape and an outside pointerdown dismiss the top layer into this callback |
| `onExited` | `() => void` | Called when the exit animation ends under `data-state="closed"` |
| `onClose` | `() => void` | Called by the listbox keyboard model on Tab |
| `children` | `HellaChildren` | The options and grouping parts |

### SelectItem

One `role="option"` row with the check indicator.

| Prop | Type | Behavior |
|---|---|---|
| `value` | `string` | Rendered as the row's `data-value` |
| `label` | `HellaChildren` | The option's text node |
| `selected` | `boolean \| (() => boolean)` | Drives `aria-selected`, `data-state` (`checked` / `unchecked`), and the check icon |
| `onselect` | `() => void` | Called on click when the item is enabled |
| `id` | `string` | Option id |
| `disabled` | `boolean` | `aria-disabled` plus `data-disabled`; blocks `onselect` |

### SelectGroup

A passthrough grouping `div` for options and labels.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The grouped items |

### SelectLabel

A section label inside a group.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The label text |

### SelectSeparator

A `role="separator"` hairline between groups.

### SelectScrollUpButton

The top edge scroll row, rendering an up chevron unless children replace it; `SelectContent` shows and hides it at the scroll bounds.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Replaces the default up chevron when given |

### SelectScrollDownButton

The bottom edge scroll row, rendering a down chevron unless children replace it; `SelectContent` shows and hides it at the scroll bounds.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Replaces the default down chevron when given |

Every part also takes a `class` string, landing last in its style composition.

```jsx
import { signal } from '@hellajs/core';
import { Portal } from '@hellajs/dom';
import SelectContent, { SelectItem } from './components/select';

const Manual = () => {
  const open = signal(false);
  const current = signal('apple');
  const state = () => (open() ? 'open' : 'closed');
  let trigger;

  return (
    <button
      type="button"
      aria-haspopup="listbox"
      aria-expanded={open() ? 'true' : 'false'}
      hook:afterMount={(node) => { trigger = node; }}
      on:click={() => open(!open())}
    >
      {current() || 'Pick one'}
      {() => open() && (
        <Portal to="body">
          <SelectContent
            state={state}
            anchor={() => trigger}
            onDismiss={() => open(false)}
          >
            <SelectItem
              value="apple"
              label="Apple"
              selected={() => current() === 'apple'}
              onselect={() => { current('apple'); open(false); }}
            />
          </SelectContent>
        </Portal>
      )}
    </button>
  );
};
```

| Attribute | Where | Purpose |
|---|---|---|
| `aria-haspopup="listbox"` / `aria-expanded` / `aria-controls` | trigger | Expands the listbox id |
| `data-state` / `data-size` / `data-placeholder` | trigger, content, value | Open state, compact size, placeholder styling hooks |
| `role="option"` / `aria-selected` / `data-state` | item | Listbox option semantics and the check indicator |
| `data-highlighted` | item | The roving highlight ring |
| `data-disabled` / `aria-disabled` | item | Skipped by roving and typeahead, unclickable |
