# Avatar

A user portrait with a graceful fallback: a rounded relative wrapper stacking an image and a fallback initial, plus a status badge, a overlapping group, and a group count. Structure and class strings match shadcn's new-york-v4 Avatar; the image/fallback swap is reimplemented over signals instead of Radix.

## Usage

There is no context object. The image owns its load state and the fallback reads it through one explicit signal you pass to both parts: `AvatarImage` hides its `img` while the signal reads false and flips it on the native `load`/`error` events, and `AvatarFallback` hides while the same signal reads true. Both parts stay mounted (the swap is attribute-driven, not conditional rendering), so a broken URL that fires `error` drops the image back out and the initial returns:

```jsx
import { signal } from '@hellajs/core';
import Avatar, { AvatarFallback, AvatarImage } from './components/avatar';

const loaded = signal(false);

const Portrait = () => (
  <Avatar>
    <AvatarImage src="/milli.png" alt="Milli" loaded={loaded} />
    <AvatarFallback loaded={loaded}>M</AvatarFallback>
  </Avatar>
);
```

An `AvatarImage` without a shared signal still hides itself until its own load resolves; pass the signal only when a sibling fallback must react.

## Groups

Groups overlap their avatars with a negative offset and a background ring; the count chip picks up the group's size:

```jsx
import Avatar, { AvatarFallback, AvatarGroup, AvatarGroupCount } from './components/avatar';

const Team = () => (
  <AvatarGroup>
    <Avatar><AvatarFallback>M</AvatarFallback></Avatar>
    <Avatar><AvatarFallback>J</AvatarFallback></Avatar>
    <AvatarGroupCount>+5</AvatarGroupCount>
  </AvatarGroup>
);
```

## Sizes and Badge

`size` sets `data-size` (`sm`, `default`, `lg`); the root, fallback, and badge read it through group selectors, so one prop rescales the whole stack. The badge pins to the bottom-right corner:

```jsx
import Avatar, { AvatarBadge, AvatarFallback } from './components/avatar';

const Statused = () => (
  <Avatar size="lg">
    <AvatarFallback>M</AvatarFallback>
    <AvatarBadge />
  </Avatar>
);
```

## Styling

The style module exports `base`, `image`, `fallback`, `badge`, `group`, and `groupCount` maps; each part's compose bakes its own class plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the size conditions compile to `[data-slot='avatar'][data-size=…]` and `:has()` ancestor selectors. The tailwind flavor carries shadcn's literal utilities verbatim, including the named-group conditions (`group-data-[size=sm]/avatar:text-xs`, `*:data-[slot=avatar]:ring-2`, and the `group-has-data-[size=lg]/avatar-group:size-10` count scaling) wrapped in `cn()`. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
