## API

The image owns its load state and the fallback reads it through one explicit signal you pass to both parts: `AvatarImage` hides its `img` while the signal reads false and flips it on the native `load`/`error` events, and `AvatarFallback` hides while the same signal reads true. Both parts stay mounted (the swap is attribute-driven, not conditional rendering), so a broken URL that fires `error` drops the image back out and the initial returns. An `AvatarImage` without a shared signal still hides itself until its own load resolves; pass the signal only when a sibling fallback must react.

### Avatar

| Prop | Type | Default |
| ---- | ---- | ------- |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The image, fallback, and badge |

`size` sets `data-size` on the root; the fallback and badge read it through group selectors, so one prop rescales the whole stack.

### AvatarImage

The portrait: an `img` carrying `data-slot="avatar-image"`, hidden until its load state resolves.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` | `-` |
| `alt` | `string` | `-` |
| `loaded` | `Signal<boolean>` | A private signal |

### AvatarFallback

The initial: a `span` carrying `data-slot="avatar-fallback"`, hidden while the shared signal reads true.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `loaded` | `() => boolean` | `-` |
| `children` | `HellaChildren` | The fallback node, typically an initial |

### AvatarBadge

The status dot: a `span` carrying `data-slot="avatar-badge"`, pinned to the bottom-right corner.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The content inside the badge |

### AvatarGroup

The overlapping row: a `div` carrying `data-slot="avatar-group"`, its members overlapping through a negative offset and a background ring.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The stacked avatars and count chip |

### AvatarGroupCount

The count chip: a `div` carrying `data-slot="avatar-group-count"`, scaled by the group's `data-size`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The count label, e.g. `+5` |

Every part also takes a `class` string, landing last in its style composition.
