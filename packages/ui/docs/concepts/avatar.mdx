## API

The composed root takes the portrait and the initial as props and works zero-config: it owns the loaded signal internally, so `src` renders the image part hidden until it loads and `fallback` renders the fallback part hidden while it reads true. Both parts stay mounted (the swap is attribute-driven, not conditional rendering), so a broken URL that fires `error` drops the image back out and the initial returns.

### Avatar

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` | `-` |
| `alt` | `string` | `-` |
| `fallback` | `HellaChildren` | `-` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

`size` sets `data-size` on the root; the fallback and badge read it through group selectors, so one prop rescales the whole stack. Omit `src` and `fallback` for a plain composition root, and render the parts yourself when siblings must share one signal explicitly.

## Manual Composition

`AvatarImage` and `AvatarFallback` stay exported: pass one signal to both when the composed root's internal threading is not enough, or mount `AvatarImage` alone and let its private signal drive the swap.

### AvatarImage

The portrait: an `img` carrying `data-slot="avatar-image"`, hidden until its load state resolves.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `loaded` | `Signal<boolean>` | A private signal |
Accepts all native `img` attributes (forwarded to the root element).

### AvatarFallback

The initial: a `span` carrying `data-slot="avatar-fallback"`, hidden while the shared signal reads true.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `loaded` | `() => boolean` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

### AvatarBadge

The status dot: a `span` carrying `data-slot="avatar-badge"`, pinned to the bottom-right corner.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

### AvatarGroup

The overlapping row: a `div` carrying `data-slot="avatar-group"`, its members overlapping through a negative offset and a background ring.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

### AvatarGroupCount

The count chip: a `div` carrying `data-slot="avatar-group-count"`, scaled by the group's `data-size`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

Every component also takes a `class` string, landing last in its style composition.
