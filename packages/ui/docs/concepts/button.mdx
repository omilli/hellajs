## API

The root carries `data-slot="button"`, `data-variant`, and `data-size`, and `aria-invalid` reflects the `ariaInvalid` prop.

### Button

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `ariaInvalid` | `boolean` | `-` |
| `class` | `string` | `-` |
| `onclick` | `() => void` | `-` |
