## API

The root carries `data-slot="button"`, `data-variant`, and `data-size`.

### Button

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
Accepts all native `button` attributes (forwarded to the root element).
| `class` | `string` | `-` |
