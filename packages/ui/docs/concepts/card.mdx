## API

Every part takes `{ children?, class? }`, and the header automatically switches to a two-column grid when a `CardAction` is present.

### Card

The panel root: a `div` carrying `data-slot="card"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The arranged parts |

### CardHeader

The top row: a `div` carrying `data-slot="card-header"`, switching to a two-column grid when a `CardAction` joins its children.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Title, description, and optional action nodes |

### CardTitle

The heading: a `div` carrying `data-slot="card-title"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The title node |

### CardDescription

The supporting line: a `div` carrying `data-slot="card-description"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The description node |

### CardAction

The header's side slot: a `div` carrying `data-slot="card-action"`, aligned opposite the title.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Action nodes, typically buttons |

### CardContent

The body: a `div` carrying `data-slot="card-content"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The body nodes |

### CardFooter

The bottom row: a `div` carrying `data-slot="card-footer"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The footer nodes |

Every part also takes a `class` string, landing last in its style composition.
