## API

The input carries `data-slot="input"` for targeting. `value` accepts a plain string or an accessor: an accessor keeps the field in sync after mount, and `oninput` receives the typed string on every input event.

### Input

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string \| (() => string)` | `-` |
| `type` | `string` | `-` |
| `placeholder` | `string` | `-` |
| `id` | `string` | `-` |
| `ariaLabel` | `string` | `-` |
| `ariaInvalid` | `boolean` | `-` |
| `oninput` | `(value: string) => void` | `-` |
| `class` | `string` | `-` |

`ariaInvalid` drives the invalid state: the destructive border and ring on failed validation.
