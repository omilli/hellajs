## Usage

A side panel sliding in from one of the four screen edges: the caller owns an `open` accessor and an `onClose` callback, and the component wires the slide animations, close button, title, description, focus trap, and escape/outside dismissal around them.

### jsx

```jsx
import { signal } from '@hellajs/core';
import Sheet from './components/sheet';

const isOpen = signal(false);
const close = () => isOpen(false);

const EditProfile = () => (
  <Sheet open={isOpen} onClose={close} side="right" title="Edit profile" description="Make changes to your profile here.">
    <p>Press escape or the X to close.</p>
  </Sheet>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${Sheet} open=${isOpen} onClose=${close} side="top" title="Notifications">
    <p>Three unread digests.</p>
  </${Sheet}>
</main>`
```

| Prop | Default | Behavior |
|---|---|---|
| `side` | `"right"` | Edge the panel mounts on; sets `data-side` and the slide variant |
| `title` | - | Optional string rendered as a wired `SheetTitle` (the panel's `aria-labelledby` target) |
| `description` | - | Optional string rendered as a wired `SheetDescription` (the panel's `aria-describedby` target) |
| `showCloseButton` | `true` | Renders the X close button in the panel's top-right corner |
| `closeOnEscape` | `true` | Escape keydown while the panel is open calls `onClose` |
| `closeOnOutside` | `true` | Pointerdown outside the panel (the overlay included) calls `onClose` |

Opening portals the overlay and panel into `document.body` under `data-state="open"`; closing keeps the panel mounted under `data-state="closed"` until its exit slide ends, with the dismissal wirings down while it leaves. The panel carries `role="dialog"` with `aria-labelledby` and `aria-describedby` pointing at the generated title and description ids - the wiring screen readers announce.

## Sides

`side` picks the edge the panel mounts on and carries both the geometry and the slide direction:

| Side | Geometry | Slide |
|---|---|---|
| `"right"` (default) | Full height, three-quarters wide capped at 24rem from wide screens up, right border | In from the right, out to the right |
| `"left"` | Full height, three-quarters wide capped at 24rem from wide screens up, left border | In from the left, out to the left |
| `"top"` | Full width, auto height, bottom border | In from the top, out to the top |
| `"bottom"` | Full width, auto height, top border | In from the bottom, out to the bottom |

## Manual Parts

Nine named parts ship beside the default `Sheet` for custom composition: `SheetTrigger`, `SheetClose`, `SheetPortal`, `SheetOverlay`, `SheetContent`, `SheetHeader`, `SheetFooter`, `SheetTitle`, and `SheetDescription`. State is explicit - portal the overlay and panel yourself and hand both a `state` accessor.

### SheetTrigger

A bare button; wire its click to your own signal write.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The trigger label |

### SheetClose

The X button with its `sr-only` "Close" label; `SheetContent` renders the same shape automatically unless `showCloseButton` is false.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives the button's `data-state` |
| `onClose` | `() => void` | Click callback |

### SheetPortal

Wraps children in a `Portal to="body"` for compositions that want the named part.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The portaled nodes |

### SheetOverlay

The screen-covering backdrop `div` carrying `data-slot="sheet-overlay"`.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives the overlay's `data-state` and its enter/exit fade |

### SheetContent

The `role="dialog"` panel carrying `data-slot="sheet-content"`: focus trap plus escape and outside dismissal while open, torn down the moment the exit starts.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle; `closed` tears the dismissal wirings down |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | Sets `data-side`, the geometry, and the slide direction (default `"right"`) |
| `labelledBy` | `string` | Rendered as the panel's `aria-labelledby` |
| `describedBy` | `string` | Rendered as the panel's `aria-describedby` |
| `showCloseButton` | `boolean` | Renders the X button in the panel's top-right corner (default `true`) |
| `closeOnEscape` | `boolean` | Escape keydown calls `onClose` (default `true`) |
| `closeOnOutside` | `boolean` | Outside pointerdown calls `onClose` (default `true`) |
| `onClose` | `() => void` | Dismissal and close-button callback |
| `onExited` | `() => void` | Called when the exit slide ends under `data-state="closed"` |
| `children` | `HellaChildren` | The panel body |

### SheetHeader

The top grouping `div` carrying `data-slot="sheet-header"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Title and description nodes |

### SheetFooter

The bottom grouping `div` carrying `data-slot="sheet-footer"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Action nodes, typically buttons |

### SheetTitle

The heading: an `h2` carrying `data-slot="sheet-title"` whose `id` the panel's `aria-labelledby` points at.

| Prop | Type | Behavior |
|---|---|---|
| `id` | `string` | Rendered as the heading's `id` |
| `children` | `HellaChildren` | The title text |

### SheetDescription

The supporting line: a `p` carrying `data-slot="sheet-description"` whose `id` the panel's `aria-describedby` points at.

| Prop | Type | Behavior |
|---|---|---|
| `id` | `string` | Rendered as the paragraph's `id` |
| `children` | `HellaChildren` | The description text |

Every part also takes a `class` string, landing last in its style composition.

```jsx
import { signal } from '@hellajs/core';
import { Portal } from '@hellajs/dom';
import Sheet, { SheetClose, SheetContent, SheetDescription, SheetFooter, SheetHeader, SheetOverlay, SheetTitle } from './components/sheet';

const isOpen = signal(false);
const state = () => (isOpen() ? 'open' : 'closed');

const Manual = () => (
  <>
    <button on:click={() => isOpen(true)}>Open</button>
    {() => isOpen() && (
      <Portal to="body">
        <SheetOverlay state={state} />
        <SheetContent state={state} side="bottom" labelledBy="sheet-manual-title" onClose={() => isOpen(false)}>
          <SheetHeader>
            <SheetTitle id="sheet-manual-title">Cart</SheetTitle>
            <SheetDescription>Three items reserved for you.</SheetDescription>
          </SheetHeader>
          <SheetFooter>
            <SheetClose onClose={() => isOpen(false)} />
          </SheetFooter>
        </SheetContent>
      </Portal>
    )}
  </>
);
```
