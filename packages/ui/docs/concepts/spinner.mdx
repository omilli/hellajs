## API

The glyph inherits `currentColor` and scales through your own size classes; the `role="status"` announcement needs no wiring. The spin is a 1s linear infinite css animation.

### Spinner

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | Optional inner nodes |
Accepts all native `svg` attributes (forwarded to the root element).

Drop the spinner into a disabled button to mark the operation in progress; pairing it with text keeps the action readable while the glyph spins.
