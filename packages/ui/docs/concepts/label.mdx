# Label

A form-field caption styled byte-faithfully to shadcn's new-york-v4 Label: the semantic `label` element with a `for` passthrough, plus the group- and peer-driven disabled styles shadcn applies in form layouts.

## Usage

The root carries `data-slot="label"`, and `for` lands directly on the element so clicking the caption focuses the input without extra wiring.

```jsx
import Label from './components/label';

const Name = () => (
  <div class="flex flex-col gap-2">
    <Label for="name">Project name</Label>
    <input id="name" placeholder="acme-site" />
  </div>
);
```

## Disabled States

The disabled styles follow shadcn's form conventions: a label inside an element marked `.group` with `data-disabled="true"` dims and drops pointer events, and a label following a disabled `.peer` sibling shows the not-allowed cursor. Neither needs props; the ancestor and sibling states drive both:

```jsx
import Label from './components/label';

const Fieldset = () => (
  <div class="group" data-disabled="true">
    <Label for="region">Region</Label>
  </div>
);
```

## Styling

The css style module exports a single `base` carrying the layout, typography, and the two disabled-state selectors (ancestor `.group[data-disabled]` and sibling `.peer:disabled`); the compose bakes `base` plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor uses shadcn's literal utilities verbatim (including the `group-data-[disabled=true]:*` and `peer-disabled:*` forms) wrapped in `cn()`. The label reads no tokens beyond the palette, so it follows your theme's foreground automatically. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
