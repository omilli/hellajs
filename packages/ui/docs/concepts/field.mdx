## API

Compose the parts by hand; there is no context object and no schema prop.

### Field

The field row: a `div` carrying `data-slot="field-item"`, laying the label and control out by `orientation`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` |
| `invalid` | `boolean` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

`invalid` renders `data-invalid="true"` and the native `disabled` attribute renders `data-disabled="true"`: the field text turns destructive and labels and titles fade to half opacity, without touching the children. `responsive` uses a container query so fields laid out inside a `FieldGroup` go horizontal only when the group is at least 28rem wide.

### FieldSet

The group container: the native `fieldset` element wrapping related fields.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `fieldset` attributes (forwarded to the root element).

### FieldLegend

The group's caption: the native `legend` element.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"legend" \| "label"` | `"legend"` |
| `children` | `HellaChildren` | `-` |

Accepts all native `legend` attributes (forwarded to the root element).

### FieldGroup

The flex row container that lays stacked or responsive fields out together.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

### FieldContent

The description stack beside the title inside `FieldLabel`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

### FieldLabel

The full `label` element wrapping title and content; `for` forwards natively like the standalone label copy.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `label` attributes (forwarded to the root element).

### FieldTitle

The label's heading line: a `div` carrying the same `data-slot="field-label"` as `FieldLabel`, which is what lets one disabled-state selector cover both parts.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

### FieldDescription

The supporting line: a `p` carrying `data-slot="field-description"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `p` attributes (forwarded to the root element).

### FieldSeparator

A rule between fields with optional centered text; the text's presence flips the wrapper's `data-content` between `true` and `false`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

### FieldError

The message row: a `role="alert"` div that renders children or derives text from `errors`, hidden when there is nothing to show.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `errors` | `Array<{ message?: string } \| undefined>` | `-` |
| `children` | `HellaChildren` | `-` |

Accepts all native `div` attributes (forwarded to the root element).

A single message renders as text, several render as a deduplicated list, and an empty error renders hidden rather than removed so both formats keep one DOM shape.

Every part also takes a `class` string, landing last in its style composition.
