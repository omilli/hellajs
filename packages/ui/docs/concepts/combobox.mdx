## Usage

The composed `Combobox` takes its options as data and renders the input shell plus the portaled panel: focusing the input opens the panel, typing filters it. The copied file carries its input-group shell inline (the entry never cross-imports) and wires its positioning, dismissal, and typeahead from the `@hellajs/dom` behavior functions.

### jsx

```jsx
import Combobox from './components/combobox';

const fruits = [
  { value: 'apple', label: 'Apple' },
  { value: 'blueberry', label: 'Blueberry' },
  { value: 'canteloupe', label: 'Canteloupe' },
];

const FruitPicker = () => (
  <Combobox items={fruits} placeholder="Search fruit" onValueChange={(value) => console.log(value)} />
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${Combobox}
    items=${fruits}
    placeholder="Search fruit"
  />
</main>`
```

| Prop | Type | Behavior |
|---|---|---|
| `items` | `{ value, label?, disabled? }[]` | Options rendered in order; each entry is one row, tabled under Items |
| `value` | `() => string \| string[]` | Controlled selection accessor; a string in single mode, an array in multiple mode. When given, the root never writes its internal signal |
| `onValueChange` | `(value: string \| string[]) => void` | Reports the requested selection (string, or array in multiple mode) |
| `multiple` | `boolean` | Toggles values in and out of an array and renders removable chips |
| `placeholder` | `string` | The input's placeholder text |
| `filter` | `(items, query) => ComboboxEntry[]` | Replaces the default case-insensitive substring filter |
| `showClear` | `boolean` | Renders the panel's clear affordance while a value is selected (single mode) |
| `class` | `string` | Extra classes on the input wrapper |

The input always shows the query, never the selection: the selected value lives in `onValueChange` (render it through `ComboboxValue` where needed). The combobox submits nothing by itself; pair it with `native-select` (or a hidden input of your own) when a form needs the value.

## Items

Each entry in the `items` array is one option:

| Field | Type | Behavior |
|---|---|---|
| `value` | `string` | Selection identity: reported through `onValueChange`, matched against the controlled `value`, and rendered as the option's `data-value` |
| `label` | `string` | The option's text and its filter target; filtering falls back to the value when a label is missing |
| `disabled` | `boolean` | Skipped by roving and typeahead, unclickable, and rendered with `aria-disabled` plus `data-disabled` |

## Filtering

The default filter is a case-insensitive substring match over item labels (falling back to the value when a label is missing); matching options stay visible while the rest hide in place. Options are never unmounted while filtering, so option ids stay stable for `aria-activedescendant`. When nothing matches, the panel marks itself `data-empty` and the built-in empty row shows through its `group-data-empty` styling.

Pass `filter` to replace the default entirely - it receives the full item list and the live query:

```jsx
import Combobox from './components/combobox';

const startsWith = (items, query) =>
  query ? items.filter((item) => item.value.startsWith(query)) : items;

const PrefixPicker = () => (
  <Combobox items={fruits} filter={startsWith} placeholder="Prefix match only" />
);
```

## Keyboard and Multiple Selection

The input keeps focus the whole time (`role="combobox"`): ArrowDown and ArrowUp move the active option (skipping disabled entries, wrapping at the edges), Enter commits it, and Escape clears the query and then closes. The active option carries `data-highlighted`, and the input's `aria-activedescendant` points at its id. Printable keystrokes also feed a [`menuTypeahead`](/reference/dom/menutypeahead) buffer that walks the visible options, so typing refines the filter and the highlight together.

In single mode, Enter closes the panel and clears the query. In `multiple` mode, Enter toggles the active value in or out of the array and the panel stays open; each selected value renders as a `ComboboxChip` whose remove button toggles it back out. `showClear` adds a clear affordance that wipes the whole selection.

Dismissal runs through [`layerDismissal`](/reference/dom/layerdismissal): Escape and a pointerdown outside the wrapper close the top layer. Closing starts the exit - the panel stays mounted under `data-state="closed"` until its animation ends, with dismissal wiring down while it leaves. The panel positions itself through [`anchorPosition`](/reference/dom/anchorposition) with `matchAnchorWidth`, anchored to the input wrapper (the chips wrapper in multiple mode), flipping sides on viewport collision.

## Manual Parts

Fifteen named parts ship beside the default `Combobox`: `ComboboxTrigger`, `ComboboxInput`, `ComboboxContent`, `ComboboxList`, `ComboboxItem`, `ComboboxGroup`, `ComboboxLabel`, `ComboboxCollection`, `ComboboxEmpty`, `ComboboxSeparator`, `ComboboxValue`, `ComboboxClear`, `ComboboxChips`, `ComboboxChip`, and `ComboboxChipsInput`. Manual composition passes state explicitly: the list takes the items plus query, selection, and active resolvers; the input takes the aria wiring; the anchor threads to the wrapper node by hand (`anchor={() => wrapperNode}`).

### ComboboxTrigger

The manual trigger button; the composed root renders its chevron twin inside the input-group addon.

| Prop | Type | Behavior |
|---|---|---|
| `onclick` | `() => void` | Click callback |
| `disabled` | `boolean` | Native `disabled` attribute |
| `children` | `HellaChildren` | The trigger label |

### ComboboxInput

The input-group shell with the chevron toggle and clear addons, carrying the combobox aria wiring.

| Prop | Type | Behavior |
|---|---|---|
| `value` | `string \| (() => string)` | The query text; an accessor keeps it reactive |
| `placeholder` | `string` | The input's placeholder text |
| `onInput` | `(value: string) => void` | Query change callback (delegated input event) |
| `onKeydown` | `(e: KeyboardEvent) => void` | Keydown handler owning the keyboard model |
| `onFocus` | `() => void` | Focus handler; the composed root opens on focus |
| `state` | `() => "open" \| "closed"` | Resolves open state for `aria-expanded` |
| `ariaControls` | `string` | The listbox id, rendered as `aria-controls` |
| `activeDescendant` | `() => string \| undefined` | Resolves the active option id for `aria-activedescendant` |
| `showTrigger` | `boolean` | Renders the chevron toggle addon |
| `showClear` | `boolean` | Renders the clear addon while `hasValue` resolves truthy |
| `onToggle` | `() => void` | Chevron toggle callback |
| `onClear` | `() => void` | Clear callback |
| `hasValue` | `() => boolean` | Resolves whether a value is selected (drives the clear addon) |
| `wire` | `(node) => () => void` | Wires the wrapper on mount and returns its dispose; the composed root anchors the panel here and attaches typeahead |
| `portal` | `() => HellaChildren` | The portaled panel, mounted while open inside the wrapper |

### ComboboxContent

The positioned panel surface.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle |
| `id` | `string` | Panel id |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | Anchor placement (default `"bottom"`) |
| `align` | `"start" \| "center" \| "end"` | Cross-axis alignment (default `"start"`) |
| `sideOffset` | `number` | Gap between the anchor and the content edge, in px (default 6) |
| `anchor` | `() => Element \| undefined` | Resolves the element the content anchors to (the input wrapper); positioning is skipped when undefined |
| `chips` | `boolean` | Sets `data-chips="true"` (chips-composition width styling) |
| `empty` | `() => boolean` | Zero-match flag; drives `data-empty` styling |
| `onDismiss` | `() => void` | Escape and an outside pointerdown dismiss the top layer into this callback |
| `onExited` | `() => void` | Called when the exit animation ends under `data-state="closed"` |
| `children` | `HellaChildren` | The list and static chrome |

### ComboboxList

The `role="listbox"` rendering one `ComboboxItem` per entry, hidden in place as the query filters.

| Prop | Type | Behavior |
|---|---|---|
| `items` | `ComboboxEntry[]` | Data-driven options, rendered once and hidden (never remounted) as the query filters |
| `query` | `() => string` | Resolves the live query driving the filter |
| `filter` | `(items, query) => ComboboxEntry[]` | Replaces the default case-insensitive substring filter |
| `selected` | `(value: string) => boolean` | Drives `aria-selected`, `data-state`, and the check icon |
| `active` | `() => string \| undefined` | Resolves the highlighted value (`data-highlighted`, the `aria-activedescendant` target) |
| `onselect` | `(value: string) => void` | Called on item click with the item value |

Every part also takes a `class` string, landing last in its style composition.

```jsx
import { signal } from '@hellajs/core';
import { Portal } from '@hellajs/dom';
import { ComboboxContent, ComboboxList, ComboboxItem } from './components/combobox';

const Manual = () => {
  const query = signal('');
  const current = signal('');
  let wrapper;

  return (
    <div hook:afterMount={(node) => { wrapper = node; }}>
      <input
        role="combobox"
        value={query}
        on:input={(event) => query(event.target.value)}
      />
      {() => (
        <Portal to="body">
          <ComboboxContent anchor={() => wrapper} onDismiss={() => query('')}>
            <ComboboxList
              items={fruits}
              query={query}
              selected={(value) => current() === value}
              active={current}
              onselect={(value) => { current(value); query(''); }}
            />
          </ComboboxContent>
        </Portal>
      )}
    </div>
  );
};
```

| Attribute | Where | Purpose |
|---|---|---|
| `role="combobox"` / `aria-expanded` / `aria-controls` / `aria-activedescendant` / `aria-autocomplete` | input | Combobox semantics; the active option is referenced by id |
| `role="listbox"` / `data-empty` | list | Options container; zero-match styling hook |
| `role="option"` / `aria-selected` / `data-state` / `data-highlighted` | item | Option semantics, the check indicator, and the active ring |
| `data-disabled` / `aria-disabled` | item | Skipped by roving and typeahead, unclickable |
| `data-chips` | content | Panel width styling in chips mode |
