## API

Give the root an explicit height (and width when needed): the viewport fills it with `size-full`, so an unbounded root has nothing to scroll.

### ScrollArea

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | any | Rendered inside the viewport's content wrapper |
| `observe` | `(target, onGrow) => () => void` | A `ResizeObserver` on the content wrapper |
| `class` | `string` | `-` |

### ScrollBar

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` |
| `observe` | `(target, onGrow) => () => void` | `-` |
| `class` | `string` | `-` |

`observe` is the injectable content watcher for a bar composed standalone.

## Both Axes

`ScrollArea` renders the vertical bar itself. For horizontal scrolling, compose a second `ScrollBar` as a child: it lands inside the viewport in the DOM, but its absolute positioning anchors it to the `relative` root, so it never scrolls with the content. Each bar measures and drags its own axis, and the root renders a corner placeholder at the intersection.

## Thumb Geometry

The bar measures the viewport and itself to place the thumb: thumb length is the `clientSize / scrollSize` ratio of the track with a 20px floor, and the position is the `scrollTop` (or `scrollLeft`) fraction of the remaining travel. Scroll events re-measure, and a `ResizeObserver` on the content wrapper re-measures when content grows or shrinks without a scroll. Dragging the thumb maps the pixel delta through the travel ratio: `scrollTop` moves by `delta / travel * maxScroll`, so a full-length drag crosses the whole content. Drags start from the scroll position at `pointerdown` and clamp to the scrollable range.

## Native Scrolling

The viewport is a real scroller and the custom bar is pure chrome on top; the choice is deliberate and visible in the copied file:

- The viewport scrolls natively (`overflow: scroll`) with the native scrollbar hidden, so momentum, rubber-banding, and keyboard scrolling stay native.
- The bar always renders, even when the content fits (a full-length thumb); the visibility decision when nothing scrolls is left to you.
- The bar's absolute positioning (insets per orientation) rides the style layer.
- The corner is a structural placeholder (`data-slot="scroll-area-corner"`); the thumb tracks may touch at the intersection instead of reserving a gap.

## Accessibility

| Aspect | Value |
|---|---|
| Keyboard scrolling | Stays native: the viewport is a real scroller, so focus plus arrow keys scroll without extra wiring |
| Pointer | The thumb is pointer-only chrome; drags never move keyboard focus |
| Announcements | Live regions are not synthesized; content remains plain DOM read in document order |
