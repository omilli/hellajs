## API

`orientation` picks between `horizontal` (the default: 1px tall, full width) and `vertical` (full height, 1px wide); both attributes key off the rendered `data-orientation` value, so no reactive rewiring is needed when the prop differs per instance.

### Separator

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `class` | `string` | `-` |

A vertical separator needs a bounded-height flex row to stretch into.
