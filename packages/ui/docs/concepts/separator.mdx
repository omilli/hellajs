# Separator

A divider styled byte-faithfully to shadcn's new-york-v4 Separator: one thin line with `orientation` switching between horizontal and vertical, exposed through `role="separator"` and matching `data-orientation` and `aria-orientation` attributes.

## Usage

`orientation` picks between `horizontal` (the default: 1px tall, full width) and `vertical` (full height, 1px wide); both attributes key off the rendered `data-orientation` value, so no reactive rewiring is needed when the prop differs per instance.

```jsx
import Separator from './components/separator';

const Settings = () => (
  <div class="flex flex-col gap-4">
    <h2 class="text-lg font-medium">Profile</h2>
    <p>Your public profile details.</p>
    <Separator />
    <h2 class="text-lg font-medium">Security</h2>
    <p>Sessions and two-factor settings.</p>
  </div>
);
```

## Vertical Orientation

A vertical separator needs a bounded-height flex row to stretch into:

```jsx
import Separator from './components/separator';

const Row = () => (
  <div class="flex h-8 items-center gap-3">
    <span>Import</span>
    <Separator orientation="vertical" />
    <span>Export</span>
  </div>
);
```

## Styling

The style module exports a single `base` carrying both orientation treatments keyed to `[data-orientation]`; the compose bakes `base` plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor uses shadcn's literal utilities verbatim (`bg-border` plus the four `data-[orientation=*]` sizing utilities) wrapped in `cn()`. The line reads the `--border` token, so it follows your theme in light and dark mode without per-instance styling. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
