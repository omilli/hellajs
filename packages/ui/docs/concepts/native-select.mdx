# Native Select

A styled native `select` styled byte-faithfully to shadcn's new-york-v4 NativeSelect: the real element (full keyboard and mobile behavior for free) inside a relative wrapper with an inlined chevron-down icon, plus thin passthroughs for `option` and `optgroup`.

## Usage

Options are authored by the caller as plain native children; the component never models them as props. `value` accepts a plain string or a bare signal and binds as the select's value property, `onchange` receives the extracted `e.target.value` string, and the wrapper dims via `:has(select:disabled)` when the control is disabled:

```jsx
import { signal } from '@hellajs/core';
import NativeSelect from './components/native-select';

const region = signal('eu');

const Picker = () => (
  <NativeSelect value={region} onchange={(v) => region(v)} ariaLabel="Region">
    <option value="eu">EU Central</option>
    <option value="us">US East</option>
    <option value="ap" disabled>AP South (coming soon)</option>
  </NativeSelect>
);
```

The html-format file (`native-select.ts`, copied with `--format html`) renders through a template; children sit between the component tags and events use the direct `e:` prefix:

```js
import { html, mount } from '@hellajs/dom';
import { signal } from '@hellajs/core';
import NativeSelect from './components/native-select';

const region = signal('eu');
mount(
  html`<${NativeSelect} value="${region}" e:change="${(e) => region(e.target.value)}">
    <option value="eu">EU Central</option>
    <option value="us">US East</option>
  </${NativeSelect}>`,
  '#app',
);
```

## Groups

Group options with the optgroup passthrough, which carries the same `bg-[Canvas]` styling:

```jsx
import NativeSelect, { NativeSelectOptGroup, NativeSelectOption } from './components/native-select';

const Grouped = () => (
  <NativeSelect ariaLabel="Plan">
    <NativeSelectOptGroup label="Standard">
      <NativeSelectOption value="basic">Basic</NativeSelectOption>
      <NativeSelectOption value="plus">Plus</NativeSelectOption>
    </NativeSelectOptGroup>
  </NativeSelect>
);
```

## Styling

The style module exports `wrapper`, `base`, `focus`, `invalid`, `icon`, `option`, and `optgroup` maps; the select's compose bakes its classes plus `props.class` (shadcn keeps user classes on the select, so the wrapper takes no merge). The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor carries shadcn's literal utilities verbatim (the `has-[select:disabled]:opacity-50` wrapper condition, `data-[size=sm]:h-8` compaction, and the `dark:hover:bg-input/50` form) wrapped in `cn()`. The icon is positioned against the wrapper's right edge, and the chevron path data is inlined so the entry stays dependency-free; replace the `path` `d` attribute to swap the glyph. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
