## Usage

Options are authored by the caller as plain native children; the component never models them as props. `value` accepts a plain string or a bare signal and binds as the select's value property, `onchange` receives the extracted `e.target.value` string, and the wrapper dims via `:has(select:disabled)` when the control is disabled:

### jsx

```jsx
import { signal } from '@hellajs/core';
import NativeSelect from './components/native-select';

const region = signal('eu');

const Picker = () => (
  <NativeSelect value={region} onchange={(v) => region(v)} ariaLabel="Region">
    <option value="eu">EU Central</option>
    <option value="us">US East</option>
    <option value="ap" disabled>AP South (coming soon)</option>
  </NativeSelect>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<${NativeSelect} value=${region} onchange=${(v) => region(v)} ariaLabel="Region">
  <option value="eu">EU Central</option>
  <option value="us">US East</option>
  <option value="ap" disabled>AP South (coming soon)</option>
</${NativeSelect}>`
```

## Size

`size="sm"` toggles the compact treatment through `data-size="sm"` on the select, trimming the control's height:

```jsx
import NativeSelect from './components/native-select';

const Compact = () => (
  <NativeSelect size="sm" ariaLabel="Compact select">
    <option value="a">Compact option A</option>
    <option value="b">Compact option B</option>
  </NativeSelect>
);
```

## Manual Parts

`NativeSelectOption` and `NativeSelectOptGroup` ship beside the default root as styled passthroughs to their native elements; plain native `option` and `optgroup` children also render as-is.

### NativeSelectOption

A passthrough to a native `option`, carrying the option color treatment.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The option's label node |

### NativeSelectOptGroup

A passthrough to a native `optgroup`, carrying the same color treatment. It forwards only `children` and `class`: a group heading needs a plain native `optgroup` with its `label` attribute.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The grouped options |

Every part also takes a `class` string, landing last in its style composition.

```jsx
import NativeSelect, { NativeSelectOption } from './components/native-select';

const Grouped = () => (
  <NativeSelect ariaLabel="Plan">
    <optgroup label="Standard">
      <NativeSelectOption value="basic">Basic</NativeSelectOption>
      <NativeSelectOption value="plus">Plus</NativeSelectOption>
    </optgroup>
  </NativeSelect>
);
```
