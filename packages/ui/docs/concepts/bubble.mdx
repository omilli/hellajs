# Bubble

Chat message bubbles styled byte-faithfully to shadcn's new-york-v4 Bubble: a group stack, a variant-carrying bubble with asymmetric content corners, the content shell, and floating reaction chips, all presentational with no runtime beyond `cn`-style class composition.

## Usage

`variant` switches the bubble surface: `default` (primary fill), `secondary`, `muted`, `tinted` (primary-tinted in light and dark), `outline`, `ghost` (borderless, padding-free), and `destructive`. `align="end"` floats the bubble to the inline end, and the same shift applies automatically to any bubble inside an end-aligned message row.

```jsx
import { Bubble, BubbleContent, BubbleGroup } from './components/bubble';

const Thread = () => (
  <BubbleGroup>
    <Bubble variant="outline">
      <BubbleContent>How does the scroller pin to the bottom?</BubbleContent>
    </Bubble>
    <Bubble align="end">
      <BubbleContent>A ResizeObserver watches the content and scrolls while you are at the bottom.</BubbleContent>
    </Bubble>
  </BubbleGroup>
);
```

## Reactions

`BubbleReactions` renders a floating chip row positioned against its bubble; you author the chips as children (typically `button` elements, which the `has-[button]` rule unpads):

```jsx
import { Bubble, BubbleContent, BubbleReactions } from './components/bubble';

const Reacted = () => (
  <Bubble variant="muted">
    <BubbleContent>Shipping the demo today.</BubbleContent>
    <BubbleReactions side="bottom" align="end">
      <button>👍 3</button>
      <button>🎉 1</button>
    </BubbleReactions>
  </Bubble>
);
```

`side` pins the chips above (`top`) or below (`bottom`, the default) and `align` picks `start` or `end` (the default).

## Composition Notes

All four exports are presentational. Upstream's `asChild` slot rendering (BubbleContent) is dropped: hella has no Radix Slot, so render the element you want directly and pass its classes through `class`. The bubble's content hover styles key on `:is(button, a)`, so an anchor or button as the content keeps the interactive affordances.

## Styling

The style module exports `base` (group), `bubble` plus `variants` (the seven bubble surfaces), `content`, and `reactions` plus `reactionsSides` and `reactionsAligns`; the bubble's compose bakes `variants[props.variant]` and `props.class` lands last. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor wraps shadcn's literal utilities, child selectors such as `*:data-[slot=bubble-content]:bg-primary` included, in `cn()`. Retune the 80% max width on the `bubble` map to widen the column. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
