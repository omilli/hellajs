## API

`variant` switches the bubble surface: `default` (primary fill), `secondary`, `muted`, `tinted` (primary-tinted in light and dark), `outline`, `ghost` (borderless, padding-free), and `destructive`. `align="end"` floats the bubble to the inline end, and the same shift applies automatically to any bubble inside an end-aligned message row.

All four exports are presentational. `BubbleContent` renders the element or node you hand it as is; there is no slot-rendering indirection, so render the element you want directly and pass its classes through `class`. The bubble's content hover styles key on `:is(button, a)`, so an anchor or button as the content keeps the interactive affordances.

### BubbleGroup

The stack: a `div` carrying `data-slot="bubble-group"` that spaces its bubbles vertically.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The bubbles |
Accepts all native `div` attributes (forwarded to the root element).

### Bubble

The bubble: a `div` carrying `data-variant` and `data-align`; end alignment floats it to the inline end.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive"` | `"default"` |
| `align` | `"start" \| "end"` | `"start"` |
| `children` | `HellaChildren` | The content shell and reaction chips |
Accepts all native `div` attributes (forwarded to the root element).

### BubbleContent

The content shell: a `div` carrying `data-slot="bubble-content"` with the asymmetric corners.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Message text or interactive nodes |
Accepts all native `div` attributes (forwarded to the root element).

### BubbleReactions

The floating chip row positioned against its bubble, carrying `data-side` and `data-align`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "bottom"` | `"bottom"` |
| `align` | `"start" \| "end"` | `"end"` |
| `children` | `HellaChildren` | The chips, typically buttons |
Accepts all native `div` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.
