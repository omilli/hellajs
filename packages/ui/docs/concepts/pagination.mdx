# Pagination

A navigation landmark for paged content styled byte-faithfully to shadcn's new-york-v4 Pagination: a centered `nav` wrapping a list of links, with previous/next controls, an ellipsis overflow marker, and an active-page state rendered through the button visual vocabulary.

## Usage

Compose the parts by hand: `Pagination` is the landmark, `PaginationContent` the list, `PaginationItem` one list entry, and `PaginationLink` an anchor styled like the button's ghost (inactive) or outline (active) variant:

```jsx
import Pagination, { PaginationContent, PaginationEllipsis, PaginationItem, PaginationLink, PaginationNext, PaginationPrevious } from './components/pagination';

const pages = [1, 2, 3, 4, 5];
const current = 2;

const Pages = () => (
  <Pagination>
    <PaginationContent>
      <PaginationItem><PaginationPrevious href={`?page=${Math.max(1, current - 1)}`} /></PaginationItem>
      {pages.map((page) => (
        <PaginationItem key={page}>
          <PaginationLink href={`?page=${page}`} isActive={page === current}>{page}</PaginationLink>
        </PaginationItem>
      ))}
      <PaginationItem><PaginationEllipsis /></PaginationItem>
      <PaginationItem><PaginationNext href={`?page=${Math.min(5, current + 1)}`} /></PaginationItem>
    </PaginationContent>
  </Pagination>
);
```

## Without a Router

`isActive` drives `aria-current="page"`, `data-active`, and the outline treatment. There is no router coupling: `href` is an optional passthrough and `onclick` replaces navigation for signal-driven paging:

```jsx
import { signal } from '@hellajs/core';
import Pagination, { PaginationContent, PaginationItem, PaginationLink } from './components/pagination';

const page = signal(1);
const Pages = () => (
  <Pagination>
    <PaginationContent>
      {[1, 2, 3].map((p) => (
        <PaginationItem key={p}>
          <PaginationLink onclick={() => page(p)} isActive={page() === p}>{p}</PaginationLink>
        </PaginationItem>
      ))}
    </PaginationContent>
  </Pagination>
);
```

## Styling

The css style module exports `base` and `content` (the landmark and list layout), `linkBase`, `linkVariants`, and `linkSizes` (the inline duplication of the button vocabulary, all eight sizes), `previous` and `next` (the edge paddings), `hiddenUntilSm` and `srOnly` (the responsive label and the screen-reader rule the css flavor needs since no utilities exist), and `ellipsis`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor carries shadcn's literal utilities verbatim, including the `size-9` icon-hit-area default on links and the `hidden sm:block` responsive labels on Previous and Next, wrapped in `cn()`. Restrict link sizes to your design by trimming the `linkSizes` map. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
