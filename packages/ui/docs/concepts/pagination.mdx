## API

Compose the parts by hand: `Pagination` is the landmark, `PaginationContent` the list, `PaginationItem` one list entry, and `PaginationLink` an anchor styled like the button's ghost (inactive) or outline (active) variant. The root renders the `role="navigation"` landmark with `aria-label="pagination"`.

Six named parts ship beside the default `Pagination`: `PaginationContent`, `PaginationItem`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, and `PaginationEllipsis`.

### Pagination

The landmark `nav` wrapper.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The list |

Accepts all native `nav` attributes (forwarded to the root element).

### PaginationContent

The list: a `ul` wrapping one `PaginationItem` per entry.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The list items |

Accepts all native `ul` attributes (forwarded to the root element).

### PaginationItem

One list slot: an `li` holding a link, the ellipsis, or a nav control.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The entry's node |

Accepts all native `li` attributes (forwarded to the root element).

### PaginationLink

The page anchor, styled through the button vocabulary: ghost inactive, outline active.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `isActive` | `boolean` | `-` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon"` |
| `children` | `HellaChildren` | The page label |

Accepts all native `a` attributes (forwarded to the root element).

`isActive` renders `aria-current="page"`, `data-active`, and swaps the ghost variant for the outline one. `href` forwards natively with no router coupling; pass `on:click` instead of a URL for signal-driven paging.

### PaginationPrevious

The previous-page anchor: an `aria-label="Go to previous page"` link with the left chevron and a screen-reader-adjacent label hidden below the `sm` breakpoint.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `isActive` | `boolean` | `-` |

Accepts all native `a` attributes (forwarded to the root element).

### PaginationNext

The next-page anchor: an `aria-label="Go to next page"` link with the right chevron and the same responsive label treatment as `PaginationPrevious`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `isActive` | `boolean` | `-` |

Accepts all native `a` attributes (forwarded to the root element).

### PaginationEllipsis

The overflow marker: an `aria-hidden` span with the ellipsis icon and a screen-reader-only "More pages" label.

Accepts all native `span` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.
