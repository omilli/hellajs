## API

Wrap the subtrees that should flip, or the whole application.

### DirectionProvider

The wrapper renders a `dir` attribute on a layout-neutral node, and that attribute is the mechanism every directional behavior reads. Hella has no context primitive, and the dom behavior layer reads `getComputedStyle(anchor).direction` when it needs to flip anchoring and flow for right-to-left locales. The wrapper exists so that read has something to find: the rendered `dir` attribute IS the broadcast, visible to every descendant behavior without any subscription wiring.

The node stays out of layout through `display: contents`, so wrapping children changes nothing about rendering; the div carries no visual styles of its own.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `dir` | `"ltr" \| "rtl"` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The wrapped subtree |
Accepts all native `div` attributes (forwarded to the root element).

## Nesting

Nest providers to flip a subtree against its parent; each wrapper scopes its own `dir` attribute.
