## API

A click-toggled panel: the trigger button opens an anchored, non-modal surface; Escape and an outside press dismiss it; stacked popovers dismiss one layer at a time, top first.

Clicking toggles; the trigger carries `data-state` and `aria-expanded` so styling and assistive tech track the open state. Dismissal runs through [`layerDismissal`](/headless/layerdismissal): Escape and a pointerdown outside the panel ask the top layer to close. The popover is non-modal - no focus trap, and focus moves to the panel on open. Closing keeps the panel mounted under `data-state="closed"` until its exit animation ends, with the dismissal wiring down while it leaves.

The composed `Popover` ships beside three content-vocabulary components: `PopoverHeader`, `PopoverTitle`, and `PopoverDescription` compose inside the root's `content` slot. Each is a thin styled wrapper over the [`popover`](/headless/popover) factory's component set, so the toggle, anchoring, dismissal, and exit timing stay in one place.

### Popover

The composed root portals its `content` prop into `document.body` while open: a `role="dialog"` panel carrying `tabindex="-1"` that focus moves to on open, positioned against the anchor with fixed coordinates, collision flipping, and repositioning on scroll and resize. A user-supplied `anchor` repositions the panel against a different element than the trigger.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `anchor` | `() => Element \| undefined` | The trigger element |
| `content` | `HellaChildren` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `button` attributes (forwarded to the root element; a user `on:click` chains with the owned toggle).

A controlled `open` stops the root from writing its internal signal; `onOpenChange` reports every requested open and close flip.

### PopoverHeader

### PopoverTitle

### PopoverDescription

The supporting line: a `p` carrying `data-slot="popover-description"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `p` attributes (forwarded to the root element).

Every component also takes a `class` string, landing last in its style composition.
