## API

A click-toggled panel: the trigger button opens an anchored, non-modal surface; Escape and an outside press dismiss it; stacked popovers dismiss one layer at a time, top first.

Clicking toggles; the trigger carries `data-state` and `aria-expanded` so styling and assistive tech track the open state. Dismissal runs through [`layerDismissal`](/headless/layerdismissal): Escape and a pointerdown outside the panel ask the top layer to close. The popover is non-modal - no focus trap, and focus moves to the panel on open. Closing keeps the panel mounted under `data-state="closed"` until its exit animation ends, with the dismissal wiring down while it leaves.

Six named components ship beside the default `Popover`: `PopoverTrigger`, `PopoverContent`, `PopoverAnchor`, `PopoverHeader`, `PopoverTitle`, and `PopoverDescription`. Each is a thin styled wrapper over the [`popover`](/headless/popover) factory's component set, so the toggle, anchoring, dismissal, and exit timing stay in one place. State is still explicit on the manual components: hand `PopoverContent` a `state` accessor and an `onDismiss` callback, and point its `anchor` at whatever should anchor it; it portals into `document.body` itself.

### Popover

The composed root portals its `content` prop into `document.body` while open.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `anchor` | `() => Element \| undefined` | The trigger element |
| `content` | `HellaChildren` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `button` attributes (forwarded to the root element; a user `on:click` chains with the owned toggle).

A controlled `open` stops the root from writing its internal signal; `onOpenChange` reports every requested open and close flip.

### PopoverTrigger

| Prop | Type | Default |

| `children` | `HellaChildren` | `-` |

### PopoverContent

The `role="dialog"` panel carrying `tabindex="-1"` for the focus-on-open contract. It portals into `document.body` on open and is wired by the [`popover`](/headless/popover) factory: positioned against the anchor (fixed coordinates, collision flipping, repositioning on scroll and resize) and dismissed through the same layered dismissal the composed `Popover` uses (Escape and outside pointerdown close only the top layer, so popovers stack cleanly). Composing it without `onDismiss` holds the panel open by never installing that wiring.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `id` | `string` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `sideOffset` | `number` | `4` |
| `alignOffset` | `number` | `0` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onDismiss` | `() => void` | `-` |
| `onExited` | `() => void` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element; a user-supplied `id` wins over the generated one).
