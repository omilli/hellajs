## API

Compose the parts by hand; there is no context object and no schema prop. `Table` renders the overflow container (`data-slot="table-container"`) around the `table` element and takes the user's `class` on the table itself. The parts carry the structural selectors: header rows get bottom borders, the last body row drops its border, and footer rows keep theirs unless last.

Seven semantic parts wrap the native table elements; each renders its `data-slot` and takes `children`, `class`, and the native attributes of its element, forwarded to the rendered element.

### Table

The overflow container and `table` root.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The caption, row groups, and rows |
Accepts all native `table` attributes (forwarded to the root element).

### TableHeader

The `thead[data-slot="table-header"]` row group.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The head rows |
Accepts all native `thead` attributes (forwarded to the root element).

### TableBody

The `tbody[data-slot="table-body"]` row group.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The body rows |
Accepts all native `tbody` attributes (forwarded to the root element).

### TableFooter

The `tfoot[data-slot="table-footer"]` row group.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The footer rows |
Accepts all native `tfoot` attributes (forwarded to the root element).

### TableRow

The `tr[data-slot="table-row"]` row.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The cells |
Accepts all native `tr` attributes (forwarded to the root element).

### TableHead

The `th[data-slot="table-head"]` header cell.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The label content |
Accepts all native `th` attributes (forwarded to the root element).

### TableCell

The `td[data-slot="table-cell"]` body cell.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The cell content |
Accepts all native `td` attributes (forwarded to the root element).

`colspan` rides the native pass-through for merged cells.

### TableCaption

The `caption[data-slot="table-caption"]` element.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The caption text |
Accepts all native `caption` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.
