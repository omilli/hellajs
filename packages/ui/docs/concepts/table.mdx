# Table

Native table elements styled byte-faithfully to shadcn's new-york-v4 Table: seven semantic parts (`thead`, `tbody`, `tfoot`, `tr`, `th`, `td`, `caption`) wrapped in an overflow container so wide tables scroll horizontally instead of breaking the page.

## Usage

Compose the parts by hand; there is no context object and no schema prop. `Table` renders the overflow container (`data-slot="table-container"`) around the `table` element and takes the user's `class` on the table itself. The parts carry shadcn's structural selectors: header rows get bottom borders, the last body row drops its border, and footer rows keep theirs unless last:

```jsx
import Table, { TableBody, TableCaption, TableCell, TableHead, TableHeader, TableRow } from './components/table';

const rows = [
  { invoice: 'INV001', status: 'Paid', amount: '$250.00' },
  { invoice: 'INV002', status: 'Pending', amount: '$125.00' },
];

const Invoices = () => (
  <Table>
    <TableCaption>A list of your recent invoices.</TableCaption>
    <TableHeader>
      <TableRow>
        <TableHead>Invoice</TableHead>
        <TableHead>Status</TableHead>
        <TableHead>Amount</TableHead>
      </TableRow>
    </TableHeader>
    <TableBody>
      {rows.map((row) => (
        <TableRow key={row.invoice}>
          <TableCell>{row.invoice}</TableCell>
          <TableCell>{row.status}</TableCell>
          <TableCell>{row.amount}</TableCell>
        </TableRow>
      ))}
    </TableBody>
  </Table>
);
```

## Merged Cells

`TableHead` and `TableCell` pass `colSpan` through for merged cells, so a summary row can span its neighbors:

```jsx
import { TableBody, TableCell, TableHead, TableRow } from './components/table';

const Summary = () => (
  <TableBody>
    <TableRow>
      <TableHead colSpan={2}>Total</TableHead>
      <TableCell>$375.00</TableCell>
    </TableRow>
  </TableBody>
);
```

## Styling

The style module exports `container`, `base`, `header`, `body`, `footer`, `row`, `head`, `cell`, and `caption` maps; each part's compose bakes its own class plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the row map carries `:hover`, `:has([aria-expanded='true'])`, and `[data-state='selected']` keys, so the hover tint is automatic and attribute-level state like `data-state` is yours to set on the rendered elements (the parts pass through only `children`, `class`, plus `colSpan`). The tailwind flavor carries shadcn's literal utilities verbatim (including the `[&_tr]:border-b` and `[&:has([role=checkbox])]:pr-0` structural selectors) wrapped in `cn()`. Part props are deliberately `children`, `class`, plus `colSpan` where the element supports it; anything else stays native attributes you set directly. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
