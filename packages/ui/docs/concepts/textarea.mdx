## Usage

The root carries `data-slot="textarea"`, and `value` accepts a plain string or a bare signal, binding as the element's value property so a controlled textarea reads and writes like Input. Typed input flows back through `oninput`, which receives the extracted `e.target.value` string rather than the event. Auto-sizing comes from `field-sizing: content` with a `min-height` floor; cap growth with a `max-h` class override.

### jsx

```jsx
import { signal } from '@hellajs/core';
import Textarea from './components/textarea';

const bio = signal('');

const Profile = () => (
  <Textarea value={bio} oninput={(v) => bio(v)} placeholder="Tell us about yourself" rows={4} />
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<${Textarea}
  value=${bio}
  oninput=${(v) => bio(v)}
  placeholder="Tell us about yourself"
  rows=${4}
/>`
```

## Invalid State

The invalid ring follows the Input lexicon: `aria-invalid` recolors the border and, once focused, the ring. Pass `ariaInvalid` and the treatment applies with no extra wiring:

```jsx
import Textarea from './components/textarea';

const Review = () => (
  <Textarea placeholder="Required field" ariaInvalid />
);
```
