# Empty

An empty-state surface styled byte-faithfully to shadcn's new-york-v4 Empty: a default `Empty` plus named `EmptyHeader`, `EmptyMedia`, `EmptyTitle`, `EmptyDescription`, and `EmptyContent` parts, each carrying its `data-slot` and composable in any arrangement.

## Usage

Every part takes `{ children?, class? }`, and `EmptyMedia` adds a `variant` prop: `default` is a bare wrapper, while `icon` renders the rounded muted 2.5rem icon tile. The css flavor composes classes as plain arrays in each part's `class` attribute, declared in [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins over the component's own rules.

```jsx
import Empty, { EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from './components/empty';

const NoResults = () => (
  <Empty>
    <EmptyHeader>
      <EmptyMedia variant="icon">
        <svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><circle cx="11" cy="11" r="8" /><path d="m21 21-4.3-4.3" /></svg>
      </EmptyMedia>
      <EmptyTitle>No results found</EmptyTitle>
      <EmptyDescription>Try a different keyword or clear your filters.</EmptyDescription>
    </EmptyHeader>
    <EmptyContent>
      <p>Queries match against file names and contents.</p>
    </EmptyContent>
  </Empty>
);
```

The html-format file (`empty.ts`, copied with `--format html`) renders through a template instead of JSX; each part is a plain function call:

```js
import { html, mount } from '@hellajs/dom';
import Empty, { EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from './components/empty';

mount(
  html`
    <${Empty}>
      ${EmptyHeader({
        children: [
          EmptyMedia({ variant: 'icon' }),
          EmptyTitle({ children: 'No results found' }),
          EmptyDescription({ children: 'Try a different keyword or clear your filters.' }),
        ],
      })}
    </${Empty}>
  `,
  '#app',
);
```

## Media Variants

The media variant stays plain for illustrations or avatars; the icon tile styling only applies when you ask for it:

```jsx
import Empty, { EmptyContent, EmptyHeader, EmptyMedia, EmptyTitle } from './components/empty';

const NoAccess = () => (
  <Empty>
    <EmptyHeader>
      <EmptyMedia>
        <img src="/illustrations/lock.svg" alt="" />
      </EmptyMedia>
      <EmptyTitle>Access restricted</EmptyTitle>
    </EmptyHeader>
    <EmptyContent>Ask an admin for permission.</EmptyContent>
  </Empty>
);
```

## Styling

The style module exports one class per part (`base`, `header`, `media`, `title`, `description`, `content`) plus `mediaVariants` (the `default`/`icon` pair); each part's compose bakes its own class plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor wraps shadcn's literal utilities (`border-dashed`, `bg-muted`) in `cn()` so later tokens override earlier ones per utility group. Every part renders its `data-slot` (`empty`, `empty-header`, `empty-icon`, `empty-title`, `empty-description`, `empty-content`), so one-off overrides can also target parts through the `[data-slot]` attribute selectors; the root's dashed border comes up at the `md` breakpoint's larger padding automatically, and the surface itself stays transparent until you give it a border or background. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
