## API

Every part takes `{ children?, class? }`, and `EmptyMedia` adds a `variant` prop: `default` is a bare wrapper, while `icon` renders the rounded muted 2.5rem icon tile.

### Empty

The empty-state root: a `div` carrying `data-slot="empty"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The arranged parts |

### EmptyHeader

The stacked top: a `div` carrying `data-slot="empty-header"`, centering its media, title, and description column.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Media, title, and description nodes |

### EmptyMedia

The media slot: a `div` carrying `data-slot="empty-icon"`, styled by its `variant`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "icon"` | `"default"` |
| `children` | `HellaChildren` | An svg, illustration, or avatar |

### EmptyTitle

The heading: a `div` carrying `data-slot="empty-title"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The title node |

### EmptyDescription

The supporting line: a `div` carrying `data-slot="empty-description"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The description node |

### EmptyContent

The body: a `div` carrying `data-slot="empty-content"` below the header.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The body nodes |

Every part also takes a `class` string, landing last in its style composition.
