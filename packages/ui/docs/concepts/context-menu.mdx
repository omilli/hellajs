## API

The composed `ContextMenu` wraps its children in a trigger zone and takes the items through the `content` prop. A `contextmenu` event (right-click, or the long-press equivalent) preventDefaults the browser menu and opens the surface; Escape and an outside press dismiss it.

Thirteen named parts ship beside the default `ContextMenu`: `ContextMenuTrigger`, `ContextMenuContent`, `ContextMenuGroup`, `ContextMenuItem`, `ContextMenuCheckboxItem`, `ContextMenuRadioGroup`, `ContextMenuRadioItem`, `ContextMenuLabel`, `ContextMenuSeparator`, `ContextMenuShortcut`, `ContextMenuSub`, `ContextMenuSubTrigger`, and `ContextMenuSubContent`. The content model is the dropdown menu's, duplicated per the registry's self-contained rule; only the trigger differs (a passive zone owning the `contextmenu` listener instead of a Button-wrapped toggle).

### ContextMenu

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `content` | `HellaChildren` | The menu items, portaled into `document.body` while open |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The trigger zone content |

A controlled `open` stops the root from writing its internal signal; `onOpenChange` reports every requested open and close flip.

### ContextMenuTrigger

The manual trigger zone: a passive `span` owning the `contextmenu` listener.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The zone content |

### ContextMenuContent

The `role="menu"` surface with the full keyboard model, anchored at the pointer coordinates.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `id` | `string` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onDismiss` | `() => void` | `-` |
| `onExited` | `() => void` | `-` |
| `onArrowLeft` | `() => void` | `-` |
| `children` | `HellaChildren` | The menu items |

`state` drives `data-state` and the enter/exit cycle; `closed` tears the wirings down. The anchor resolves to the planted pointer anchor; positioning is skipped when undefined. `onDismiss` receives Escape and outside pointerdowns from the top layer, and item selection closes every open layer through it. `onExited` fires when the exit animation ends; `onArrowLeft` closes the menu when provided (submenu exit; a top-level menu stays inert).

### ContextMenuGroup

A passthrough grouping `div`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The grouped items |

### ContextMenuItem

A `role="menuitem"` row; activation closes every open layer.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `onclick` | `() => void` | `-` |
| `destructive` | `boolean` | `-` |
| `inset` | `boolean` | `-` |
| `disabled` | `boolean` | `-` |
| `shortcut` | `string` | `-` |
| `children` | `HellaChildren` | The row's label |

`onclick` fires before the close-all activation event; `destructive` renders the destructive `data-variant` treatment; `inset` renders `data-inset="true"` for the indented alignment; `disabled` renders `data-disabled` plus `aria-disabled` and blocks `onclick` and the close; `shortcut` renders as a trailing `ContextMenuShortcut` span.

### ContextMenuCheckboxItem

A `role="menuitemcheckbox"` row with the check indicator.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `checked` | `boolean \| (() => boolean)` | `-` |
| `onCheckedChange` | `(checked: boolean) => void` | `-` |
| `disabled` | `boolean` | `-` |
| `children` | `HellaChildren` | The row's label |

A boolean `checked` seeds the internal signal; an accessor makes the item controlled - activation then only reports through `onCheckedChange`, which fires on every requested flip before every open layer closes.

### ContextMenuRadioGroup

A group rendering one radio item per entry.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `{ value, label?, disabled? }[]` | `-` |
| `value` | `() => string` | `-` |
| `onValueChange` | `(value: string) => void` | `-` |
| `children` | `HellaChildren` | Static group content rendered alongside the items |

A controlled `value` stops the group from writing its internal signal; `onValueChange` reports the requested selection.

### ContextMenuRadioItem

A `role="menuitemradio"` row with the circle indicator.

| Prop | Type | Default |
| ---- | ---- | ------- |

| `children` | `HellaChildren` | The row's label |

`checked` reads statically as a boolean; an accessor keeps the row reactive against its owning group. `onSelect` is called on click when the row is enabled.

### ContextMenuSub

A sub-trigger plus its portaled sub-content; open state owned here. The sub opens on hover after roughly 100ms of rest, on click, or on ArrowRight, anchors against its trigger, and hands Escape to its own dismissal layer first.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `content` | `HellaChildren` | The sub-surface items |
| `children` | `HellaChildren` | The sub-trigger label |

### ContextMenuSubTrigger

The manual sub-trigger row (chevron, `aria-haspopup`).

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `onOpen` | `() => void` | `-` |
| `inset` | `boolean` | `-` |
| `children` | `HellaChildren` | The sub-trigger label |

`state` drives `aria-expanded` and `data-state`; the composed `ContextMenuSub` wires it. `onOpen` is called on click and hover intent.

### ContextMenuSubContent

The `role="menu"` sub-surface, anchored against its sub-trigger.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `-` |
| `align` | `"start" \| "center" \| "end"` | `-` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onDismiss` | `() => void` | `-` |
| `onExited` | `() => void` | `-` |
| `onArrowLeft` | `() => void` | `-` |
| `onPointerEnter` | `() => void` | `-` |
| `children` | `HellaChildren` | The sub-surface items |

`onDismiss` closes the sub's own layer; `onExited` fires when the exit animation ends; `onArrowLeft` closes the submenu; `onPointerEnter` cancels the trigger's pending close when the pointer enters the content.

Every part also takes a `class` string, landing last in its style composition.

## Dismissal and Positioning

Coordinate anchoring: opening plants a zero-size fixed anchor node at the pointer position (`data-slot="context-menu-anchor"` in the document body) and positions the surface against it through [`anchorPosition`](/reference/dom/anchorposition) on the `bottom-start` placement, so the menu's top-left corner sits at the click point with the same collision flipping and scroll or resize repositioning as every anchored overlay. Reopening moves the anchor; closing removes it and restores focus to the trigger zone.

Dismissal runs through [`layerDismissal`](/reference/dom/layerdismissal): Escape and a pointerdown outside the panel ask the top layer to close, so stacked menus dismiss one layer at a time. Activating an item closes every open menu layer through a document-level activation event, which is also how Enter and Space close from the keyboard. Focus moves to the first activatable item on open; the menu is non-modal, with no focus trap.

## Keyboard Interaction

| Key | Behavior |
|---|---|
| `ArrowDown` / `ArrowUp` | Roves items with wrap, skipping disabled entries |
| `Home` / `End` | Jumps to the first or last activatable item |
| `Enter` / `Space` | Activates the focused item (toggles checkbox and radio rows) |
| `ArrowRight` / `ArrowLeft` | Enters a focused sub-trigger or exits the sub; flips with the resolved writing direction |
| `Escape` | Dismisses the top layer only |
| `Tab` | Closes every open layer |
| printable keys | Typeahead: selects the first item starting with the buffered keys |

The menu opens from the pointer, so there is no trigger-key open path: keyboard users reach a context menu through the surrounding app (for example a button that opens a controlled `ContextMenu` via its `open` accessor).
