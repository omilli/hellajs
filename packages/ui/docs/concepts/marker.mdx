## API

`Marker` renders the strip, `MarkerIcon` an optional leading icon box, and `MarkerContent` the label. Anchors inside a marker inherit the underline and hover-to-foreground treatment from its selectors.

### Marker

The labeled divider strip: carries `data-variant` for the treatment selectors.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | Icon and content nodes |

`default` renders the bare strip, `separator` adds flex-filling rules before and after the content, and `border` adds a bottom border.

### MarkerIcon

The leading icon box: an `aria-hidden` span, sized by the style layer.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Icon node or glyph |

### MarkerContent

The label: a `span` centered by the separator variant's selectors.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The label text |

Every part also takes a `class` string, landing last in its style composition.
