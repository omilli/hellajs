# Marker

A labeled divider row styled byte-faithfully to shadcn's new-york-v4 Marker: a full-width strip that presents a short label, with optional rule pseudo-elements or a bottom border, built for timeline captions, empty-state annotations, and section leads.

## Usage

`Marker` renders the strip, `MarkerIcon` an optional leading icon box, and `MarkerContent` the label:

```jsx
import Marker, { MarkerContent, MarkerIcon } from './components/marker';

const Caption = () => (
  <Marker>
    <MarkerIcon>X</MarkerIcon>
    <MarkerContent>Migrated 12 entries</MarkerContent>
  </Marker>
);
```

## Variants

`variant` picks the treatment: `default` renders the bare strip, `separator` adds flex-filling rules before and after the content, and `border` adds a bottom border. Anchors inside a marker inherit the underline and hover-to-foreground treatment from its selectors:

```jsx
import Marker, { MarkerContent } from './components/marker';

const Ruled = () => (
  <Marker variant="separator">
    <MarkerContent>Chapter 4</MarkerContent>
  </Marker>
);
```

## Styling

The css style module exports `base` (the strip layout and link treatment), `variants` (the separator pseudo-element rules and the border treatment; the map carries no `default` key, mirroring the classless ref variant), `icon`, and `content` plus the raw marker-variant selector that centers content between the rules. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor carries shadcn's literal utilities verbatim, including the `before:`/`after:` rule pseudo-element utilities and the `wrap-break-word` label treatment, wrapped in `cn()`. Restyle the rules by editing the `&::before` and `&::after` keys inside the separator variant map. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
