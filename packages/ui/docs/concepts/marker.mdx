# Marker

A labeled divider row styled byte-faithfully to shadcn's new-york-v4 Marker: a full-width strip that presents a short label, with optional rule pseudo-elements or a bottom border, built for timeline captions, empty-state annotations, and section leads.

## Install

```bash
bunx @hellajs/ui add marker
```

`--style css|tailwind` picks the flavor (css is the default) and `--format jsx|html` picks the canonical file; both are remembered in `hella.ui.json` once `bunx @hellajs/ui init` has run. The component copies as one editable file into `src/components/`; there is no importable package surface.

Every project adds its theme entry once, then every component reads the same properties:

```bash
bunx @hellajs/ui add theme
```

| Style | Extra peers | Theme artifact |
|---|---|---|
| css (default) | `@hellajs/css` | `tokens.js`, a [`vars`](/reference/css/vars) sheet collected by `cssText()` for SSR |
| tailwind | `clsx`, `tailwind-merge` | `theme.css` plus `cn.ts` |

## CSS Style

The css flavor composes classes as a plain array in the `class` attribute; declarations live in [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins over the component's own rules. `Marker` renders the strip, `MarkerIcon` an optional leading icon box, and `MarkerContent` the label.

```jsx
import Marker, { MarkerContent, MarkerIcon } from './components/marker';

const Caption = () => (
  <Marker>
    <MarkerIcon>X</MarkerIcon>
    <MarkerContent>Migrated 12 entries</MarkerContent>
  </Marker>
);
```

`variant` picks the treatment: `default` renders the bare strip, `separator` adds flex-filling rules before and after the content, and `border` adds a bottom border. Anchors inside a marker inherit the underline and hover-to-foreground treatment from its selectors.

```jsx
import Marker, { MarkerContent } from './components/marker';

const Ruled = () => (
  <Marker variant="separator">
    <MarkerContent>Chapter 4</MarkerContent>
  </Marker>
);
```

The html-format file (`marker.ts`, copied with `--format html`) renders through a template; children sit between the part tags exactly like the jsx form:

```js
import { html, mount } from '@hellajs/dom';
import Marker, { MarkerContent } from './components/marker';

mount(
  html`<${Marker} variant="border">
    <${MarkerContent}>End of list</${MarkerContent}>
  </${Marker}>`,
  '#app',
);
```

## Tailwind Style

The tailwind flavor never touches `@hellajs/css`: the copied strings carry shadcn's literal utilities verbatim, including the `before:`/`after:` rule pseudo-element utilities and the `wrap-break-word` label treatment, and the class arrays wrap in `cn()`.

```jsx
import Marker, { MarkerContent } from './components/marker';

const Plain = () => (
  <Marker class="text-xs">
    <MarkerContent>Updated today</MarkerContent>
  </Marker>
);
```

## Customizing

The copied file is yours. The css style module exports `base` (the strip layout and link treatment), `variants` (the separator pseudo-element rules and the border treatment; the default variant carries no declarations, mirroring the ref), `icon`, and `content` plus the raw marker-variant selector that centers content between the rules. Restyle the rules by editing the `&::before` and `&::after` keys inside the separator variant map.
