# Item

A flexible list-row composition kit styled byte-faithfully to shadcn's new-york-v4 Item: ten parts covering the group, separator, row, media slot, content stack, title, description, actions, header, and footer, built for settings lists, result rows, and media objects.

## Usage

Compose the parts by hand; there is no context object and no schema prop:

```jsx
import Item, { ItemActions, ItemContent, ItemDescription, ItemGroup, ItemMedia, ItemSeparator, ItemTitle } from './components/item';
import Button from './components/button';

const Results = () => (
  <ItemGroup>
    <Item>
      <ItemMedia variant="icon">A</ItemMedia>
      <ItemContent>
        <ItemTitle>Archive</ItemTitle>
        <ItemDescription>Move the report to long-term storage.</ItemDescription>
      </ItemContent>
      <ItemActions>
        <Button size="sm" variant="outline">Run</Button>
      </ItemActions>
    </Item>
    <ItemSeparator />
  </ItemGroup>
);
```

## Variants and Sizes

`variant` picks the row treatment (`default` transparent, `outline` bordered, `muted` tinted) and `size` its padding (`default` or `sm`). `ItemMedia` takes `icon` or `image` variants for its own sizing box:

```jsx
import Item, { ItemContent, ItemTitle } from './components/item';

const Muted = () => (
  <Item variant="muted" size="sm">
    <ItemContent><ItemTitle>Compact row</ItemTitle></ItemContent>
  </Item>
);
```

## Selection

`selected` marks the row interactively: pass a boolean or a reactive function and the row renders `data-selected` plus `aria-selected`, updating as the signal changes. Rows carry no click wiring of their own; delegate the click on a wrapping element, find the row through its `data-slot`, and flip the signal:

```jsx
import { signal } from '@hellajs/core';
import Item, { ItemContent, ItemGroup, ItemTitle } from './components/item';

const active = signal(0);

const Picker = () => (
  <div on:click={(e) => {
    const row = e.target.closest('[data-slot="item"]');
    if (row) active([...row.parentElement.children].indexOf(row));
  }}>
    <ItemGroup>
      {['Alpha', 'Beta'].map((label, i) => (
        <Item key={label} selected={() => active() === i}>
          <ItemContent><ItemTitle>{label}</ItemTitle></ItemContent>
        </Item>
      ))}
    </ItemGroup>
  </div>
);
```

## Composition Notes

`ItemHeader` and `ItemFooter` render full-width (`basis-full`) rows that break out of the flex-wrap flow, matching the ref's layout for titled sections. The row is self-contained: the separator markup is re-stated inline rather than imported, and anchors inside an item pick up the underline and hover rules from the row's own selectors.

## Styling

The css style module exports `group`, `separatorBase` plus `separator`, `base`, `variants` and `sizes` (the row treatments), `media` plus `mediaVariants`, `content`, `title`, `description`, `actions`, `header`, and `footer`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor carries shadcn's literal utilities verbatim, including the media's `group-has-[[data-slot=item-description]]/item:self-start` shift and the link hover treatment `[a]:hover:bg-accent/50` inherited from the ref, wrapped in `cn()`. The description clamps to two lines through the `-webkit-line-clamp` keys; raise the clamp there if your copy needs more room. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
