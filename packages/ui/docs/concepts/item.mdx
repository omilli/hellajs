## API

Compose the parts by hand; there is no context object and no schema prop. Anchors inside a row pick up its underline and hover treatment from the row's own selectors.

### Item

The list row: carries `data-variant`, `data-size`, and the selection attributes the styles key off.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size` | `"default" \| "sm"` | `"default"` |
| `selected` | `boolean \| (() => boolean)` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | Media, content, and action nodes |

`selected` marks the row interactively: pass a boolean or a reactive function and the row renders `data-selected` plus `aria-selected`, updating as the signal changes. Rows carry no click wiring of their own; delegate the click on a wrapping element, find the row through its `data-slot`, and flip the signal.

### ItemGroup

The list container: a `role="list"` wrapper for related rows.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Rows and separators |

### ItemSeparator

The rule between rows: a `role="separator"` div. Takes an optional `class`.

### ItemMedia

The leading sizing box before the content stack; `variant="icon"` or `"image"` picks its sizing.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |
| `children` | `HellaChildren` | Icon or image node |

### ItemContent

The title and description stack.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Title and description nodes |

### ItemTitle

The row heading: a `div` carrying `data-slot="item-title"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The title node |

### ItemDescription

The supporting line: a `p` clamped to two lines.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The description node |

### ItemActions

The trailing action slot.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Action nodes, typically buttons |

### ItemHeader

A full-width row that breaks out of the flex-wrap flow, for titled sections.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Header nodes |

### ItemFooter

A full-width row that breaks out of the flex-wrap flow, for footer content.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Footer nodes |

Every part also takes a `class` string, landing last in its style composition.
