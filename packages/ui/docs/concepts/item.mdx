## Usage

Compose the parts by hand; there is no context object and no schema prop:

### jsx

```jsx
import Item, { ItemActions, ItemContent, ItemDescription, ItemGroup, ItemMedia, ItemSeparator, ItemTitle } from './components/item';
import Button from './components/button';

const Results = () => (
  <ItemGroup>
    <Item>
      <ItemMedia variant="icon">A</ItemMedia>
      <ItemContent>
        <ItemTitle>Archive</ItemTitle>
        <ItemDescription>Move the report to long-term storage.</ItemDescription>
      </ItemContent>
      <ItemActions>
        <Button size="sm" variant="outline">Run</Button>
      </ItemActions>
    </Item>
    <ItemSeparator />
  </ItemGroup>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${ItemGroup}>
    <${Item}>
      <${ItemMedia} variant="icon">A</${ItemMedia}>
      <${ItemContent}>
        <${ItemTitle}>Archive</${ItemTitle}>
        <${ItemDescription}>Move the report to long-term storage.</${ItemDescription}>
      </${ItemContent}>
      <${ItemActions}><${Button} size="sm" variant="outline">Run</${Button}></${ItemActions}>
    </${Item}>
    <${ItemSeparator} />
  </${ItemGroup}>
</main>`
```

## Variants and Sizes

`variant` picks the row treatment (`default` transparent, `outline` bordered, `muted` tinted) and `size` its padding (`default` or `sm`):

```jsx
import Item, { ItemContent, ItemTitle } from './components/item';

const Muted = () => (
  <Item variant="muted" size="sm">
    <ItemContent><ItemTitle>Compact row</ItemTitle></ItemContent>
  </Item>
);
```

## Selection

`selected` marks the row interactively: pass a boolean or a reactive function and the row renders `data-selected` plus `aria-selected`, updating as the signal changes. Rows carry no click wiring of their own; delegate the click on a wrapping element, find the row through its `data-slot`, and flip the signal:

```jsx
import { signal } from '@hellajs/core';
import Item, { ItemContent, ItemGroup, ItemTitle } from './components/item';

const active = signal(0);

const Picker = () => (
  <div on:click={(e) => {
    const row = e.target.closest('[data-slot="item"]');
    if (row) active([...row.parentElement.children].indexOf(row));
  }}>
    <ItemGroup>
      {['Alpha', 'Beta'].map((label, i) => (
        <Item key={label} selected={() => active() === i}>
          <ItemContent><ItemTitle>{label}</ItemTitle></ItemContent>
        </Item>
      ))}
    </ItemGroup>
  </div>
);
```

## Manual Parts

`ItemGroup`, `ItemSeparator`, `ItemMedia`, `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemActions`, `ItemHeader`, and `ItemFooter` ship beside the default `Item` row for custom composition.

### Item

The list row: carries `data-variant`, `data-size`, and the selection attributes the styles key off.

| Prop | Type | Behavior |
|---|---|---|
| `variant` | `"default" \| "outline" \| "muted"` | Row treatment (default `"default"`) |
| `size` | `"default" \| "sm"` | Row padding (default `"default"`) |
| `selected` | `boolean \| (() => boolean)` | Renders `data-selected` and `aria-selected`; an accessor keeps it reactive |
| `children` | `HellaChildren` | Media, content, and action nodes |

### ItemGroup

The list container: a `role="list"` wrapper for related rows.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Rows and separators |

### ItemSeparator

The rule between rows: a `role="separator"` div. Takes an optional `class`.

### ItemMedia

The leading sizing box before the content stack; `variant="icon"` or `"image"` picks its sizing.

| Prop | Type | Behavior |
|---|---|---|
| `variant` | `"default" \| "icon" \| "image"` | Media sizing (default `"default"`) |
| `children` | `HellaChildren` | Icon or image node |

### ItemContent

The title and description stack.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Title and description nodes |

### ItemTitle

The row heading: a `div` carrying `data-slot="item-title"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Title node |

### ItemDescription

The supporting line: a `p` clamped to two lines.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Description node |

### ItemActions

The trailing action slot.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Action nodes, typically buttons |

### ItemHeader

A full-width row that breaks out of the flex-wrap flow, for titled sections.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Header nodes |

### ItemFooter

A full-width row that breaks out of the flex-wrap flow, for footer content.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Footer nodes |

Every part also takes a `class` string, landing last in its style composition. Anchors inside a row pick up its underline and hover treatment from the row's own selectors.
