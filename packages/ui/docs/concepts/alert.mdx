## API

A callout carrying `role="alert"`: a direct `svg` child before the title occupies the reserved icon column, inheriting the current text color.

### Alert

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The callout parts |
Accepts all native `div` attributes (forwarded to the root element).

### AlertTitle

The bold heading: a `div` carrying `data-slot="alert-title"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The title node |
Accepts all native `div` attributes (forwarded to the root element).

### AlertDescription

The supporting line: a `div` carrying `data-slot="alert-description"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The description nodes, plain paragraphs included |
Accepts all native `div` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.
