## Usage

The composed root takes an items array, not children slots; items render joined into one segment strip (`data-spacing="0"`, `--gap: 0`):

| Prop | Type | Behavior |
|---|---|---|
| `items` | `{ value, label?, pressed?, disabled? }[]` | One item button per entry; `pressed` seeds the uncontrolled state |
| `type` | `"single" \| "multiple"` | Single keeps one active value; multiple keeps a set |
| `value` | `() => string` | Controlled single selection |
| `values` | `() => string[]` | Controlled multiple selection |
| `onValueChange` | `(value: string \| string[]) => void` | Single reports the newly active value (`""` when deselected); multiple reports the full active array |
| `variant` | `"default" \| "outline"` | Visual variant (`default`) |
| `size` | `"default" \| "sm" \| "lg"` | Control size (`default`) |
| `class` | `string` | Lands on the root next to the component class |

The `data-[spacing=...]` classes ride along in both style modules, so relaxing the joined strip into spaced buttons is an edit of the copied file away.

### jsx

```jsx
import ToggleGroup from './components/toggle-group';

const Formats = () => (
  <ToggleGroup
    type="multiple"
    items={[
      { value: 'bold', label: 'B' },
      { value: 'italic', label: 'I', pressed: true },
      { value: 'underline', label: 'U' },
    ]}
  />
);
```
### html

The html-format (`--format html`) works the same way; build the items array once and pass it in.

```js
const items = [
  { value: 'day', label: 'Day' },
  { value: 'week', label: 'Week' },
];

html`<main><${ToggleGroup} type="single" items=${items} /></main>`
```

## Controlled and Uncontrolled

Without `value` / `values`, the root owns its state seeded by the items' `pressed` flags. In single mode, clicking the active item deselects it and reports `""`; in multiple mode, clicking toggles membership and reports the full array. Pass an accessor (`value` for single, `values` for multiple) and the group becomes controlled: clicks turn into `onValueChange` requests without writing state, so a parent signal that ignores the request keeps the selection unchanged.

```jsx
import { signal } from '@hellajs/core';
import ToggleGroup from './components/toggle-group';

const view = signal('week');

const Controlled = () => (
  <ToggleGroup
    type="single"
    items={[
      { value: 'day', label: 'Day' },
      { value: 'week', label: 'Week' },
    ]}
    value={view}
    onValueChange={(next) => view(next)}
  />
);
```

## Manual Parts

`ToggleGroupItem` ships beside the default root for custom composition; it renders the joined-segment classes and the `data-variant` / `data-size` / `data-spacing` attributes the styles key off.

### ToggleGroupItem

One pressed-state button inside the group.

| Prop | Type | Behavior |
|---|---|---|
| `value` | `string` | The item's value in the group |
| `pressed` | `boolean \| (() => boolean)` | Pressed state: a boolean reads statically, an accessor keeps the manual part reactive; drives `aria-pressed` and `data-state` (`on` / `off`) |
| `onSelect` | `() => void` | Click callback |
| `variant` | `"default" \| "outline"` | Visual variant (default `"default"`) |
| `size` | `"default" \| "sm" \| "lg"` | Control size (default `"default"`) |
| `disabled` | `boolean` | Native `disabled` attribute |
| `children` | `HellaChildren` | The item's label |

Every part also takes a `class` string, landing last in its style composition.

```jsx
import { signal } from '@hellajs/core';
import { ToggleGroupItem } from './components/toggle-group';

const active = signal(false);

const Custom = () => (
  <ToggleGroupItem
    value="custom"
    pressed={active}
    onSelect={() => active(!active())}
    variant="outline"
  >
    Custom
  </ToggleGroupItem>
);
```

## Accessibility

| Aspect | Value |
|---|---|
| Roles | `group` on the root; each item is a toggle button carrying `aria-pressed` in both modes |
| State | `aria-pressed` plus `data-state` (`on` / `off`) per item |
| Keyboard | Arrow keys move focus (wrapping at both ends); Space and Enter toggle through native button activation; disabled items are skipped |
| Tab | Roving tabindex: `0` on the first item, `-1` on the rest; selection never steals focus |
| Labeling | Item text content names each button; icon-only items pair an `aria-label` through an edited copy of the file |
