## API

The composed root takes an items array, not children slots; items render joined into one segment strip (`data-spacing="0"`, `--gap: 0`). The `data-[spacing=...]` classes ride along in both style modules, so relaxing the joined strip into spaced buttons is an edit of the copied file away.

### ToggleGroup

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `{ value, label?, pressed?, disabled? }[]` | `-` |
| `type` | `"single" \| "multiple"` | `"single"` |
| `value` | `() => string` | `-` |
| `values` | `() => string[]` | `-` |
| `onValueChange` | `(value: string \| string[]) => void` | `-` |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `class` | `string` | `-` |

`pressed` in an item seeds the uncontrolled state. Without `value` / `values`, the root owns its state seeded by the items' `pressed` flags: in single mode, clicking the active item deselects it and reports `""`; in multiple mode, clicking toggles membership and reports the full array. Pass an accessor (`value` for single, `values` for multiple) and the group becomes controlled: clicks turn into `onValueChange` requests without writing state, so a parent signal that ignores the request keeps the selection unchanged.

### ToggleGroupItem

One pressed-state button inside the group; it renders the joined-segment classes and the `data-variant` / `data-size` / `data-spacing` attributes the styles key off.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | `-` |
| `pressed` | `boolean \| (() => boolean)` | `-` |
| `onSelect` | `() => void` | `-` |
| `variant` | `"default" \| "outline"` | `"default"` |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `disabled` | `boolean` | `-` |
| `children` | `HellaChildren` | The item's label |

A boolean `pressed` reads statically, an accessor keeps the manual part reactive; it drives `aria-pressed` and `data-state` (`on` / `off`).

Every part also takes a `class` string, landing last in its style composition.

## Accessibility

| Aspect | Value |
|---|---|
| Roles | `group` on the root; each item is a toggle button carrying `aria-pressed` in both modes |
| State | `aria-pressed` plus `data-state` (`on` / `off`) per item |
| Keyboard | Arrow keys move focus (wrapping at both ends); Space and Enter toggle through native button activation; disabled items are skipped |
| Tab | Roving tabindex: `0` on the first item, `-1` on the rest; selection never steals focus |
| Labeling | Item text content names each button; icon-only items pair an `aria-label` through an edited copy of the file |
