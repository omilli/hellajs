## API

A hover-triggered label: the trigger wraps your content, the label portals into `document.body`, opens after a hover delay, and anchors to the trigger with collision flipping. Keyboard focus opens it with the same path a pointer takes.

The composed `Tooltip` wraps its children in the trigger span. Hovering starts the open timer; leaving starts the close timer; focusing the trigger follows the same path for keyboard users. Adjacent triggers share a 500ms skip window through [`hoverIntent`](/headless/hoverintent): moving from one tooltip straight onto another opens the next one instantly, without paying the delay again - after 500ms without any tooltip open, the full delay applies.

Three named components ship beside the default `Tooltip`: `TooltipTrigger`, `TooltipContent`, and `TooltipProvider`. Each is a thin styled wrapper over the [`tooltip`](/headless/tooltip) factory's component set, so the hover timing, anchoring, dismissal, and exit timing stay in one place. State is still explicit on the manual components: hand `TooltipContent` a `state` accessor, and point its `anchor` at whatever should anchor it; it portals into `document.body` itself.

### Tooltip

The composed root portals its `content` prop into `document.body` while open.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `content` | `HellaChildren` | `-` |
| `delayDuration` | `number` | `700` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

### TooltipTrigger

The manual trigger span; the composed `Tooltip` renders the same shape wired to [`hoverIntent`](/headless/hoverintent) and carries the label's id as its `aria-describedby`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

### TooltipContent

The `role="tooltip"` label carrying `data-slot="tooltip-content"`, wired by the [`tooltip`](/headless/tooltip) factory: positioned against the anchor through [`anchorPosition`](/headless/anchorposition) (fixed coordinates against the trigger, flipping to the opposite side on viewport collision, repositioning on scroll and resize) and dismissed through [`layerDismissal`](/headless/layerdismissal) - Escape and an outside pointerdown close only the top layer. A controlled `state` accessor holds the label open unless the composer reacts.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `() => "open" \| "closed"` | `-` |
| `id` | `string` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `anchor` | `() => Element \| undefined` | `-` |
| `onExited` | `() => void` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element; a user-supplied `id` wins over the generated one).

`state` drives `data-state` and the enter/exit cycle. The label `id` is what the trigger's `aria-describedby` points at. The anchor resolves to the element the label anchors to; positioning is skipped when undefined. `onExited` fires when the exit animation ends under `data-state="closed"`.

### TooltipProvider

A passthrough wrapper carrying nothing but children. Delay configuration is the per-Tooltip `delayDuration` prop, not a provider setting, and the label carries no arrow glyph - both absences are deliberate.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

Every component also takes a `class` string, landing last in its style composition.
