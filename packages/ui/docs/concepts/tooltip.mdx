## API

A hover-triggered label: the trigger wraps your content, the label portals into `document.body`, opens after a hover delay, and anchors to the trigger with collision flipping. Keyboard focus opens it with the same path a pointer takes.

The composed `Tooltip` wraps its children in the trigger span. Hovering starts the open timer; leaving closes the label immediately; focusing the trigger follows the same path for keyboard users. Adjacent triggers share a 500ms skip window through [`hoverIntent`](/headless/hoverintent): moving from one tooltip straight onto another opens the next one instantly, without paying the delay again - after 500ms without any tooltip open, the full delay applies.

### Tooltip

The composed root portals its `content` prop into `document.body` while open.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `content` | `HellaChildren` | `-` |
| `delayDuration` | `number` | `700` |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` |
| `align` | `"start" \| "center" \| "end"` | `"center"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

Every component also takes a `class` string, landing last in its style composition.

## Controlled

Pin or drive the tooltip from outside. Pass `open` and the root renders exactly the state the accessor reports - never writing its own - while hover, focus, and dismissal still report through `onOpenChange`. Write the signal back and the DOM follows; return `true` to pin the label open regardless of the pointer:

```tsx
import { signal } from "@hellajs/core";
import { Button } from "./components/button";
import { Tooltip } from "./components/tooltip";

const shown = signal(false);

<Tooltip content="Save" open={() => shown()} onOpenChange={(v) => shown(v)}>
  <Button>Save</Button>
</Tooltip>;
```

Without `open`, the hover intent owns the state internally and `delayDuration` sets the open delay.
