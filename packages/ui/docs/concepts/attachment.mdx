## API

`Attachment` renders `data-state` from its `state` prop: `idle` (dashed border), `uploading`, `processing`, `error` (destructive border and description tint), or `done` (the default). The state drives every descendant condition through attribute selectors, so one prop moves the whole chip. `size` and `orientation` flow to the media and content parts the same way, so the chip rescales as one unit.

### Attachment

The chip root: a `div` carrying the three state attributes the whole chip keys off.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"` |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | The media, content, and action nodes |

Accepts all native `div` attributes (forwarded to the root element).

### AttachmentMedia

The media well: a `div` carrying `data-variant`; with no authored children it inlines the loading spinner on `uploading` and the error glyph on `error`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"icon" \| "image"` | `"icon"` |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `-` |
| `children` | `HellaChildren` | Authored media nodes; suppress the inlined icons |

Accepts all native `div` attributes (forwarded to the root element).

### AttachmentContent

The text column: a `div` carrying `data-slot="attachment-content"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Title and description nodes |

Accepts all native `div` attributes (forwarded to the root element).

### AttachmentTitle

The filename line: a `span` carrying `data-slot="attachment-title"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The title node |

Accepts all native `span` attributes (forwarded to the root element).

### AttachmentDescription

The status line: a `span` carrying `data-slot="attachment-description"`, tinted on error.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The description node |

Accepts all native `span` attributes (forwarded to the root element).

### AttachmentActions

The action row: a `div` carrying `data-slot="attachment-actions"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Action buttons |

Accepts all native `div` attributes (forwarded to the root element).

### AttachmentAction

A real button for remove/retry actions.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon-xs"` |
| `children` | `HellaChildren` | Icon or label node |

Accepts all native `button` attributes (forwarded to the root element).

### AttachmentTrigger

An invisible button stretched over the whole chip for open interactions.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | Optional label nodes |

Accepts all native `button` attributes (forwarded to the root element).

### AttachmentGroup

The scroll-snapping chip row: a `div` carrying `data-slot="attachment-group"`.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The chips |

Accepts all native `div` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.

## Composition Notes

A reactive `state` signal animates the whole lifecycle from one value: the inlined spinner and glyph follow the state, so wiring `state` through a signal is the only glue an upload flow needs. The `AttachmentMedia` icon variants (`icon` and `image`) restyle authored children: `image` dims until the state reads `done` or `idle` and object-fits its `img` children square. `AttachmentTrigger` renders the stretch button itself rather than delegating to its children, so there is no slot indirection to replicate; compose the parts directly and pass your own element classes through `class`. The media's error glyph uses the `octagon-x` icon; swap the path data if your project carries its own icon.
