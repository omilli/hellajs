## API

A rich preview card: hovering a trigger opens an anchored panel, moving the pointer into the panel keeps it open, and leaving both closes it. Keyboard focus follows the same open and close path a pointer takes.

### HoverCard

The composed `HoverCard` wraps its children in the trigger span. It opens 200ms after the pointer rests on the trigger and closes 300ms after it leaves. Moving the pointer from the trigger into the panel keeps it open: the content carries a second [`hoverIntent`](/headless/hoverintent) with zero delays that re-arms the open state the moment the pointer enters, cancelling the trigger's pending close. Leaving the content closes it immediately; returning to the trigger cancels that close in turn, so crossing between the two regions in either direction never flickers. The `content` prop portals into `document.body` while open and stays mounted under `data-state="closed"` until its exit animation ends.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `() => boolean` | `-` |
| `onOpenChange` | `(open: boolean) => void` | `-` |
| `content` | `HellaChildren` | `-` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `span` attributes (forwarded to the root element).

A controlled `open` stops the root from writing its internal signal; `onOpenChange` reports every requested open and close flip.

Every component also takes a `class` string, landing last in its style composition. [`anchorPosition`](/headless/anchorposition) fixes the coordinates against the trigger, flips on viewport collision, and repositions on scroll and resize.
