# Kbd

A keyboard-key chip styled byte-faithfully to shadcn's new-york-v4 Kbd: a `Kbd` element for single keys and a `KbdGroup` for sequences, both rendering the semantic `kbd` tag.

## Usage

Both parts take `{ children?, class? }`; the root carries `data-slot="kbd"`, the group `data-slot="kbd-group"`, and both render the `kbd` element for browser and assistive-tech semantics.

```jsx
import Kbd from './components/kbd';

const Shortcut = () => (
  <span class="flex items-center gap-2 text-sm">
    Save changes <Kbd>⌘S</Kbd>
  </span>
);
```

## Grouped Sequences

`KbdGroup` lays a run of keys out as one sequence with a shared gap:

```jsx
import Kbd, { KbdGroup } from './components/kbd';

const Sequence = () => (
  <KbdGroup>
    <Kbd>ctrl</Kbd>
    <Kbd>shift</Kbd>
    <Kbd>P</Kbd>
  </KbdGroup>
);
```

## Tooltip Inverse

Inside a tooltip with `data-slot="tooltip-content"`, the key chip flips to a translucent inverse surface so it stays readable on the tooltip's dark background; nothing extra to wire:

```jsx
import Kbd, { KbdGroup } from './components/kbd';

const Hint = () => (
  <KbdGroup>
    Press <Kbd>?</Kbd> anywhere
  </KbdGroup>
);
```

## Styling

The style module exports `base` (the key chip) and `group` (the sequence wrapper); each part's compose bakes its own class plus `props.class`. The css flavor composes [`style`](/reference/css/style) maps under the `hella` cascade layer, so unlayered author CSS always wins; the tailwind flavor wraps shadcn's literal utilities (`bg-muted`, `rounded-sm`) in `cn()` so later tokens override earlier ones per utility group. The tooltip inverse is a selector on `base` keyed to `[data-slot='tooltip-content']`, and an inline `svg` child scales to the chip's `size-3` icon slot automatically, so icon fonts and lucide paths drop in without extra classes. Flavor choice and theme setup: [Installation](/ui/installation). Tokens and the override contract: [Theming](/ui/theming).
