## API

The root renders the semantic `kbd` element carrying `data-slot="kbd"`, so browser and assistive-tech semantics come free. Inside a tooltip with `data-slot="tooltip-content"`, the key chip flips to a translucent inverse surface so it stays readable on the tooltip's dark background; nothing extra to wire.

### Kbd

| Prop | Type | Default |
| ---- | ---- | ------- |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `kbd` attributes (forwarded to the root element).

### KbdGroup

The sequence wrapper: a `kbd` element carrying `data-slot="kbd-group"`, laying a run of keys out as one sequence with a shared gap.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `kbd` attributes (forwarded to the root element).

Every component also takes a `class` string, landing last in its style composition.
