## API

The composed root derives each row's trigger/content id pair and threads the open state through the manual parts.

### Accordion

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `AccordionEntry[] \| (() => AccordionEntry[])` | `-` |
| `keyBy` | `"value"` | `-` |
| `type` | `"single" \| "multiple"` | `"single"` |
| `collapsible` | `boolean` | `-` |
| `open` | `string \| string[]` | `-` |
| `class` | `string` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

### AccordionEntry

Each entry is one row; `value` keys its `data-value`, the generated id pair, and the `open` lookup.

| Field | Type | Default |
| ----- | ---- | ------- |
| `value` | `string` | `-` |
| `trigger` | `HellaChildren` | `-` |
| `content` | `HellaChildren` | `-` |
| `disabled` | `boolean` | `-` |

### AccordionItem

The row wrapper: a `div` carrying the value and open state.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | `-` |
| `active` | `() => boolean` | `-` |
| `children` | `HellaChild[]` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

### AccordionTrigger

The header row: an `h3` wrapping the toggle button, with the chevron icon appended after the children.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | `-` |
Accepts all native `button` attributes (forwarded to the root element).

### AccordionContent

The body region: a `role="region"` div whose inner wrapper carries the collapse animation.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `active` | `() => boolean` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.

## Type

| Props | Open-click behavior | Open-item-click behavior |
|---|---|---|
| `type="single"` (default) | Closes the previous item, opens the clicked one | Does nothing unless `collapsible` is set |
| `type="single" collapsible` | Same swap | Closes the item, leaving none open |
| `type="multiple"` | Opens it alongside the rest | Closes it |

## Dynamic items

`items` reads once at mount when passed a plain array; pass a signal accessor and the rows re-render as the array grows, shrinks, or reorders:

```jsx
import { signal } from "@hellajs/core";
import { Accordion } from "./components/accordion";

const sections = signal([
  { value: "a", trigger: "A", content: "A body" },
]);

<Accordion items={sections} keyBy="value" type="multiple" open={["a"]} />;

// Appends a live row without remounting the existing ones.
sections([...sections(), { value: "b", trigger: "B", content: "B body" }]);
```

By default rows key by array index: a reorder rebuilds them, losing transient state such as focus or an in-flight collapse animation (rendered state like `data-state` re-derives from the root's signal either way). `keyBy="value"` reuses each row's DOM by its entry `value` instead, so nodes move to their new positions intact through reorders and removals. Order always follows the array, never the key history. A row reused under the same `value` keeps its rendered children, so swapping an entry's `trigger` or `content` under a repeated value needs a getter for that content to reach the DOM.
