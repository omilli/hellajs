## API

The composed root derives each row's trigger/content id pair and threads the open state through the manual parts.

### Accordion

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `AccordionEntry[]` | `-` |
| `type` | `"single" \| "multiple"` | `"single"` |
| `collapsible` | `boolean` | `-` |
| `open` | `string \| string[]` | `-` |
| `class` | `string` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

### AccordionEntry

Each entry is one row; `value` keys its `data-value`, the generated id pair, and the `open` lookup.

| Field | Type | Default |
| ----- | ---- | ------- |
| `value` | `string` | `-` |
| `trigger` | `HellaChildren` | The row's trigger label |
| `content` | `HellaChildren` | The row's body |
| `disabled` | `boolean` | `-` |

### AccordionItem

The row wrapper: a `div` carrying the value and open state.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | `-` |
| `active` | `() => boolean` | `-` |
| `children` | `HellaChild[]` | The trigger and content pair |
Accepts all native `div` attributes (forwarded to the root element).

### AccordionTrigger

The header row: an `h3` wrapping the toggle button, with the chevron icon appended after the children.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `HellaChildren` | The label inside the button |
Accepts all native `button` attributes (forwarded to the root element).

### AccordionContent

The body region: a `role="region"` div whose inner wrapper carries the collapse animation.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `active` | `() => boolean` | `-` |
| `children` | `HellaChildren` | The body inside the region |
Accepts all native `div` attributes (forwarded to the root element).

Every part also takes a `class` string, landing last in its style composition.

## Type

| Props | Open-click behavior | Open-item-click behavior |
|---|---|---|
| `type="single"` (default) | Closes the previous item, opens the clicked one | Does nothing unless `collapsible` is set |
| `type="single" collapsible` | Same swap | Closes the item, leaving none open |
| `type="multiple"` | Opens it alongside the rest | Closes it |
