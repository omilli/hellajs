# Plain JavaScript

The registry's canonical source is TypeScript, and `--lang ts` (the default) copies it verbatim. `--lang js` strips the types at copy time: same components, same style declarations, plain `.jsx` and `.js` files on disk.

## The Flag

Pass the flag per call:

```bash
npx @hellajs/ui add button --lang js
# writes src/components/button.jsx: plain JS with JSX preserved, ready for your transpiler
```

Or make it the project default in `hella.ui.json`, where `add` picks it up like `style`:

```json
{
  "componentsDir": "src/components",
  "lang": "js"
}
```

`init` writes `"lang": "ts"` into new configs, and a config written before the field existed keeps behaving as `ts`.

## What Lands on Disk

`--lang js` retargets every TypeScript file the entry copies; stylesheets pass through untouched.

| Source | `--lang ts` (default) | `--lang js` |
|---|---|---|
| `button.tsx` | `button.tsx` | `button.jsx` |
| `cn.ts` | `cn.ts` | `cn.js` |
| `tokens.ts` | `tokens.ts` | `tokens.js` |
| `theme.css` | unchanged | unchanged |

The strip runs after the style splice, so the copied file still carries its full css or tailwind declarations. The strip is structural, not cosmetic: no `interface` or `import type` remains, and JSX survives verbatim in `.jsx` for the compile plugin to consume. Imports of `@hellajs/*` packages stay exactly as authored.

## JSX Projects Without TypeScript

The `.jsx` copies are not browser-ready: HellaJS JSX compiles to vnode calls, not `React.createElement`, so the files need the HellaJS babel plugin, delivered as [`vite-plugin-hellajs`](/plugins/vite):

```js
// vite.config.js
import { defineConfig } from "vite";
import viteHellaJS from "vite-plugin-hellajs";

export default defineConfig({
  plugins: [viteHellaJS()],
});
```

A generic JSX transpiler is not a substitute: only the HellaJS plugin (or the babel plugin behind it) produces the vnode calls the runtime consumes.

## Bun and Deno

Bun and Deno execute TypeScript natively, so they need none of this: default `--lang ts` copies run as-is with no flag and no strip step. `--lang js` exists for toolchains that only speak JavaScript.
