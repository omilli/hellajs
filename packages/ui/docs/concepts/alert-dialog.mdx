## Usage

A modal confirmation: the composed `AlertDialog` portals an overlay plus a centered panel and takes the open accessor plus the panel copy, with an Action/Cancel button pair closing through your own wiring.

### jsx

```jsx
import { signal } from '@hellajs/core';
import AlertDialog, { AlertDialogAction, AlertDialogCancel, AlertDialogFooter } from './components/alert-dialog';

const isOpen = signal(false);
const close = () => isOpen(false);

const DeleteProject = () => (
  <AlertDialog open={isOpen} onClose={close} title="Delete project" description="This removes every deployment attached to it.">
    <AlertDialogFooter>
      <AlertDialogCancel onClose={close}>Cancel</AlertDialogCancel>
      <AlertDialogAction variant="destructive" onClose={close}>Delete</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialog>
);
```
### html

The html-format (`--format html`) works the same way.

```js
html`<main>
  <${AlertDialog} open=${isOpen} onClose=${close} title="Revoke API key">
    <p>Applications using this key stop authenticating.</p>
    <${AlertDialogAction} variant="destructive" onClose=${close}>Revoke</${AlertDialogAction}>
    <${AlertDialogCancel} onClose=${close}>Cancel</${AlertDialogCancel}>
  </${AlertDialog}>
</main>`
```

| Prop | Default | Behavior |
|---|---|---|
| `title` | - | Optional string rendered as a wired `AlertDialogTitle` (the panel's `aria-labelledby` target) |
| `description` | - | Optional string rendered as a wired `AlertDialogDescription` (the panel's `aria-describedby` target) |
| `size` | `"default"` | Sets `data-size`; `"sm"` narrows the panel to 20rem and grids the footer into two columns |
| `closeOnEscape` | `true` | Escape keydown while the panel is open calls `onClose` |

Flipping `open` false keeps the panel mounted under `data-state="closed"` until its exit animation ends, with the dismissal wirings down while it leaves.

## No Outside Dismissal

Alert dialogs demand a deliberate answer, so the panel has no outside-click dismissal at all: there is no `closeOnOutside` prop, and pointerdowns on the overlay or the page behind it do nothing. Escape closes (suppressible with `closeOnEscape`), and the Action and Cancel buttons close through your own wiring - unlike [Dialog](/ui/dialog), dismissal never starts outside the panel.

## Manual Parts

Eleven named parts ship beside the default `AlertDialog`: `AlertDialogTrigger`, `AlertDialogPortal`, `AlertDialogOverlay`, `AlertDialogContent`, `AlertDialogHeader`, `AlertDialogFooter`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogMedia`, `AlertDialogAction`, and `AlertDialogCancel`. State is explicit - portal the overlay and panel yourself, hand both a `state` accessor, and point the panel's `labelledBy` and `describedBy` at the title and description ids yourself.

### AlertDialogTrigger

A bare button; wire its click to your own signal write.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The trigger label |

### AlertDialogPortal

Wraps children in a `Portal to="body"` for compositions that want the named part.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The portaled nodes |

### AlertDialogOverlay

The screen-covering backdrop `div` carrying `data-slot="alert-dialog-overlay"`.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives the overlay's `data-state` and its enter/exit fade |

### AlertDialogContent

The `role="alertdialog"` panel carrying `data-slot="alert-dialog-content"`: focus trap plus escape dismissal while open, torn down the moment the exit starts, and no outside dismissal.

| Prop | Type | Behavior |
|---|---|---|
| `state` | `() => "open" \| "closed"` | Drives `data-state` and the enter/exit cycle; `closed` tears the dismissal wirings down |
| `size` | `"default" \| "sm"` | Sets `data-size`, restyling the header, footer, and media parts |
| `labelledBy` | `string` | Rendered as the panel's `aria-labelledby` |
| `describedBy` | `string` | Rendered as the panel's `aria-describedby` |
| `closeOnEscape` | `boolean` | Escape keydown calls `onClose` (default `true`) |
| `onClose` | `() => void` | Dismissal callback |
| `onExited` | `() => void` | Called when the exit animation ends under `data-state="closed"` |
| `children` | `HellaChildren` | The panel body |

### AlertDialogHeader

The top grouping `div` carrying `data-slot="alert-dialog-header"`.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Title, description, and optional media nodes |

### AlertDialogFooter

The bottom grouping `div` carrying `data-slot="alert-dialog-footer"`, laying the Action and Cancel pair out.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | Action and Cancel nodes |

### AlertDialogTitle

The heading: an `h2` carrying `data-slot="alert-dialog-title"` whose `id` the panel's `aria-labelledby` points at.

| Prop | Type | Behavior |
|---|---|---|
| `id` | `string` | Rendered as the heading's `id` |
| `children` | `HellaChildren` | The title text |

### AlertDialogDescription

The supporting line: a `p` carrying `data-slot="alert-dialog-description"` whose `id` the panel's `aria-describedby` points at.

| Prop | Type | Behavior |
|---|---|---|
| `id` | `string` | Rendered as the paragraph's `id` |
| `children` | `HellaChildren` | The description text |

### AlertDialogMedia

An icon slot above the title, re-flowing the header rows around it.

| Prop | Type | Behavior |
|---|---|---|
| `children` | `HellaChildren` | The icon node, typically an `svg` |

### AlertDialogAction

The confirm button: a composed Button (default variant) calling `onClose` when clicked.

| Prop | Type | Behavior |
|---|---|---|
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | Any Button variant pick (default `"default"`) |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | Any Button size pick (default `"default"`) |
| `onClose` | `() => void` | Click callback |
| `children` | `HellaChildren` | The button label |

### AlertDialogCancel

The dismiss button: a composed Button (outline variant) calling `onClose` when clicked.

| Prop | Type | Behavior |
|---|---|---|
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | Any Button variant pick (default `"outline"`) |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | Any Button size pick (default `"default"`) |
| `onClose` | `() => void` | Click callback |
| `children` | `HellaChildren` | The button label |

Every part also takes a `class` string, landing last in its style composition. The header, footer, title, and media parts follow the panel's `data-size`: `"default"` left-aligns the text from wide screens up, `"sm"` keeps everything centered.

```jsx
import { signal } from '@hellajs/core';
import { Portal } from '@hellajs/dom';
import AlertDialog, { AlertDialogAction, AlertDialogCancel, AlertDialogContent, AlertDialogDescription, AlertDialogFooter, AlertDialogHeader, AlertDialogOverlay, AlertDialogTitle } from './components/alert-dialog';

const isOpen = signal(false);
const state = () => (isOpen() ? 'open' : 'closed');

const Manual = () => (
  <>
    <button on:click={() => isOpen(true)}>Delete</button>
    {() => isOpen() && (
      <Portal to="body">
        <AlertDialogOverlay state={state} />
        <AlertDialogContent state={state} labelledBy="alert-manual-title" describedBy="alert-manual-description" onClose={() => isOpen(false)}>
          <AlertDialogHeader>
            <AlertDialogTitle id="alert-manual-title">Remove this project?</AlertDialogTitle>
            <AlertDialogDescription id="alert-manual-description">Deployments attached to it stop immediately.</AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter>
            <AlertDialogCancel onClose={() => isOpen(false)}>Cancel</AlertDialogCancel>
            <AlertDialogAction onClose={() => isOpen(false)}>Continue</AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </Portal>
    )}
  </>
);
```
