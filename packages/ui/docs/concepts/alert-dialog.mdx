## API

A modal confirmation: the composed `AlertDialog` portals an overlay plus a centered panel and takes the open accessor plus the panel copy, with an Action/Cancel button pair closing through your own wiring. Flipping `open` false keeps the panel mounted under `data-state="closed"` until its exit animation ends, with the dismissal wirings down while it leaves.

### AlertDialog

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `Signal<boolean>` | `-` |
| `onClose` | `() => void` | `-` |
| `title` | `string` | `-` |
| `description` | `string` | `-` |
| `size` | `"default" \| "sm"` | `"default"` |
| `closeOnEscape` | `boolean` | `true` |
| `class` | `string` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `div` attributes (forwarded to the root element).

`title` renders as a wired `AlertDialogTitle` (the panel's `aria-labelledby` target) and `description` as a wired `AlertDialogDescription` (the `aria-describedby` target). `"sm"` narrows the panel to 20rem and grids the footer into two columns.

### AlertDialogAction

The confirm button: a composed Button calling `onClose` when clicked.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `onClose` | `() => void` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `button` attributes (forwarded to the root element; a user `on:click` chains with the owned dismiss).

### AlertDialogCancel

The dismiss button: a composed Button calling `onClose` when clicked.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"outline"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
| `onClose` | `() => void` | `-` |
| `children` | `HellaChildren` | `-` |
Accepts all native `button` attributes (forwarded to the root element; a user `on:click` chains with the owned dismiss).

Every component also takes a `class` string, landing last in its style composition. The header, footer, title, and media components follow the panel's `data-size`: `"default"` left-aligns the text from wide screens up, `"sm"` keeps everything centered.

## No Outside Dismissal

Alert dialogs demand a deliberate answer, so the panel has no outside-click dismissal at all: there is no `closeOnOutside` prop, and pointerdowns on the overlay or the page behind it do nothing. Escape closes (suppressible with `closeOnEscape`), and the Action and Cancel buttons close through your own wiring - unlike [Dialog](/ui/dialog), dismissal never starts outside the panel.
