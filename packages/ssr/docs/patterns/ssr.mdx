# SSR

Copy-paste recipes for server rendering with [`@hellajs/ssr`](/reference/ssr/ssr). For URL→view routing on the server (a request URL driving the rendered view, with shared client [`hydrate`](/reference/dom/hydrate)), see the [Routing](/learn/patterns/routing) SSR recipes.

### Plain HTML with Bun.serve

Render a template to a string and return a full document via [`doc`](/reference/ssr/doc).

```js
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';

const page = (name) => html`<div><h1>Hello ${name}</h1></div>`;

Bun.serve({
  port: 3000,
  fetch: () => new Response(
    doc({ head: { title: 'Hello' }, body: ssr(page('World')) }),
    { headers: { 'content-type': 'text/html' } }
  )
});
```

### Render from JSX

`ssr` consumes any [`HellaNode`](/reference/dom): the [`html`](/reference/dom/html) tag and JSX compile to the same AST, so render a JSX component exactly like a template.

```jsx
import { ssr } from '@hellajs/ssr';

const App = ({ name }: { name: string }) => <div><h1>Hello {name}</h1></div>;
const body = ssr(<App name="World" />);
// body: "<div><h1>Hello World</h1></div>"
```

The babel/vite/rollup plugin must run on the **server** entry; without the compile-time transform JSX is not a `HellaNode` (see [Build Tools Plugins](/plugins)).

### Styled output

[`@hellajs/css`](/reference/css) registers styles on both platforms; collect the generated text with [`cssText`](/reference/css/csstext) and pass it to [`doc`](/reference/ssr/doc)'s `styles` to emit a single `<style>` tag per response.

```js
import { html } from '@hellajs/dom';
import { style, cssText } from '@hellajs/css';
import { ssr, doc } from '@hellajs/ssr';
const card = style({ border: '1px solid #ccc' }, { label: 'card' });
const body = ssr(html`<div class=${card}>Content</div>`);
const page = doc({ head: { title: 'Card', styles: [cssText()] }, body });
```

### Express handler

Use `ssr` inside any Node framework; the stringifier is framework-agnostic, with the document assembled via [`doc`](/reference/ssr/doc).

```js
import express from 'express';
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';

const app = express();
app.get('/', (req, res) => {
  const body = ssr(html`<div><h1>Hello ${req.query.name ?? 'World'}</h1></div>`);
  res.send(doc({ head: { title: 'Hello' }, body }));
});
app.listen(3000);
```

### Bind an existing node with $ref

Enhance server-rendered HTML by binding an existing node into reactivity on the client.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';

// Server
const body = ssr(html`<div id="app"><span id="count">0</span></div>`);
```

```typescript
import { signal } from '@hellajs/core';
import { $ref } from '@hellajs/dom';
// Client
const count = signal(0);
const span = $ref('#count');
span.bind(() => String(count()));
```

### Mount an island into an empty slot

Leave an empty placeholder on the server and mount a reactive island into it on the client.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';

// Server leaves an empty slot
const body = ssr(html`<div><h1>Post</h1><div id="slot"></div></div>`);
```

```js
import { signal } from '@hellajs/core';
import { html, mount } from '@hellajs/dom';
// Client mounts an interactive island
const Counter = () => {
  const clicks = signal(0);
  return html`<button on:click=${() => clicks(clicks() + 1)}>${clicks}</button>`;
};
mount(Counter, '#slot');
```

### Hydrate server-rendered HTML

Re-execute the full component tree against the existing server DOM to make the entire page interactive without replacing any nodes.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';

// Server renders the whole app into the target element
const body = ssr(html`<${App} />`);
```

```js
import { hydrate, html } from '@hellajs/dom';

// Client attaches effects/handlers to the existing nodes
hydrate(html`<${App} />`, '#app');
```

### Async data fetching

Fetch server-side data directly in the tree with [`ssr.async`](/reference/ssr/ssr#async): a getter that returns a Promise is awaited.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';

const user = (id) => fetch(`/api/users/${id}`).then(r => r.text());
const App = (id) => html`<p>Hello ${() => user(id)}</p>`;
const body = await ssr.async(App(1));
// body: "<p><!--[-->Ada<!--]--></p>"
```

### Ship server data to the client

Fetch on the server, render it, and send the data with the markup: [`doc`](/reference/ssr/doc)'s `data` option serializes it into a JSON payload script the client reads back to seed [`resource`](/reference/resource/resource) with `initialData`, so the server's fetch is the fetch.

```js
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';

// Server: one fetch feeds both the markup and the payload
const user = await fetch('/api/users/1').then(r => r.json());
const body = ssr(html`<h1>Hello ${user.name}</h1>`);
const page = doc({ mount: '#app', data: { user }, body });
// <body><div id="app">…</div><script type="application/json" id="hella-data">{"user":…}</script></body>
```

```js
import { resource } from '@hellajs/resource';
const { user } = JSON.parse(document.getElementById('hella-data').textContent);
const userResource = resource('/api/users/1', { initialData: user });

userResource.data();      // the server-fetched value
userResource.isLoading(); // false; initialData counts as data
```

### Per-route head entries

Let each route component carry its own `<title>`/`<meta>` instead of assembling the head at the handler: [`ssr.head()`](/reference/ssr/ssr#head) creates the bag, the walk hoists the tree's head tags into it, and [`doc`](/reference/ssr/doc) emits them.

```js
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';
const Profile = (user) => html`
  <div>
    <title>${user.name} - Profile</title>
    <meta name="description" content=${user.tagline} />
    <link rel="canonical" href=${`/users/${user.id}`} />
    <h1>${user.name}</h1>
  </div>
`;
Bun.serve({
  port: 3000,
  async fetch() {
    const user = await fetch('/api/users/1').then(r => r.json());
    const head = ssr.head();
    const body = await ssr.async(Profile(user), { head });   // <title>/<meta>/<link> hoist out of the body
    return new Response(
      doc({ body, head, mount: '#app' }),
      { headers: { 'content-type': 'text/html' } }
    );
  }
});
```

With the [Routing](/learn/patterns/routing) SSR recipes, each route view owns its entries the same way. Under [`ssr.stream`](/reference/ssr/ssr#stream) the bag fills as the walk proceeds, but a streamed document emits its `<head>` up front; pass head entries to `doc` explicitly when streaming.

### Streaming responses

Stream HTML to the client as it renders with [`ssr.stream`](/reference/ssr/ssr#stream): the static shell flushes before async values resolve.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';
const user = (id) => fetch(`/api/users/${id}`).then(r => r.text());
const page = (id) => html`<div><h1>Hello</h1><p>${() => user(id)}</p></div>`;
Bun.serve({
  port: 3000,
  fetch: (req) => {
    const id = new URL(req.url).searchParams.get('id') ?? '1';
    return new Response(
      ssr.stream(page(id)).pipeThrough(new TextEncoderStream()),
      { headers: { 'content-type': 'text/html' } }
    );
  }
});
```

Wrap the stream in a full document with [`doc`](/reference/ssr/doc): the shell (head, `lang`, the `mount` wrapper) flushes first and the closing tags land only after the body closes, so nothing is collected:

```js
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';
const user = (id) => fetch(`/api/users/${id}`).then(r => r.text());
const page = (id) => html`<div><h1>Hello</h1><p>${() => user(id)}</p></div>`;
Bun.serve({
  port: 3000,
  fetch: (req) => {
    const id = new URL(req.url).searchParams.get('id') ?? '1';
    return new Response(
      doc({
        lang: 'en',
        mount: '#app',                              // the wrapper hydrate(node, '#app') targets
        head: { scripts: [{ type: 'module', src: '/client.js' }] },
        body: ssr.stream(page(id)),
      }).pipeThrough(new TextEncoderStream()),
      { headers: { 'content-type': 'text/html' } }
    );
  }
});
```

### Out-of-order streaming with Suspense

Wrap async data in [`<Suspense>`](/reference/dom/suspense) so the shell and a `fallback` flush immediately while the children resolve; a slow fetch no longer blocks the rest of the page.

```js
import { html, Suspense } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';
const user = (id) => fetch(`/api/users/${id}`).then(r => r.text());
const App = () => html`
  <div>
    <h1>Profile</h1>
    <${Suspense} fallback=${html`<p>Loading…</p>`}>${() => user(1).then(name => html`<p>${name}</p>`)}</${Suspense}>
  </div>
`;

// Shell + fallback flush first; each resolved region streams in as a <template> + an inline $hs swap script; hydrate later adopts
const stream = ssr.stream(html`<${App} />`);
```

### Error handling

`ssr`, [`ssr.async`](/reference/ssr/ssr#async), and [`ssr.stream`](/reference/ssr/ssr#stream) propagate render failures instead of swallowing them: a throwing child, function-ref prop getter, or `use` callback surfaces to the caller (see [Errors Propagate](/reference/ssr/ssr#errors-propagate)). Catch the failure at the server handler: render a fallback page for the sync/async renderers (`await` the render inside the `try` for `ssr.async`), or catch at the stream consumer for `ssr.stream`.

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';
const Profile = (user) => html`<h1>${() => user.name.toUpperCase()}</h1>`;
const ErrorPage = (msg) => html`<div class="error">Render failed: ${msg}</div>`;

function render(user) {
  try {
    return ssr(Profile(user));
  } catch (err) {
    return ssr(ErrorPage(err.message));
  }
}
render({ name: 'Ada' });   // "<h1><!--[-->ADA<!--]--></h1>"
render({});                 // "<div class=\"error\">Render failed: ...</div>"
```

```js
import { html } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';
const fetchName = () => fetch('/api/missing').then(r => r.json()).then(d => d.name);

async function respond() {
  const stream = ssr.stream(html`<p>${() => fetchName()}</p>`).pipeThrough(new TextEncoderStream());
  try {
    for await (const chunk of stream) { /* write chunk to the response body */ }
  } catch (err) {
    // The rejection surfaced as a stream error; the shell may already have flushed, so emit any fallback here
  }
}
```
