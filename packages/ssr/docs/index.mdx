## SSR

Render HellaNode templates to HTML strings on the server with zero runtime dependencies. Pair with [`@hellajs/dom`](/reference/dom) templates and, optionally, [`@hellajs/css`](/reference/css) for styled output.

### Installation

```bash
npm install @hellajs/dom @hellajs/ssr
```

### Example

```js
import { html } from '@hellajs/dom';
import { ssr, doc } from '@hellajs/ssr';

const greet = (name) => html`<div><h1>Hello ${name}</h1></div>`;

const body = ssr(greet('World'));
// body: "<div><h1>Hello World</h1></div>"

// Assemble a full document
const page = doc({ head: { title: 'Hello' }, body });
```

### API

- **[ssr](/reference/ssr/ssr)**: Serialize a HellaNode AST into an HTML string
- **[ssrAsync](/reference/ssr/ssr-async)**: Serialize a HellaNode AST into an HTML string, awaiting Promises in the tree
- **[ssrStream](/reference/ssr/ssr-stream)**: Serialize a HellaNode AST into a streaming HTML response (`ReadableStream`)
- **[doc](/reference/ssr/doc)**: Assemble a rendered body and head into a full HTML document string
