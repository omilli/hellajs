# Server-Side Rendering

Render HellaNode templates to HTML strings on the server, then enhance them on the client.

## The String-Renderer Model

`@hellajs/ssr` is a pure stringifier; see [`ssr`](/reference/ssr/ssr).

`ssr` walks a [`HellaNode`](/reference/dom) AST, the tree JSX compiles to, and emits an HTML string. Attribute serialization follows browser rules: falsy values are omitted, `true` renders a bare attribute, arrays join with spaces. Static template text is emitted as written; interpolated text and attribute values are escaped. Every dynamic region (a reactive child, a [`raw`](/reference/dom/raw) child, a control-flow component, or a nested fragment) is wrapped in `<!--[-->…<!--]-->` markers that [`hydrate`](/reference/dom/hydrate) reads; static elements and text are unwrapped (matched by position), keeping the payload minimal.

```jsx
import { signal } from '@hellajs/core';
import { ssr } from '@hellajs/ssr';

// A resolved interpolation value (here a signal) is escaped and marker-wrapped.
const markup = signal('<b>');
const body = ssr(<div class="card">{markup}</div>);
// body: "<div class=\"card\"><!--[-->&lt;b&gt;<!--]--></div>"
```

Because no DOM is involved, `ssr` runs in Bun, Node, Deno, and workers alike.

## Zero Runtime Dependencies

`ssr` imports nothing at runtime from any `@hellajs/*` package; the [`HellaNode`](/reference/dom) import is type-only and erased. This keeps the server bundle minimal and lets `ssr` operate whether or not the other packages are installed.

## Control Flow on the Server

[`ForEach`](/reference/dom/foreach) renders each item in array order. [`Transition`](/reference/dom/transition) renders its child when `show` is truthy, nothing otherwise. [`Lazy`](/reference/dom/lazy) renders its `loading` fallback without calling the loader; the async members await it and render the loaded component. [`Portal`](/reference/dom/portal) renders nothing: there is no document to teleport into. [`Suspense`](/reference/dom/suspense) renders its children directly and drops the `fallback`, because nothing waits; only [`ssr.stream`](/reference/ssr/ssr#stream) ships the fallback and streams the resolved children after it. Each control-flow component carries its own server-render rule, so the walk needs no DOM.

## Raw HTML Children

`raw` wraps an HTML string as an opaque child: `ssr` emits it verbatim (unescaped), marker-wrapped, and `hydrate` adopts the region without binding anything inside. Use it to embed pre-rendered HTML (e.g. a meta-framework's slot output); never pass unsanitized user input (XSS).

```jsx
import { raw } from '@hellajs/dom';
import { ssr } from '@hellajs/ssr';

ssr(<main>{raw('<h1>Hi</h1>')}</main>);
// => "<main><!--[--><h1>Hi</h1><!--]--></main>"
```

## Client Enhancement

The shipped HTML is the source of truth. The client can either hydrate the full tree or enhance the static HTML selectively.

- [`hydrate`](/reference/dom/hydrate) re-executes the component tree against the existing DOM, locating each `<!--[-->…<!--]-->` marker region and attaching effects/handlers/state without replacing it. Pass the same node the server passed to `ssr`; reactive state must initialize to the server-rendered values. See [Hydration](/learn/concepts/hydration).
- Bind individual existing server-rendered nodes into reactivity with [`$ref`](/reference/dom/$ref) and [`$collection`](/reference/dom/$collection).
- Mount a reactive island into an empty placeholder the template left for it.

```jsx
import { ssr, doc } from '@hellajs/ssr';

const App = () => <h1>Hello</h1>;

// Server: the app renders inside the #app wrapper
const page = doc({ mount: '#app', body: ssr(<App />) });
```

```jsx
import { hydrate } from '@hellajs/dom';

// Client: the same tree binds to the existing nodes in place
hydrate(<App />, '#app');
```

Server-fetched values ride along via [`doc`](/reference/ssr/doc)'s `data` option: the data ships as a JSON payload the client reads in one line, seeding a [`resource`](/reference/resource/resource) with `initialData`:

```js
// Client; recover the server's data
const { user } = JSON.parse(document.getElementById('hella-data').textContent);
```

> **Never mount over server HTML**: [`mount`](/reference/dom/mount) replaces the container's children, so a full-tree mount over the server-rendered container wipes the shipped markup and any DOM state in that subtree. Use `hydrate`, the enhancement modes above, or reserve full re-mount for throwaway SEO-only content.

## Synchronous Render

`ssr` walks the tree once. Reactive values are read at their current value with no effect scheduling or batching. Resolve server-side data before building the tree.

For data that must be fetched during render, [`ssr.async`](/reference/ssr/ssr#async) is the async counterpart: it awaits any Promise a resolved value returns, so a getter can fetch directly. Output and markers are identical to `ssr`; [`hydrate`](/reference/dom/hydrate) consumes either unchanged.

[`ssr.stream`](/reference/ssr/ssr#stream) streams the same walk as `ReadableStream` chunks, flushing the static prefix before each awaited Promise (progressive paint), and [`doc`](/reference/ssr/doc) wraps that stream in a full document (head, `lang`, and a mount-point wrapper) without collecting it.
