# Reactivity

Copy-paste recipes for common reactive-state tasks using [`@hellajs/core`](/reference/core). Each recipe is self-contained; the [reactivity concepts](/learn/concepts/reactivity) page explains the model behind them.

### Debounced Search Input

Delay a downstream write until the input settles: every keystroke re-runs the [`effect`](/reference/core/effect), and the returned cleanup cancels the pending timer before the next wait starts.

```typescript
import { signal, effect } from '@hellajs/core';

const searchInput = signal('');
const settledQuery = signal('');

const stopDebounce = effect(() => {
  const input = searchInput(); // tracked: every keystroke re-runs the effect
  const timer = setTimeout(() => settledQuery(input), 300);
  return () => clearTimeout(timer); // runs before each re-run: the wait resets
});

searchInput('hel');
searchInput('hell');
searchInput('hello');
// One effect re-run at the microtask boundary, one fresh 300ms timer;
// settledQuery receives 'hello' 300ms after the last keystroke

stopDebounce();
```

### Validation With Equality Gate

Derive an errors array with [`computed`](/reference/core/computed) and gate it with a content `equals` comparator: a fresh-but-equal recompute stops at the derivation instead of waking downstream effects.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const email = signal('');
const password = signal('');

const errors = computed(
  () => {
    const found: string[] = [];
    if (!email().includes('@')) found.push('enter a valid email');
    if (password().length < 8) found.push('password needs 8+ characters');
    return found; // a new array reference on every recompute
  },
  {
    // without the gate, every fresh array propagates by reference
    equals: (previous, next) =>
      previous.length === next.length &&
      previous.every((message, index) => message === next[index]),
  },
);

effect(() => console.log('errors:', errors().join('; ') || 'valid'));

email('ada@hella.dev');
password('correct-horse');
// drain recompute: [] differs from the initial two errors, the effect logs "valid"

email('grace@hella.dev');
// recompute allocates a fresh [], content-equal: propagation stops, no log
```

### Fetch Data as Input Changes

Refetch whenever a key signal changes: the effect body stays synchronous, results land through signal writes, and the cleanup flags stale responses so a slow previous fetch never overwrites a newer one.

```typescript
import { signal, effect } from '@hellajs/core';

type Profile = { id: number; name: string };

const userId = signal(1);
const profile = signal<Profile | null>(null);
const loading = signal(false);

const stopFetch = effect(() => {
  const id = userId(); // tracked: writing a new id refetches
  loading(true);
  let stale = false; // set by the cleanup when this fetch is superseded
  fetch(`/api/users/${id}`)
    .then((res) => res.json())
    .then((data: Profile) => {
      if (stale) return;
      profile(data);
      loading(false);
    });
  return () => {
    stale = true; // runs before each refetch and on dispose
  };
});

userId(2); // refetch starts; a late response for id 1 is discarded

stopFetch();
```

### Persist State to localStorage

Write every change through to storage, and keep multiple tabs in sync through the browser's `storage` event.

```typescript
import { signal, effect } from '@hellajs/core';

const settings = signal({ theme: 'dark', compact: false });

const stopPersist = effect(() => {
  localStorage.setItem('settings', JSON.stringify(settings()));
});

const onStorage = (event: StorageEvent) => {
  if (event.key !== 'settings' || event.newValue === null) return;
  settings(JSON.parse(event.newValue) as { theme: string; compact: boolean });
};
window.addEventListener('storage', onStorage);
// A tab never receives its own writes as events: no feedback loop

// Teardown
stopPersist();
window.removeEventListener('storage', onStorage);
```

### Mirror Browser State into Signals

Bridge non-reactive browser state into a [`signal`](/reference/core/signal) with a listener whose lifetime is bound to the effect: the handler writes each change into the signal, and the returned cleanup unsubscribes on disposal.

```typescript
import { signal, effect } from '@hellajs/core';

const viewportWidth = signal(0);

const stopTracking = effect(() => {
  const measure = () => viewportWidth(window.innerWidth);
  measure(); // capture the size as it stands right now
  window.addEventListener('resize', measure);
  return () => window.removeEventListener('resize', measure);
});
// Reads no signals: the effect is a lifecycle-bound listener, not a reactor

stopTracking();
```

### Row-Level List Effects

Track one element of a [`signalArray`](/reference/core/signalarray) without waking the other elements' effects: a value write wakes only that element's readers, while a structural operation wakes every positional reader.

```typescript
import { signalArray, effect } from '@hellajs/core';

const readings = signalArray([21, 19, 25]);

const trackSensor = (index: number) =>
  effect(() => {
    console.log(`sensor ${index}: ${readings.get(index)}`);
  });

trackSensor(0);
trackSensor(2);

readings.set(0, 22); // wakes sensor 0's effect only; sensor 2 stays asleep
readings.push(31); // structural: every get() reader re-runs, the index mapping may shift
```

### Undo History

Keep past and future stacks as separate signals and build new array references on every transition so each write propagates.

```typescript
import { signal } from '@hellajs/core';

type Draft = { text: string };

const present = signal<Draft>({ text: '' });
const past = signal<Draft[]>([]);
const future = signal<Draft[]>([]);

const edit = (text: string) => {
  past([...past(), present()]);
  future([]);
  present({ text });
};

const undo = () => {
  const history = past();
  const previous = history[history.length - 1];
  if (previous === undefined) return;
  future([present(), ...future()]);
  present(previous);
  past(history.slice(0, -1));
};

edit('Hello');
edit('Hello, world');
undo();
console.log(present().text); // "Hello"; redo is the same move in reverse
```

### Telemetry Without Retriggers

Read context inside an effect with [`untracked`](/reference/core/untracked) so changing the context never re-runs the effect, while each run still logs the current value.

```typescript
import { signal, effect, untracked } from '@hellajs/core';

const query = signal('');
const auditTag = signal('[prod]');

const stopAudit = effect(() => {
  const tag = untracked(() => auditTag()); // read without subscribing
  console.log(`${tag} query changed: ${query()}`);
});

auditTag('[debug]'); // no re-run: auditTag is not a dependency
query('hella'); // re-runs, and the log picks up the current tag

stopAudit();
```

### A Feature's Full Lifecycle

Collect every effect a feature creates into one [`scope`](/reference/core/scope): the returned stop function retires the interval and all effects with a single call.

```typescript
import { signal, effect, scope } from '@hellajs/core';

const createStopwatch = () => {
  const elapsed = signal(0);
  const stop = scope(() => {
    effect(() => {
      const timer = setInterval(() => elapsed(elapsed() + 1), 1000);
      return () => clearInterval(timer);
    });
    effect(() => console.log(`elapsed: ${elapsed()}`));
  });
  return { elapsed, stop };
};

const stopwatch = createStopwatch();

// Later, one call disposes every effect the feature created
stopwatch.stop();
```

### Deterministic Effects in Tests

Effects drain at the microtask boundary; call [`flush`](/reference/core/flush) when the next line must observe their output, with consecutive writes coalesced into one run.

```typescript
import { signal, effect, flush } from '@hellajs/core';

const count = signal(0);
const observed: number[] = [];

effect(() => observed.push(count()));

count(1);
count(2);

flush(); // drain now, ahead of the microtask
console.log(observed); // [0, 2]: initial run, then one run for both writes
```
