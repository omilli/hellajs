# State

Signals provide the foundation for all reactive state in HellaJS. Use signals directly for local component state or global shared state.

## Component State

Encapsulate state within components using signals. Each signal is independent: only the values that change trigger updates.

```typescript
import { signal, effect } from '@hellajs/core';

const count = signal(0);
const isVisible = signal(true);

effect(() => console.log(`Count: ${count()}`));
effect(() => console.log(`Visible: ${isVisible()}`));

count(1);       // Logs: "Count: 1"
isVisible(false); // Logs: "Visible: false"
```

## Global Shared State

Signals declared in module scope are shared across all components that import them. Combine with [`computed`](/reference/core/computed) for derived values.

```typescript
import { signal, computed } from '@hellajs/core';

const user = signal(null);
const theme = signal('light');

const isLoggedIn = computed(() => !!user());
```
