# effect

Runs automatically when reactive dependencies change.

## API

```typescript
function effect(effectFn: () => void): () => void
```
- `effectFn`: Re-executed whenever a signal read inside it changes
- **Returns**: A function that stops the effect and prevents further executions

## Basic Usage

Runs immediately, then again whenever a dependency changes.

Call the returned function to stop the effect when no longer needed.

```typescript
import { signal, effect } from '@hellajs/core';

const count = signal(0);

// This effect runs immediately, then whenever `count` changes.
const cleanup = effect(() => {
  console.log(`The count is: ${count()}`);
});

count(1); // Logs: "The count is: 1"
count(2); // Logs: "The count is: 2"

// Stop the effect. Future changes to `count` will not be logged.
cleanup();
count(3); // (nothing is logged)
```

## Key Concepts

### Conditional Effects

Only reacts to the signals that are read during the ***last*** execution.

```typescript
import { signal, effect } from '@hellajs/core';

const showData = signal(true);
const data = signal('value');

effect(() => {
  if (showData()) {
    console.log(data()); // Only reacts to 'data' when showData is true
  }
});
```

## Important Considerations

### Avoid Async

Must be synchronous functions that may contain asynchronous operations.

```typescript
import { effect } from '@hellajs/core';

// ❌ Async function directly
effect(async () => { /* ... */ });

// ✅ Handle async operations inside
effect(() => {
  fetch('/api/data').then(data => {
    // Handle the data here
    console.log(data);
  });
});
```

### Infinite Loops

Writing to a signal that the effect also reads creates infinite loops.

Use [`untracked`](/reference/core/untracked) for non-reactive reads or [`batch`](/reference/core/batch) to group the read and write into a single update cycle.

```typescript
import { signal, effect, untracked } from '@hellajs/core';

const count = signal(0);

// ❌ Effect reads and writes the same signal
effect(() => {
  count(count() + 1); // Triggers itself infinitely
});

// ✅ Use untracked to read without creating dependency
effect(() => {
  const current = untracked(() => count());
  console.log(`Count: ${current}`);
});
```
