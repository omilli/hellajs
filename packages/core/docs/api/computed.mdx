# computed

Read-only value that automatically updates when dependencies change.

## Basic Usage

Values update automatically when any of their dependencies change.

```typescript
import { signal, computed } from '@hellajs/core';

const firstName = signal("John");
const lastName = signal("Doe");
const fullName = computed(() => `${firstName()} ${lastName()}`);

console.log(fullName()); // "John Doe"

firstName("Jane");

console.log(fullName()); // "Jane Doe"
```

## API

```typescript
function computed<T>(computedFn: (previousValue?: T) => T): () => T

// With an equality override
function computed<T>(
  computedFn: (previousValue?: T) => T,
  options: EqualsOptions<T>
): () => T
```
- `computedFn`: The function to compute the derived value. Receives `previousValue` (the last computed result) as an optional argument.
- `previousValue`: The previously computed value. `undefined` on the first call. Useful for incremental calculations.
- `options`: An optional `{ equals }` comparator that replaces the default result check (`===`, with `NaN` equal to itself).
- **Returns**: A read-only getter function

## Key Concepts

### Previous Value

Receives the previously computed value as its only (optional) argument.

```typescript
import { signal, computed } from '@hellajs/core';

const items = signal<number[]>([]);

const total = computed<{ sum: number; count: number }>((prev = { sum: 0, count: 0 }) => {
  const currentItems = items();

  // Only process new items since last computation
  const newItems = currentItems.slice(prev.count);
  const additionalSum = newItems.reduce((sum, item) => sum + item, 0);

  return {
    sum: prev.sum + additionalSum,
    count: currentItems.length,
  };
});

items([10, 20]);
console.log(total().sum); // 30

items([10, 20, 15]);
console.log(total().sum); // 45 (incrementally calculated)
```

### Result Comparison

Reference equality (`===`) prevents propagation when a value is unchanged.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const count = signal(1);
const doubled = computed(() => count() * 2);

effect(() => {
  console.log('Effect:', doubled());
});

// Triggers the effect - value changed from 2 to 4
count(2);  // Logs: "Effect: 4"

// Same result (4) - no recomputation, no effect triggered
count(2);  // Nothing logged
```

New object or array references always trigger updates, even with identical content.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const items = signal([1, 2, 3]);

// Every call creates a new array reference, so effects always run
const doubled = computed(() => items().map(value => value * 2));

effect(() => {
  console.log('Effect:', doubled());
});

items([2, 4, 6]);  // Logs: "Effect: [4, 8, 12]"
items([2, 4, 6]);  // Logs: "Effect: [4, 8, 12]" again (new array reference)
```

### Custom Equality

The `equals` option replaces the default equality check on the recomputed result (`===`, with `NaN` equal to itself). When it returns `true`, the old reference is kept and downstream subscribers are not notified; the recomputation itself still runs.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const items = signal([1, 2, 3]);
const doubled = computed(() => items().map(value => value * 2), {
  equals: (a, b) => a.length === b.length && a.every((v, i) => v === b[i])
});

effect(() => console.log('Effect:', doubled()));

items([1, 2, 3]); // Recomputes to equal content: no effect triggered
items([4]);       // Different content: effect logs "Effect: [8]"
```

The comparator is skipped on the first evaluation, when the previous value is still `undefined`; the default check applies there.

### Lazy Evaluation

Computed values recalculate only when read, not when dependencies change. The result is cached until a dependency actually changes.

```typescript
import { signal, computed } from '@hellajs/core';

const count = signal(0);
const doubled = computed(() => {
  // This function only runs when doubled() is called
  // and count has changed since last read
  return count() * 2;
});

// Changing count does NOT trigger recomputation yet
count(1);

// Reading triggers one recomputation
console.log(doubled()); // 2

// Cached: no recomputation on repeated reads
console.log(doubled()); // 2 (cached, function not called)
```

### Computation Chaining
Values can depend on other computed values.

```typescript
import { signal, computed } from '@hellajs/core';

const price = signal(100);
const quantity = signal(2);

const subtotal = computed(() => price() * quantity());
const tax = computed(() => subtotal() * 0.07); // 7% tax
const total = computed(() => subtotal() + tax());

console.log(total()); // 214

quantity(3);
console.log(total()); // 321
```

### Conditional Dependencies
Depends only on signals read during the ***last*** execution.

```typescript
import { signal, computed } from '@hellajs/core';

const showAdvanced = signal(false);
const basic = signal('basic');
const advanced = signal('advanced');

const setting = computed(() => {
  if (showAdvanced()) {
    return `Advanced: ${advanced()}`;
  }
  return `Basic: ${basic()}`;
});

// Initially, `setting` only depends on `showAdvanced` and `basic`.
// Changing `advanced` will not trigger a re-computation.
advanced('new advanced'); 
console.log(setting()); // "Basic: basic"

// After this, `setting` depends on `showAdvanced` and `advanced`.
showAdvanced(true);
console.log(setting()); // "Advanced: new advanced"
```

## Important Considerations

### Avoid Side Effects

Should not have side effects. Use [`effect`](/reference/core/effect) instead.

```typescript
import { signal, computed } from '@hellajs/core';

const count = signal(1);

// ❌ Side effects in computed
const result = computed(() => {
  fetch('/api/data');
  return count() * 2;
});

// ✅ Pure computation
const doubled = computed(() => count() * 2);
```

### Async Getters Cache the Promise

The getter must be synchronous. An `async` getter returns a pending Promise at its first `await`, and that Promise becomes the cached value: subscribers receive the Promise, never the resolved payload. Signal reads after the first `await` also subscribe nothing, so the derivation never updates. Keep the getter synchronous; move async work into an [`effect`](/reference/core/effect) that writes a signal when it resolves.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const userId = signal(1);
const profile = signal<{ name: string } | undefined>(undefined);

// ❌ async getter: the cached value is the Promise itself, and reads
// after the first await are untracked
const badProfile = computed(async () => {
  const res = await fetch(`/api/users/${userId()}`);
  return res.json();
});

// ✅ sync derivation over signal state written by an effect
const profileLabel = computed(() => profile()?.name ?? 'guest');

effect(() => {
  const id = userId(); // tracked: the fetch re-runs when id changes
  fetch(`/api/users/${id}`)
    .then(res => res.json())
    .then(data => profile(data));
});
```

### Auto-GC

A [`computed`](/reference/core/computed) with no subscribers releases its dependencies and is marked for lazy recomputation. When a new subscriber reads the value, the dependency graph is rebuilt and the value recomputed on demand.

```typescript
import { signal, computed, effect } from '@hellajs/core';

const source = signal(1);
const doubled = computed(() => source() * 10);

const cleanup1 = effect(() => doubled());
console.log(doubled()); // 10

cleanup1(); // doubled has no subscribers: dependencies released, marked DIRTY

source(2); // doubled is not notified: no propagation

const cleanup2 = effect(() => doubled());
console.log(doubled()); // 20 (graph rebuilt, recomputed)
```

### Error Recovery

A throw inside the getter marks the computed for re-execution before the error escapes: every later read re-runs the getter and rethrows (no silent `undefined`, no stale cached value). Only the dependencies read before the throw survive; reads after the throw point are pruned. Handle expected failures inside the getter so every read returns a usable value:

```typescript
import { signal, computed } from '@hellajs/core';

const raw = signal('{"n":1}');

const parsed = computed(() => {
  try {
    return JSON.parse(raw()) as { n: number };
  } catch {
    return { n: 0 }; // fallback: every read stays usable, tracking preserved
  }
});

raw('not json');
console.log(parsed().n); // 0
```

Reserve read-site handling for errors no fallback can absorb. An unhandled throw retries the getter on every read until a dependency change allows success; the next successful read rebuilds tracking:

```typescript
import { signal, computed } from '@hellajs/core';

const shouldThrow = signal(true);
const data = signal(10);

const badComputed = computed(() => {
  if (shouldThrow()) throw new Error('fail');
  return data() * 2;
});

// First read throws - no dependencies tracked
try {
  badComputed(); // Throws: Error 'fail'
} catch {}

// Unchanged deps: the read retries the computation and rethrows
try {
  badComputed(); // Throws again: Error 'fail'
} catch {}

shouldThrow(false);
// Re-execution after recovery tracks dependencies correctly
console.log(badComputed()); // 20

data(5); // Computed updates because data is now a dependency
console.log(badComputed()); // 10
```
