# batch

Groups [`signal`](/reference/core/signal) updates into a single [`effect`](/reference/core/effect) run.

## API

```typescript
function batch<T>(batchFn: () => T): T
```

- `batchFn`: Contains the [signal](/reference/core/signal) updates to be batched
- **Returns**: The value returned by the function `batchFn`

## Basic Usage

All updates are grouped and any corresponding [`effect`](/reference/core/effect) runs only once.

```typescript
import { signal, batch, effect } from "@hellajs/core";

const count = signal(1);
const multiplier = signal(2);

effect(() => {
  console.log(count() * multiplier());
});

batch(() => {
  count(2); // Effect doesn't run yet
  multiplier(3); // Effect doesn't run yet
});

// Effect runs once and logs 6
```

## Key Concepts

### Batch Boundaries

Only applies to synchronous [`signal`](/reference/core/signal) updates. Async operations execute outside the boundary.

```typescript
import { signal, batch, effect } from "@hellajs/core";

const count = signal(1);
const multiplier = signal(2);

effect(() => {
  console.log(count() * multiplier());
});

batch(() => {
  setTimeout(() => multiplier(3), 0); // Not batched: runs after batch completes
  count(2); // Batched
});

// Effect runs once during batch (logs 4: count(2) * multiplier(2))
// Then setTimeout fires, triggering another run (logs 6: count(2) * multiplier(3))
```

### Nested Batching

Effects only run once the outermost `batch` completes, regardless of nesting depth.

```typescript
import { signal, batch, effect } from "@hellajs/core";

const count = signal(0);
const multiplier = signal(1);

effect(() => {
  console.log(count() * multiplier());
});

function innerUpdate() {
  batch(() => {
    count(2);
    multiplier(2);
  });
}

batch(() => {
  count(1);       // count -> 1
  innerUpdate();  // count -> 2, multiplier -> 2
  multiplier(3);  // overwrite multiplier -> 3
});

// Effect runs once and logs 6
```
