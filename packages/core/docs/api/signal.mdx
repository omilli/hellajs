# signal

Holds a value and notifies dependents when the value changes.

## API

```typescript
// The Signal type: a getter/setter function
type Signal<T> = {
  (): T; // getter
  (value: T): void; // setter
};

// With an initial value
function signal<T>(initialValue: T): Signal<T>;

// Without an initial value
function signal<T>(): Signal<T | undefined>;

// With an equality override
function signal<T>(initialValue: T, options: EqualsOptions<T>): Signal<T>;
```
- `initialValue`: The initial value for the signal. Omit to start as `undefined`.
- `options`: An optional `{ equals }` comparator that replaces the default equality check (`===`, with `NaN` equal to itself). Pass `signal(undefined, { equals })` to combine a comparator with no initial value.
- **Returns**: A `Signal<T>` function that gets the value when called with no arguments, or sets the value when called with an argument. Importable as `import type { Signal } from '@hellajs/core'` for typing function parameters.

## Basic Usage

Create signals and read values.

```typescript
import { signal } from '@hellajs/core';

// Create a signal with an initial value
const count = signal(0);

// Read the current value
console.log(count()); // 0

// Update the value  
count(5);
console.log(count()); // 5
```

## Key Concepts

### Reactive Links
Signals create reactive links when accessed inside other reactive contexts like [`computed`](/reference/core/computed) or [`effect`](/reference/core/effect).

```typescript
import { signal, computed, effect } from '@hellajs/core';

const count = signal(0);

// The computed automatically tracks the signal
const doubled = computed(() => count() * 2);

// The effect runs when count changes
effect(() => {
  console.log(`Count is: ${count()}, Doubled: ${doubled()}`);
});

count(5); // Triggers both the computed and effect
```

### Value Comparison

Reference equality (`===`) prevents propagation when a value is the same.

```typescript
import { signal, effect } from '@hellajs/core';

const name = signal('Alice');

effect(() => console.log('Effect triggered:', name()));

name('Alice'); // No effect triggered - same value
name('Bob');   // Effect triggered - different value
```

`NaN` is self-equal under the default equality: writing `NaN` to a signal that already holds `NaN` is treated as unchanged and skips propagation. Transitions to or from `NaN` still propagate.

```typescript
import { signal, effect } from '@hellajs/core';

const count = signal(NaN);

effect(() => console.log('Effect triggered:', count()));

count(NaN); // No effect triggered - NaN is self-equal
count(1);   // Effect triggered - different value
```

### Custom Equality

The `equals` option replaces the default reference check. When it returns `true`, the write is skipped entirely: the value, the old reference, and all subscriptions stay untouched.

```typescript
import { signal, effect } from '@hellajs/core';

const todos = signal([{ id: 1, done: false }], {
  equals: (a, b) => a.length === b.length && a.every((t, i) => t.id === b[i].id)
});

const stable = todos();
todos([{ id: 1, done: false }]); // Content-equal by id: write skipped
console.log(todos() === stable); // true - the old reference is kept

effect(() => console.log('Todos changed:', todos()));

todos([{ id: 1, done: true }]); // Different content: effect triggered
```

An equal write keeps the old reference, so consumers comparing by identity never see a rejected value.

`NaN` needs no comparator — the default already treats it as self-equal. Use `Object.is` as `equals` only to also distinguish `+0` from `-0`; under the default they compare equal.

The comparator receives the freshest stored value, and `{ equals: undefined }` behaves as no options.

## Important Considerations

### Direct Mutation

Mutating objects or arrays stored in signals prevents reactivity. Create a new reference instead.

```typescript
import { signal } from '@hellajs/core';

const todos = signal([{ id: 1, text: 'Learn HellaJS' }]);

// ❌ Direct mutation - no updates triggered
todos()[0].text = 'Learn Signals';

// ✅ Create new reference to trigger updates
todos(todos().map(todo => 
  todo.id === 1 ? { ...todo, text: 'Learn Signals' } : todo
));
```
