# scope

Batch-collect multiple [`effect`](/reference/core/effect) functions for a single cleanup.

## API

```typescript
function scope(fn: () => void): () => void
```
- `fn`: All [`effect`](/reference/core/effect) functions created during execution are collected
- **Returns**: A cleanup function that disposes all collected effects

## Basic Usage

Run multiple [`effect`](/reference/core/effect) cleanup functions at once.

```typescript
import { signal, effect, scope } from '@hellajs/core';

const count = signal(0);

const dispose = scope(() => {
  effect(() => console.log(`Count: ${count()}`));
  effect(() => console.log(`Doubled: ${count() * 2}`));
});

count(5); // Logs: "Count: 5" and "Doubled: 10"

dispose(); // Stops both effects
count(10); // Nothing logged
```

## Key Concepts

### Nested Scopes

Scopes can be nested, with each scope managing its own set of [`effect`](/reference/core/effect) functions independently.
```typescript
import { signal, effect, scope } from '@hellajs/core';

const value = signal(0);

const disposeOuter = scope(() => {
  effect(() => console.log(`Outer: ${value()}`));

  const disposeInner = scope(() => {
    effect(() => console.log(`Inner: ${value()}`));
  });

  // Inner scope can be disposed independently
  value(1); // Logs: "Outer: 1" and "Inner: 1"

  disposeInner();
  value(2); // Logs: "Outer: 2" only (inner stopped)
});

disposeOuter();
value(3); // Nothing logged (both stopped)
```

### Lazy Scopes

A scope without [`effect`](/reference/core/effect) functions returns a cleanup function that does nothing.

```typescript
import { scope } from '@hellajs/core';

const dispose = scope(() => {
  // No effects created
  const value = 42;
});

dispose(); // Safe to call, does nothing
```

## Important Considerations

### Multiple Cleanup Calls

Calling the cleanup function multiple times is safe.

```typescript
import { signal, effect, scope } from '@hellajs/core';

const count = signal(0);

const dispose = scope(() => {
  effect(() => console.log(count()));
});

dispose(); // Stops effects
dispose(); // Safe, does nothing
dispose(); // Safe, does nothing
```

### Effects Outside Scope

Only [`effect`](/reference/core/effect) functions created **within** the scope callback are collected.

```typescript
import { signal, effect, scope } from '@hellajs/core';

const count = signal(0);

// Outside scope
const cleanupUnscoped = effect(() => console.log(`Unscoped: ${count()}`));

const disposeScope = scope(() => {
  effect(() => console.log(`Scoped: ${count()}`));
});

count(1); // Both effects run

disposeScope();
count(2); // Only unscoped effect runs

cleanupUnscoped();
```

### Effect Only Cleanup

[`signal`](/reference/core/signal) and [`computed`](/reference/core/computed) values created within a scope are **not** disposed when the scope is cleaned up.

```typescript
import { signal, computed, effect, scope } from '@hellajs/core';

const count = signal(0);
const doubled = computed(() => count() * 2);

const dispose = scope(() => {
  effect(() => console.log(`Doubled: ${doubled()}`));
});

console.log(doubled()); // 0

count(1); // Logs: "Doubled: 2"

dispose();

// Computed still works after scope disposal - only the effect is stopped
count(5);
console.log(doubled()); // 10 (computed value still accessible)
```
