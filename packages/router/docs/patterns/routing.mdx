
# Routing

Short, copy-pasteable code patterns for common routing tasks with [`router`](/reference/router/router), [`navigate`](/reference/router/navigate), and [`route`](/reference/router/route).

### Basic Route Setup

Map URL patterns to handlers that update a signal. Each handler runs when its pattern matches the current path.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const HomePage = () => <div>Home</div>;
const AboutPage = () => <div>About</div>;
const UserProfile = ({ id }: { id?: string }) => <div>User {id}</div>;
const NotFound = () => <div>Not found</div>;
const DashboardLayout = () => <div>Dashboard</div>;
const Overview = () => <div>Overview</div>;
const UserDetail = ({ id }: { id?: string }) => <div>User {id}</div>;
const SearchResults = ({ term, sort }: { term?: string; sort?: string }) => (
  <div>Results for {term} (sorted by {sort})</div>
);
const Feed = () => <div>Feed</div>;
const Settings = () => <div>Settings</div>;
const Chat = () => <div>Chat</div>;
const Docs = ({ path }: { path?: string }) => <div>Docs {path}</div>;
const Users = () => <div>Users</div>;
const Profile = ({ id }: { id?: string }) => <div>Profile {id}</div>;
const currentView = signal(<div>Loading…</div>);

router({
  routes: {
    '/': () => currentView(<HomePage />),
    '/about': () => currentView(<AboutPage />),
    '/users/:id': (params) => currentView(<UserProfile id={params.id} />)
  },
  notFound: () => currentView(<NotFound />)
});
```

### 404 Page

The `notFound` handler runs when no route matches. Accepts a function or a redirect string.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

// Function handler
router({
  routes: { '/': () => currentView(<HomePage />) },
  notFound: () => currentView(<NotFound />)
});

// String redirect
router({
  routes: {
    '/': () => currentView(<HomePage />),
    '/404': () => currentView(<NotFound />)
  },
  notFound: '/404'
});
```

### Auth Guard

Use a `before` hook to block unauthenticated access by returning `false`. No handler-level guard needed for sync checks.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const LoginPage = () => <div>Login</div>;
const Dashboard = ({ user }: { user?: unknown }) => <div>Dashboard</div>;

const user = signal<{ name: string } | null>(null);
const currentView = signal(<div>Loading</div>);

router({
  routes: {
    '/login': () => currentView(<LoginPage />),
    '/dashboard': {
      before: () => {
        if (!user()) return false;
      },
      handler: () => {
        currentView(<Dashboard user={user()} />);
      }
    }
  }
});
```

To redirect to login instead:

```jsx
router({
  routes: {
    '/dashboard': {
      before: () => {
        if (!user()) return '/login';
      },
      handler: () => {
        currentView(<Dashboard user={user()} />);
      }
    }
  }
});
```

Async guards cannot block — guard the handler too:

```jsx
router({
  routes: {
    '/dashboard': {
      before: async () => {
        if (!user()) await navigate('/login');
      },
      handler: () => {
        if (!user()) return;
        currentView(<Dashboard user={user()} />);
      }
    }
  }
});
```

### Nested Routes

Organize routes hierarchically with `children`. Child routes inherit all parent parameters automatically.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

router({
  routes: {
    '/dashboard': {
      handler: () => currentView(<DashboardLayout />),
      children: {
        '/overview': () => currentView(<Overview />),
        '/users/:id': (params) => currentView(<UserDetail id={params.id} />)
      }
    }
  }
});
// /dashboard → DashboardLayout
// /dashboard/overview → Overview
// /dashboard/users/42 → UserDetail (params.id = '42')
```

### Query Parameter Handling

Query parameters are parsed automatically and passed as the second argument. Pass query strings with the `query` option in [`navigate`](/reference/router/navigate).

```jsx
import { router, navigate } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

router({
  routes: {
    '/search': (params, query) => {
      currentView(<SearchResults term={query.q} sort={query.sort} />);
    }
  }
});

// Navigate with query → /search?q=hello&sort=date
navigate('/search', { query: { q: 'hello', sort: 'date' } });
```

### Redirect

String values in the routes object act as redirects. Use the `redirects` array to map multiple sources to one destination.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

router({
  routes: {
    '/': () => currentView(<HomePage />),
    '/home': '/',
    '/old-about': '/about',
    '/about': () => currentView(<AboutPage />)
  },
  redirects: [
    { from: ['/tasks', '/items'], to: '/todos' }
  ]
});
```

### Scroll Behavior

Control scroll position at three levels: global default, route-level override, and inline per-navigation. Priority: inline > route > global.

```jsx
import { router, navigate } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

router({
  scrollBehavior: 'top',
  routes: {
    '/feed': {
      scroll: 'preserve',
      handler: () => currentView(<Feed />)
    },
    '/chat': {
      scroll: false,
      handler: () => currentView(<Chat />)
    },
    '/docs/*': {
      scroll: (to, from) => ({ top: 80 }),
      handler: (params) => currentView(<Docs path={params['*']} />)
    }
  }
});

// Inline override (highest priority)
navigate('/long-page', { scroll: 'top' });
```

### SPA Link Interception

Same-origin `<a href>` clicks are intercepted by default and routed through `navigate()` — no special handling needed.

```jsx
import { router } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

// Plain <a> tags work out of the box
router({
  routes: {
    '/': () => currentView(<HomePage />),
    '/about': () => currentView(<AboutPage />)
  }
});
```

For hybrid SPA + MPA apps, disable interception:

```jsx
router({
  routes: { '/': () => currentView(<HomePage />) },
  intercept: false
});
```

### Active Links

Use [`route`](/reference/router/route)`().active()` to highlight the current section in a nav bar. The predicate uses ancestor semantics — a parent link stays lit while a child route is active.

```jsx
import { router, route, navigate } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

router({
  routes: {
    '/dashboard': () => currentView(<Dashboard />),
    '/dashboard/users': () => currentView(<Users />),
    '/dashboard/settings': () => currentView(<Settings />)
  }
});

const navItems = [
  { path: '/dashboard', label: 'Dashboard' },
  { path: '/dashboard/users', label: 'Users' },
  { path: '/dashboard/settings', label: 'Settings' }
];

// active() reads route().path reactively
<nav>
  {navItems.map(item => (
    <a
      href={item.path}
      class={route().active(item.path) ? 'active' : ''}
    >
      {item.label}
    </a>
  ))}
</nav>
```

### Breadcrumbs

Render a breadcrumb trail from [`route`](/reference/router/route)`().crumbs`. Each crumb's `path` is a linkable href; `segment` keys into a label dictionary.

```jsx
import { router, route, navigate } from '@hellajs/router';
import { signal } from '@hellajs/core';

const currentView = signal(<div>Loading…</div>);

const labels: Record<string, string> = {
  '/admin': 'Admin',
  '/admin/users': 'Users',
  '/admin/users/:id': 'Profile'
};

router({
  routes: {
    '/admin': {
      children: {
        '/users': {
          children: {
            '/:id': ({ id }) => currentView(<Profile id={id} />)
          }
        }
      }
    }
  }
});

// crumbs is parent-to-leaf; each crumb.path is a valid href
<ol class="breadcrumbs">
  {route().crumbs.map(crumb => (
    <li>
      <a href={crumb.path} on:click={(e) => {
        e.preventDefault();
        navigate(crumb.path);
      }}>
        {labels[crumb.segment] || crumb.segment}
      </a>
    </li>
  ))}
</ol>
```
