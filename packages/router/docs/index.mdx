## Router

Client-side routing with nested routes, lifecycle hooks, and automatic parameter inheritance. Declarative route configuration with strict resolution order and History API integration.

### Installation

```bash
npm install @hellajs/core @hellajs/router
```

### Example

```jsx
import { mount } from '@hellajs/dom';
import { router, navigate } from '@hellajs/router';

mount(<>Loading...</>);

router({
  routes: {
    '/': () => mount(<HomePage />),
    '/users/:id': (params) => mount(<UserProfile id={params.id} />),
    '/settings': {
      before: () => checkAuth(), // Guard route with authentication
      handler: () => mount(<Settings />)
    }
  },
  notFound: () => mount(<NotFoundPage />)
});

// Programmatic navigation
navigate('/users/123');
navigate('/settings');
```
