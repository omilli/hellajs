# route

A reactive signal containing current route information including path, parameters, query, and handler.

## API

```typescript
function route(): RouteInfo

interface RouteInfo {
  path: string;
  params: Record<string, string>;
  query: Record<string, string>;
  handler: Handler | null;
  meta?: Record<string, unknown>;
}
```

## Basic Usage

Access the `route` signal inside a reactive context to get the current path, parameters, and query string.

```typescript
import { effect } from '@hellajs/core';
import { route } from '@hellajs/router';

effect(() => {
  const { path, params, query } = route();
  
  console.log(`Current path: ${path}`);
  
  if (params.id) {
    console.log(`User ID from params: ${params.id}`);
  }
  
  if (query.sort) {
    console.log(`Sort order from query: ${query.sort}`);
  }
});
```

## Key Concepts

### Reactive Signal

`route()` is a reactive signal that automatically updates when the current route changes, triggering any dependent computations or effects.

```typescript
effect(() => {
  console.log('Route changed to:', route().path);
  // This runs automatically when navigation occurs
});
```

### Route Information

Provides comprehensive route data including the current path, extracted parameters from route patterns, parsed query string values, and optional route metadata. Parameters automatically include inheritance from parent routes in nested structures.

```typescript
// For URL: /users/123?sort=name&page=2 (flat route)
const { path, params, query } = route();
// path: "/users/123?sort=name&page=2"
// params: { id: "123" }
// query: { sort: "name", page: "2" }

// For URL: /admin/users/123/edit (nested route with inheritance)
// Router config: /admin -> /users -> /:id -> /edit
const { path, params, query } = route();
// path: "/admin/users/123/edit"
// params: { id: "123" } (inherited from parent route)
// query: {}
```

### Route Metadata

Access metadata defined on the matched route via the `meta` property.

```typescript
// Router config with meta
router({
  routes: {
    '/about': {
      meta: { title: 'About Us', section: 'info' },
      handler: () => showAbout()
    }
  }
});

// Access in effects or components
effect(() => {
  const { meta } = route();
  document.title = meta?.title || 'My App';
});
```

### Handler Reference

Contains a reference to the active route handler function. This is useful for inspecting which handler is active; avoid calling it manually since the router already executes handlers during route resolution.

```typescript
effect(() => {
  const { handler } = route();
  // Use for inspection, conditional logic, or debug logging
  if (handler) {
    console.log('Active route handler:', handler.name);
  }
});
```

## Important Considerations

### Destructuring for Clarity

Destructure route data once at the start of effects for cleaner code.

```typescript
// ✅ Destructure once for cleaner code
effect(() => {
  const { path, params, query } = route();
  console.log('Route changed:', path);
  console.log('Route params:', params);
  console.log('Route query:', query);
});

// ✅ Use computed for derived values used in multiple places
const currentPath = computed(() => route().path);
const routeParams = computed(() => route().params);
const hasQueryParams = computed(() => Object.keys(route().query).length > 0);
```

### Route Parsing

Parameters and query values are always strings - cast to other types as needed.

```typescript
// ✅ Cast values as needed
const { params, query } = route();
const userId = parseInt(params.id);
const page = parseInt(query.page) || 1;
```

### Handler Availability

The `handler` property is `null` when no route matches and no `notFound` handler is configured.

```typescript
// ✅ Check handler exists before calling
effect(() => {
  const { handler } = route();
  if (handler) {
    // Handler exists and can be called
    handler();
  }
});
```
