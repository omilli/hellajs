# onEscape

Calls a handler when an Escape keydown fires on a target, returning the dispose handle that removes the listener.

## API

```typescript
function onEscape(
  target: Node | Window,
  handler: () => void
): () => void
```

- `target`: Node or window receiving the keydown. The listener fires for Escape keydowns on the target and anything bubbling into it.
- `handler`: Zero-argument callback fired on Escape.
- **Returns**: Dispose handle. Calling it removes the keydown listener.

## Basic Usage

```jsx
import { mount } from "@hellajs/dom";
import { onEscape } from "@hellajs/primitives";

let dismiss: (() => void) | undefined;

const Panel = () => (
  <div
    hook:afterMount={(node) => {
      if (node instanceof HTMLElement) dismiss = onEscape(node, () => node.remove());
    }}
    hook:beforeDestroy={() => dismiss?.()}
  >
    Press Escape while focus is inside this panel to remove it
  </div>
);

mount(<Panel />, "#app");
```

## Key Concepts

### Escape Only

The handler fires for `key === "Escape"` and nothing else; every other key is ignored without touching default behavior.

### Pairs with onOutside

Escape covers the keyboard close gesture; [`onOutside`](/reference/primitives/onoutside) covers the pointer gesture. A dismissible panel wires both on the same node and disposes both on close:

```jsx
import { mount } from "@hellajs/dom";
import { onEscape, onOutside } from "@hellajs/primitives";

const dismissals: (() => void)[] = [];
const close = () => {
  dismissals.forEach((dispose) => dispose());
  dismissals.length = 0;
};

const Panel = () => (
  <div
    hook:afterMount={(node) => {
      if (!(node instanceof HTMLElement)) return;
      dismissals.push(onEscape(node, close), onOutside(() => [node], close));
    }}
    hook:beforeDestroy={close}
  >
    <button on:click={close}>Close</button>
  </div>
);

mount(<Panel />, "#app");
```

## Important Considerations

### Dispose With the Feature

The listener attaches to the target for as long as the wiring lives. A component that unmounts must call the dispose handle in its cleanup path, or the handler keeps firing on a detached tree.

### Input Validation

`onEscape()` throws when `target` or `handler` is `null` or `undefined`: `[primitives] onEscape: target is required`, `[primitives] onEscape: handler is required`.

```typescript
// ❌ Throws
onEscape(null, () => {}); // [primitives] onEscape: target is required
```
