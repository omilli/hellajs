# Build a Blog App

Build a post browsing app with search, pagination, post details, and user profiles, powered by [store](/reference/store/store), [router](/reference/router/router), and [resource](/reference/resource/resource) working together.

Jump to the [Complete Code](#complete-code) for the finished application.

## What You'll Learn

- **[store](/reference/store/store)**: Centralized app state with granular reactive properties
- **[resource](/reference/resource/resource)**: Async data fetching with caching and explicit fetch control
- **[router](/reference/router/router)**: Client-side routing with params, query strings, and scroll behavior
- **[signal](/reference/core/signal)**: Reactive values for view state and page titles
- **[computed](/reference/core/computed)**: Derived pagination state from resource data
- **[style](/reference/css/style) / [vars](/reference/css/vars)**: Design tokens and scoped hashed classes
- **[ForEach](/reference/dom/foreach)**: Rendering lists with keyed reconciliation
- **[navigate](/reference/router/navigate)**: Programmatic navigation with params and query strings

The core pattern: router handlers set store signals and render page components into a view [signal](/reference/core/signal). Page components call `fetch()` on their resources to load data. Components dispatch navigation via [navigate](/reference/router/navigate).

## App State

This app uses [store](/reference/store/store) for centralized state and [resource](/reference/resource/resource) for data fetching. The store holds the search query, page number, and selected IDs. Resources derive their cache keys from store signals.

Create `src/state.ts`:

```tsx
// src/state.ts
import { store } from "@hellajs/store";
import { resource } from "@hellajs/resource";

export interface Post {
  id: number;
  title: string;
  body: string;
  tags: string[];
  reactions: { likes: number; dislikes: number };
  views: number;
  userId: number;
  message?: string;
}

interface PostsResponse {
  posts: Post[];
  total: number;
  skip: number;
  limit: number;
}

interface User {
  id: number;
  firstName: string;
  lastName: string;
  email: string;
  image: string;
  company: { title: string; name: string; department: string };
  message?: string;
}

export const appStore = store({
  searchValue: "",
  page: 1,
  postId: "",
  userId: "",
});

const BASE = "https://dummyjson.com";

const cacheTime = 300000; // 5 minutes

export const postsResource = resource<PostsResponse, string>(
  (urlPath) => fetch(`${BASE}/${urlPath}`).then(r => r.json()),
  {
    key: () => {
      const search = appStore.searchValue();
      const skip = (appStore.page() - 1) * 10;
      const base = search ? "posts/search" : "posts";
      const params = new URLSearchParams({ limit: "10", skip: String(skip) });
      if (search) params.set("q", search);
      return `${base}?${params}`;
    },
    staleTime: 30000,
    cacheTime,
  }
);

export const postResource = resource<Post, string>(
  (id) => fetch(`${BASE}/posts/${id}`).then(r => r.json()),
  { key: () => appStore.postId(), cacheTime, }
);

export const userResource = resource<User, string>(
  (id) => fetch(`${BASE}/users/${id}`).then(r => r.json()),
  { key: () => appStore.userId(), cacheTime, }
);

export const userPostsResource = resource<PostsResponse, string>(
  (id) => fetch(`${BASE}/users/${id}/posts`).then(r => r.json()),
  { key: () => appStore.userId(), cacheTime, }
);
```

**Code Explanation**

- **[`store`](/reference/store/store)`({ ... })`**: Creates a deeply reactive store where each property is an independent signal
- **`searchValue` and `page`**: Drive the posts list API query. Changing either produces a new cache key for `postsResource`
- **`postId` and `userId`**: Selected items for detail and profile views
- **`BASE`**: The DummyJSON API base URL
- **[`resource`](/reference/resource/resource)`(fetcher, { key, ... })`**: Creates a reactive async data container with a key function for caching
- **`key: () => ...`**: A function reading store signals. Produces a cache key for deduplication and caching
- **`postsResource`**: Key encodes search query and page number. Returns the full URL path as the cache key
- **`staleTime: 30000`**: Data stays fresh for 30 seconds. Subsequent fetches within that window return cached data instantly
- **`cacheTime: 300000`**: Cached data persists for 5 minutes in memory

## Shared Styles

Define reusable design tokens with [`vars`](/reference/css/vars) and shared styles with [`css`](/reference/css/css) + [`style`](/reference/css/style). Each component file adds its own `style()` call for component-specific styles.

Create `src/theme.ts`:

```tsx
// src/theme.ts
import { css, style, vars } from "@hellajs/css";

export const theme = vars({
  color: {
    bg: "#f5f5f5",
    surface: "#fff",
    border: "#e0e0e0",
    text: "#333",
    muted: "#555",
    subtle: "#888",
    link: "#2563eb",
    tag: "#e8e8e8",
  },
  radius: {
    sm: "0.375rem",
    md: "0.5rem",
    pill: "1rem",
  },
});

css({
  body: {
    margin: 0,
    fontFamily: "sans-serif",
    backgroundColor: theme.color.bg,
    color: theme.color.text,
  },
});

// Shared card styles — composed by PostCard via style(card, ...) and consumed
// directly by UserProfile.
export const card = style({
  backgroundColor: theme.color.surface,
  borderRadius: theme.radius.md,
  padding: "1rem",
  marginBottom: "0.75rem",
  border: `1px solid ${theme.color.border}`,
}, { label: "card" });

export const cardTitle = style({
  fontSize: "1.1rem",
  fontWeight: 600,
  margin: "0 0 0.5rem",
}, { label: "card-title" });

export const cardBody = style({
  color: theme.color.muted,
  fontSize: "0.9rem",
  lineHeight: 1.5,
}, { label: "card-body" });
```

**Code Explanation**

- **[`vars`](/reference/css/vars)`({ ... })`**: Creates CSS custom properties. Returns an object where each value is a `var()` reference
- **`theme.color.surface`**: Resolves to `var(--color-surface)`. Use it anywhere you'd use a CSS value
- **Nested objects**: `color: { bg: "..." }` becomes `--color-bg`. Dots become hyphens in the variable name
- **[`css`](/reference/css/css)`({ body: { ... } })`**: Registers global element selectors
- **[`style`](/reference/css/style)`({ ... }, { label })`**: Returns a content-hashed class for `class={card}` — `label` embeds a readable segment in the name. Export the classes shared across files (`card`, `cardTitle`, `cardBody`); PostCard composes onto `card` later

## Entry Point

The entry point wires everything together. Two [signals](/reference/core/signal) hold the page title and the rendered view. The [router](/reference/router/router) maps URL patterns to handlers that set store signals and render page components. An [effect](/reference/core/effect) keeps the document title in sync.

Create `src/main.tsx`:

```tsx
// src/main.tsx
import { effect, signal } from "@hellajs/core";
import { style } from "@hellajs/css";
import { mount } from "@hellajs/dom";
import { router } from "@hellajs/router";
import { appStore } from "./state.ts";
import "./theme.ts";
import { Placeholder } from "./components/Placeholder.tsx";
import { PostDetail } from "./pages/PostDetail.tsx";
import { UserProfile } from "./pages/UserProfile.tsx";
import { PostList } from "./pages/PostList.tsx";

const title = signal("");
const view = signal(<Placeholder message="Loading..." />);

effect(() => document.title = `Blog - ${title}`);

router({
  scrollBehavior: 'top',
  routes: {
    "/": "/posts",
    "/posts": (_params, query) => {
      appStore.page(query.page ? Number(query.page) : 1);
      view(PostList());
      title("Posts");
    },
    "/posts/:id": ({ id }) => {
      appStore.postId(id);
      view(PostDetail());
      title(`Post ${id}`);
    },
    "/users/:id": ({ id }) => {
      appStore.userId(id);
      view(UserProfile());
      title(`User ${id}`);
    },
  },
  notFound: () => view(PostList()),
});

const appContainer = style({
  maxWidth: "48rem",
  margin: "0 auto",
  padding: "1rem",
}, { label: "app-container" });

const appTitle = style({
  fontSize: "1.5rem",
}, { label: "app-title" });

const App = <div class={appContainer}>
  <h1 class={appTitle}>{title}</h1>
  {view}
</div>;

mount(App, "#app");
```

**Code Explanation**

- **[`signal`](/reference/core/signal)`("")`**: Creates a reactive value. `title` holds the page heading, `view` holds the rendered DOM for the current page
- **[`effect`](/reference/core/effect)`(() => ...)`**: Reacts to `title()` changes and updates the document title
- **[`router`](/reference/router/router)`({ routes, ... })`**: Maps URL patterns to handler functions
- **`"/": "/posts"`**: Redirect from root to `/posts`
- **`"/posts": (_params, query) => ...`**: The second argument `query` provides query string parameters. Used here to read the `page` param
- **[`appStore.page`](/reference/store/store)`(query.page ? Number(query.page) : 1)`**: Sets the page from the URL, defaulting to 1
- **[`signal`](/reference/core/signal)` `view` `(PostList())`**: Renders the PostList component into the view signal. The component is evaluated immediately and its DOM stored in the signal
- **`"/posts/:id": ({ id }) => ...`**: Dynamic parameter extracted from the URL, stored in `appStore.postId`
- **`scrollBehavior: 'top'`**: Scrolls to the top on every navigation
- **[`mount`](/reference/dom/mount)`(App, '#app')`**: Renders the App element into the DOM. Since `App` is a plain element (not a function), it's mounted directly


```tsx
import { theme } from "../theme.ts";

const tagList = style({
  display: "flex",
  gap: "0.4rem",
  flexWrap: "wrap",
```

## Interactive Components

These components handle user interaction through function-ref props, event handlers, and Signal props.

### SearchBar

A search input with two-way binding and keyboard handling.

Create `src/components/SearchBar.tsx`:

```tsx
// src/components/SearchBar.tsx
import { style } from "@hellajs/css";
import type { Signal } from "@hellajs/core";
import { theme } from "../theme.ts";

const searchBar = style({
  display: "flex",
  gap: "0.5rem",
  marginBottom: "1rem",
  "input": {
    flex: 1,
    padding: "0.5rem 0.75rem",
    borderRadius: theme.radius.sm,
    border: `1px solid ${theme.color.border}`,
    fontSize: "0.9rem",
  },
  "button": {
    cursor: "pointer",
    borderRadius: theme.radius.sm,
    border: `1px solid ${theme.color.border}`,
    backgroundColor: theme.color.surface,
    color: theme.color.text,
    padding: "0.5rem 1rem",
    fontSize: "0.9rem",
  },
}, { label: "search-bar" });

interface SearchBarProps {
  value: Signal<string>;
  onSearch: () => void;
}

export const SearchBar = ({ value, onSearch }: SearchBarProps) => {
  const handleKeyup = (e: KeyboardEvent) => {
    (e.key === "Enter" || value() === "") && onSearch();
  };

  return (
    <div class={searchBar}>
      <input
        type="text"
        placeholder={"Search..."}
        value={value}

        on:input={e => value((e.target as HTMLInputElement).value)}
        on:keyup={handleKeyup}
      />
      <button on:click={onSearch}>Search</button>
    </div>
  );
};
```

**Code Explanation**

- **`Signal<string>`**: The component accepts a signal directly as a prop, enabling two-way binding without callbacks
- **`value``={value}`**: Two-way binding between the input and the signal. The input value stays in sync with `searchValue`
- **`on:input={e => value(...)}`**: Delegated input event. Updates the signal on every keystroke
- **`on:keyup={handleKeyup}`**: Triggers search on Enter or when the input is cleared
- **Nested selectors**: `"input": { ... }` inside the `searchBar` object generates `.h-search-bar-… input { ... }` — descendants scope under the generated class

### PostCard

A reusable card component that composes Tags, Reactions, and user links. Accepts an optional click handler for navigation.

Create `src/components/PostCard.tsx`:

```tsx
// src/components/PostCard.tsx
import { style } from "@hellajs/css";
import { navigate } from "@hellajs/router";
import { card, cardTitle, cardBody, theme } from "../theme.ts";
import { Tags } from "./Tags.tsx";
import { Reactions } from "./Reactions.tsx";
import type { Post } from "../state.ts";

interface PostCardProps {
  post: Post;
  onClick?: () => void;
}

// Compose onto the shared card class — the returned class string carries both
// ("h-card-… h-post-card-…"), each side keeping its own rule.
const postCard = style(card, {
  "&:hover": {
    boxShadow: "0 4px 8px rgba(0, 0, 0, 0.1)",
  },
}, { label: "post-card" });

const userLink = style({
  color: theme.color.link,
  display: "inline-block",
  fontSize: "0.9rem",
  marginTop: "0.5rem",
  cursor: "pointer",
  textDecoration: "none",
  "&:hover": {
    textDecoration: "underline"
  },
}, { label: "user-link" });

const openUser = (id: number) => navigate(`/users/${id}`);

export const PostCard = ({ post, onClick }: PostCardProps) => (
  <div class={postCard} style={onClick ? "cursor: pointer;" : ""}>
    <div on:click={onClick}>
      <h3 class={cardTitle}>{post.title}</h3>
      <p class={cardBody}>{post.body}</p>
      <Tags tags={post.tags} />
      <Reactions likes={post.reactions?.likes} views={post.views} />
    </div>
    <a class={userLink} on:click={e => { e.stopPropagation(); openUser(post.userId); }}>
      User {post.userId}
    </a>
  </div>
);
```

**Code Explanation**

- **`onClick?: () => void`**: Optional click handler. When provided, the card shows a pointer cursor and is clickable
- **[`style`](/reference/css/style)`(card, { ... }, { label: "post-card" })`**: Composes onto the shared card class — the returned string carries both (`"h-card-… h-post-card-…"`), each side keeping its own rule
- **[`navigate`](/reference/router/navigate)**: String interpolation builds URLs like `` `/users/${id}` `` directly. No param substitution needed
- **`e.stopPropagation()`**: Prevents the user link click from bubbling up to the card's click handler
- **`import type { Post }`**: Type-only import keeps the interface out of the runtime bundle
- **`&:hover`**: The `&` refers to the parent selector. `.h-post-card-…:hover { ... }` adds a subtle shadow on hover

### Pagination

Page navigation controls with Signal props and reactive disabled state.

Create `src/components/Pagination.tsx`:

```tsx
// src/components/Pagination.tsx
import { style } from "@hellajs/css";
import type { Signal } from "@hellajs/core";
import { theme } from "../theme.ts";

const pagination = style({
  display: "flex",
  justifyContent: "center",
  alignItems: "center",
  gap: "0.5rem",
  marginTop: "1rem",
  "button": {
    cursor: "pointer",
  },
}, { label: "pagination" });

const pageInfo = style({
  fontSize: "0.85rem",
  color: theme.color.subtle,
  padding: "0 0.5rem",
}, { label: "page-info" });

interface PaginationProps {
  page: Signal<number>;
  totalPages: () => number;
  onPageChange: (page: number) => void;
}

export const Pagination = ({ page, totalPages, onPageChange }: PaginationProps) => (
  <div class={pagination}>
    <button
      on:click={() => onPageChange(Math.max(1, page() - 1))}
      disabled={() => page() <= 1}
    >
      Prev
    </button>
    <span class={pageInfo}>
      Page {page()} of {totalPages()}
    </span>
    <button
      on:click={() => onPageChange(Math.min(totalPages(), page() + 1))}
      disabled={() => page() >= totalPages()}
    >
      Next
    </button>
  </div>
);
```

**Code Explanation**

- **`Signal<number>` and `() => number`**: The `page` prop is a signal (read+write), while `totalPages` is a computed function (read-only). Both are reactive
- **`disabled``={() => page() <= 1}`**: Reactive disabled state. The button disables when on the first page
- **`onPageChange`**: Callback that handles the actual page change logic. The parent page component decides how to update the URL
- **`Math.max(1, page() - 1)`**: Clamps the page number so it never goes below 1

## Post List Page

The Post List page shows searchable, paginated posts. It uses [computed](/reference/core/computed) for derived pagination state and explicitly calls `fetch()` to load data.

Create `src/pages/PostList.tsx`:

```tsx
// src/pages/PostList.tsx
import { computed } from "@hellajs/core";
import { ForEach } from "@hellajs/dom";
import { navigate } from "@hellajs/router";
import { appStore, postsResource } from "../state.ts";
import { Placeholder } from "../components/Placeholder.tsx";
import { PostCard } from "../components/PostCard.tsx";
import { SearchBar } from "../components/SearchBar.tsx";
import { Pagination } from "../components/Pagination.tsx";

const { fetch, isFetching, data } = postsResource;
const { searchValue, page } = appStore;

const totalPages = computed(() => {
  const dataValue = data();
  return dataValue ? Math.ceil(dataValue.total / 10) : 0;
});

const goToPage = (p: number) => navigate("/posts", { query: { page: String(p) } });

export const PostList = () => {
  fetch();

  return <>
    <SearchBar
      value={searchValue}
      onSearch={fetch}
    />

    {() => {
      const posts = data()?.posts ?? [];

      return isFetching() ?
        <Placeholder message="Loading posts..." /> :
        posts.length > 0 ?
          <ForEach each={posts} use={(post) =>
            <PostCard post={post} onClick={() => navigate(`/posts/${post.id}`)} />
          } /> :
          <Placeholder message={`No posts found "${searchValue()}".`} />;
    }}

    {totalPages() > 1 &&
      <Pagination page={page} totalPages={totalPages} onPageChange={goToPage} />
    }
  </>;
};
```

**Code Explanation**

- **`const { fetch, isFetching, data } = postsResource`**: Destructures resource methods for cleaner usage. `fetch()` triggers the API call, `isFetching()` returns the loading state, `data()` returns the cached response
- **[`computed`](/reference/core/computed)`(() => ...)`**: Derives total pages from resource data. Cached until `data()` changes
- **`fetch()`**: Called at the top of the component. Triggers a data load if the key is new or data is stale. Returns instantly if cached and fresh
- **[`navigate`](/reference/router/navigate)`("/posts", { query: { page: ... } })`**: Navigates with a query string, producing URLs like `/posts?page=2`. The route handler reads `query.page` to set the store
- **`<SearchBar>` outside the reactive block**: Static elements placed outside `{() => {}}` never re-render. The search bar doesn't depend on fetched data, so it stays mounted across fetches
- **`{() => { ... } }`**: Function expression makes the block reactive. When `data()` changes, the posts list re-renders
- **`isFetching() ? ... : ... ? ... : ...`**: Single ternary returning directly handles three states: loading, has results, no results. No wrapping `<div>` needed
- **`searchValue` as a Signal prop**: Passed directly to SearchBar, which uses it for `value` two-way binding
- **`<Pagination>` in its own reactive block**: Separated into its own reactive expression so pagination controls stay mounted while posts update independently

## Post Detail Page

The Post Detail page shows a single post. It demonstrates explicit resource fetching and conditional rendering based on loading and data state.

Create `src/pages/PostDetail.tsx`:

```tsx
// src/pages/PostDetail.tsx
import { postResource } from "../state.ts";
import { Placeholder } from "../components/Placeholder.tsx";
import { PostCard } from "../components/PostCard.tsx";
import { BackLink } from "../components/BackLink.tsx";

const { fetch, isFetching, data } = postResource;

export const PostDetail = () => {
  fetch();

  return <>
    <BackLink />

    {() => {
      const post = data();

      return <div class="post-detail">
        {isFetching() ?
          <Placeholder message="Loading post..." /> :
          post?.body ?
            <PostCard post={post!} /> :
            <Placeholder message="Post not found" />
        }
      </div>;
    }}
  </>;
};
```

**Code Explanation**

- **`<BackLink>` outside the reactive block**: Static navigation stays mounted across fetches. Only the content inside `{() => {}}` re-renders when data changes
- **`fetch()`**: Called with the current `key` derived from `appStore.postId()`. Uses cached data if fresh, fetches if stale or new
- **`post?.body`**: Checks if the post has content. The DummyJSON API returns `{ message: "..." }` for invalid IDs instead of a 404
- **`post!`**: Non-null assertion since the `post?.body` check already confirmed the post exists
- **`<PostCard post={post!} />`**: Reuses the PostCard component without an `onClick` prop, so it renders as a static card
- **No component-specific styles**: This page relies entirely on shared global styles and child component styles

```tsx
export const UserProfile = () => {

            </div>
          </div>
        </div>
      </div>;
    }}

      const posts = postsData()?.posts ?? [];
```

**Code Explanation**

- **`fetchUser()` and `fetchPosts()`**: Two independent resources keyed by `appStore.userId()`. Both fetch in parallel when the component renders
- **`<div class="user-profile">` as root**: A semantic wrapper class (no generated rule — the avatar/user-info/user-meta classes carry the styles). Static elements (`BackLink`, heading) sit outside reactive blocks
- **`const { firstName, ... } = user || {}`**: Destructures with a fallback. The fields are undefined while loading, and the JSX handles that gracefully
- **`user?.id`**: Checks if the user data is valid. The DummyJSON API returns `{ message: "..." }` for invalid IDs
- **Separate reactive blocks for user and posts**: Each `{() => {}}` handles one concern independently. User info re-renders without touching the posts list and vice versa
- **`"& p": { margin: "0.15rem 0" }`**: The `&` refers to the parent selector, producing `.h-user-meta-… p { ... }`
- **`isFetchingPosts()` checked first**: Returns a loading placeholder while fetching. Only shows posts or "not found" when loading is done
- **`class={card}`**: The profile header reuses the shared card class imported from `theme.ts`; `avatar`, `userInfo`, and `userMeta` are their own hashed classes, so the styles are scoped to the user profile page

```tsx
import { store } from "@hellajs/store";
import { resource } from "@hellajs/resource";

export interface Post {
  id: number;
  title: string;
  body: string;
  tags: string[];
  reactions: { likes: number; dislikes: number };
  views: number;
  userId: number;
  message?: string;
}

interface PostsResponse {
  posts: Post[];
  total: number;
  skip: number;
  limit: number;
}

interface User {
  id: number;
  firstName: string;
  lastName: string;
  email: string;
  image: string;
  company: { title: string; name: string; department: string };
  message?: string;
}

export const appStore = store({
  searchValue: "",
  page: 1,
  postId: "",
  userId: "",
});

const BASE = "https://dummyjson.com";

const cacheTime = 300000; // 5 minutes

export const postsResource = resource<PostsResponse, string>(
  (urlPath) => fetch(`${BASE}/${urlPath}`).then(r => r.json()),
  {
    key: () => {
      const search = appStore.searchValue();
      const skip = (appStore.page() - 1) * 10;
      const base = search ? "posts/search" : "posts";
      const params = new URLSearchParams({ limit: "10", skip: String(skip) });
      if (search) params.set("q", search);
      return `${base}?${params}`;
    },
    staleTime: 30000,
    cacheTime,
  }
);

export const postResource = resource<Post, string>(
  (id) => fetch(`${BASE}/posts/${id}`).then(r => r.json()),
  { key: () => appStore.postId(), cacheTime, }
);

export const userResource = resource<User, string>(
  (id) => fetch(`${BASE}/users/${id}`).then(r => r.json()),
  { key: () => appStore.userId(), cacheTime, }
);

export const userPostsResource = resource<PostsResponse, string>(
  (id) => fetch(`${BASE}/users/${id}/posts`).then(r => r.json()),
  { key: () => appStore.userId(), cacheTime, }
);
```

```tsx
import { computed } from "@hellajs/core";
import { ForEach } from "@hellajs/dom";
import { navigate } from "@hellajs/router";
import { appStore, postsResource } from "../state.ts";
import { Placeholder } from "../components/Placeholder.tsx";
import { PostCard } from "../components/PostCard.tsx";
import { SearchBar } from "../components/SearchBar.tsx";
import { Pagination } from "../components/Pagination.tsx";

const { fetch, isFetching, data } = postsResource;
const { searchValue, page } = appStore;

const totalPages = computed(() => {
  const dataValue = data();
  return dataValue ? Math.ceil(dataValue.total / 10) : 0;
});

const goToPage = (p: number) => navigate("/posts", { query: { page: String(p) } });

export const PostList = () => {
  fetch();

  return <>
    <SearchBar
      value={searchValue}
      onSearch={fetch}
    />

    {() => {
      const posts = data()?.posts ?? [];

      return isFetching() ?
        <Placeholder message="Loading posts..." /> :
        posts.length > 0 ?
          <ForEach each={posts} use={(post) =>
            <PostCard post={post} onClick={() => navigate(`/posts/${post.id}`)} />
          } /> :
          <Placeholder message={`No posts found "${searchValue()}".`} />;
    }}

    {totalPages() > 1 &&
      <Pagination page={page} totalPages={totalPages} onPageChange={goToPage} />
    }
  </>;
};
```
