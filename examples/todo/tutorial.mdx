## App State

Every todo app starts with defining what a "todo" looks like and setting up [reactive state](/reference/core/signal).

Replace the content of `main.tsx` with the component shell.

```tsx
// main.tsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

interface Todo {
  id: number;
  text: string;
  completed: boolean;
}

const TodoApp = () => {
  const todos = signal<Todo[]>([
    { id: 1, text: "Learn HellaJS", completed: false },
    { id: 2, text: "Build a todo app", completed: false },
  ]);

  const newTodoText = signal("");

  // placeholder until the full view lands in a later section
  return <h1>Todo App</h1>;
};

mount(TodoApp, "#app");
```

**Code Explanation**

- **`interface Todo`**:  Defines the shape of each todo item
- **[`signal`](/reference/core/signal)`<Todo[]>([...])`**:  Creates reactive state for the todo list with initial data
- **`signal("")`**:  Creates reactive state for the new todo input field
- **[`mount`](/reference/dom/mount)`(TodoApp, "#app")`**:  Renders the component into the DOM

```tsx
  textDecoration: "line-through",
  color: "#999",
});

//... rest of the code unchanged
```

**Code Explanation**
- **`css({ body: { ... } })`**:  Registers global element selectors
- **`style()`**:  Scopes the styles under a generated class and returns it for `class={app}`
- **`alignItems: "center"`**:  Vertically centers the children of every `row` flex container
- **`class={[flex, todo.completed && done]}`**:  Combines class names in an array: `done` applies only when the todo is completed

## Todo Actions

Now let's add the functions that modify our state. All state updates create new arrays to trigger reactivity, and each user action wraps its writes in [`batch`](/reference/core/batch) so every effect observes the action once.

```tsx
//... add batch to the core import
import { batch, signal } from "@hellajs/core";

const TodoApp = () => {
  //after this signal
  const newTodoText = /**/

  const addTodo = () => {
    const text = newTodoText().trim();
    if (!text) return;

    // one flush: the list and the cleared input land together
    batch(() => {
      todos([...todos(), { id: Date.now(), text, completed: false }]);
      newTodoText("");
    });
  };

  const toggleTodo = (id: number) => {
    todos(todos().map((todo) => (todo.id === id ? { ...todo, completed: !todo.completed } : todo)));
  };

  const removeTodo = (id: number) => {
    todos(todos().filter((todo) => todo.id !== id));
  };
  
  //...
}
```

**Code Explanation**

- **`todos([...todos(), newTodo])`**:  Creates a new array with spread to trigger reactive updates
- **`Date.now()`**:  Generates unique IDs for new todos
- **[`batch`](/reference/core/batch)`(() => { ... })`**:  Groups the two writes (list update + input clear) into one flush: effects run once, not once per write
- **`todos().map(...)`**:  Creates a new array with the toggled todo
- **`todos().filter(...)`**:  Creates a new array without the removed todo

<Callout variant="error">Always create new arrays when updating signals. Mutating existing arrays won't trigger updates.</Callout>

**Good:** Creates a new array
```jsx
todos([...todos(), newTodo]);
```

**Bad:** Mutates an existing array
```jsx
todos().push(newTodo); // Won't trigger updates
```

## The View

Now let's add the JSX that renders our todo list. Add the `return` statement inside `TodoApp`.

```tsx
//... add ForEach to the dom import
import { mount, ForEach } from "@hellajs/dom";

const TodoApp = () => {
  //...
  // after the actions
  const removeTodo = (id: number) => {
    //...
  };

  return (
    <div class={app}>
      <h1>Todo App</h1>

      <div class={row}>
        <input
          type="text"
          value={newTodoText}
          on:input={(e) => newTodoText((e.target as HTMLInputElement).value)}
          placeholder="What needs to be done?"
          class={flex}
        />
        <button on:click={addTodo}>Add</button>
      </div>

      <ul class={list}>
        <ForEach each={todos} use={(todo) => (
          <li class={row} key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              on:change={() => toggleTodo(todo.id)}
            />
            <span class={[flex, todo.completed && done]}>
              {todo.text}
            </span>
            <button on:click={() => removeTodo(todo.id)}>Delete</button>
          </li>
        )} />
      </ul>

      {todos().length === 0 && (
        <div>No todos yet! Add one above.</div>
      )}
    </div>
  );
};
```

Start the development server to see your app in action.

```bash
npm run dev
```

Your app will be running at `http://localhost:5173`. Add some todos and watch them update automatically!

**Code Explanation**

- **`value={newTodoText}`**:  Two-way binding for the input field
- **[`<ForEach>`](/reference/dom/foreach) `each={todos} use={(todo) => ...}`**:  Renders the list with optimized diffing
- **`class={row}` on `<li>`**:  Reuses the flex row style so each todo item lays out like the form rows
- **`class={['flex', todo.completed && 'done']}`**:  Conditionally adds the `done` class when completed
- **`{todos().length === 0 && (...)}`**:  Conditional empty state

<Callout variant="error">Always use `<ForEach>` for signal lists or they won't be reactive.</Callout>

**Good:** Reactive lists
```jsx
<ForEach each={todos} use={(todo) => (
  <li key={todo.id}>
    {todo.text}
  </li>
)} />
```

**Bad:** Only rendered once
```jsx
todos().map(todo => (
  <li key={todo.id}>
    {todo.text}
  </li>
));
```

## Filtering and Statistics

Let's add filtering and live statistics using [computed](/reference/core/computed) values. We need a filter signal, two computed values, filter buttons in the JSX, and updated list/empty-state rendering.

```tsx
//... import computed at the top
import { batch, signal, computed } from "@hellajs/core";

//... CSS code

// add this type definition for filter state
type FilterType = "all" | "active" | "completed";

const TodoApp = () => {
  // after this signal
  const newTodoText = /**/
  // add this signal
  const filter = signal<FilterType>("all");

  // add these actions
  const filteredTodos = computed(() => {
    const allTodos = todos();
    switch (filter()) {
      case "active": return allTodos.filter((t) => !t.completed);
      case "completed": return allTodos.filter((t) => t.completed);
      default: return allTodos;
    }
  });

  const stats = computed(() => {
    const allTodos = todos();
    return {
      total: allTodos.length,
      active: allTodos.filter((t) => !t.completed).length,
      completed: allTodos.filter((t) => t.completed).length
    };
  });

  //...
}
```

Add filter buttons between the input and the list:

```tsx
//... 
<div class={row}>
  <input
    /**/
  />
</div>
{/* add the filter buttons: */}
<div class={row}>
  <button on:click={() => filter("all")}>
    All ({stats().total})
  </button>
  <button on:click={() => filter("active")}>
    Active ({stats().active})
  </button>
  <button on:click={() => filter("completed")}>
    Done ({stats().completed})
  </button>
</div>

<ul class={list}>
  <ForEach
    /**/
   />
</ul>
```

Update `<ForEach>` to use `filteredTodos` instead of `todos`, and update the empty state:

```tsx
<ul class={list}>
  {/* only the source changes: todos -> filteredTodos */}
  <ForEach each={filteredTodos} use={(todo) => (
    <li class={row} key={todo.id}>
      {/* ... same item markup as before ... */}
    </li>
  )} />
</ul>

{filteredTodos().length === 0 && (
  <div>
    {filter() === "all" && "No todos yet! Add one above."}
    {filter() === "active" && "No active todos. Great job!"}
    {filter() === "completed" && "No completed todos yet."}
  </div>
)}
```

**Code Explanation**

- **`computed(() => { ... })`**:  Creates filtered view that updates when `todos` or `filter` changes
- **`stats` computed**:  Calculates live statistics (total, active, completed counts)
- **Multiple dependencies**:  Computed values automatically track both `todos()` and `filter()` signals
- **Dynamic counts**:  `{stats().total}` shows live counts in button text
- **Contextual empty states**:  Different messages based on current filter state

[Computed](/reference/core/computed) values are automatically cached and only recalculate when their dependencies actually change.

**Efficient:** `const filtered = computed(() => todos().filter(...))`

**Inefficient:** `const filtered = () => todos().filter(...)` (recalculates every time)

## State Persistence

Now let's make the app production-ready by adding data persistence and user experience enhancements. This showcases how effects handle side actions elegantly.

Update the import to include `effect`:

```tsx
//... import effects at the top
import { batch, signal, computed, effect } from "@hellajs/core";
```

Add a `loadTodos` function outside the component:

```tsx
//... Add before TodoApp

const loadTodos = (): Todo[] => {
  try {
    const saved = localStorage.getItem("hellajs-todos");
    return saved ? JSON.parse(saved) : [
      { id: 1, text: "Learn HellaJS", completed: false },
      { id: 2, text: "Build a todo app", completed: false },
    ];
  } catch {
    return [];
  }
};

const TodoApp = () => {
  //...
}
```

Use `loadTodos()` as the initial value and add effects at the top of the component:

```tsx
//... previous code unchanged, updating

const TodoApp = () => {
  const todos = signal<Todo[]>(loadTodos());
  //... other signals unchanged

  // Persist todos to localStorage
  effect(() => {
    localStorage.setItem("hellajs-todos", JSON.stringify(todos()));
  });

  // Update document title
  effect(() => {
    const activeCount = todos().filter((t) => !t.completed).length;
    document.title = activeCount === 0
      ? "Todo App"
      : `Todo App (${activeCount} active)`;
  });

  //... computed values and functions unchanged
};
```

Add a `clearCompleted` function and a "Clear Done" button:

```tsx
const clearCompleted = () => {
  todos(todos().filter((todo) => !todo.completed));
};
```

Update the return to show stats in the header and add the clear button:

```tsx
const TodoApp = () => {
  //... signals, effects, and actions unchanged

  return (
    <div class={app}>
      <h1>Todo App</h1>
      <div>{stats().active} active, {stats().completed} done</div>

      {/* ... input div unchanged */}

      <div class={row}>
        {/* ... filter buttons unchanged */}
        {stats().completed > 0 && (
          <button on:click={clearCompleted}>Clear Done</button>
        )}
      </div>

      {/* ... list and empty state unchanged */}
    </div>
  );
};
```

**Code Explanation**

- **`loadTodos()` function**:  Loads persisted todos from localStorage with error handling
- **Persistence effect**:  `effect(() => { localStorage.setItem(...) })` saves todos automatically
- **Title effect**:  `effect(() => { document.title = ... })` updates browser tab title
- **Progressive disclosure**:  `{stats().completed > 0 && (...)}` shows "Clear Done" conditionally
- **Error handling**:  Try/catch blocks prevent localStorage errors from breaking the app
- **Enhanced UX**:  Live statistics in header, bulk operations, and visual feedback

## Complete Code

```tsx
import { batch, signal, computed, effect } from "@hellajs/core";
import { mount, ForEach } from "@hellajs/dom";
import { css, style } from "@hellajs/css";

css({
  body: {
    margin: 0,
    fontFamily: "sans-serif",
  },
});

const app = style({
  maxWidth: "30rem",
  margin: "0 auto",
});

const row = style({
  display: "flex",
  gap: "0.5rem",
  alignItems: "center",
});

const list = style({
  listStyle: "none",
  padding: 0,
});

const flex = style({
  flex: "1",
});

const done = style({
  textDecoration: "line-through",
  color: "#999",
});

type FilterType = "all" | "active" | "completed";

interface Todo {
  id: number;
  text: string;
  completed: boolean;
}

const loadTodos = (): Todo[] => {
  try {
    const saved = localStorage.getItem("hellajs-todos");
    return saved
      ? JSON.parse(saved)
      : [
          { id: 1, text: "Learn HellaJS", completed: false },
          { id: 2, text: "Build a todo app", completed: false },
        ];
  } catch {
    return [];
  }
};

const TodoApp = () => {
  const todos = signal<Todo[]>(loadTodos());
  const newTodoText = signal("");
  const filter = signal<FilterType>("all");

  effect(() => {
    localStorage.setItem("hellajs-todos", JSON.stringify(todos()));
  });

  effect(() => {
    const activeCount = todos().filter((t) => !t.completed).length;
    document.title = activeCount === 0 ? "Todo App" : `Todo App (${activeCount} active)`;
  });

  const filteredTodos = computed(() => {
    const allTodos = todos();
    switch (filter()) {
      case "active":
        return allTodos.filter((t) => !t.completed);
      case "completed":
        return allTodos.filter((t) => t.completed);
      default:
        return allTodos;
    }
  });

  const stats = computed(() => {
    const allTodos = todos();
    return {
      total: allTodos.length,
      active: allTodos.filter((t) => !t.completed).length,
      completed: allTodos.filter((t) => t.completed).length,
    };
  });

  const addTodo = () => {
    const text = newTodoText().trim();
    if (!text) return;
    // One flush: the list, the footer stats, and the persistence effect each
    // observe the added todo once, not twice (todos write + input clear).
    batch(() => {
      todos([...todos(), { id: Date.now(), text, completed: false }]);
      newTodoText("");
    });
  };

  const toggleTodo = (id: number) => {
    todos(todos().map((todo) => (todo.id === id ? { ...todo, completed: !todo.completed } : todo)));
  };

  const removeTodo = (id: number) => {
    todos(todos().filter((todo) => todo.id !== id));
  };

  const clearCompleted = () => {
    todos(todos().filter((todo) => !todo.completed));
  };

  return (
    <div class={app}>
      <h1>Todo App</h1>
      <div>
        {stats().active} active, {stats().completed} done
      </div>

      <div class={row}>
        <input
          type="text"
          value={newTodoText}
          on:input={(e) => newTodoText((e.target as HTMLInputElement).value)}
          placeholder="What needs to be done?"
          class={flex}
        />
        <button on:click={addTodo}>Add</button>
      </div>

      <div class={row}>
        <button on:click={() => filter("all")}>All ({stats().total})</button>
        <button on:click={() => filter("active")}>Active ({stats().active})</button>
        <button on:click={() => filter("completed")}>Done ({stats().completed})</button>
        {stats().completed > 0 && <button on:click={clearCompleted}>Clear Done</button>}
      </div>

      <ul class={list}>
        <ForEach
          each={filteredTodos}
          use={(todo) => (
            <li class={row} key={todo.id}>
              <input
                type="checkbox"
                checked={todo.completed}
                on:change={() => toggleTodo(todo.id)}
              />
              <span class={[flex, todo.completed && done]}>{todo.text}</span>
              <button on:click={() => removeTodo(todo.id)}>Delete</button>
            </li>
          )}
        />
      </ul>

      {filteredTodos().length === 0 && (
        <div>
          {filter() === "all" && "No todos yet! Add one above."}
          {filter() === "active" && "No active todos. Great job!"}
          {filter() === "completed" && "No completed todos yet."}
        </div>
      )}
    </div>
  );
};

mount(TodoApp, "#app");
```
