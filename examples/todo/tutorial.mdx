## App State

Every todo app starts with defining what a "todo" looks like and setting up [reactive state](/reference/core/signal).

Replace the content of `main.tsx` with the component shell.

```tsx
// main.tsx
import { signal } from "@hellajs/core";
import { mount, ForEach } from "@hellajs/dom";

interface Todo {
  id: number;
  text: string;
  completed: boolean;
}

const TodoApp = () => {
  const todos = signal<Todo[]>([
    { id: 1, text: 'Learn HellaJS', completed: false },
    { id: 2, text: 'Build a todo app', completed: false }
  ]);

  const newTodoText = signal('');
};

mount(TodoApp, '#app');
```

**Code Explanation**

- **`interface Todo`**:  Defines the shape of each todo item
- **[`signal`](/reference/core/signal)`<Todo[]>([...])`**:  Creates reactive state for the todo list with initial data
- **`signal('')`**:  Creates reactive state for the new todo input field
- **[`mount`](/reference/dom/mount)`(TodoApp, '#app')`**:  Renders the component into the DOM

## Todo Actions

Now let's add the functions that modify our state. All state updates create new arrays to trigger reactivity.

```tsx
const TodoApp = () => {
  //after this signal
  const newTodoText = /**/

  const addTodo = () => {
    const text = newTodoText().trim();
    if (!text) return;

    todos([
      ...todos(),
      { id: Date.now(), text, completed: false }
    ]);
    newTodoText('');
  };

  const toggleTodo = (id: number) => {
    todos(todos().map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ));
  };

  const removeTodo = (id: number) => {
    todos(todos().filter(todo => todo.id !== id));
  };
  
  //...
}
```

**Code Explanation**

- **`todos([...todos(), newTodo])`**:  Creates a new array with spread to trigger reactive updates
- **`Date.now()`**:  Generates unique IDs for new todos
- **`todos().map(...)`**:  Creates a new array with the toggled todo
- **`todos().filter(...)`**:  Creates a new array without the removed todo

<div role="alert" class="alert alert-error text-base">
  <span>⚠️</span>
  <span>Always create new arrays when updating signals. Mutating existing arrays won't trigger updates.</span>
</div>

**Good:** Creates a new array
```jsx
todos([...todos(), newTodo]);
```

**Bad:** Mutates an existing array
```jsx
todos().push(newTodo); // Won't trigger updates
```

## The View

Now let's add the JSX that renders our todo list. Add the `return` statement inside `TodoApp`.

```tsx
const TodoApp = () => {
  //...
  // after the actions
  const removeTodo = (id: number) => {
    //...
  };

  return (
    <div class={app}>
      <h1>Todo App</h1>

      <div class={row}>
        <input
          type="text"
          value={newTodoText}
          on:input={e => newTodoText((e.target as HTMLInputElement).value)}
          on:keydown={e => e.key === 'Enter' && addTodo()}
          placeholder="What needs to be done?"
          class={flex}
        />
        <button on:click={addTodo}>Add</button>
      </div>

      <ul class={list}>
        <ForEach each={todos} use={(todo) => (
          <li key={todo.id}>
            <input
              type="checkbox"
              checked={todo.completed}
              on:change={() => toggleTodo(todo.id)}
            />
            <span class={[flex, todo.completed && done]}>
              {todo.text}
            </span>
            <button on:click={() => removeTodo(todo.id)}>Delete</button>
          </li>
        )} />
      </ul>

      {todos().length === 0 && (
        <div>No todos yet! Add one above.</div>
      )}
    </div>
  );
}
```

Start the development server to see your app in action.

```bash
npm run dev
```

Your app will be running at `http://localhost:5173`. Add some todos and watch them update automatically!

**Code Explanation**

- **`value={newTodoText}`**:  Two-way binding for the input field
- **`on:keydown={e => e.key === 'Enter' && addTodo()}`**:  Submits on Enter key
- **[`<ForEach>`](/reference/dom/foreach) `each={todos} use={(todo) => ...}`**:  Renders the list with optimized diffing
- **`class={['flex', todo.completed && 'done']}`**:  Conditionally adds the `done` class when completed
- **`{todos().length === 0 && (...)}`**:  Conditional empty state

<div role="alert" class="alert alert-error text-base">
  <span>⚠️</span>
  <span>Always use `<ForEach>` for signal lists or they won't be reactive.</span>
</div>

**Good:** Reactive lists
```jsx
<ForEach each={todos} use={(todo) => (
  <li key={todo.id}>
    {todo.text}
  </li>
)} />
```

**Bad:** Only rendered once
```jsx
todos().map(todo => (
  <li key={todo.id}>
    {todo.text}
  </li>
));
```

## Filtering and Statistics

Let's add filtering and live statistics using [computed](/reference/core/computed) values. We need a filter signal, two computed values, filter buttons in the JSX, and updated list/empty-state rendering.

```tsx
//... import computed at the top
import { signal, computed } from "@hellajs/core";

//... CSS code

interface Todo {
  //...
}

// add this type definition for filter state
type FilterType = 'all' | 'active' | 'completed';

const TodoApp = () => {
  // after this signal
  const newTodoText = /**/
  // add this signal
  const filter = signal<FilterType>('all');

  // add these actions
  const filteredTodos = computed(() => {
    const allTodos = todos();
    switch (filter()) {
      case 'active': return allTodos.filter(t => !t.completed);
      case 'completed': return allTodos.filter(t => t.completed);
      default: return allTodos;
    }
  });

  const stats = computed(() => {
    const allTodos = todos();
    return {
      total: allTodos.length,
      active: allTodos.filter(t => !t.completed).length,
      completed: allTodos.filter(t => t.completed).length
    };
  });

  //...
}
```

Add filter buttons between the input and the list:

```tsx
//... 
<div class={row}>
  <input
    /**/
  />
</div>
{/* add the filter buttons: */}
<div class={row}>
  <button on:click={() => filter('all')}>
    All ({stats().total})
  </button>
  <button on:click={() => filter('active')}>
    Active ({stats().active})
  </button>
  <button on:click={() => filter('completed')}>
    Done ({stats().completed})
  </button>
</div>

<ul class={list}>
  <ForEach
    /**/
   />
</ul>
```

Update `<ForEach>` to use `filteredTodos` instead of `todos`, and update the empty state:

```tsx
<ul class={list}>
  <ForEach each={filteredTodos} use={(todo) => (
    //...
  )} />
</ul>

{filteredTodos().length === 0 && (
  <div>
    {filter() === 'all' && "No todos yet! Add one above."}
    {filter() === 'active' && "No active todos. Great job!"}
    {filter() === 'completed' && "No completed todos yet."}
  </div>
)}
```

**Code Explanation**

- **`computed(() => { ... })`**:  Creates filtered view that updates when `todos` or `filter` changes
- **`stats` computed**:  Calculates live statistics (total, active, completed counts)
- **Multiple dependencies**:  Computed values automatically track both `todos()` and `filter()` signals
- **Dynamic counts**:  `{stats().total}` shows live counts in button text
- **Contextual empty states**:  Different messages based on current filter state

[Computed](/reference/core/computed) values are automatically cached and only recalculate when their dependencies actually change.

**Efficient:** `const filtered = computed(() => todos().filter(...))`

**Inefficient:** `const filtered = () => todos().filter(...)` (recalculates every time)

## Interactive Editing

Now let's add inline editing. This introduces editing state management and shows how multiple signals work together.

Add two new signals for tracking edit state:

```tsx
const TodoApp = () => {
  // after this signal
  const filter = /**/
  // add these signals
  const editingId = signal<number | null>(null);
  const editText = signal('');
}
```

Add the editing functions:

```tsx
const TodoApp = () => {
  // after the existing actions
  const removeTodo = (id: number) => {
    //...
  };

  const startEditing = (id: number, currentText: string) => {
    editingId(id);
    editText(currentText);
  };

  const saveEdit = () => {
    const id: number = editingId()!;
    const newText = editText().trim();
    if (!newText) {
      removeTodo(id);
    } else {
      todos(todos().map(todo =>
        todo.id === id ? { ...todo, text: newText } : todo
      ));
    }
    editingId(null);
    editText('');
  };

  const cancelEdit = () => {
    editingId(null);
    editText('');
  };

  const handleEditKeydown = (e: KeyboardEvent) => {
    if (e.key === 'Enter') saveEdit();
    if (e.key === 'Escape') cancelEdit();
  };

  //...
}
```

Update the list item JSX inside `<ForEach>` to support edit mode:

```tsx
<ForEach each={filteredTodos} use={(todo) => (
  <li key={todo.id}>
    <input
      type="checkbox"
      checked={todo.completed}
      on:change={() => toggleTodo(todo.id)}
    />
    {editingId() === todo.id ? (
      <input
        type="text"
        value={editText}
        on:input={e => editText((e.target as HTMLInputElement).value)}
        on:keydown={handleEditKeydown}
        on:blur={saveEdit}
        class={flex}
        autofocus
      />
    ) : (
      <span
        class={[flex, todo.completed && done]}
        on:dblclick={() => startEditing(todo.id, todo.text)}
        title="Double-click to edit"
      >
        {todo.text}
      </span>
    )}
    {editingId() === todo.id ? (
      <>
        <button on:click={saveEdit}>✓</button>
        <button on:click={cancelEdit}>✕</button>
      </>
    ) : (
      <button on:click={() => removeTodo(todo.id)}>Delete</button>
    )}
  </li>
)} />
```

**Code Explanation**

- **`editingId` signal**:  Tracks which todo is currently being edited (null when none)
- **`editText` signal**:  Stores the temporary text while editing
- **Conditional rendering**:  `{editingId() === todo.id ? (...) : (...)}` switches between edit and display mode
- **Event coordination**:  `on:dblclick`, `on:keydown`, and `on:blur` work together for editing
- **State coordination**:  Multiple signals (`editingId`, `editText`, `todos`) work together seamlessly
- **Smart validation**:  Empty text triggers todo deletion instead of saving empty content

**Code Explanation**

- **`loadTodos()` function**:  Loads persisted todos from localStorage with error handling
- **Persistence effect**:  `effect(() => { localStorage.setItem(...) })` saves todos automatically
- **Title effect**:  `effect(() => { document.title = ... })` updates browser tab title
- **Progressive disclosure**:  `{stats().completed > 0 && (...)}` shows "Clear Done" conditionally
- **Error handling**:  Try/catch blocks prevent localStorage errors from breaking the app
- **Enhanced UX**:  Live statistics in header, bulk operations, and visual feedback
