# Build a Theme Switcher

Let's build a theme switcher using reactive CSS variables that update when state changes.

Jump to the [Complete Code](#complete-code) for the finished application.

## What You'll Learn

- **[Signals](/reference/core/signal)**:  Reactive state for the theme mode
- **[CSS Variables](/reference/css/vars)**:  Reactive bridge between state and styles
- **[Global CSS](/reference/css/css)**:  Element styles that consume reactive variables

We'll start simple and add complexity step by step, so you see how each concept builds on the previous ones.

## Project Setup

### Installation

Use your favorite package manager to scaffold a new Vite project.

```bash
npm create vite@latest theme-app -- --template vanilla-ts
```

Navigate into your new project directory and install the HellaJS packages and the Vite plugin.

```bash
cd theme-app
npm install @hellajs/core @hellajs/dom @hellajs/css
npm install -D vite-plugin-hellajs
```

### Configuration

Update your `vite.config.js` to use the HellaJS plugin.

```js
// vite.config.js
import { defineConfig } from 'vite';
import viteHellaJS from 'vite-plugin-hellajs';

export default defineConfig({
  plugins: [viteHellaJS()],
});
```

Update your `tsconfig.json` to add HellaJS type definitions.

```json
{
  "compilerOptions": {
    //...
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
    //...
  }
}
```

Finally, give the app a mount point. Replace the contents of `index.html` with a root element and a module script pointing at the entry file (the template's default `main.ts` is replaced by `main.tsx` below).

```html
<!-- index.html -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Theme Switcher</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

## Theme State

Start by creating a [signal](/reference/core/signal) for the dark mode flag and rendering the app shell.

Replace the content of `main.tsx` with the component shell.

```tsx
// main.tsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const isDark = signal(false);

const ThemeSwitcher = () => (
  <>
    <h1>Theme Switcher</h1>
    <p>Toggle the button to switch themes.</p>
  </>
);

mount(ThemeSwitcher, "#app");
```

Start the development server to see your app in action.

```bash
npm run dev
```

Your app will be running at `http://localhost:5173`.

**Code Explanation**

- **[`signal`](/reference/core/signal)`(false)`**:  Creates reactive state for the dark mode flag, starting in light mode
- **`<>`**:  Fragment syntax: renders the children with no wrapper element
- **[`mount`](/reference/dom/mount)`(ThemeSwitcher, '#app')`**:  Renders the component into the DOM

## Reactive CSS Variables

Now let's connect our theme state to CSS. [`vars`](/reference/css/vars) creates reactive CSS custom properties that update when signals change.

Add the CSS import and define the theme variables:

```tsx
//... add after the core import
import { vars } from "@hellajs/css";

const colors = vars({
  dark: "#1a1a2e",
  light: "#fff",
});

const theme = vars({
  bg: () => (isDark() ? colors.dark : colors.light),
  text: () => (isDark() ? colors.light : colors.dark),
});
```

**Code Explanation**

- **[`vars`](/reference/css/vars)`({...})`**:  Creates reactive CSS custom properties; function leaves re-evaluate when the signals they read change
- **`colors.dark`, `colors.light`**:  Static palette leaves: fixed values, so no function is needed
- **`theme.bg`**:  A derived leaf that reads `isDark()` and picks from the palette, recalculating when the flag flips
- **Two `vars` calls**:  The palette holds raw values while `theme` holds the switching logic, so each concern stays separate

## Global Styles and Toggle

Define global styles with [`css`](/reference/css/css) and add the toggle button. The styles read the reactive variables, so flipping the flag restyles the whole page.

```tsx
//... update the css import
import { css, vars } from "@hellajs/css";

css({
  body: {
    textAlign: "center",
    backgroundColor: theme.bg,
    color: theme.text,
  },
  button: {
    backgroundColor: theme.text,
    color: theme.bg,
  },
});

const ThemeSwitcher = () => (
  <>
    <h1>Theme Switcher</h1>
    <button on:click={() => isDark(!isDark())}>{isDark() ? "☀️ Light" : "🌙 Dark"}</button>
    <p>Toggle the button to switch themes.</p>
  </>
);
```

**Code Explanation**

- **[`css`](/reference/css/css)`({...})`**:  Registers global styles for the `body` and `button` selectors, consuming the reactive variables
- **`backgroundColor: theme.bg`**:  Reads a derived variable, so the page background follows the flag
- **`isDark(!isDark())`**:  Reads the flag and writes the flipped value back to the signal
- **`{isDark() ? "☀️ Light" : "🌙 Dark"}`**:  Conditional button label that updates reactively

## Complete Code

```tsx
import { signal } from "@hellajs/core";
import { css, vars } from "@hellajs/css";
import { mount } from "@hellajs/dom";

const isDark = signal(false);

const colors = vars({
  dark: "#1a1a2e",
  light: "#fff",
});

const theme = vars({
  bg: () => (isDark() ? colors.dark : colors.light),
  text: () => (isDark() ? colors.light : colors.dark),

css({
  body: {
    textAlign: "center",
    backgroundColor: theme.bg,
    color: theme.text,
  },
  button: {
    backgroundColor: theme.text,
    color: theme.bg,
  },
});

const ThemeSwitcher = () => (
  <>
    <h1>Theme Switcher</h1>
    <button on:click={() => isDark(!isDark())}>{isDark() ? "☀️ Light" : "🌙 Dark"}</button>

```
