# Build a Counter App

Let's build an interactive counter app to learn the fundamentals of HellaJS step-by-step.

Jump to the [Complete Code](#complete-code) for the finished application.

## What You'll Learn

- **[Signals](/reference/core/signal)**:  How to create and use reactive state
- **[Computed](/reference/core/computed)**:  Deriving values from signals
- **[Global styles](/reference/css/css)**:  Styling the whole app with one call
- **[Event handling](/learn/concepts/attribute-prefixes)**:  Reactive state updates from user interactions
- **[Conditional rendering](/learn/concepts/control-flow)**:  Showing different UI based on state

We'll start simple and add complexity step by step, so you see how each concept builds on the previous ones.

## Project Setup

### Installation

Use your favorite package manager to scaffold a new Vite project.

```bash
npm create vite@latest counter-app -- --template vanilla
```

Navigate into your new project directory and install the HellaJS packages and the Vite plugin.

```bash
cd counter-app
npm install @hellajs/core @hellajs/dom @hellajs/css
npm install -D vite-plugin-hellajs
```

### Configuration

Update your `vite.config.js` to use the HellaJS plugin.

```js
// vite.config.js
import { defineConfig } from 'vite';
import viteHellaJS from 'vite-plugin-hellajs';

export default defineConfig({
  plugins: [viteHellaJS()],
});
```

If you're using TypeScript, add type definitions for HellaJS. Update your `tsconfig.json`.

```json
{
  "compilerOptions": {
    //...
    "jsx": "preserve",
    "types": ["@hellajs/dom"]
    //...
  }
}
```

Finally, give the app a mount point. Replace the contents of `index.html` with a root element and a module script pointing at the entry file (the template's default `main.js` is replaced by `main.jsx` below).

```html
<!-- index.html -->
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Counter App</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
```

## Reactive Component

[Components](/learn/concepts/components) are functions that return an element and [signals](/reference/core/signal) automatically update when their values change.

Replace the content of `main.jsx` with the component shell.

```jsx
// main.jsx
import { signal } from "@hellajs/core";
import { mount } from "@hellajs/dom";

const Counter = () => {
  const count = signal(0);

  const increment = () => count(count() + 1);

  return (
    <>
      <h1>Counter: {count}</h1>
      <div>
        <button on:click={increment}>+</button>
      </div>
    </>
  );
};

mount(Counter, "#app");
```

**Code Explanation**

- **`signal(0)`**:  Creates a reactive state with an initial value of 0
- **`{count}`**:  Creates a reactive binding that updates automatically
- **`increment`**:  A named handler that writes a new value to the signal on click
- **[`mount`](/reference/dom/mount)`(Counter, "#app")`**:  Renders the component into the DOM
- **`<>...</>`**:  A fragment groups sibling elements without adding an extra DOM node

Start the development server to see your app in action.

```bash
npm run dev
```

Your app will be running at `http://localhost:5173`. Click the button and watch the count update without any re-rendering code.

## Global Styles

Define global styles with [`css`](/reference/css/css). Each top-level key is a raw CSS selector and the rules are injected into the document once.

```jsx
//... add after the dom import
import { css } from "@hellajs/css";

css({
  body: {
    textAlign: "center",
  },
  button: {
    margin: "0.1rem",
  },
});
```

**Code Explanation**

- **[`css`](/reference/css/css)`({ ... })`**:  Writes global CSS rules from the object; every top-level key is a raw CSS selector
- **`body` / `button`**:  Tag selectors center the page and add breathing room between the buttons
- **Module level**:  The call sits outside the component, so it runs once at startup instead of on every render

For scoped, content-hashed styles, see [`style`](/reference/css/style).

## Derived State

What if you need a value that depends on the count? Like whether the decrement button should be disabled at zero? [`computed`](/reference/core/computed) creates a cached derived value that updates when its dependencies change.

Update the import to include `computed`:

```jsx
//... import computed at the top
import { signal, computed } from "@hellajs/core";
```

Add a computed value to the component:

```jsx
const Counter = () => {
  const count = signal(0);

  const increment = () => count(count() + 1);

  // add this computed value
  const isDisabled = computed(() => count() === 0);

  return (
    <>
      ...
    </>
  );
};
```

**Code Explanation**

- **[`computed`](/reference/core/computed)`(() => count() === 0)`**:  Creates a cached derived value that updates when `count` changes
- **`isDisabled`**:  Tracks whether the count is zero; the next section binds it to button `disabled` attributes

Regular functions work fine for derived state, but [`computed`](/reference/core/computed) caches the result and skips recomputation when the value has not changed.

**Cached:** `const isDisabled = computed(() => count() === 0)` (skips recomputation when `count` is unchanged)

**Uncached:** `const isDisabled = () => count() === 0` (re-executes on every call)

## Counter Controls

Let's finish the counter with decrement and reset buttons that disable themselves at zero.

Add two more handlers and update the return:

```jsx
const Counter = () => {
  const count = signal(0);

  const increment = () => count(count() + 1);
  const decrement = () => count(count() - 1);
  const reset = () => count(0);
  const isDisabled = computed(() => count() === 0);

  return (
    <>
      <h1>Counter: {count}</h1>
      <div>
        <button on:click={decrement} disabled={isDisabled}>
          -
        </button>

        <button on:click={increment}>+</button>

        <button on:click={reset} disabled={isDisabled}>
          Reset
        </button>
      </div>
    </>
  );
};
```

Try clicking the buttons: the count and both disabled states update reactively. When the count reaches zero, the - and Reset buttons switch themselves off.

**Code Explanation**

- **Event handlers**:  Named functions that write new values to the signal
- **`disabled={isDisabled}`**:  Binds the computed directly; no wrapper function, the attribute tracks the signal
- **`on:click={decrement}`**:  Zero-argument handlers bind by name
