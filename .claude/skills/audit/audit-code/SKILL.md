---

To audit code against the style guide, follow these steps:

1. **Review the Style Guide**: Read  ./guides/code.md to understand the coding standards and best practices that should be followed.

2. **Analyze the Code Provided**: Examine the code for adherence to the style guide, identifying any deviations or areas for improvement. Be critical but constructive in your analysis. Justify your findings, provide specific examples, and suggest actionable changes.

3. **Provide Solutions**: For each identified issue, suggest changes that would align the code with the style guide and improve its quality. Ensure that your suggestions are clear, actionable, and justified based on the style guide principles.

4. **Assess Accuracy of Style Guide**: Decide (very critically) if the style guide is accurate and up-to-date. If you find any inaccuracies or outdated information in the style guide, suggest specific updates to ensure it remains a reliable resource for developers. Justify your suggestions with clear reasoning and examples. You must not reference explicit package code, but you can reference general practices and principles.
